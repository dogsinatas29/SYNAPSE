# SYNAPSE Visualizer v0.3.22

![SYNAPSE Banner](https://img.shields.io/badge/SYNAPSE-v0.3.22-orange?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Stabilized-green?style=for-the-badge)

## 🚀 개요
SYNAPSE는 추상적인 코드 관계와 시각적 로직 사이의 간극을 메우기 위해 설계된 고성능 아키텍처 시각화 엔진입니다. v0.3.22 버전은 **완벽한 동기화(Parity)**와 **지능형 진단(Diagnostic Intelligence)**에 초점을 맞췄습니다.

## 🛡️ 안정화 주요 특징 (v0.3.22)
- **하이브리드 렌더링 동기화**: 2D 캔버스와 3D WebGL 가속 모드 간의 이질감 없는 시각적 전환.
- **결함 허용 ID 처리**: 정제되지 않은 프로젝트 데이터에서도 크래시를 방지하는 강력한 Stem 기반 매칭 시스템.
- **지능형 툴팁**: 실시간 연결 매핑, 아키텍처 아이콘, LOD 대응 렌더링이 적용된 고급 진단 오버레이.

## 🛠 핵심 개선 사항
### 1. 탁월한 렌더링 품질
- **8비트 RGBA 컬러**: WebGL에서 투명도가 포함된 핵스 코드를 완벽 지원.
- **강화된 셰이더 윤곽선**: 아키텍처 컴포넌트를 위한 고대비 테두리 구현.
- **통일된 기하학 구조**: 모든 렌더링 레이어에서 박스(Box) 구조로 표준화.

### 2. 지능형 진단 체계
- **시니어의 처방**: 100% 데이터 정확도를 위한 데바운스 텔레메트리 적용.
- **검증 동기화**: 에지 배치 검증 중 실시간 시각적 피드백 제공.
- **정체성 해소**: "Unknown" 노드 제거 – 풀네임 및 아이콘 바인딩 완료.

## 📦 설치 및 사용법
1. VS Code에서 프로젝트를 엽니다.
2. **SYNAPSE: Open Canvas**를 실행합니다.
3. **Accel: ON/OFF**를 토글하여 하이브리드/WebGL 성능을 조정합니다.
