🛠️ 2. 기술적 변경 사항 (Action Plan)

Orthogonal Routing: 그리드 선을 따라 90도로 꺾이는 직각 엣지 알고리즘 도입 검토.

SYNAPSE는 코딩 도구가 아니라, 전략적 통찰 도구로 정의하네.

영향도 분석: 특정 노드 수정 시 파급 효과를 그리드 위에서 시각화.

설계 감시: 아키텍처 규칙(Layered Constraint) 위반 시 즉각적인 레드아웃 경고.
