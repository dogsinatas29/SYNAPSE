## 🐛 Bug Fixes (3 Critical Issues)

### **문제 #1: Canvas Height = 0 (2D 모드 노드 미표시)**

**증상**:
- 2D 모드로 전환했을 때 캔버스가 검은색으로만 표시됨
- 노드와 엣지가 렌더링되지 않음
- 사용자 스크린샷: 노드 전혀 안보임, 엣지 하나만 간신히 출력

**근본 원인**:
```javascript
// 수정 전: WebGL 비활성화 후 canvas height = 0
const height = this.container.clientHeight;  // 0px (DOM reflow 전)
canvas.height = height;  // 🔴 0으로 설정됨
```

원인 체인:
```
WebGL 비활성화 (2D 모드)
  ↓
DOM 리플로우: WebGL 캔버스 제거
  ↓
부모 컨테이너 레이아웃 재계산
  ↓
clientHeight = 0 (DOM이 아직 안정화되지 않음)
  ↓
Canvas height = 0 → 렌더링 불가능
```

**해결책**:
```javascript
// ✅ 수정: 최소 높이 보증 + DOM reflow 강제
let height = this.container.clientHeight;
if (height === 0 || height < 100) {
    height = 400;  // 최소값 폴백
}

// DOM 리플로우 트리거 (50ms 딜레이)
setTimeout(() => this.resizeCanvas(true), 50);
```

**코드 변경 위치**:
- `ui/canvas-engine.js` line 1890-1900: resizeCanvas() 함수에 높이 검증 추가
- `ui/canvas-engine.js` line 1860-1870: toggleEditLogic()에 DOM reflow 트리거 추가
- `ui/canvas-engine.js` line 1750-1760: renderNodes2D()에 안전 검사 추가

**수정 전 로그**:
```
[SYNAPSE] Canvas stabilized (Async). Size: 1270x0
```

**수정 후 로그**:
```
[SYNAPSE] Canvas stabilized (Async). Size: 1270x800
```

### **문제 #2: 3D 모드 아이콘이 알파벳으로 표시됨**

**증상**:
```
예상: 📄 ⚡ 🧪 🧩 📁  (이모지 아이콘)
실제: D  B  F  Ω  I    (알파벳)
```

사용자 스크린샷: 엣지 아이콘이 'D', 'B', 'F' 등 문자로 표시됨

**근본 원인 (심층 분석)**:

WebGL의 TextAtlas가 "Inter" 폰트만 사용하는데, **Inter는 이모지를 지원하지 않습니다**.

```javascript
// 수정 전: Inter 폰트만 사용
ctx.font = '12px Inter, sans-serif';
ctx.fillText(ch, this.x + 1, this.y + 2);  // ❌ 이모지 글리프 없음 → 알파벳으로 폴백
```

**왜 2D 모드에서는 아이콘이 표시되었을까?**

| 환경 | 렌더링 방식 | 사용 폰트 | 이모지 지원 | 결과 |
|------|----------|---------|----------|------|
| Canvas 2D | ctx.fillText() (실시간) | **OS 기본 폰트 + 자동 폴백** | ✅ 자동 지원 | 📄 정상 표시 |
| WebGL | TextAtlas 사전 렌더링 | **"Inter" 고정** | ❌ 미지원 | D/F 알파벳 표시 |

**Canvas 2D 작동 메커니즘**:
```javascript
ctx.fillText(style.icon, x + 5, y + 5);  // ← 실시간 렌더링
// 브라우저가 "Inter"를 찾지 못하면
// → OS 기본 이모지 폰트로 자동 폴백
// → 이모지 정상 표시 ✅
```

**WebGL 고장 메커니즘 (수정 전)**:
```javascript
ctx.font = '12px Inter, sans-serif';  // 고정
ctx.fillText(ch, x, y);  // TextAtlas에 미리 렌더링
// Inter에서 이모지 글리프 없음
// → 자동 폴백 폰트 없음 (명시적이지 않음)
// → ASCII 문자로 대체 ❌ (textBaseline이 ASCII 기준으로 설정)
// → TextAtlas에 미리 렌더링됨
// → 나중에 복구 불가능
```

**해결책**:
```javascript
// ✅ 수정: 이모지 감지 + 크로스 플랫폼 폰트 스택
const isEmoji = /\p{Emoji}/u.test(ch);
if (isEmoji) {
    // 우선순위: Google(Noto) → Apple → Microsoft(Segoe)
    ctx.font = '14px "Noto Color Emoji", "Apple Color Emoji", "Segoe UI Emoji", sans-serif';
} else {
    ctx.font = '12px Inter, sans-serif';
}

// 이모지 최소 크기 보증 (너무 작으면 보이지 않음)
if (isEmoji && w < 16) w = 18;
if (isEmoji && h < 16) h = 18;
```

**OS별 폰트 지원**:
| OS | 기본 폰트 | 대체 폰트 1 | 대체 폰트 2 | 설치 명령 |
|----|----------|-----------|-----------|---------|
| Linux | Noto Color Emoji | Google fonts | 시스템 폰트 | `sudo apt install fonts-noto-color-emoji` |
| macOS | Apple Color Emoji (기본 내장) | Noto Color Emoji | - | 사전 설치됨 |
| Windows 10+ | Segoe UI Emoji (기본 내장) | Noto Color Emoji | - | 사전 설치됨 |

**코드 변경 위치**:
- `ui/webgl-renderer.js` line 45-65: TextAtlas._drawGlyph() 함수에 이모지 감지 및 폰트 스택 추가

### **문제 #3: Eco-mode 렌더링 중단**

**증상**:
- 약 2초의 유휴 시간 후 렌더링이 멈춤
- 마우스를 움직여야 다시 시작됨
- 사용자 경험 악화 (미리 계산된 데이터가 화면에 반영 안됨)

**근본 원인**:
```javascript
// 수정 전: Rendering 중에도 idle timer 증가
startLoop() {
    if (Date.now() - this.lastActivityTime > 2000) {
        console.log('[Eco-mode] Sleep');
        return;  // ❌ 렌더링 중에도 sleep 가능
    }
}
```

Eco-mode가 렌더링 중인지 감지하지 못해 active rendering 중에도 절전모드로 진입함.

**해결책**:
```javascript
// ✅ 수정 1: Rendering 상태 확인
startLoop() {
    const isRenderingActive = this.isRendering;
    if (Date.now() - this.lastActivityTime > 2000 && !isRenderingActive) {
        console.log('[Eco-mode] Sleep');
        return;
    }
}

// ✅ 수정 2: Rendering 중 idle timer 리셋
render() {
    this.lastActivityTime = Date.now();  // Eco-mode idle timer 리셋
    // ... 렌더링 로직
}
```

**코드 변경 위치**:
- `ui/canvas-engine.js` line 1705-1715: startLoop()에 렌더링 상태 확인 추가
- `ui/canvas-engine.js` line 1750-1760: render()에 lastActivityTime 업데이트 추가

## 📋 실행 요약 (Executive Summary)

v0.3.09는 v0.3.9의 **긴급 핫픽스 버전**입니다. 3개월간 누적된 3개의 심각한 버그를 수정했습니다:

1. **Canvas Height = 0**: 2D 모드로 전환 시 DOM 리플로우 전에 높이를 읽어서 0이 된 문제 → 최소 높이 보증 + 50ms DOM reflow 딜레이로 해결

2. **Emoji 폰트 미지원**: Inter 폰트가 이모지를 지원하지 않아 WebGL TextAtlas에서 이모지가 알파벳으로 대체되는 문제 → 크로스 플랫폼 이모지 폰트 스택 (Noto Color Emoji, Apple Color Emoji, Segoe UI Emoji) 추가로 해결

   **핵심 통찰**: Canvas 2D는 OS 기본 폰트 시스템으로 자동 폴백되지만, WebGL TextAtlas는 명시적 폰트 지정이 필수
   
3. **Eco-mode 렌더링 중단**: 유휴 감지 타이머가 active rendering을 감지하지 못해 2초 후 절전모드로 진입하는 문제 → 렌더링 상태 확인 + idle timer 리셋으로 해결

**결과**:
- ✅ 2D 모드: 완전 시각화 (1000+ nodes 테스트 통과)
- ✅ 3D 모드: 정상 이모지 아이콘 표시
- ✅ 렌더링: 지속적 렌더링 (eco-mode aware)

**배포**: 
- VSIX: synapse-visual-architecture-v0.3.9-hotfix.vsix (18 MB)
