# 🛠️ Implementation Plan - v0.3.09_fix (SYNAPSE Rendering & State Stability)

## 📌 개요
v0.3.09 릴리즈 이후 발견된 렌더링 품질 및 상태 유지 관련 버그를 수정하고, 엣지 시각화(태그/뱃지)를 고도화합니다. 특히 2D와 3D 모드 간의 일관성 확보와 뷰 전환 시의 안정성에 집중합니다.

---

## 🎯 주요 목표
1. **렌더링 동기화**: 2D Canvas와 WebGL 모드 간 노드/엣지 좌표 일치 확인 및 수정.
2. **성능 예산 최적화**: 2D 모드에서 요소가 사라지지 않도록 `RendererCore` 임계치 조정.
3. **상태 격리 강화**: 뷰 전환(Graph/Tree/Flow) 시 WebGL 컨텍스트 및 Canvas 강제 클리어.
4. **영속성 복구**: 스냅샷 저장 데이터가 시작 시 정확히 복원되도록 데이터 로딩 로직 수정.
5. **엣지 시각화 고도화**: 다중 태그/뱃지 지원, 레이어링 개선(화살표 위), 사이즈 확대.

---

## 📂 주요 수정 대상 및 로직 (작업 난이도 순 재배열)



### 🟡 [난이도: 중] 2. Snapshot Persistence (`src/core/SnapshotSystem.ts`, `src/core/VscdbAdapter.ts`, `extension.ts`)
- **현상**: 저장된 스냅샷(배치) 좌표가 재시작 시 반영되지 않음.
- **분석**: `project_state.json` 로딩 시 위치 데이터(`position`)가 UI로 주입 전 누락되거나 기본값으로 오버라이드.
- **수정 계획**:
  - `VscdbAdapter` 데이터 로드시 좌표 우선순위 보장 및 강제 주입(Force Apply) 적용.

### 🔴 [난이도: 상] 3. Renderer Budget & 2D 렌더링 불완전성 디버깅 (`ui/canvas-engine.js`, `src/core/RendererCore.ts`)
- **현상**: 
  - 2D 모드(Accel OFF)에서 노드/엣지가 예측 불가하게 깜빡이거나 소멸됨.
  - 노드 클릭 시 연관되지 않은 모든 엣지가 함께 그려지고 화면 줌인/아웃 파탄. (가속 모드는 정상 작동 중)
- **분석**: 
  - `calculateDynamicThreshold`의 하드 컷오프 문제. 
  - 브라우저 Canvas의 `clearRect` 누락 혹은 상태(`selectedNodes`, `ctx.save|restore`) 렌더 루프 간섭.
- **수정 계획**:
  - `SOFT_BUDGET_NODES` 상향(500) 및 2D 전용 렌더 루프 변수 타당성 정밀 검증.
