- 모든 단계는 **검증 통과 전까지 다음 단계로 진행 금지**
- 실패 시:
  1. Scenario 재현
  2. Rule / Mutation 수정
  3. Runner 재실행

## 2. Pipeline Integrity Phase

### 검증 대상
EventHandler → Intent → RuleEngine → StateManager → Render

### Harness
- 중간 bypass 감지 시 실패
- Intent 없이 상태 변경 시 실패

PASS 조건:
- 모든 state 변화가 pipeline 통과

## 3. Rule Engine Isolation Phase

### 검증 대상
- Visual / Spatial / Logic 분리

### Harness
- RuleEngine 내부 로직 존재 시 실패
- cross-engine 의존 발생 시 실패

PASS 조건:
- RuleEngine = aggregator only

- 전체 시나리오 통과

## 9. Final Lock

### 조건
- 모든 phase PASS

### 결과
- 시스템 freeze
- 이후 변경 = mutation model 통해서만 가능

## 핵심 원칙

- Validation ≠ Scoring
- RuleEngine ≠ Logic Container
- StateManager ONLY mutation point
- Determinism is mandatory
