# 0.2 🔗 REFERENCE SEMANTICS EXTRACTION (NEW)

## Problem

When:

```text
Node A → Node B (via Edge)
```

System implicitly decides:

- import (JS/TS style)
- include (C/C++ style)
- reference (graph link)
- dependency injection

👉 These decisions are currently:
- hidden
- language-specific
- inconsistent

---

## 🎯 Goal

Make reference behavior **explicit and rule-driven**

---

## 🧩 Edge → Reference Mapping

Edge is no longer just a connection.

It becomes:

```text
Edge = Relationship + Reference Semantics
```

---

## 📦 Reference Rule Definition

### Example

```ts
ReferenceRule = {
  edgeType: "dependency",
  resolution: "import",   // import | include | link | inject
  direction: "unidirectional",
  runtimeBinding: false
}
```
