## 🧠 상세 설계 및 로직

### 1. [Load Phase] 정적 무결성 확보 (Static Integrity)
시스템 가동 전 15개의 핵심 파일을 로드하여 구조적 결함을 사전 차단합니다.
- **대상:** `spec`, `state`, `extraction_rules`, `logical_rule`, `merger`, `intent`, `mutation_model` 등.
- **로직:** 파일 누락, 타입 불일치, 인터페이스 Mismatch 발생 시 즉시 프로세스를 중단(Fail-Fast)합니다.

### 2. [Pipeline Integrity] 데이터 흐름 격리
상태 변경의 유일한 경로를 확보하여 부수 효과(Side Effect)를 제거합니다.
- **경로:** `EventHandler` → `Intent` → `RuleEngine` → `StateManager` → `Render`
- **검증:** `Intent`를 거치지 않는 직접적인 `StateManager` 수정이나 `RuleEngine` 내부의 직접 로직 수행을 감지하여 차단합니다.

### 3. [Merger & Scoring] 합리적 모델 선택
여러 후보(Candidates) 중 최적의 상태 변화를 선택하는 로직을 검증합니다.
- **순차 처리:** `Veto`(거부) → `Priority`(우선순위) → `Scoring`(점수제) 순서를 엄격히 준수합니다.
- **Logic Veto:** 논리적 거부권이 발생할 경우 하위 후보군을 즉시 폐기합니다.

### 4. [Failure Loop & Convergence] 결정론적 수렴
가장 핵심적인 단계로, 시나리오 재현을 통해 시스템의 안정성을 확보합니다.
- **Core Loop:** 실행 → 실패 식별 → 규칙/변이 모델 수정 → 재실행의 반복.
- **수렴성:** 동일한 시나리오 입력에 대해 100% 동일한 결과(Non-determinism 제거)를 보장합니다.
