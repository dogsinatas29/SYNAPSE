## 1. Goal

Implement the smallest possible end-to-end pipeline for MOVE_NODE.

Focus: - See actual behavior - Validate pipeline - Establish debugging
baseline

## 2. Pipeline

EventHandler\
→ Intent (MOVE_NODE)\
→ RuleEngine (basic pass)\
→ Candidate Generator (3 candidates)\
→ Scoring (overlap only)\
→ StateManager (apply)

------------------------------------------------------------------------

``` ts
type MoveNodeIntent = {
  type: 'MOVE_NODE';

};
```

------------------------------------------------------------------------

## 4. Candidate Generation (Minimal)

``` ts
function generateCandidates(position) {
  return [
    position,
    snapToGrid(position),
    { x: position.x + 20, y: position.y },
  ];
}
```

------------------------------------------------------------------------

## 5. Overlap Detection (Basic)

``` ts
function hasOverlap(candidate, nodes) {
  return nodes.some(n =>
    Math.abs(n.x - candidate.x) < 20 &&
    Math.abs(n.y - candidate.y) < 20
  );
}
```

------------------------------------------------------------------------

## 6. Scoring (Single Rule)

``` ts
function score(candidate, context) {
  if (hasOverlap(candidate, context.nodes)) {
    return -1000;
  }
  return 0;
}
```

------------------------------------------------------------------------

## 7. Selection

``` ts
function selectBest(candidates, context) {
  return candidates
    .map(c => ({
      candidate: c,
      score: score(c, context),
    }))
    .sort((a, b) => b.score - a.score)[0].candidate;
}
```

------------------------------------------------------------------------

## 8. Apply State

``` ts
function applyMove(state, nodeId, position) {
  return {
    ...state,
    nodes: state.nodes.map(n =>
      n.id === nodeId ? { ...n, ...position } : n
    ),
  };
}
```

------------------------------------------------------------------------

## 9. Execution Flow

``` ts
function handleMove(intent, state) {
  const candidates = generateCandidates(intent.target);

  const best = selectBest(candidates, {
    nodes: state.nodes.filter(n => n.id !== intent.nodeId),
  });

  return applyMove(state, intent.nodeId, best);
}
```
