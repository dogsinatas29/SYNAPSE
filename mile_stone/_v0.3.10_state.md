## 🎯 Goal

Execute a single Intent end-to-end through the system:

> Phase → Rule → Mutation → Commit → Result

This defines the **minimum viable execution pipeline**.

---

# 1. 🧠 Core Principle

Start with the smallest possible working system.

- No abstraction
- No extension
- No optimization

Only:

> "One Intent fully executed"

# 2. 🏗️ Minimal Data Model

```ts
type State = {
  nodes: Record<string, any>
}

type Intent = {
  type: "CREATE_NODE"
  id: string
}
```

```text
Intent

```

---

# 4. 🔧 Minimal Implementation

## 4.1 Runner

```ts
function run(intent: Intent, state: State) {
  // Phase
  if (!allow(intent)) {
    return { ok: false, reason: "PHASE_BLOCK" }
  }

  // Rule
  if (!validate(intent, state)) {
    return { ok: false, reason: "RULE_FAIL" }
  }

  // Mutation
  const newState = mutate(intent, state)

  // Commit
  return { ok: true, state: newState }
}
```

---

## 4.2 PhaseGate (temporary)

```ts
function allow(intent) {
  return true
}
```

---

## 4.3 RuleEngine (minimal)

```ts
function validate(intent, state) {
  if (intent.type === "CREATE_NODE") {
    return !state.nodes[intent.id]
  }
  return true
}
```

---

## 4.4 MutationEngine

```ts
function mutate(intent, state) {
  if (intent.type === "CREATE_NODE") {
    return {
      ...state,
      nodes: {
        ...state.nodes,
        [intent.id]: { id: intent.id }
      }
    }
  }
}
```

---

# 5. ▶️ Execution Example

```ts
const state = { nodes: {} }

const intent = {
  type: "CREATE_NODE",
  id: "A"
}

const result = run(intent, state)
```
