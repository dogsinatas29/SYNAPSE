---

## 2. Transaction Layer

### Purpose
Guarantee atomic execution (All-or-Nothing)

### Structure

```ts
function executeWithTransaction(graph: DraftGraph) {
  beginTransaction()
  try {
    executeCommit(graph)
    commitTransaction()
  } catch (e) {
    rollbackTransaction()
    throw e
  }
}
```

### Rules

- Any failure triggers full rollback
- No partial file persistence
- Temp workspace recommended

---

## 3. Deterministic Commit

### Purpose
Ensure same input → identical output

### Rules

```ts
nodes.sort((a,b)=>a.name.localeCompare(b.name))
edges.sort((a,b)=> (a.from+a.to).localeCompare(b.from+b.to))
```

- Stable ordering for:
  - file generation
  - import generation

---

## 4. Idempotency

### Goal
Multiple executions produce identical result

### Rules

- Do not duplicate imports
- Overwrite deterministically
- No random naming
