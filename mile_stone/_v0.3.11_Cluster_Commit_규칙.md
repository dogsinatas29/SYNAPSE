# v0.3.11_Cluster_Commit_규칙.md

---

## 1. 핵심 결론

> Confirm(확정)만이 Buffer → Reserved 전이를 발생시키는 유일한 조건이다.  
> Edge는 필수 조건이 아니다.

---

## 2. 잘못된 규칙 (금지)

```
Edge 연결 + Confirm → Reserved 이동
```

문제:
- Edge가 필수 조건처럼 강제됨
- 구조 왜곡 발생
- 고립 노드 생성 불가

---

## 3. 올바른 규칙

```
Node 생성 → Buffer
Edge 연결 → Buffer 유지
Confirm → Reserved 이동
```

---

## 4. Edge의 역할

- 관계(Structure) 정의
- 실행 트리거가 아님

---

## 5. Confirm의 역할

- 상태 전이 트리거
- 스냅샷 제출
- 실제 파일 생성의 유일한 진입점

---

## 6. 처리 로직

```
if edges 존재:
    import 생성
else:
    단일 파일 생성
```

---

## 7. Commit 구조

```ts
type CommitRequest = {
  nodes: NodeDraft[]
  edges: EdgeDraft[]
}
```

---

## 8. 처리 단계

### Phase 1: Validation

- 순환 참조 검사
- 금지된 연결 검사

### Phase 2: Materialization

- 파일 생성
- import 자동 생성
- 그래프 구축

---

## 9. 핵심 규칙

- Buffer 상태에서는 파일 생성 금지
- Edge 연결 시 import 생성 금지
- Core 접근은 Confirm 이후만 허용

---

## 10. 한 줄 정의

> 연결은 의미이고, 확정은 현실화다.
