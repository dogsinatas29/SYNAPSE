# v0.3.11_ExecutionLayer.md

---

## 1. 정의

> Execution Layer는 DraftGraph를 실제 파일 시스템과 코드로 변환하는 단계이다.

---

## 2. 목표

- DraftGraph → 실행 가능한 코드로 변환
- validate 이후 동일 입력 유지
- 중간 변환 없이 직접 실행

---

## 3. 전체 흐름

```
DraftGraph
  ↓
validateDraft
  ↓
resolveLayer (ID → path)
  ↓
edgeTransform (dependency → import)
  ↓
executeCommit
  ↓
파일 생성 + 코드 생성
```

---

## 4. Resolve 규칙

### 목적
tempId 기반 Node를 실제 파일 경로로 변환

```ts
type ResolvedNode = {
  id: string
  path: string
  name: string
  type: string
}
```

### 규칙

- 모든 NodeDraft는 고유한 파일 경로를 가져야 한다
- 동일 name 충돌 시 자동 suffix 처리
- type 기반 디렉토리 분리 가능

### 예시

```ts
function resolveNode(node: NodeDraft): ResolvedNode {
  return {
    id: node.id,
    name: node.name,
    path: `/src/${node.name}.ts`,
    type: node.type
  }
}
```

---

## 5. Import 생성 규칙

### 목적
EdgeDraft를 실제 import 구문으로 변환

### 규칙

- edge.from → 현재 파일
- edge.to → import 대상
- 상대 경로 기반 import 생성
- 중복 import 제거

### 예시

```ts
function generateImport(from: ResolvedNode, to: ResolvedNode): string {
  const relativePath = getRelativePath(from.path, to.path)
  return `import ${to.name} from '${relativePath}'`
}
```

---

## 6. Dependency Map 생성

```ts
function buildDependencyMap(graph: DraftGraph) {
  const map = new Map<string, string[]>()

  for (const edge of graph.edges) {
    if (!map.has(edge.from)) {
      map.set(edge.from, [])
    }
    map.get(edge.from)!.push(edge.to)
  }

  return map
}
```

---

## 7. Commit 실제 구현 구조

```ts
function executeCommit(graph: DraftGraph): CommitResult {
  const resolvedNodes = graph.nodes.map(resolveNode)
  const dependencyMap = buildDependencyMap(graph)

  for (const node of resolvedNodes) {
    const deps = dependencyMap.get(node.id) || []
    const imports = deps.map(depId => {
      const target = resolvedNodes.find(n => n.id === depId)!
      return generateImport(node, target)
    })

    const content = [
      ...imports,
      "",
      node.content || ""
    ].join("\n")

    writeFile(node.path, content)
  }

  return { success: true }
}
```

## 8. 파일 생성 전략

### 규칙

- 모든 파일은 resolve 이후 생성
- 디렉토리는 자동 생성
- 기존 파일 덮어쓰기 정책 명확히 정의

### 예시

```ts
function writeFile(path: string, content: string) {
  ensureDir(path)
  fs.writeFileSync(path, content, "utf-8")
}
```

---

## 9. 금지 사항

- resolve 이전 파일 생성 금지
- DraftGraph 변형 금지
- validate 이후 구조 변경 금지

## 10. 불변식

```
validate(graph) 통과 → executeCommit(graph) 성공
```

```
모든 import는 유효한 파일을 참조해야 한다
```

---

## 11. 성공 기준

- DraftGraph만으로 프로젝트 생성 가능
- 모든 파일 정상 생성
- import 경로 오류 없음
- 실행 가능한 코드 상태

---

## 12. 핵심 요약

> Execution Layer는 DraftGraph를 실제 코드와 파일로 1:1 대응시키는 단계이다.
