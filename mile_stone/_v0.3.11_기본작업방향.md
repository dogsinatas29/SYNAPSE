# v0.3.11 기본 작업 방향

## 1. 핵심 결론
- 기존 소스는 유지한다.
- 구조는 재해석한다.
- Core와 View를 분리한다.

## 2. 구조 재정의
BEFORE: 데이터 → 바로 렌더링  
AFTER: Graph → Projection → Rule → View → Render

## 3. Core (수정 금지)
- Node / Edge 생성
- Dependency 분석
- ID 시스템
- 파일 스캔

## 4. 분리 대상
- Renderer 내부 로직
- Edge 계산
- UI 이벤트 기반 상태 변경

## 5. Projection Layer
- File Projection
- Function Projection

## 6. Rule Engine
- Edge Compression
- Layer Isolation
- Core 내부 하드코딩 금지

## 7. Rendering 흐름
graph = buildGraph(files)
projection = selectProjection()
rules = loadRules()
view = project(graph, projection, rules)
render(view)

## 8. 원칙
- Graph는 immutable
- View만 변한다

## 9. 실행 전략
1. Core Freeze
2. Projection Layer 추가
3. Rule Engine 분리
4. Renderer 단순화

## 10. 목표
- 해상도 제어
- 엣지 폭발 방지
- 결정론 유지
