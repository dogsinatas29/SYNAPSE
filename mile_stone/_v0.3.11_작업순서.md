# v0.3.11 작업 순서

## 0. 목표 고정
- Graph = immutable
- View = projection 결과
- Rule = 외부 정의

---

## 1. Core Freeze
### 목표
사실 계층 고정

### 작업
- Node / Edge 생성 코드 확인
- ID 생성 로직 확인
- dependency 분석 흐름 정리

### 결과 기준
- graph 생성이 단일 함수로 정리됨
- 외부에서 graph 수정 불가

---

## 2. Renderer 경계 분리
### 목표
Renderer가 graph 직접 접근 금지

### 변경
render(graph) → render(view)

### 결과 기준
- renderer는 view만 입력으로 사용

---

## 3. Projection Layer 도입
### 목표
Graph → View 변환 분리

### 구성
- Projection 인터페이스 정의
- File Projection 구현
- Function Projection (초기 stub)

### 결과 기준
- projection 변경 시 view 구조만 변경

---

## 4. Rule Engine 분리
### 목표
표현 규칙 외부화

### 구성
- Rule 인터페이스 정의
- Rule 적용 파이프라인 구성
- Edge Compression Rule
- Layer Isolation Rule

### 결과 기준
- 조건 분기 제거
- 규칙은 외부 파일로 존재

---

## 5. 파이프라인 연결
graph → projection → rules → view → render

### 결과 기준
- 단일 흐름으로 데이터 처리

---

## 6. 이벤트 시스템 재정의
### 목표
UI 이벤트는 상태만 변경

### 변경
- 기존: 데이터 직접 수정
- 변경: 상태 변경만 수행

### 결과 기준
- 데이터 흐름 단일화

---

## 7. Overlay 도입
### 목표
Scope Isolation 구현

### 동작
- 더블 클릭 → Sub-Canvas 진입
- 메인 상태 유지
- 내부 view만 변경

### 결과 기준
- global canvas 오염 없음

---

## 8. 검증
### 체크리스트
- projection 변경 시 graph 동일성 유지
- rule 제거 시 view만 단순화
- renderer는 graph 구조를 모름
