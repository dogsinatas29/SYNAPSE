# 🧠 1. 문제 정의

현재 지뢰/해골 마크는 단순한 "시각적 경고"에 머물러 있음.

### 한계
- 왜 문제가 발생했는지 알 수 없음
- 실제 디버깅으로 이어지지 않음
- 정보는 있지만 “행동”으로 연결되지 않음

👉 **경고 → 분석 → 행동**으로 확장 필요

---

> 경고 = 디버깅 진입점 (Trigger)

# 🔍 4. 영향도 분석 (Impact Analysis)

## 목적
특정 노드 변경 시 전체 시스템에 미치는 영향 추적

```ts
function getImpact(node) {
  return traverseOutgoingEdges(node);
}
```

### 결과
- 영향 받는 노드 리스트
- 영향 범위 (depth)
- 변경 파급 경로

---

# ⚠️ 5. 병목 추적 (Bottleneck Detection)

## 조건
- 높은 fan-in / fan-out
- 순환 참조
- 과도한 include 연결

```ts
function detectBottleneck(node) {
  return node.inDegree + node.outDegree > THRESHOLD;
}
```

# 🧩 7. Debug Context 패널

클릭 시 표시되는 정보:

## Node 정보
- 파일 이름
- include 관계
- 의존성 수

## 경고 원인
- 결정론적 충돌 여부
- 함수/심볼 오류 가능성

## 영향도
- downstream 노드 수
- 영향 깊이

## 병목 여부
- 연결 밀도
- 순환 여부

# 📊 10. 최종 구조

```ts
onWarningClick(node) {
  const impact = getImpact(node);
  const bottlenecks = detectBottlenecks(impact);

  renderDebugView({
    node,
    impact,
    bottlenecks
  });
}
```
