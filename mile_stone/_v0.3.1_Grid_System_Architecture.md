# 🎯 2. 핵심 개념

## ❗ Grid = 공간적 질서의 강제 장치

- 모든 노드는 임의 좌표 금지
- 모든 위치는 규칙 기반으로 결정

---

# 📏 3. Snap-to-Grid

```ts
function snapToGrid(pos) {
  return Math.round(pos / 40) * 40;
}
```

### 효과
- 좌표 일관성 확보
- 렌더링 안정성 증가
- 재현성 보장

---

# 📐 4. Deterministic Layout

## 규칙 기반 배치

```ts
x = depth * GRID_SIZE;
y = index * GRID_SIZE;
```

### 특징
- 실행 환경과 무관하게 동일 결과
- 디버깅 가능성 상승

---

# 🔗 5. Orthogonal Edge Routing

## 직각 경로 강제

```ts
route = [
  {x: start.x, y: start.y},
  {x: target.x, y: start.y},
  {x: target.x, y: target.y}
];
```

### 효과
- 가독성 증가
- 경로 추적 용이
- 충돌 감소

---

# 🧩 6. Grid Cell 기반 관리

## Cell 정의

```ts
cellX = x / GRID_SIZE;
cellY = y / GRID_SIZE;
```

## 활용
- 노드 밀집도 계산
- 병목 감지
- 클러스터링

---

# ⚠️ 7. 충돌 방지 (Overlap Handling)

```ts
if (cellOccupied(cell)) {
  shiftToNextAvailableCell();
}
```

# 📊 8. Density 기반 병목 탐지

if (nodesInCell > THRESHOLD) {

# 🧠 9. Cluster 생성
