# Runtime Phase Enforcement System v0.3.1

## 목표
- 잘못된 순서 실행 차단
- 실패 시 하위 시스템 실행 금지
- 단일 Phase 기준 강제

---

## 1. Phase 정의
```ts
export enum Phase {
  DATA = 0,
  GRAPH = 1,
  SNAPSHOT = 2,
  CONTROL = 3,
  GRID = 4,
  RENDER = 5,
  DEBUG = 6,
  FINAL = 7
}

let currentPhase: Phase = Phase.DATA;
let locked = false;
```

---

## 2. 진입 가드
```ts
export function assertPhase(required: Phase) {
  if (locked) {
    throw new Error("SYSTEM LOCKED");
  }

  if (currentPhase < required) {
    throw new Error(
      `PHASE VIOLATION: required=${Phase[required]}, current=${Phase[currentPhase]}`
    );
  }
}
```

---

## 3. Phase 전이
```ts
export function advancePhase(next: Phase) {
  if (locked) return;

  if (next !== currentPhase + 1) {
    lockSystem("INVALID PHASE TRANSITION");
    return;
  }

  currentPhase = next;
}
```

---

## 4. 시스템 락
```ts
export function lockSystem(reason: string) {
  console.error("SYSTEM LOCK:", reason);
  locked = true;
}
```

---

## 5. 적용 규칙

### Rule 1
모든 public 함수는 assertPhase 호출

### Rule 2
advancePhase는 성공 경로에서만 호출

### Rule 3
catch → lockSystem

```ts
try {
  buildGraph();
} catch (e) {
  lockSystem("GRAPH FAILURE");
}
```

```ts
runEventLoop(); // SNAPSHOT 없이 실행
```

```
PHASE VIOLATION
```
