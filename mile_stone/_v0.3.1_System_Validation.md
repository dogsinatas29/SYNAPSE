# v0.3.1_System_Validation.md

---

## 목적
시스템의 모든 Phase가 **정상적으로 차단/진행/락 동작을 수행하는지 검증**한다.

---

## 검증 원칙

- 모든 Phase는 **성공/실패 케이스를 반드시 가진다**
- 실패는 반드시 **SYSTEM LOCK 또는 PHASE VIOLATION**으로 이어져야 한다
- 검증은 **자동 실행 가능해야 한다**

---

## Phase 1 — DATA / GRAPH

### ✅ 성공 조건
- Node 생성 성공
- Edge 연결 정상
- include 파싱 완료

### ❌ 실패 테스트

#### Test 1: 잘못된 include
```
buildGraph(invalidInclude)
```

Expected:
```
GRAPH FAILURE
SYSTEM LOCK
```

#### Test 2: Edge 연결 실패
```
connectEdge(null, node)
```

Expected:
```
GRAPH FAILURE
SYSTEM LOCK
```

---

## Phase 2 — SNAPSHOT

### ✅ 성공 조건
- save() 성공
- load() 성공

### ❌ 실패 테스트

#### Test 1: Snapshot 없이 restore
```
load()
```

Expected:
```
SNAPSHOT FAILURE
SYSTEM LOCK
```

#### Test 2: Corrupted Snapshot
```
load(corruptedData)
```

Expected:
```
SNAPSHOT FAILURE
SYSTEM LOCK
```

---

## Phase 3 — CONTROL

### ✅ 성공 조건
- infinite loop 없음
- tick 안정성 유지

### ❌ 실패 테스트

#### Test 1: Snapshot 없이 EventLoop 실행
```
runEventLoop()
```

Expected:
```
PHASE VIOLATION
```

#### Test 2: Infinite Loop 유도
```
while(true) {}
```

Expected:
```
CONTROL FAILURE
SYSTEM LOCK
```

---

## Phase 4 — GRID

### ✅ 성공 조건
- deterministic 좌표
- snapping 정확

### ❌ 실패 테스트

#### Test 1: 비결정적 좌표
```
node.position = random()
```

Expected:
```
GRID FAILURE
SYSTEM LOCK
```

---

## Phase 5 — RENDER

### ✅ 성공 조건
- frame drop 없음
- warning render 정상

### ❌ 실패 테스트

#### Test 1: Draw Call 초과
```
drawCalls = 100
```

Expected:
```
PERFORMANCE VIOLATION
SYSTEM LOCK
```

---

## Phase 6 — DEBUG

### ✅ 성공 조건
- 클릭 분석 정상
- 병목 탐지 가능

### ❌ 실패 테스트

#### Test 1: Debug 진입 순서 위반
```
runDebugTools() // before render
```

Expected:
```
PHASE VIOLATION
```

## 결론

이 문서는 시스템이:

- 잘못된 입력을 차단하고
- 올바른 흐름만 허용하며
- 실패 시 즉시 정지하는지

를 **실제로 증명하기 위한 문서**이다.
