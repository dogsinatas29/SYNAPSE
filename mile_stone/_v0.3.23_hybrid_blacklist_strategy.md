# 🚀 SYNAPSE v0.3.23 - Hybrid Blacklist Defense Strategy (Discard + Rebuild)

## 📌 Objective
Establish a **real-time + corrective hybrid system**:
- Immediate discard at GraphModel level (prevent explosion)
- Snapshot-based rebuild for consistency recovery

---

# 🧠 Core Principle

> Block bad data at entry, clean remaining inconsistencies periodically.

---

# 🏗️ Architecture

```
Filesystem
   ↓
FileScanner
   ↓
GraphModel (🔥 DISCARD LAYER)
   ↓
Snapshot (createSnapshot)
   ↓
filterSnapshot
   ↓
restoreSnapshot (REBUILD)
```

---

# 1️⃣ REAL-TIME DEFENSE (GraphModel Discard)

## Goal
Prevent blacklisted nodes from ever entering the graph.

## Implementation

```ts
const discarded = new Set<string>()

function addNode(node: Node) {
  if (isBlacklisted(node.path)) {
    discarded.add(node.id)
    return
  }

  nodeMap.set(node.id, node)
}

function addEdge(edge: Edge) {
  if (discarded.has(edge.from) || discarded.has(edge.to)) return
  edgeList.push(edge)
}
```

---

## Key Rules

- Node rejected → mark as discarded
- Edge creation must respect discarded state
- No partial insertion allowed

---

# 2️⃣ REBUILD (Consistency Recovery)

## Flow

```ts
function rebuildWithBlacklist() {
  const snapshot = graphModel.createSnapshot()
  const filtered = filterSnapshot(snapshot)
  graphModel.restoreSnapshot(filtered)
}
```

---

## Responsibilities

- Remove residual contamination
- Fix cluster integrity
- Fix edge consistency

---

# 3️⃣ HYBRID EXECUTION FLOW

```
[Node Created]
   ↓
GraphModel.addNode()
   ↓
✔ allowed → inserted
✖ blacklisted → discarded

-------------------------

[Blacklist Changed / Manual Trigger]
   ↓
rebuildWithBlacklist()
```

# 4️⃣ OPTIONAL OPTIMIZATION (AUTO SELECTION)

```ts
function shouldRebuild(totalNodes: number, affected: number): boolean {
  const ratio = affected / totalNodes
  if (totalNodes < 1000) return true
  if (ratio > 0.2) return true
  return false
}
```

# 5️⃣ FAILURE PREVENTION

| Risk | Solution |
|-----|--------|
| Graph explosion | Discard at addNode |
| Orphan edges | Edge validation |
| Dirty snapshot | filterSnapshot |
| UI freeze | Chunked purge (optional) |
