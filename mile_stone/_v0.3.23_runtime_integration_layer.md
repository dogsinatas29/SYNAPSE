# 3️⃣ AFFECTED NODE CALCULATION

## Required Implementation

```ts
function getAffectedNodes(): Node[] {
  return Array.from(graphModel.nodes.values())
    .filter(n => isBlacklisted(n.path))
}
```

# 4️⃣ UI STATE PRESERVATION (MANDATORY)

## Problem

restoreSnapshot() resets everything

## Solution

```ts
function preserveUIState() {
  return {
    zoom: camera.zoom,
    pan: camera.pan,
    selected: selection.ids
  }
}

function restoreUIState(state) {
  camera.zoom = state.zoom
  camera.pan = state.pan
  selection.set(state.selected)
}
```

---

## Integration

```ts
const uiState = preserveUIState()

rebuildWithBlacklist()

restoreUIState(uiState)
```
