# 🚀 SYNAPSE v0.3.23 - Runtime Safety Hardening Guide

## 📌 Objective
Address critical runtime failure points in the blacklist system:

1. UI State Loss (Context Disruption)
2. Edge / Cluster / Flow Integrity (Dangling References)
3. Path Normalization Failures

---

# 🧠 Core Principle

> Trust nodes only. Validate everything else. Recover safely.

---

# 1️⃣ UI STATE SAFETY (FAIL-SAFE RECOVERY)

## Problem
After restoreSnapshot(), UI may reference deleted nodes.

## Solution

```ts
function restoreUIStateSafe(state, graphModel) {
  const validIds = new Set(graphModel.getNodeIds())

  const filteredSelection = state.selected.filter(id => validIds.has(id))

  if (filteredSelection.length === 0) {
    selection.clear()
    camera.fitView()
    return
  }

  selection.set(filteredSelection)
  camera.focus(filteredSelection[0])
}
```

---

## Preserve State

```ts
function preserveUIState() {
  return {
    zoom: camera.zoom,
    pan: camera.pan,
    selected: selection.ids ?? []
  }
}
```

# 2️⃣ EDGE / CLUSTER / FLOW INTEGRITY

## Problem
Filtered snapshot may leave dangling references.

## Solution: Rebuild Derived Data

```ts
function rebuildDerived(graphModel) {
  const nodes = Array.from(graphModel.nodes.values())

  graphModel.edges = computeEdges(nodes)
  graphModel.clusters = computeClusters(nodes)
  graphModel.cluster_flows = computeFlows(graphModel.clusters)
}
```

---

## Rule

> Never trust snapshot edges/clusters/flows. Always rebuild from nodes.

# 3️⃣ PATH NORMALIZATION (CRITICAL)

## Problem
Different path formats bypass blacklist.

## Solution

```ts
import path from 'path'
import fs from 'fs'

function normalizePath(p: string): string {
  let resolved = path.resolve(p)

  try {
    resolved = fs.realpathSync(resolved)
  } catch {}

  return resolved.toLowerCase()
}
```

---

## Apply Everywhere

```ts
function addToBlacklist(p: string) {
  blacklist.add(normalizePath(p))
}

function isBlacklisted(p: string) {
  return blacklist.has(normalizePath(p))
}
```

---

# 4️⃣ ATOMIC RESET VALIDATION

```ts
function reset() {
  this.nodes.clear()
  this.edges = []
  this.clusters = []
  this.cluster_flows = []

  if (this.nodes.size !== 0) {
    throw new Error('Reset failed')
  }
}
```
