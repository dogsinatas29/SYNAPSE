🚀 Milestone v0.3.3 - Edge Metadata Restoration & Pipeline Parity

## 📅 작업 정보 - **상태:** 🚧 In-Progress (Refining Regression)
- **관련 마일스톤:** [v0.3.2](v0.3.2.md) (Arrowhead & Tapering Fix)
- **목표:** 2D/3D 캔버스 메타데이터 유실 및 렌더링 성능 저하(잔상) 해결.

## 🧠 상세 설계 및 로직
- **Fixing State Stack Corruption**: `canvas-engine.js`의 `renderEdge` 내부 `save/restore` 불균형으로 인한 Context 스택 오버플로 및 잔상(Ghosting) 수정.
- **Lowering Icon Threshold**: 줌 레벨 `0.75` 수준에서도 아이콘이 보이도록 `showIcons` 임계치를 `0.3`으로 하향 조정.
- **WebGL Fix**: `webgl-renderer.js`의 `updateTextData` 내부에서 `nodeMap` 참조 오류로 인한 렌더링 중단(Black screen) 해결.

## 🛠️ 기술적 변경 사항
- **Canvas Engine Update**: `renderEdge` 내부 `if (showIcons || ...)` 블록 끝에 누락된 `ctx.restore()` 추가.
- **Renderer Update**: `updateTextData` 함수 시그니처에 `nodeMap` 추가 또는 내부에서 로컬 맵 생성.
- **LOD Update**: `showIcons` 기준값 수정 (`1.2` -> `0.3`).

## ⚠️ 예외 처리 및 주의 사항
- `●` (원형 배지 배경) 특수 문자가 WebGL SDF 텍스트 아틀라스에서 정상 출력되는지 재확인.
- 3 FPS 현상은 스택 오염으로 인한 브라우저 렌더링 병목이었을 가능성이 큼.
