## 🧠 상세 설계 및 로직 (v0.2.16)

### 1. 워룸(War Room): 수직 폭포(Vertical Waterfall) 알고리즘
- **Layered Digraph**: 소스 코드의 호출 깊이(Depth)를 계산하여 각 노드에 레이어를 강제 배정.
- **Rank Alignment**: 상위 노드와 하위 노드 사이의 엣지 교차를 최소화하는 정렬 최적화.
- **Logic Inversion Handling**: 하위에서 상위로 흐르는 콜백 엣지는 점선 처리로 시각적 혼선 차단.

### 2. SQLite 리포트 엔진: 이원화 관리
- **Executive Summary View**: 프로젝트 복잡도와 보안 건전성을 시각화하여 경영진 보고용 데이터 생성.
- **Traceability Report**: 데이터 노드에서 서비스 노드까지의 전송 이력을 테이블화.
- **Automated PDF Export**: 시냅스 워룸 스냅샷을 포함한 보고서 출력 모듈.

### 3. 수익화 기초 설계
- **Server Registry**: managed_nodes 테이블을 통해 서버 고유 ID와 등록 시각 관리.
- **Session Manager**: 동시 접속 세션을 모니터링하여 임계치 초과 시 유료 플랜 안내.
   -- 세션 매니저는 기능만 부여할 것. 리미트 확인했어니 주석 처리하고 실제 윺료 모델을 만들 때 활성화할 것.
- **Node Update**: NodeType 필드 확장 (Data, Processor, Service, Gate, Trigger 추가).
- **Edge Update**: 데이터 전송량에 비례한 선 굵기 동적 조절 (Weight 필드 추가).
- **DB Schema**: billing_meta 테이블 신설. 무료 사용량 및 결제 상태 트래킹.
- **Rendering**: 대규모 환경 대응을 위한 가속 렌더링 로직 검토.

## ⚠️ 예외 처리

## 📝 Post-Work Log (작업 후 기록)
- ✅ **완료 내역 (Completed):**
  - **Node Type & Edge Weight Extension:** `Data`, `Processor`, `Service`, `Gate`, `Trigger` 노드 타입을 `ui/canvas-engine.js`에 시각적으로 반영(고유 아이콘 및 굵은 테두리). 엣지의 굵기를 동적 제어하는 `Weight` 처리 구현.
  - **Vertical Waterfall Layout:** `FlowchartGenerator.ts`의 `generateInitialFlowchart`에 Longest-path 기반 DFS(깊이 우선 탐색) 알고리즘을 도입하여 정확한 Layered Digraph 분배 로직 구현. 또한, 하위 랭크에서 상위 랭크로 흐르는 엣지(콜백)를 감지하여 점선 처리(`loop_back`)하는 Logic Inversion Handling 완료.
  - **Report Engine & Billing:** `sqlite3` 네이티브 모듈 빌드 이슈(VS Code Extension 호환성)를 우회하기 위해 VS Code의 `globalState`(`memento` API)를 활용하여 `DatabaseEngine.ts`와 `BillingManager.ts`를 구현. 추적 가능한 데이터(Traceability)와 세션 한도 관리 기초 구현 완료. 또한 `ReportExporter.ts` 모듈을 연동하여 `synapse.exportReport` 명령어로 HTML 요약 보고서 생성이 가능하게 조치함.
  - **Error Checking & Performance:** 환각에 의한 알 수 없는 NodeType 오류나 끊어진 엣지를 감지하는 스키마 무결성 검증 로직(`detectSchemaViolations`)을 `LogicAnalyzer.ts`에 추가. `FlowchartGenerator.ts`에서 동일 Rank 내의 노드들이 완전히 겹치지 않도록 Y축 오프셋 지그재그 분산 처리(Vertical Alignment Optimization) 완료.
  - **Bug Fix:** 클러스터 접기/펴기(`toggleClusterCollapse`) 시 내부 노드가 다시 나타나지 않던 렌더링 버그 수정.

## 🌟 기대 효과 (Expected Effects)
이번 **v0.2.16 상용화 베이스캠프** 마일스톤이 완료되었을 때 기대할 수 있는 핵심 효과는 다음과 같습니다.

1. **상용화 가치 입증을 위한 기반 마련 (Base for Monetization)**:
   - 과금 시스템(`BillingManager`)의 데이터 구조 및 상태 관리 뼈대만 우선 구현하여, 향후 프리미엄(PRO) 버전 전환 등 상용화 기능을 확장할 수 있는 기초 체력을 다집니다. (실제 과금 로직 적용은 추후 진행)
2. **시각적 인지 능력 극대화 (Cognitive Overload Reduction)**:
   - Node Type(`Data`, `Processor`, `Service` 등)과 엣지의 두께(`Weight`)가 시각적으로 구분되고, **Vertical Waterfall** (수직 폭포) 및 **Logic Inversion Handling**(역방향 점선 처리)을 통해 수백 개의 파일이 얽힌 복잡한 아키텍처라도 데이터의 흐름과 콜백(역방향)의 구조를 빠르고 직관적으로 파악할 수 있습니다.
3. **경영진 / 이해관계자 보고 역량 강화 (Automated Reporting)**:
   - `DatabaseEngine`이 수집한 Traceability 정보와 프로젝트 복잡도를 기반으로 **경영진 요약 보고서(Executive Summary)**를 생성하고, 추후 HTML/문서 포맷으로 출력하여 설계 검토나 감사(Audit) 자료로 바로 활용 가능한 B2B 수준의 도구로 도약합니다.
