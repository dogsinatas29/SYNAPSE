## 🧠 상세 설계 및 로직
- **좀비 노드(Resurrection) 차단 원리:**
  웹뷰(React/Canvas)는 특정한 비동기 타이밍에 전체 노드 스냅샷을 백엔드로 밀어넣습니다(`saveState`). 이때 이미 삭제되었으나 캐시에 남아있는 노드가 백엔드 JSON (`project_state.json`) 에 다시 기입되면서 화면에 좀비처럼 부활하는 현상이 있었습니다. 이를 막기 위해 "사용자의 명시적 커맨드(ex: `createManualNode`) 없이는, 배열을 루프 돌 때 백엔드에 존재하지 않는 노드(`!backendNode`)는 절대 데이터베이스에 추가하지 않는다"는 방어적(Defensive) 허용 원칙을 도입했습니다.
- **Edge 방향성에 따른 Import 주입 (A ➔ B):**
  선(Edge)의 방향이 곧 코드 의존성의 방향입니다. A가 B에게 화살표를 던지면, A 파일 최상단에 `import B` 가 기록됩니다.
- **히트박스 스케일링 (Badge Hitbox):**
  웹 캔버스의 확대/축소(Zoom) 비율에 따라 실제 클릭 포인트가 어긋나던 버그를 잡기 위해 수학적 바운딩 박스를 확장(`r * 2.5`)하였습니다.
- **Buffer ➔ Reserved 자동 도약:**
  드래그 도중 소속을 잃어버리는 문제를 `priority_cluster` 데이터 태그로 해결하고, 연결 성공 즉시 해당 클래스터 구역으로 좌표를 강제 점핑시킵니다.

## ⚠️ 예외 처리 및 주의 사항
- `sys_cluster_buffer`나 `sys_cluster_reserved`는 시스템 코어 클러스터입니다. 사용자가 캔버스에서 해당 박스를 강제로 지우더라도 코드는 다음 프레임에 다시 렌더링하도록 락이 걸려있습니다.
- Python이나 JS의 모듈 위치 구성을 완전히 무너뜨리는 매우 특이한 코드 컨벤션이 발동하면 정규식이 빗나갈 수 있으므로 향후 LSP 기반 AST 분석 체제로의 완전한 전환이 필요합니다.
