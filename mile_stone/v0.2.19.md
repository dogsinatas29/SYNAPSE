## 🧠 상세 설계 및 로직

### 1. 계층형 메뉴 구조 개편 (Hierarchical Menu Architecture)
상단 툴바의 복잡도를 줄이기 위해 클릭 시 하위 메뉴가 나타나는 계층 구조를 도입합니다.
- **Snap Shot**: 시스템 형상 관리
  - **존재의 이유(정체성)**: 
    1. 온전한 아키텍처 뼈대가 있던 시기를 기억하기 위해
    2. 형상적 결단(대규모 노드/엣지 삭제 등) 시점에서의 심리적 부담감 감소를 위해
    - **주의**: 스냅샷은 위 두 가지 목적을 위해서만 존재하며, 그 외의 기능(미세 파일 백업 등)은 **절대 제공하지 않음**을 명시.
  - `Save`: 현재 상태 즉시 저장 (수동/자동 트리거)
  - `History`: 외부 창(External Window)으로 관리, 검색 편의를 위한 스크롤바 지원.
- **Context (Vault)**: 컨텍스트 관리
  - `Rec` 아이콘: 활성화 시 하단에 녹화 상태 버튼 표출.
  - `History` 아이콘: 스냅샷 히스토리와 동일 로직으로 외부 창 격리 관리.

### 2. 디자인 고도화 및 시각적 안정성 (Design & Stability)
- **세련된 디자인(Premium Look)**: 버튼 높이와 디테일(그림자, 테두리, 그라디언트) 조정.
- **클릭 시 크기 고정(Visual Anchor)**: 버튼 호출 시 툴바 레이아웃 변동 방지.

### 3. 기능 공간 격리 및 가시성 (Spatial Isolation & Auto Alignment)
- **외부 패널 전환**: 캔버스 내 비대한 컨텍스트 클러스터를 외부 패널로 분리.
- **스마트 자동 배치**: 노드 생성 시 겹침 방지 알고리즘 도입.
- **수동 위치 영구 기억**: 드래그한 노드의 좌표를 `project_state.json`에 영구 기록.

### 4. 고스트(Ghost) & 예약(Reserved) 노드 전이 모델
v0.2.18 좀비 차단 로직과 충돌하지 않도록 **'상태 기반 필터링'** 도입.
- **Ghost Node (사유의 파편)**: LLM 생성 가설. 백엔드에 기록되나 물리 파일 미생성 (반투명).
- **Materialize (실체화)**: 클릭 시 Ghost → Active 전환 및 실제 파일 생성.
- **Reserved Node (지연된 집행)**: 위험 조치 대기열. 최종 승인 전까지 EdgeCodeRefactorer 가동 유예.
