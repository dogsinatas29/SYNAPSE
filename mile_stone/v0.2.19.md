🎨 사용자 경험 최적화 (UI/UX Refinement)

### 2. 계층형 메뉴 구조 개편 (Hierarchical Menu Architecture)
상단 툴바의 복잡도를 줄이기 위해 클릭 시 하위 메뉴가 나타나는 계층 구조를 도입합니다.
- **Snap Shot**: 시스템 형상 관리
  - `Save`: 현재 상태 즉시 저장
  - `History`: 외부 창(External Window)으로 관리하며, 검색 편의를 위한 스크롤바 지원
- **Context (Vault)**: 컨텍스트 관리
  - `Rec` 아이콘: 활성화 시 하단에 녹화 상태 버튼으로 기능 한정 표출
  - `History` 아이콘: 스냅샷 히스토리와 동일한 로직으로 외부 창으로 격리 관리 / View 모드의 Show vault에만 히스토리 나오게 처리. 캔버스에서 완전히 분리해서 속도 보장할것.

### 2. 디자인 고도화 및 시각적 안정성 (Design & Stability)
- **세련된 디자인(Premium Look)**: 버튼의 높이(Weight)와 디테일(그림자, 테두리, 그라디언트)을 조정하여 더 견고하고 전문적인 톤앤매너를 구축합니다.
- **클릭 시 크기 고정(Visual Anchor)**: 특정 버튼(예: Edit Logic) 호출 시 레이아웃이 미세하게 흔들리거나 사이즈가 변하던 현상을 수정하여 완벽한 시각적 안정성을 확보합니다.

### 3. 기능 공간 격리 (Spatial Isolation)
- **외부 패널 전환**: 캔버스 내부에 위치하던 비대한 컨텍스트 클러스터(Context Vault)를 외부 패널로 완전히 격리합니다.
- **링크 버튼 체제**: 캔버스에는 볼트 접근을 위한 간결한 **'링크 버튼'**만 남겨, 아키텍처 본연의 형상에 집중할 수 있는 쾌적한 작업 환경을 구축합니다.

### 4. 노드 자동 정렬 및 위치 기억 (Auto Alignment & Memory)
- **스마트 자동 배치**: 복잡한 의존성을 가진 노드 생성 시 겹침을 방지하는 알고리즘을 도입하여 캔버스의 가독성을 높입니다.
- **수동 위치 영구 기억**: 한 번 사용자가 드래그하여 배치한 노드의 `x, y` 좌표는 `project_state.json`에 영구적으로 기록되어, 창을 다시 열어도 아키텍처의 형상(Shape)이 철저히 유지됩니다.

### 4. 필요성 및 기대효과
- **시각적 공해 제거**: 수많은 컨텍스트 노드가 캔버스 공간을 차지하여 메인 아키텍처 파악을 방해하는 현상을 원천 차단합니다.
- **정보 계층화**: 시각적 구조(Architecture)와 기록적 데이터(Context)를 물리적으로 분리하여 인지 부하를 혁명적으로 감소시킵니다.
- **작업 공간 효율화**: 복잡한 아키텍처 작업 시 사용자의 시야를 가리지 않도록 최적의 위치에 창을 배치할 수 있게 합니다.

👻 고스트(Ghost) & 예약(Reserved) 노드 전이 모델
v0.2.18의 좀비 차단 로직과 충돌하지 않도록 **'상태 기반 필터링'**을 도입합니다.

Ghost Node (사유의 파편): LLM이 생성한 잠재적 가설입니다. 백엔드에는 기록되되 물리 파일은 건드리지 않는 '반투명' 상태를 유지합니다.

Materialize (실체화): 사령관님의 클릭 시 Ghost에서 Active로 전환되며 실제 파일이 생성됩니다.

Reserved Node (지연된 집행): 위험 조치 대기열입니다. '최종 승인(Confirm)' 전까지는 EdgeCodeRefactorer의 가동을 유예합니다.
