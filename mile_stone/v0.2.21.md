# 4. Canvas Rendering Architecture

## Problem in Previous Design

Previous canvas structure used nested loops:

for layer in layers\
 for node in layer.nodes

Increasing layers significantly degraded performance.

------------------------------------------------------------------------

## New Node‑Centric Model

Rendering is now node‑based.

Node - id - position - cluster - layer

Render loop:

for node in nodes\
 draw(node)

Layers act only as filtering metadata.

# 8. Entropy Analysis Model

Synapse measures structural complexity through entropy metrics.

## Node Entropy

Measured by:

-   cyclomatic complexity
-   forbidden keywords
-   memory usage patterns

## Edge Entropy

Weights:

include = 1\
function call = 2\
template = 3\
macro = 4

## Total Graph Entropy

TotalEntropy = NodeEntropy + EdgeEntropy
