시니어님의 날카로운 통찰과 "주머니 대신 지갑을 털라"는 전략에 따라, v0.2.36 정밀 유격 타격 및 Direct Reading 진화를 완료했습니다. 🎯

리눅스 환경에서 우리를 배신하던 클립보드를 완전히 폐기하고, VS Code의 심장부인 데이터베이스에서 직접 대화 내역을 낚아채는 구조로 체질을 개선했습니다.

🛠️ v0.2.36 작업 완료 보고
1. ClipboardScraperAdapter → DirectChatScraper 진화 완료

더 이상 클립보드(selectAll + copy)를 믿지 않습니다.
Direct Reading: 이제 VscdbAdapter를 통해 state.vscdb 파일을 직접 스캔하여 대화 내역을 JSON 수준에서 즉시 추출합니다.
클립보드 백업/복구 로직이 제거되어 리소스 소모가 줄고 'No text captured' 루프가 원천 차단되었습니다.
2. 포커스 커맨드 다이어트 (Senior's Choice)

토글 충돌을 일으키던 잡다한 커맨드를 모두 제거했습니다.
최정예 커맨드만 잔류:
workbench.panel.chat.view.copilot.focus (실측된 직접 타격용)
antigravity.toggleChatFocus (안티그래비티 전용)
3. 리눅스 환경 최적화 (Snap/Flatpak 대응)

리눅스 설치 환경(Snap, Flatpak, Standard 등)에 따른 state.vscdb 경로 추적 로직을 강화하여 데이터 탈취 성공률을 극대화했습니다.
4. 문서 동기화
