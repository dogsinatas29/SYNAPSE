## 🧠 상세 설계 및 로직
- **DPI Unification**: `window.devicePixelRatio`를 WebGL 투영 행렬에 통합하여 CSS 좌표와 렌더링 좌표를 1:1로 매칭.
- **Pre-baked Layout Strategy**: 매 프레임 발생하는 고비용의 레이아웃 연산을 사전 계산 방식으로 전환하여 Stutter(버벅임) 제거.
- **Coordinate System Parity**: 줌/팬 시 WebGL 레이어와 2D 레이어 간의 극미세 오차(Jitter) 근본적 해결.

## 🛠️ 기술적 변경 사항
- **Node Update**: `ui/webgl-renderer.js` (Projection matrix scale 보정)
- **Edge Update**: `ui/canvas-engine.js` (Pre-baked layout 도입 및 스파이크 제거)
- **File Changes**: `ui/index.html` (배경 처리 순서 최적화)

## ⚠️ 예외 처리 및 주의 사항
- `devicePixelRatio`가 1이 아닌 환경(Mac Retina, 4K Monitor)에서의 테스트 필수.
- 노드 데이터 로드 시 `position` 객체 누락에 대한 Crash Guard 적용.
