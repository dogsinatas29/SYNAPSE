## 🧠 상세 설계 및 로직
- **Rendering Logic Unification**: `getNodeStyle`의 색상 결정 로직을 WebGL 엔진에도 동일하게 적용(Hardcoding 제거).
- **Cluster State Mirroring**: 클러스터가 접혔을(Collapsed) 때 내부 노드를 숨기는 동작을 WebGL 레이어에서도 동일하게 구현.
- **Visual Property Support**: `node.visual.opacity` 등 시각적 속성을 3D 모드에서도 지원하여 Ghost 노드 표현 일치화.
- **Layer Filter Sync**: Base Logic과 User Logic 필터링이 양쪽 모드에서 즉각적으로 반영되도록 구조화.
