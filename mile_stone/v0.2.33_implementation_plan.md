## 🏗️ Technical Architecture

### 1. Clipboard Scraper Enhancement
- **Target:** `src/core/ClipboardScraperAdapter.ts`
- **Logic:** 
  - Trace `workbench.action.chat.copyAll` execution.
  - Implement a fallback attempt to focus the chat panel if copying returns empty.
  - Add more permissive regex for speaker detection.
  - Ensure `last_scrape_raw.txt` is always written for debugging if configured.

### 2. PB Sniffer String Extraction (Direct Buffer Scan)
- **Target:** `src/core/PbSessionWatcher.ts`
- **Logic:** 
  - Instead of `buffer.toString('utf-8')` (which fails on binary with invalid sequences), scan the Raw Buffer.
  - Find all contiguous ASCII (0x20-0x7E) or UTF-8 Hangeul sequences.
  - Only collect sequences that look "meaningful".

## ⚠️ Known Risks & Mitigation
- **Encryption**: If `.pb` files are truly fully encrypted (as indicated by the `strings` test), sniffing will never work. We must rely on the scraper.
- **Scraper Focus**: `copyAll` might require the chat pane to be the active view. If so, we need a way to focus it without disrupting the user's flow.
