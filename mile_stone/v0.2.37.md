## 🧠 상세 설계 및 로직
- **[Action 1] API-based Extraction (Clipboard-Free):** 
    - Clipboard와 DB를 모두 우회하여, VS Code 내부의 `vscode.ChatController` 또는 `InteractiveSession` API를 통해 현재 활성화된 세션의 `responses` 배열을 직접 탈취.
- **[Action 2] DB Retry & WAL Sync Optimization:** 
    - PB Trigger 감지 후 DB 기록까지의 시차(Latency)를 고려하여 2초의 지연(Retry) 로직 도입.
    - `-wal`, `-shm` 파일의 복제 및 병합 읽기 로직을 강화하여 미커밋 스냅샷을 완벽하게 포착.
- **[Action 3] RawTextMiner (Hangeul Scouter):** 
    - PB 파일 또는 바이너리 데이터 내의 '외계어' 사이에서 UTF-8 기반의 한글(가-힣) 문자열만 정밀하게 추출하는 전용 스니퍼(Sniffer) 실장.
