## 🧠 상세 설계 및 로직
- **[Action 1] Targeted PB Scanning:** 
    - PB Trigger 수신 시 전달된 `sessionId`를 활용하여, 수만 개의 파일 중 변경이 발생한 특정 `.pb` 파일만 우선적으로 스캐닝.
- **[Action 2] Precision Noise Filter (RawTextMiner):** 
    - `workbench.`, `antigravity.`, `ItemTable` 등 VS Code 커널 수준의 키값과 메타데이터를 필터링하는 블랙리스트 도입.
    - 점(.)이 2개 이상이거나 언더바(_)가 많은 식별자형 문자열 자동 제외.
    - 공백이 없는 영문 숫자로만 된 문자열(ID류) 제외.
- **[Action 3] Human-Centric Heuristics (VscdbAdapter):**
    - 단순 텍스트 나열이 아닌, 공백이나 한글이 포함된 '문장형' 데이터만 Assistant 응답으로 인정하도록 강화.
    - 질문형 키워드(`?`, `해줘`, `왜` 등) 기반의 정밀한 User/Assistant 역할 판정 도입.
