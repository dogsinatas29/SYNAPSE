## 🧠 상세 설계 및 로직
- **[핵심 설계 내용 1] Wildcard Namespace Hooking**:
    - `antigravity.*`, `gemini.*`, `chat.*` 접두사를 가진 모든 `executeCommand` 호출을 가로챔.
    - 필터링 없이 일단 모든 인자(Arguments)를 심층 분석 파이프라인으로 전달.
- **[핵심 설계 내용 2] Deep Argument Inspector (Recursive)**:
    - 인자가 객체, 배열, 문자열 무엇이든 상관없이 재귀적으로 탐색하여 유의미한 길이(>1)의 문자열을 추출.
    - 특히 한글(Hangeul)이 포함된 경우 'HIGH_PRIORITY' 태그와 함께 즉각 로깅.
- **[핵심 설계 내용 3] Logic Blackbox (intercept_hits.log)**:
    - 발견된 모든 라이브 데이터를 `intercept_hits.log`에 타임스탬프와 함께 기록하여 물리적 증거 확보.

## 🛠️ 기술적 변경 사항
- **CommandInterceptor.ts Update**: `patchExecuteCommand` 필터 확장 및 `findMessageInArgs`를 `recursiveScan`으로 업그레이드.
- **Diagnostic Upgrade**: 인자 구조(Schema)를 함께 덤프하여 명령어별 페이로드 규격 분석.

## ⚠️ 예외 처리 및 주의 사항
- **로그 폭발(Log Bloat) 방지**: 동일한 명령어의 동일한 인자가 반복될 경우 중복 제거 로직 적용.
- **성능 오버헤드**: 재귀 탐색 깊이 제한(Depth Limit: 3-5)을 두어 UI 프리징 방지.
