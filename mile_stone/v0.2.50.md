- **"Wall Penetrator" Evolution**: HTML Setter 가로채기 방식에서 벗어나, Chromium 기반의 CDP(Chrome DevTools Protocol)를 통해 Webview 런타임에 직접 명령을 실행함.
- **CDP Attachment Logic**:
  - `Runtime.evaluate`를 사용하여 런타임 객체(`window.acquireVsCodeApi`)를 직접 패치.
  - CSP 및 iframe isolation을 완벽하게 무시하고 렌더러단 도청 확보.
- **Target Selection**: VS Code 내부의 여러 Webview 중 `antigravity` 관련 타겟을 식별하여 자동 Attach.
