## 🧠 상세 설계 및 로직
- **"Runtime-Only" Strategy**: HTML 정적 주입은 포기하고, Chromium 렌더러의 디버깅 컨텍스트(`Runtime.evaluate`)를 통해 동적 패치 실행.
- **Native Port Hijacking**: 
  - `--remote-debugging-port=9222` 강제 활성화 혹은 `antigravity.getChromeDevtoolsMcpUrl` 명령을 통한 디버거 접속 주소 확보.
  - CSP(Content Security Policy)는 Chromium 엔진 레벨에서 무시되므로, Nonce-based CSP를 완벽하게 관통.
- **Persistent Injection**: Webview가 새로고침되거나 다른 탭으로 이동하더라도 CDP Event Monitoring을 통해 주입 상태 유지.

## ⚠️ 예외 처리 및 주의 사항
- **Port 9222 Lock**: `argv.json` 설정이 무시되는 경우, Antigravity를 `--remote-debugging-port=9222` 인자와 함께 직접 실행해야 함.
- **MCP Protocol Mismatch**: `google.chrome-devtools-mcp`가 SSE 방식을 강제할 경우, 단순 HTTP GET으로는 타겟 목록 획득이 불가능하므로 후속 버전에서 SSE 클라이언트 구현 필요.
