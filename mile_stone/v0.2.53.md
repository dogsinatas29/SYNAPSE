## 🧠 상세 설계 및 로직
- **Context Selection (The "Main World" Hunt)**: 
  - `Runtime.executionContextCreated` 이벤트 수신 시, `name` 속성이 없거나 `isDefault: true`인 컨텍스트를 Main World로 간주.
  - Context 2 (Isolated)가 아닌 Context 1을 명시적으로 조준하여 `Runtime.evaluate` 실행.
- **Bridge Hijacking (World Crossing)**:
  - `window.acquireVsCodeApi`를 즉시 후킹하여, 모든 `postMessage` 트래픽을 완벽하게 가로챕니다.
- **VSCode API Hijacking**:
  - `window.postMessage` 전체 훅이 아닌, `acquireVsCodeApi()`가 반환하는 객체의 `postMessage`를 타겟팅하여 안정성 확보.
