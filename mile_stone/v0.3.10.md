## 🧠 상세 설계 및 로직
### 1. v0.3.10-LOCK: Reality-First Protocol
- **Partial Confirmation Sequence:** 전체 상태 재전송(Re-broadcast)의 부작용을 막기 위해, 확정된 노드 정보만 부분 업데이트(`updateNode`)하여 UI 레이아웃 보존.
- **Atomic File Creation:** `fs.writeFile` 후 즉각적인 `fs.stat` 검증으로 파일 존재 여부를 물리적으로 확정한 뒤 UI에 Solid 상태 부여.
- **Host Pressure Sync:** 파일 생성 즉시 `saveAll` 명령을 실행하여 VS Code 탐색기와 동기화 지연 해소.

### 2. 클릭 상호작용 수복 (Click Continuity)
- **Label-based Fallback:** 노드 ID가 시스템 ID(`node_manual_...`)인 경우에도, 사용자가 입력한 **라벨(Label)**을 파일 경로로 인식하여 에디터를 호출하는 지능형 경로 해석기 구현.
- **Hierarchical Path Sync:** 익스텐션에서 온 `filePath`를 노드 최상위(`file`)와 하위(`data.file`)에 모두 각인하여 클릭 자격(Eligibility) 완벽 확보.

### 3. 데이터 및 렌더링 무결성
- **엣지 통계 정규화:** 유효하지 않은(Orphaned) 엣지를 집계에서 제거하여 화면 하단 정보창 수치와 실제 가시적 엣지 수(12개)를 1:1 동기화.
- **Boot Hardening:** `engine-core.js` 로딩 시의 403 Forbidden 문제 해결 및 렌더링 루프 전체에 Null-Safety 가드 설치.
