# Implementation Plan - v0.3.10 Hotfix (Stabilizing Interaction & UI)

## 1. Path Doubling Fix (src/webview/CanvasPanel.ts)
- **Problem**: `openFile` incorrectly joins absolute paths with the workspace folder, causing `ENOENT` errors.
- **Fix**: Check `path.isAbsolute(filePath)` before joining. If absolute, use as-is.

## 2. Layer Visibility in Flow View (ui/canvas-engine.js)
- **Problem**: `FlowRenderer` does not check `showBaseLayer` or `showUserLayer` during `buildFlow`, causing hidden nodes to remain visible in Flow View.
- **Fix**: Update `FlowRenderer.buildFlow` to filter nodes based on layer visibility flags.

## 3. Cluster Promotion Persistence (src/webview/CanvasPanel.ts)
- **Problem**: Node promotion to `Reserved Cluster` was only dispatched to memory, not applied to the local `projectState` object before file persistence.
- **Fix**: Directly update the cluster ID in the `projectState.nodes` array during `handleCreateManualEdge`.

## 4. Tree View Rooting (ui/canvas-engine.js & src/webview/CanvasPanel.ts)
- **Problem**: Tree View shows absolute paths starting from `/root` if nodes have absolute paths.
- **Fix**: 
    - (Backend) Include `workspaceFolder` path in the `projectState` message.
    - (Frontend) In `TreeRenderer.buildTree`, strip the workspace root from paths to show a clean local hierarchy.

## 5. Metadata Sync
- Ensure `v0.3.10.md` tracks these critical hotfixes.
