## 🧠 상세 설계 및 로직
- **좌표계 대통합 (Coordinate Reconciliation)**:
    - 그룹화(Group) 시: 노드들의 중심점을 계산하여 클러스터 위치로 설정하고, 노드 좌표를 전역(Global)에서 상대(Relative)로 변환.
    - 언그룹(Ungroup) 시: 부모 클러스터의 오프셋을 현재 좌표에 더해 다시 전역 Coordinates로 복구. 이로써 언그룹 즉시 발생하는 "좌표 붕괴" 현상 원천 차단.
- **입력 가드 (Input Protection)**:
    - 전역 `keydown` 리스너에 `INPUT/TEXTAREA` 포커스 가드를 추가하여, 텍스트 입력 중 `Backspace`나 `Delete`가 노드 삭제 명령으로 오작동하는 것을 방지.
- **SSOT(Single Source of Truth) 강화**:
    - 웹뷰 저장(`handleSaveState`) 시 백엔드 엔진 스냅샷을 우선순위로 병합하여, UI 조작 중 발생할 수 있는 데이터 증발(Ghost Wipe) 방어.
- **고령 논리 퇴출 (Legacy Logic Cleanup)**:
    - 엣지 확정 시 노드를 `sys_cluster_reserved`로 강제 이동시키던 `promoteToReserved` 로직 폐기. 이를 통해 사용자가 설정한 클러스터 구조의 영속성 보장.

## 🛠️ 기술적 변경 사항
- **Node Update:** 'ID Sovereignty' 프로토콜 도입 (AI 스캐너의 매뉴얼 ID 덮어쓰기 완전 차단)
- **Edge Update:** 'Path-to-ID Aliasing' 리졸버 구현 (노드 ID 변조 시에도 기본 로직 엣지 100% 복구)
- **Cluster Update:** 시스템 클러스터 명칭 강제 동기화 (Reserved Cluster 명칭 고정)
- **Counting Logic:** 리로드 없이 실시간 사용자 레이어 도수 집계 정확도 99.9% 확보

- **[거대 루트 클러스터(`sys_cluster_root`) 폐지]**: (Rule 1) 모든 노드를 일률적으로 가두던 최상위 루트 박스를 폐지. 이제 프로젝트의 물리적 폴더들이 각각 독립적인 최상위 클러스터가 되어 캔버스에 펼쳐지는 유연한 아키텍처로 전환.
- **[폴더-클러스터 위계 확립]**: (Rule 2) IDE의 실제 폴더 구조가 AI 레이어의 기본 뼈대(Skeleton)가 됨. AI 스캐너가 발견한 모든 폴더 클러스터는 사용자가 위치를 옮기더라도 **AI Layer**에 고속(Pinned)되어 프로젝트의 물리적 정체성 유지.
- **[사용자 자산 자동 분류 및 승격]**: (Rule 3) 사용자 노드의 연결성(`degree`)에 따른 동적 배치 시스템 도입.
  - **Rule 3-1 (Buffer)**: 연결(Edge)이 0개인 독립 노드는 자동으로 `sys_cluster_buffer`에 배치 (아이디어 로딩 단계).
  - **Rule 3-2 (Reserved)**: 최소 1개 이상의 연결이 형성되는 즉시 `sys_cluster_reserved`로 자동 승격 (로직 편입 단계).
  - **Rule 3-3 (User Custom)**: `Group` 기능을 통해 명시적으로 묶인 클러스터는 사용자 레이어와 커스텀 배치를 최우선적으로 존중.
- **[백엔드 권위 기반 레이어 카운팅]**: `StateManager`에서 직접 계산한 `userCount`, `aiCount`를 UI로 전송. UI는 이를 기반으로 즉시 배지를 업데이트하여 "노드 추가 시 숫자가 안 올라가는 현상" 해결.
- **[불변성(Immutability) 강화를 통한 런타임 에러 해결]**: `TypeError: object is not extensible` 해결을 위해 `StateManager`의 상태 생성 로직을 비파괴적(Non-mutating) 구조로 전면 재편. 원본 모델을 오염시키지 않고 레이어를 재할당하는 안전한 파이프라인 수립.
- **[SSoT 일원화 완료]**: UI의 독자적인 정화(Sanitize) 로직을 제거하고 백엔드의 판정 결과를 100% 신밀하게 수용하도록 동기화. 이제 "사용자 레이어를 꺼도 AI 클러스터가 사라지지 않는" 진정한 위계 관리 가능.
