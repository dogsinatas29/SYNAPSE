### 3️⃣ 구현 방식 (비용 효율성)
이미 edge 데이터가 존재하므로 O(E) 1회 순회로 계산 가능:
```javascript
function getNodeStats(nodeId, edges) {
  let inCount = 0;
  let outCount = 0;
  const connected = new Set();

  for (const e of edges) {
    if (e.source === nodeId) {
      outCount++;
      connected.add(e.target);
    }
    if (e.target === nodeId) {
      inCount++;
      connected.add(e.source);
    }
  }

  return {
    in: inCount,
    out: outCount,
    total: inCount + outCount,
    connectedNodes: connected.size
  };
}
```

## 🛠️ 기술적 변경 사항

- **Performance Update:** `nodeStatsMap`을 통한 캐싱 (useMemo 활용)
```javascript
const nodeStatsMap = useMemo(() => {
  const map = new Map();
  nodes.forEach(n => {
    map.set(n.id, getNodeStats(n.id, edges));
  });
  return map;
}, [nodes, edges]);
```
