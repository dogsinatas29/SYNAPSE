3️⃣ 힌트 생성 엔진
function generateHints(stats) {
  const hints = [];

  const { in: inCount, out, connectedNodes, distribution } = stats;
  const total = inCount + out;
  const groups = Object.keys(distribution);
  const values = Object.values(distribution);

  // Rule 1
  if (groups.length >= 3) {
    hints.push("Multiple domains detected. Consider splitting by responsibility.");
  }

  // Rule 2
  const max = Math.max(...values);
  if (max / total >= 0.7) {
    const dominant = groups[values.indexOf(max)];
    hints.push(`Highly coupled with ${dominant}. Consider isolating.`);
  }

  // Rule 3
  if (out / total >= 0.7) {
    hints.push("High outbound dependency. Too many responsibilities.");
  }

  // Rule 4
  if (inCount / total >= 0.7) {
    hints.push("High inbound dependency. Consider abstraction layer.");
  }

  // Rule 5
  if (connectedNodes >= 30) {
    hints.push("Super node detected. Consider decomposition.");
  }

  return hints;
}

## 🧠 상세 설계 및 로직 (근거 연결 & 시맨틱 정체성)
1. **진단 엔진: Evidence-Based Hints**
   - **판단 근거 노출**: 단순 결론이 아닌, 해당 판단을 내린 수치적 증거(Ratio, Count)를 힌트에 포함합니다.
   - **비율 기반 해석**: `Group (Count/Total, Ratio%)` 형태의 포맷을 사용하여 의존성 심각도를 직관화합니다.
   - **가독성 최우선**: 소수점 2자리의 정밀도보다는 `Math.round()`를 통한 정수 백분율로 정보 전달력을 높입니다.

2. **Node Role Taxonomy (정체성 부여)**
   - **문제 탐지에서 역할 식별로**: 복잡한 노드를 '리팩토링 대상'으로만 보지 않고, 시스템 내 핵심 위상인 **Orchestrator, Controller, Hub, Leaf**로 분류합니다.
   - **우선순위 기반 식별**: `Leaf` → `Orchestrator` → `Controller` → `Hub` 순의 엄격한 판별 로직을 통해 노드의 설계 의도를 명확히 합니다.
   - **Role vs. Hint 분리**: 정체성(Role)은 상수적 속성으로, 진단(Hint)은 가변적 상태로 이원화하여 노드 정보를 구조화합니다.

3. **Triple Expression System (인지-집중-판단)**
   - **Color (정체성 인지)**: 역할별 고유 색상(Orange/Green/Blue/Gray)을 테두리와 글로우에 적용하여 캔버스 탐색 시 직관적 역할 판별 가능.
   - **Layer (노이즈 필터)**: `Hide Leaf Nodes` 토글을 통해 부수적인 리프 노드와 엣지를 한 번에 제거하여 핵심 아키텍처 구조에 집중.
   - **Priority (정량적 판단)**: 연결성 및 의존성 비율을 합산한 별점 시스템(`★★★☆`)을 도입하여 개선이 시급한 노드에 대한 정량적 지표 제공.

3. **Zero-Unknown 원칙 및 데이터 정합성**
   - **정체성 복구**: 클러스터 미배정 노드에 대해 `Type` 및 `Status` 분석을 선행하여 `external`, `ghost`, `unmapped` 등 시맨틱 라벨을 부여합니다.
   - **로직 단일화**: 통계 계산(`updateNodeStats`)과 툴팁 렌더링(`getGroupLabel`) 함수를 통합하여 상세 결합 리스트(└ ...)의 데이터 정합성을 100% 확보했습니다.

## ⚠️ 예외 처리 및 주의 사항
- **Role Hallucination 방지**: `if-else` 체인을 엄격히 타서 단 하나의 Role만 부여되도록 함 (Orchestrator이면서 동시에 Leaf일 수 없음).
- **Performance**: 노드 증가 시 매 프레임 Priority를 계산하지 않도록 `onDataChange` 이벤트(updateNodeStats) 시점에만 계산하여 캐싱.
- **Priority Stars 의도**: 단순히 수치가 아닌, "가장 먼저 리팩토링하거나 추상화해야 할 대상" 임을 직관적으로 전달 (★★★☆).
