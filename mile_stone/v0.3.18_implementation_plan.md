## 🧠 상세 설계 및 로직

### 1. 진단 엔진 (Diagnostic Logic)
- **데이터 소스**: `updateNodeStats()`에서 집계된 `in/out` 연결 수 및 `distribution` 맵.
- **분석 규칙**:
    - **R1 (Multi-Domain)**: 서로 다른 3개 이상의 레이어와 연결된 경우 ("God Object" 의심).
    - **R2 (Concentration)**: 특정 레이어에 70% 이상의 연결이 집중된 경우 (강결합 및 종속성 위험).
    - **R3 (High Fan-out)**: 출력 연결이 전체의 70% 이상인 경우 (책임 과다).
    - **R4 (High Fan-in)**: 입력 연결이 전체의 70% 이상인 경우 (병목 지점).
    - **R5 (Super Node)**: 총 연결 수가 30개 이상인 경우 (복잡도 임계점).
- **노이즈 방지**: 연결 수가 5개 미만인 노드는 분석 대상에서 제외.

### 2. 레이어 분포 집계 (Layer Distribution)
- 노드가 속한 `cluster_id`를 기반으로 `clusterLayerMap`을 생성하여 레이어 정보를 역추적.
- 각 노드 선택 시 연결된 상대 노드의 레이어 분포를 O(E) 복잡도로 실시간 계산.

### 3. UI 통합 (Node Summary Tooltip)
- 기존 툴팁 하단에 `Distribution` 섹션과 `Hints` 섹션을 동적으로 렌더링.
- KISS(Keep It Simple, Stupid) 원칙에 따라 간결한 텍스트 리터럴만 사용.
