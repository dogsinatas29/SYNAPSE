## 🧠 상세 설계 및 로직

### 1. 포커스 알고리즘 (Sorting & Selection)
단순한 가시성 제어가 아니라, 아키텍처적 중요도에 따른 리소팅을 수행합니다.
- **정렬 기준**: `priority`(0~4) DESC -> `connectedNodes` DESC -> `outRatio` DESC.
- **Top-N 임계치**: 초기값 10 (상황에 따라 동적 조절 가능성 열어둠).
- **맥락 보존(Context Expansion)**: Top-N 노드와 직접 연결된 모든 1-hop 인접 노드를 가시 집합(`focusNodeSet`)에 포함시켜 "왜 이 노드가 중요한지"를 주변 관계와 함께 설명함.

### 2. 가시성 인터셉터 (Strategic Visibility)
- **Node Filtering**: `this.focusTopNodes` 모드가 활성화되면, `focusNodeSet`에 존재하지 않는 모든 노드 렌더링 스킵.
- **Edge Filtering**: 양쪽 노드가 모두 가시 상태일 때만 엣지 렌더링 (Ghost Edge 방지).

### 3. 성능 설계 (Performance Constraint Compliance)
- **O(1) Access**: 렌더링 루프에서는 `focusNodeSet.has(id)` 수준의 O(1) 연산만 허용.
- **Event-Driven Pre-computation**: 포커스 대상 계산은 `updateNodeStats` 단계에서만 수행하며, 결과는 캐싱함.

## 🛠️ 기술적 변경 구성 요소

### 1. UI Layer (`ui/index.html`)
- **컨테이너**: `layer-controller` 패널 내부에 새로운 섹션 추가.
- **컨트롤**: `Focus Top Nodes` 토글 스위치 (ID: `btn-toggle-focus`).

### 2. Engine Layer (`ui/canvas-engine.js`)
- **상태 필드**: 
  - `this.focusTopNodes`: 모드 활성화 여부.
  - `this.focusNodeSet`: 계산된 가시 노드 ID 집합.
- **핵심 메서드 수정**:
  - `updateNodeStats()`: 분석 완료 후 Top-N 정렬 및 1-hop 확장 로직 추가.
  - `renderNode()`: `focusTopNodes` 활성화 시 필터링 로직 삽입.
  - `renderEdge()`: 필터링된 노드와 연결된 엣지 자동 스킵.

## ⚠️ 예외 처리 및 주의 사항
- **빈 노드 예외**: 노드가 10개 미만일 경우 모든 노드 노출.
- **ID 불일치**: 고스트 노드나 외부 라이브러리 노드도 중요도에 따라 포커스 대상이 될 수 있으므로 ID 매핑 정밀도 유지.
- **메모리 오버헤드**: `Set` 객체의 크기가 커지지 않도록 필터링 시점마다 `.clear()` 후 재발행.
