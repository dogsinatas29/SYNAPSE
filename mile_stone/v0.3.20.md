## 🧠 상세 설계 및 로직
- **Strategic Alignment Fix (A-1)**: 시뮬레이션 루틴을 엔진 렌더 루프에 통합하고 `isAligning` 타이머를 통해 애니메이션을 제어하여 "반응 없음" 현상 해결.
- **Safe-Spring Physics (Stability)**: 
  - **Velocity Clamping**: 노드가 화면 밖으로 탈출하는 것을 방지하기 위해 최대 속도(MAX_VELOCITY: 100) 제한.
  - **Damped Spring**: 복원력과 감쇄 계수를 정밀 튜닝하여 낮은 FPS 환경에서도 노드가 안정적으로 안착하도록 보정.
- **Path-Resilient Tree Engine**: 
  - 절대 경로와 상대 경로가 혼용되는 환경에서 프로젝트 루트를 정확히 찾아내는 **Segment Recovery** 로직 도입.
  - 계층 구조 구축 실패 시 데이터를 유실하지 않고 출력하는 **Flat Fallback** 모드 구현.
- **Node ID Uniqueness (SSoT)**: Rust의 `mod.rs`, `lib.rs` 중복 문제 해결을 위해 ID 체계를 파일 이름에서 **상대 경로(filePath)**로 전면 격상.
- **Role Detection Refinement**: 소규모 모듈에서도 아키텍처적 의미(Orchestrator, Controller 등)가 누락되지 않도록 임계값(Threshold)을 포괄적으로 조정.
- **Diagnostic Resilience**: 툴팁의 `Top Connections` 누락을 방지하기 위해 ID 불일치 시 파일명 기반으로 매칭하는 **Stem-based lookup** 적용.

## 🛠️ 기술적 변경 사항 - **Node & Edge Update:**
- **Path-based ID Sync**: 노드와 엣지의 식별자를 파일 경로로 통일하여 네임스페이스 충돌 및 참조 오류 원천 차단.
- **Semantic Grouping Unit**: `CanvasEngine.getSemanticGroup`으로 그룹 분류 로직을 단일화하여 통계와 시각 효과의 정합성 확보.

- **UI & Interaction:**
  - **Aggressive Loading Cleanup**: 데이터 로딩이 완료되는 즉시 `Loading project...` 오버레이를 강제 제거하여 UX 정체 방지.
  - **Auto Fit-to-View**: 프로젝트 최초 로드 시 노드들이 화면 밖에 있을 가능성에 대비하여 자동으로 센터링 및 줌 조절 실행.
  - **Hotfix (Render Crash)**: `renderHotspots2D` 및 `getGroupLabel`에서 발생하던 `null` 참조 런타임 에러 완전 가드 처리.

- **File Changes:**
  - `canvas-engine.js`: 물리 엔진 가속도 제어, 트리 빌더 경로 보강, 세이프 렌더링 도입.
  - `DataPipeline.ts`: Rust 확장자(`.rs`) 지원 및 경로 기반 ID 생성 파이프라인 구축.
  - `GeminiParser.ts`: BOM/UTF-8 공백 탄력성을 확보하여 아키텍처 원칙 로딩 안정화.
