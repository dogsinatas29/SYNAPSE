## 📅 작업 정보 - **상태:** ✅ Completed

## 🧠 상세 설계 및 로직

### 1. Semantic Hotspot Mapping (A-1)
- **Anchor-based Clusters**: 상위 노드(Top-N)를 앵커로 삼아 1-hop 이웃(비Leaf 노드)을 하나의 기능적 영역으로 그룹화.
- **Dynamic Bounding Box**: 클러스터 노드들을 감싸는 최소 사각형을 실시간 계산하고 60px 패딩을 적용하여 영역화.
- **Overlap Merge**: 50% 이상 중첩되는 영역은 자동으로 하나의 거대 핫스팟으로 병합하여 시각적 복잡도 감소.
- **Visual Style**: 역할(Role) 컬러 기반의 Soft Fill(0.05) 및 Dashed Boundary 적용.

### 2. Strategic Alignment 2.0 (Spring Bias & Grid-spread)
- **Spring Bias Simulation**: 노드 단위의 강제 스냅 대신, `ALGIN_STRENGTH(0.04)` 기반의 부드러운 인력을 도입하여 그래프 본연의 균형과 계층을 보존.
- **Order from Chaos**: 무질서한 그래프를 '바둑판식 설계도' 형태로 유연하게 재편.

### 2.1 Layout & Hotspot Refinement (v0.3.20/v0.4.1)
- **Horizontal Expansion**: `COLUMN_WIDTH`를 350px로 확장하여 세로로 쏠린 레이아웃을 수평적 아키텍처 다이어그램으로 최적화.
- **Vertical Constraint**: 핫스팟 생성 시 Y축 거리 제한(600px)을 추가하여 비정상적으로 긴 '수직 영역' 발생 원천 차단.
- **Improved Cohesion**: 영역 간의 물리적 정합성을 높여 의미 있는 기능 단위로 더 명확하게 시각화.

### 3. Edge Bundling Lite (A-2)
- **Shared Control Point**: 동일 소스에서 파생된 엣지들을 하나의 '번들'로 묶어 흐름 가시화.
- **Quadratic Bezier Path**: 공유 제어점(Shared CP)을 통해 선들이 중앙으로 합류했다가 목적지에서 퍼지는 유려한 경로 구현.
- **Complexity Reduction**: 엣지 난사 현상을 '의미 있는 흐름'으로 요약하여 시각 효율 극대화.

### 4. Rendering & Hygiene Patch
- **Ghosting Fix**: 캔버스 렌더링 루프 시작 시 DPR을 고려한 완벽한 버퍼 클리어를 통해 잔상(Trails) 문제 해결.
- **Ghost Node Purge**: 삭제된 테스트 파일(`test_new_session.js`)의 흔적을 `project_state.json` 및 `synapse_history.json`에서 완전 소거하여 데이터 무결성 회복.
