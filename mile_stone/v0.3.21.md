1️⃣ 핵심 아이디어 (Lite 방식)

“진짜 번들링”이 아니라 시각적 수렴(convergence) 만 만든다

👉 각 엣지를:

직선 → 약한 곡선(Bezier)

👉 곡선의 control point를 “중앙으로 살짝 당김”

2️⃣ 알고리즘 설계
Step 1. 기본 벡터 계산
dx = target.x - source.x
dy = target.y - source.y
dist = sqrt(dx*dx + dy*dy)
Step 2. 수직 방향 벡터 (퍼짐 방지용)
nx = -dy / dist
ny = dx / dist
Step 3. 중앙점 + 약간의 오프셋
mx = (source.x + target.x) * 0.5
my = (source.y + target.y) * 0.5
Step 4. “번들링 강도” 적용
bundleStrength = min(dist * 0.15, 40)
Step 5. Control Point 생성

👉 핵심

cx = mx + nx * bundleStrength
cy = my + ny * bundleStrength
Step 6. Bezier로 렌더링
ctx.moveTo(source.x, source.y)
ctx.quadraticCurveTo(cx, cy, target.x, target.y)
3️⃣ 같은 방향 엣지 묶기 (핵심 업그레이드)
방향 quantize
angle = atan2(dy, dx)
bucket = round(angle / (PI / 8))   // 16방향

👉 같은 bucket끼리 같은 offset 사용

groupOffset = bucket * 3  // 살짝만 차이
cx += nx * groupOffset
cy += ny * groupOffset
