## 🧠 상세 설계 및 로직

### 1. 렌더링 엔진 안정화 (Blackout Recovery)
- **Syntax & Reference Error 박멸**: `getStem` 중복 선언 및 `nodeName` 참조 오류 등 엔진을 멈추게 하던 모든 구문 오류를 제거.
- **Null-Safe 데이터 처리**: `getStem` 헬퍼를 도입하여 malformed ID나 null 데이터가 들어와도 엔진이 중단되지 않도록 방어막 구축.

### 2. 2D/3D 시각적 일치 (Visual Parity)
- **형상 통일**: 불필요한 평행사변형 오버라이드 로직을 제거하고, `external` 노드를 포함한 모든 요소를 박스(Box) 형태로 통일.
- **색상 정밀도**: WebGL `hexToRgb` 파서를 개선하여 8자리(RGBA) 핵스 코드를 완벽 지원, 2D와 동일한 Teal 외곽선 색상 구현.
- **테두리 존재감 강화**: 3D 셰이더의 `borderThreshold`를 `-0.04`로 확장하여 2D 모드와 시각적 부피감을 동기화.

### 3. 지능형 툴팁 시스템 (Senior's Prescription)
- **Debounced Intelligence**: 100ms 지연 로직을 적용하여 배치 검증 및 데이터 갱신 시점과의 충돌 방지.
- **Identity 실명제**: `SYNAPSE_THEME.getNodeIcon`을 결합하여 연결 노드의 아이콘과 실명을 툴팁에 동시 노출.
- **LOD Guard**: 줌 레벨 0.4 이하에서는 상세 리스트를 숨기고 고해상도 뷰에서만 정보를 노출하는 최적화 적용.
- **레이아웃 개선**: 유연한 너비 조정 및 자동 줄바꿈을 통해 텍스트 잘림 현상 방지.
