# 🚀 Implementation Plan - Milestone v0.3.22
## 📅 Milestone Info
- **Version:** v0.3.22
- **Objective:** 100% synchronization between 2D (Canvas) and 3D (WebGL) engines.
- **Status:** 🏗️ Planned

## 🧠 상세 설계 및 로직 (Detailed Design)

### 1. Unified Theme Architecture
- **synapse-theme.js** (Proposed): Create a shared configuration for both `canvas-engine.js` and `webgl-renderer.js`.
- **Constants to unify**:
  - `ZOOM_THRESHOLD_LOD`: 0.4 (Satellite vs Detail)
  - `NODE_ICON_OFFSET`: `{ x: 5, y: 5 }`
  - `COLORS`: Standard Gruvbox/Synapse palette (e.g., `#83a598`, `#fb4934`, `#8a2be2`).
  - `ICON_MAPPING`: Map node types to emojis (📄, ⚡, 📁, etc.).

### 2. Node & Status Synchronization
- **2D Engine (`canvas-engine.js`)**:
  - Update `getNodeStyle` to use the unified theme.
  - Fix `renderNode` to strictly follow the `(5, 5)` icon placement.
  - Implement full status badge set (Necrosis, Tombstone, Mine, etc.).
- **WebGL Engine (`webgl-renderer.js`)**:
  - Update `updateNodeData` to pass the correct status codes (0-10+) to the shader.
  - **Shader Upgrade**:
    - Support `vStatus` for all new states (Necrosis static noise, Warning pulse, Ghost dashed border).
    - Implement High DTR purple glow in the fragment shader.

### 3. Coordinate Back-propagation (Hybrid Parity)
- **Goal**: Align 2D badges (Approval, Hazard) exactly with WebGL nodes.
- **Logic**:
  - WebGL renderer must calculate the final screen position of each node (including any curvature/distortion) and expose this data.
  - 2D Overlay layer reads this data to position emojis.

### 4. Edge & Flow Markers
- **Styles**: Standardize thickness and dash patterns.
- **Icons**: Edge icons (🔗, 📡, 📊) must be rendered at the midpoint (bezier center).
