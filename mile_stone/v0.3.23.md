# 🚀 Milestone v0.3.23 - Hybrid Blacklist System

## 📅 작업 정보 - **상태:** ✅ Completed
- **관련 마일스톤:** [v0.3.22](v0.3.22.md)
- **목표:** 그래프 폭발 방지를 위한 하이브리드 블랙리스트 방어 체계 구축 및 런타임 안정성 극대화 (Level 2 Hardening)

## 🧠 상세 설계 및 로직
- **Hybrid Defense**: `GraphModel`의 실시간 차단(Discard)과 `Snapshot`의 전수 재빌드(Rebuild)를 결합하여 성능과 무결성 동시 확보.
- **Adaptive Selection**: 그래프 크기와 데이터 변화율에 따라 `Full Rebuild`와 `Incremental Purge`를 지능적으로 선택.
- **Orchestration**: `BlacklistOrchestrator`를 통한 이벤트 기반의 중앙 집중식 제어 구조 확립.
- **L2 Hardening**: O(1) 경로 매칭(Pre-normalized Cache), OS Semantics 반영(대소문자 구분), 프레임 예산(10ms) 기반의 청킹 프로세스 도입.
- **Intelligent Onboarding**: 사용자의 첫 진입 장벽을 낮추기 위해 `synapse.config.json` 자동 생성 및 에디터 즉시 연결 커맨드 구현.

## 🛠️ 기술적 변경 사항
- **Node Update**: `GraphModel.addNode`에 블랙리스트 가드 추가, 런타임 주입 차단.
- **Build Guard**: `BM_SYNC_VER=v0.3.23` 환경 변수 강제 및 프로덕션 컴파일 에러(TS2749, TS1128) 수정.
- **UI/Layout Fix**: 캔버스 리사이즈 로직 전면 수정.
  - 강제 400px 고정 로직 제거 및 CSS `100%` 위임.
  - 초기 로딩 시 `clientHeight: 0` 이슈 대응을 위한 뷰포트 참조 폴백 적용.
- **File Changes**: 
  - [src/extension.ts](../src/extension.ts): `synapse.openBlacklistConfig` 커맨드 및 자동 생성 로직 추가.
  - [ui/index.html](../ui/index.html): 캔버스 CSS `width/height: 100%` 강제.
  - [ui/canvas-engine.js](../ui/canvas-engine.js): `resizeCanvas` 로직 안정화.

## ⚠️ 예외 처리 및 주의 사항
- `restoreSnapshot`은 항상 원자적(Atomic)이어야 하며, 부분적 수정을 금지함.
- 대규모 그래프 처리 시 UI 프리징 방지를 위해 `requestAnimationFrame` 및 프레임 예산(10ms) 기반의 청킹(Chunking) 엄격 준수.
- 에디터 분할(블랙리스트 설정 열기) 시 캔버스 웹뷰의 리사이즈 이벤트 정합성 확보.

## 📝 Post-Work Log (작업 후 기록) & Release Notes

### 🌟 Summary / 요약
This release introduces the **Hybrid Blacklist System** and **Explorer Context Menu Integration**, significantly reducing noise in large-scale project analysis and maximizing user convenience. It also resolves canvas layout collapse issues during editor splitting.

이번 릴리스는 대규모 프로젝트 분석 시 발생하는 노이즈를 효율적으로 제거하고, 사용자 경험(UX)을 극대화하는 **하이브리드 블랙리스트 시스템**과 **탐색기 우클릭 등록** 기능을 도입했습니다. 또한, 에디터 분할 시 발생하던 캔버스 레이아웃 붕괴 문제를 해결하여 시각적 안정성을 확보했습니다.

### ✨ Key Updates / 주요 업데이트

1. **🚫 Hybrid Blacklist System (L2 Hardening) / 하이브리드 블랙리스트 시스템**
   - **O(1) Path Matching**: 대규모 경로 데이터에서도 성능 저하 없이 블랙리스트 여부를 즉시 판별합니다.
   - **Absolute Path Intelligence**: 리눅스 및 윈도우의 절대 경로를 지능적으로 감지하여 프로젝트 루트 기준의 상대 경로로 정규화 후 체크합니다.
   - **Real-time Engine Sync**: 블랙리스트 설정 변경 시 메모리 상의 엔진 상태가 즉시 동기화되어 별도의 재시작 없이 캔버스에서 노드가 제거됩니다.

2. **🖱️ Explorer Context Menu Integration / 탐색기 컨텍스트 메뉴 통합**
   - **Add to Blacklist**: VS Code 탐색기에서 파일이나 폴더를 우클릭하여 즉시 분석 대상에서 제외할 수 있습니다.
   - **Instant Refresh**: 등록과 동시에 캔버스 그래프가 자동으로 갱신되어 분석 제외 대상이 즉시 사라집니다.

3. **🖼️ Canvas Layout Recovery / 캔버스 레이아웃 복구**
   - **Flex-based Resizing**: 하드코딩된 400px 높이 제한을 제거하고, CSS Flexbox를 기반으로 캔버스 크기를 유연하게 조정합니다.
   - **Resizing Stability**: 에디터 그룹 분할 또는 창 크기 조절 시 캔버스가 잘리거나 찌그러지는 현상을 완벽하게 해결했습니다.

## 🚫 블랙리스트 등록 및 설정 가이드 (User Guide)
사용자는 다음 세 가지 방법으로 분석 제외 대상을 관리할 수 있습니다.

1. **자동 생성 및 열기 (추천)**: VS Code 상단 메뉴 바의 **톱니바퀴 아이콘(Configure Blacklist)**을 클릭하세요.
2. **탐색기(Explorer) 우클릭**: 제외하고 싶은 폴더나 파일을 우클릭한 후 **[SYNAPSE: Add to Blacklist]**를 선택하세요. (가장 간단한 방법!)
   - 선택 시 즉시 `synapse.config.json`에 반영되며 캔버스에서 해당 노드가 실시간으로 사라집니다.
3. **수동 편집**: `synapse.config.json` 파일을 직접 편집하세요.
   - 모든 경로는 프로젝트 루트 기준의 **상대 경로**로 작성해야 합니다.
