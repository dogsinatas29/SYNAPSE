# 🚀 Milestone v0.3.28 - Accel:Off 2D 엣지 렌더링 버그 수정 (4-Fix Patch)

## 📅 작업 정보
- **상태:** ✅ Completed
- **관련 마일스톤:** [v0.3.27](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/mile_stone/v0.3.27.md)
- **목표:**
  - Accel:ON(WebGL) 상태에서 정상 렌더링되던 엣지가, Accel:OFF(2D Canvas) 전환 시 대부분 사라지고 노드에 검은 원형 도트가 나타나는 복합 버그를 수정한다.
  - 2D 엣지 핫패스 내의 O(N) 순회 연산을 완전 제거하여 프레임 루프 원칙(O(1) 제약)을 준수한다.
  - 화면 축소(Zoom-out) 시 서브픽셀 렌더링으로 인해 발생하는 엣지 가시성 상실 버그를 수정하여 Accel:ON/OFF 모드 간 엣지 시각적 패리티(가시성 일치)를 달성한다.

## 🧠 상세 설계 및 로직

### 복합 버그 원인 분석

**Bug #1 — `isPathSelected` 핫패스 내 O(N) 순회:**
- `renderEdge()` 내부에서 `Array.from(this.selectedNodes).some(n => ...)` 를 모든 엣지마다 실행.
- Accel:ON 시엔 WebGL이 엣지를 담당하므로 이 코드가 badge 경로에서만 호출되어 증상 은닉.
- Accel:OFF 시엔 272개 엣지 × selectedNodes 수만큼 매 프레임 전체 순회 → CPU 폭주로 렌더 누락.

**Bug #2 — 2D 엣지 기본 알파 0.3:**
- 선택/호버되지 않은 일반 엣지의 `finalAlpha`가 `0.3`으로 고정.
- Accel:ON의 WebGL은 자체 알파 처리로 커버, Accel:OFF 2D에서만 거의 투명하게 렌더링됨.

**Bug #3 — `isGraphDataDirty` 2D 경로 미초기화:**
- WebGL 경로(Accel:ON)에서는 렌더 종료 시 `isGraphDataDirty = false` 처리.
- 2D 경로(Accel:OFF) `else` 블록에는 해당 초기화 코드 누락 → 매 프레임 캐시 전체 재빌드.

**Bug #4 — Pulse 애니메이션 `globalAlpha` 누수:**
- `[v0.3.15] Pulse Animation` 블록에서 `ctx.fill()` 후 `globalAlpha` 미복원.
- `renderEdge()` 종료 후 오염된 `globalAlpha`(= `finalAlpha`, 0.3~0.5) 상태로 `renderNode()`가 실행.
- 노드 배경이 거의 투명한 상태로 그려지면서 **검은 원형 도트** 현상 발생.
- Accel:ON: `renderEdge`가 badge 경로만 처리하므로 pulse 코드 미진입 → 증상 없음.

**Bug #5 — Canvas2D Zoom Out 시 서브픽셀 감쇄 현상(Sub-pixel anti-aliasing Fade-out):**
- Canvas2D는 화면을 축소할 때 엣지 굵기가 고정(`style.lineWidth`)되어 렌더링 시 스케일 변환의 영향을 직접 받음 (예: Zoom 0.24일 때 2px 엣지가 0.48px로 그려짐).
- 안티-앨리어싱에 의해 두께가 1픽셀 미만인 선은 투명도가 강제로 낮아지고, 기본 알파 0.5와 결합되어 검은 화면에서 완전히 보이지 않게 되는 문제.
- 핫패스 후반부에 계산된 `lineWidth`가 `style.lineWidth`로 그대로 덮어씌워지는 버그 존재.

**Bug #6 — 엣지 번들링 로직에서 클러스터 크기 누락으로 인한 좌표 NaN 산출 (Silent Fail):**
- `renderEdges2D()`의 `edgeGroupsCP` 계산 과정에서, 저장된 `cluster.width` 또는 `cluster.height`가 정의되지 않은(Undefined) 경우 `clusterCenterX/Y`가 `NaN`으로 계산됨.
- `renderEdge()`가 이 `NaN` 좌표를 제어점(`cpX`, `cpY`)으로 넘겨받아 `ctx.quadraticCurveTo(NaN, NaN)`을 호출하게 되어 선과 화살표 그리기가 조용히 실패(Silently skipped)함.
- 배지 렌더러는 `NaN` 방어 로직이 있어 중간값으로 폴백하여 정상 출력되므로 "배지는 보이나 선이 안 보이는" 기괴한 증상을 유발함. WebGL은 이 번들링 연산을 쓰지 않아 증상이 없었음.

**Bug #7 — Canvas 2D 엣지 왜곡 (Downward Belly Spaghetti) 현상:**
- 2D 모드의 번들링 연산이 `targetClusterId`의 중심 좌표(`groupCPCenter.y`)에 과도하게 종속되도록 하드코딩 되어있음 (`cpY = (midY * 0.4 + groupCPCenter.y * 0.6) - 100`).
- 이로 인해 목적지가 화면 하단일 경우, 출발지가 어디든 상관없이 제어점(Control Point)이 극단적으로 밑으로 끌려내려가 거대한 U자형 왜곡 굴곡(Downward Belly)이 생성됨.
- 반면 WebGL은 노드 간의 거리와 직교 법선 벡터(Perpendicular Normal Vector)를 기반으로 하여 대칭적이고 아름다운 활꼴(Arch)을 계산함.

### 해결 전략

- `render()` 루프 시작 시 `this._selectedNodeIds = new Set(...)` 를 **1회만** 계산하고 캐싱.
- `renderEdge()` 내부는 `this._selectedNodeIds.has()` O(1) 조회로 교체.
- 2D 기본 알파를 `0.3 → 0.5`로 상향하여 WebGL 패리티 달성.
- 2D `else` 경로 종료 후 `isGraphDataDirty / isEdgeDirty / isTextDirty = false` 추가.
- Pulse 블록 종료 후 `this.ctx.globalAlpha = 1.0` 복원.
- **최소 화면 두께 하한선 강제:** Zoom 역수를 기반으로 하여 화면(Screen Space)에서 엣지가 최소 2픽셀 이상으로 렌더링 되도록 동적으로 굵기 보정식(Calculated Line Width) 추가 및 덮어씌우기 버그 해결.
- **번들링 제어점 예외 처리:** 클러스터 크기가 없을 때 기본값(Width 400, Height 300)을 제공하여 `NaN` 발생을 원천 차단.
- **번들링 수학적 패리티 동기화 (O(N) 병목 제거):** 기존 2D의 클러스터 의존적 제어점 공식을 완전히 폐기하고, WebGL의 직교 법선 벡터(Perpendicular Normal Vector) 연산식을 100% 동일하게 이식. 프레임 렌더 루프 상단의 거대한 `bundles` O(N) 순회 로직을 삭제하여 성능 극대화 및 왜곡 제거.

## ⚠️ 예외 처리 및 주의 사항

- `_selectedNodeIds`는 `render()` 내에서 **캐시 재빌드 블록 이후** 계산되어야 함. 순서 변경 금지.
- `globalAlpha` 복원은 Pulse 블록 내 `forEach` 루프 **종료 직후**, `if` 블록 **내부**에 위치해야 함. Pulse가 없을 때 불필요한 상태 쓰기를 방지.
- `isEdgeDirty`, `isTextDirty` 초기화는 2D 경로에도 추가되었으나, 이 플래그들이 WebGL에서 의미 있게 사용되므로 2D 전환 후 첫 프레임에서만 한 번 초기화되는 것이 안전함.
