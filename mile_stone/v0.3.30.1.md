## 🧠 상세 설계 및 로직
- **상호 배타적 툴팁 병합 로직 (Z-Index Bleeding 해결)**
  - 노드 요약 정보(Node Summary)와 엣지 검증 사유(Edge Validation) 팝업이 같은 캔버스 좌표에서 겹쳐 렌더링되는 문제 식별.
  - 마우스 포인터에 노드와 엣지가 동시에 감지될 경우, 엣지 전용 툴팁 표시를 억제하고 해당 정보를 노드 요약 툴팁(`showNodeSummary`)의 인자로 전달.
  - 노드 요약 툴팁 하단에 `[Edge] Validation` 영역을 동적으로 추가하여 두 정보를 하나의 팝업으로 매끄럽게 병합(Merge) 렌더링함.
- **Tree View 모드 비활성화**
  - 그래프/노드 중심의 시각화 아키텍처 철학과 상충되고, 빈 화면 노출 등 기능상 오류가 잦은 `Tree View` 모드 식별.
  - UI 상단 View 컨트롤러에서 `data-mode="tree"` 버튼을 주석 처리하여 사용자의 오진입 원천 차단.

#### 🧠 상세 내용
**1. 툴팁 병합(Merge) 로직 도입을 통한 시각적 겹침 문제 해결**
- **문제점:** 화면 중앙에서 노드와 엣지에 마우스 포인터가 겹쳤을 때, `노드 요약 정보(Node Summary)` 팝업과 `엣지 검증 사유(Edge Validation)` 팝업이 동시에 출력되면서 내용이 겹쳐 보여 읽을 수 없는 문제가 있었습니다.
- **해결책:** 두 툴팁을 무작정 끄지 않고, **하나의 창으로 매끄럽게 병합(Merge)** 되도록 개선했습니다. 노드와 엣지를 동시에 가리킬 때, 노드 정보창 하단에 `[Edge] Validation` 섹션이 동적으로 렌더링됩니다. 빈 공간의 엣지를 가리킬 때는 기존처럼 엣지 전용 정보창이 뜹니다.

**2. Tree View 모드 진입 완전 차단**
- **문제점:** 시각적인 노드-엣지 아키텍처 철학과 맞지 않으며, 빈 화면을 띄우는 등 버그가 잦은 `Tree View`가 혼란을 주었습니다.
- **해결책:** 유지보수 비용을 줄이고 본질적인 그래프 기능에 집중하기 위해 상단의 `View` 메뉴에서 `Tree View` 모드로 진입하는 버튼 자체를 주석 처리하여 완전 비활성화했습니다.

### 🇺🇸 English

#### 🎯 Key Updates
- **UI/UX Improvement:** Fixed tooltip overlapping (Z-Index Bleeding) bug in the center of the screen.
- **UX Optimization:** Completely disabled the problematic Tree View mode in the UI.

#### 🧠 Details
**1. Resolved Visual Overlap by Introducing Tooltip Merge Logic**
- **Problem:** When hovering over a point where a node and an edge intersect, the `Node Summary` popup and `Edge Validation` popup were displayed simultaneously, causing the text to overlap and become unreadable.
- **Solution:** Instead of arbitrarily hiding one tooltip, they are now **seamlessly merged into a single window**. When hovering over both a node and an edge, the `[Edge] Validation` section is dynamically rendered at the bottom of the node info window. Hovering over an edge in empty space will still display the dedicated edge info window.

**2. Completely Disabled Tree View Mode Access**
- **Problem:** `Tree View` caused confusion as it did not align with the visual node-edge architecture philosophy and frequently encountered bugs, such as rendering a blank screen.
- **Solution:** To reduce maintenance costs and focus on essential graph functionalities, the button to enter `Tree View` mode in the top `View` menu was commented out, completely disabling the feature.

#### 🛠 Technical Changes
- `ui/canvas-engine.js` & `demo/canvas-engine.js`: Extended the `showNodeSummary(x, y, node, stats, edgeReason)` signature and added conditional HTML merge insertion. Integrated mutually exclusive rendering calls on mouse hover (`handleMouseMove`).
- `ui/index.html` & `demo/index.html`: Commented out the `<button class="btn" data-mode="tree">Tree View</button>` component HTML.
