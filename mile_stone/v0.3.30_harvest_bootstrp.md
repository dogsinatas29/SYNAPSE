# Programming Principles

## 1. Think Before Coding

추측하지 않는다.

명세가 모호하면 구현하지 않는다.

요구사항이 명확하지 않으면 질문한다.

코드 작성 전에 목표를 설명한다.

---

## 2. Simplicity First

가장 단순한 해결책을 우선한다.

필요하지 않은 추상화를 만들지 않는다.

필요하지 않은 기능을 추가하지 않는다.

---

## 3. Minimal Change

기존 동작을 깨지 않는다.

요구된 범위만 수정한다.

전체 재작성보다 최소 수정 우선.

---

## 4. Goal → Plan → Implementation → Validation

모든 작업은 다음 순서를 따른다.

Goal

↓

Plan

↓

Implementation

↓

Validation

검증 실패 시 다음 단계 진행 금지.

---

## 5. No Hallucinated APIs

존재하지 않는 API를 만들지 않는다.

존재 여부를 확인한다.

---

## 6. Validation First

모든 단계는 검증 테스트를 가진다.

테스트 통과 전 완료로 간주하지 않는다.
