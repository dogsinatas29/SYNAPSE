# SYNAPSE v0.3.30

# Phase 1 - Project Boundary Foundation

---

# Mission

협업 기능(Session, Layer, Verify, Harvest)의 기반이 되는 프로젝트 경계를 확립한다.

모든 후속 시스템은 Phase 1에서 정의된 Project Boundary를 반드시 준수해야 한다.

---

# Goal

다음 조건을 만족해야 한다.

1. 프로젝트 간 접근이 불가능하다.
2. 프로젝트 외부 파일 접근이 불가능하다.
3. 프로젝트 상태를 Snapshot으로 저장할 수 있다.
4. 프로젝트의 Symbol Index를 생성할 수 있다.
5. Server가 Project Metadata의 단일 관리자가 된다.

# Implementation Log

## Created Files

### `src/core/ProjectMetadata.ts`
- **Singleton** — Server(Extension)가 단일 소유
- `data/project_metadata.json`에 저장
- **Fields:** projectUUID, projectName, version, createdAt, updatedAt, snapshotCount, metadataVersion
- `validatePath(targetPath)` — 프로젝트 경계 검증 (path.resolve → startsWith root)
- `initialize(projectRoot, projectName?)` — 경로 설정, 기존 파일 있으면 로드, 없으면 기본 생성
- `loadSync()` / `saveSync()` — 동기 파일 I/O (Node fs 사용, vscode 의존성 없음)

### `src/core/SymbolIndex.ts`
- **Singleton** — 프로젝트 단일 Symbol Registry
- **Components:**
  - `FolderTree` — 계층형 디렉토리 구조 (path, name, children, fileCount)
  - `FileEntry` — 파일별 메타데이터 (path, extension, size, isSource, isDocumentation, functionCount, classCount)
  - `FunctionEntry` — 함수 단위 카탈로그 (functionId, functionName, filePath, className, lineNumber)
- `rebuildFromFiles(files[])` — 파일 목록으로 전체 인덱스 재구축
- `addFunction()` — Symbol Index에 함수 등록
- 소스 확장자: .py .ts .js .rs .cpp .c .go .java .kt .swift
- 문서 확장자: .md .mdx .rst .txt

## Modified Files

### `src/types/schema.ts`
- `ProjectMetadata` interface 추가
- `GraphSnapshot` 확장: `snapshotVersion`, `metadata` (projectUUID, projectName, snapshotCount), `checksum`

### `src/core/SnapshotSystem.ts`
- **Versioned save:** snapshotVersion 자동 증가
- **Checksum:** SHA-256 기반 무결성 검증 (저장 시 생성, 복구 시 검증)
- **Metadata stamp:** ProjectMetadata의 UUID/Name/SnapshotCount를 스냅샷에 포함
- **History 확장:** 최대 10→20개, 각 entry에 version/checksum 필드 추가
- `restore()`에 checksum 검증 로직 (불일치 시 경고, 복구는 진행)

### `src/core/DataPipeline.ts`
- **Security boundary:** `processFiles()` 진입 시 ProjectMetadata.validatePath()로 모든 파일 경계 검증
- **SymbolIndex integration:** 파일 스캔 완료 후 `symbolIndex.rebuildFromFiles()` + 각 파일의 function 목록을 `addFunction()`으로 등록

### `src/extension.ts`
- `ProjectMetadata` / `SymbolIndex` 초기화 코드 추가 (activate() 내 workspaceFolder 확인 후)
