# SYNAPSE v0.3.30

# Phase 2 - Identity & Session Foundation

---

# Mission

프로젝트 참여자와 권한을 관리하고 협업 세션을 생성하기 위한 기반 시스템을 구축한다.

Phase 2는 네트워크 전송(SSH)을 다루지 않는다.

Phase 2의 목적은 다음 질문에 답하는 것이다.

* 누가 프로젝트에 참여하는가?
* 어떤 권한을 가지는가?
* 어떤 세션에 참여하는가?
* 서버는 이를 어떻게 관리하는가?

---

# Goal

다음 기능을 제공한다.

* User Identity
* Role Management
* Permission Management
* Project Runtime Initialization
* Session Lifecycle
* Session Registry
* Join / Leave Workflow

---

# Core Principle

권한은 사용자를 기준으로 계산하지 않는다.

권한은 다음 기준으로 계산한다.

Project + Role

---

# Example

Kim

Project AXON

Role = Lead

---

Kim

Project SYNAPSE

Role = Member

---

동일 사용자가 프로젝트마다 다른 권한을 가질 수 있어야 한다.

---

# Identity System

모든 참여자는 Identity를 가진다.

Identity는 프로젝트 참여자를 식별하기 위한 로컬 식별자이다.

---

# Identity Model

Identity

* user_id
* display_name

---

# Identity Rules

Identity는 Server가 생성한다.

Client는 Identity를 임의 생성할 수 없다.

---

Identity는 프로젝트 단위로 관리된다.

---

# Non Goals

다음 기능은 제공하지 않는다.

* Google Login
* Github Login
* Microsoft Login
* 외부 계정 연동

---

SYNAPSE는 자체 Local Identity만 사용한다.

---

# Role System

프로젝트 내 역할을 정의한다.

---

# Role Types

Lead

Member

---

# Lead Permissions

* Create Session
* Close Session
* Approve Join Request
* Reject Join Request
* Verify
* Harvest
* Remote Edit
* Disconnect Client

---

# Member Permissions

* Join Session
* Leave Session
* Submit Changes
* Receive Commands

---

# Permission Model

Permission은 Role로부터 파생된다.

---

# Permission Types

* Read Layer
* Write Layer
* Verify
* Harvest
* Approve Join
* Close Session
* Remote Edit

---

Member는 Permission을 직접 소유하지 않는다.

Role을 통해 간접적으로 획득한다.

---

# Runtime Initialization

프로젝트를 열 때 Runtime이 시작된다.

---

# Runtime Startup Flow

Project Open

↓

Load Project Metadata

↓

Load Symbol Index

↓

Initialize Runtime Database

↓

Runtime Ready

---

Session 생성은 Runtime Ready 상태에서만 가능하다.

---

# Runtime Ownership

Project Runtime은 Server가 소유한다.

Client는 Runtime을 소유하지 않는다.

---

# What Phase 2 Does NOT Do

다음 기능은 Phase 2 범위에 포함되지 않는다.

* SSH Authentication
* SSH Transport
* Remote Layer Synchronization
* Submission Snapshot Creation
* Submission Transfer
* Verify Engine
* Harvest Engine
* Ownership System
