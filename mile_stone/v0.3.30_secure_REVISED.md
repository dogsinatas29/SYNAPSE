# SYNAPSE v0.3.30 Secure Architecture

# Core Principles

## Principle 1 — Server Authority

Architect(Server)는 유일한 Source Of Truth이다.

Client는 Authority가 아니다.

## Principle 2 — Project Boundary First

기존 동일

## Principle 3 — Restricted SSH Model

허용:

- 로그인
- 프로젝트 조회
- 파일 조회
- 파일 저장
- Layer 비교
- Harvest

제출(Submission) 개념 제거

---

# Authority Model

Server만 Authority가 될 수 있다.

Client 변경은 공식 상태가 아니다.

---

# Harvest Session Security

## Workspace Lock Rule

Harvest Session 시작 시

Client Workspace Lock

Lock 상태에서는:

- 편집 금지
- Synapse 작업 금지
- 상태 변경 금지

## Lock Ownership

Server만 Lock 생성 가능

Client는 Lock 해제 불가

## Unlock Rule

Harvest 종료 후

Server가 Unlock 수행

# Final Definition

SYNAPSE는 Submission 기반 협업 시스템이 아니다.

SYNAPSE는 Server Authority 기반 Session 협업 시스템이다.

Harvest Session 동안 Client Workspace는 Lock 된다.

Server만 Authority가 될 수 있다.
