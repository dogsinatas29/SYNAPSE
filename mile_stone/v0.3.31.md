## 🧠 상세 설계 및 로직 
- **전역 블랙리스트 (Global Blacklist) 누락 교정:**
  - 하베스트(Harvest)로 받아온 타 클라이언트 소스가 `.synapse/clients/`에 저장됨에도, `RuleEngine`에서 이를 무시하지 않아 로컬 데이터 파이프라인에서 무차별적으로 파싱되는 환각 현상 발생. 
  - 네트워크 단절 시 `project_state.json` 폴백 과정에서 이 오염된 상태가 렌더링되어 유령 노드가 무한정 남는 현상을 수정.
  - `.synapse` 디렉토리를 전역 블랙리스트 `ignoreFolders`에 명시적 등록.

- **Role-based 정렬 (Spring Alignment) 물리 엔진 안정화:**
  - **무한 피드백 루프 파괴:** 클러스터 중심점 계산 로직이 "매 프레임마다 현재 노드 좌표 기준"으로 연산되어 노드가 이동할수록 중심점이 흔들려 우주로 튕겨나가는 불안정성을 수정. 목표(Target) 좌표 산출을 시뮬레이션 진입 전에 단 1회(Once)만 고정.
  - **동적 충돌 회피 기동:** 하드코딩된 X축 오프셋(`Leaf: -300`, `Hub: -100`)을 폐기. 대신 각 역할(Role) 내의 열(Column) 개수를 역산하여 겹치지 않게 가변적 공간 할당(`totalCols` 기반).

- **컴팩트 레이아웃 (Compact Layout) 알고리즘 도입:**
  - 기존 최대 3열 고정 배치로 인해 세로로 무한정 길어지던 현상을 방지하고자, 노드 개수의 제곱근(`Math.sqrt`)을 구하여 정사각형 대형(Square-ish Grid)을 이루도록 진형(Formation) 계산식 교체.
  - 노드 간 간격(COLUMN_WIDTH: 350→250, ROW_HEIGHT: 160→80)을 대폭 줄여 한 화면(Viewport) 안에서 아키텍처를 쉽게 조망할 수 있도록 시각적 밀집도 최적화.

- **클러스터 초기 진형(Spacing) 대폭 압축:**
  - `FlowchartGenerator`에서 클러스터 간 기본 간격으로 주어지던 방대한 여백(`X: 1000, Y: 1500`)을 대폭 축소(`X: 400, Y: 400`).
  - 초기 생성 시 최대한 빽빽하게 모아둔 뒤, 충돌 회피 알고리즘(`resolveClusterOverlaps`)이 필요한 만큼만 최소한으로 밀어내도록 유도하여 전체 그래프의 극단적인 비대화를 방지함.
- **바운더리 제한 및 극한의 공간 압축 (Max Width & Tight Packing):**
  - 클러스터 내부 역할(Role) 블록이 가로로 무한정 늘어나는 것을 막기 위해 최대 너비 제한(`MAX_CLUSTER_WIDTH = 1200px`) 도입 및 초과 시 강제 줄바꿈(Wrap) 적용.
  - 노드 사이의 여백을 30px, 10px 수준으로 대폭 제거하여 (`COLUMN_WIDTH`: 150, `ROW_HEIGHT`: 70) 불필요한 빈 공간 완전 삭제.
  - 클러스터 간 충돌 시 밀어내는 마진(`PADDING`)을 40px에서 20px로 반 토막 내어 전체 캔버스 확장 억제.

- **무한 팽창 버그(Infinite Expansion) 원천 차단 (Two-Pass Centering):**
  - 노드 재조정 시 시작 X 좌표가 강제 이동되어 다음 정렬 때 클러스터가 표류(Drifting)하는 현상 해결.
  - (1차) 가상 정렬 후 (2차) 정확한 기하학적 중심(Geometric Center)을 산출하여 원래 중심점에 100% 일치시키도록 2-Pass 보정 알고리즘 적용.

- **방치된 노드(Stranded Nodes)에 의한 바운더리 비대화 버그 수정:**
  - `primaryRole`이 할당되지 않은 노드(예: Ghost 노드, 미분석 노드 등)가 정렬 대상에서 제외(continue)되어 초기 위치(저 멀리)에 방치되는 현상 발견.
  - 이 방치된 노드들까지 포함하여 클러스터의 경계 상자(Bounding Box)가 계산되면서, 클러스터가 보이지 않는 거대한 크기를 갖게 되어 타 클러스터를 우주 끝까지 밀어내는 원인으로 작용함.
  - `Other` 역할(Role) 범주를 신설하여, 역할이 없는 모든 노드도 예외 없이 컴팩트 그리드 내부로 강력하게 끌어오도록 수정.

## 📝 Post-Work Log #2 – v0.3.31 Diagnostics Stabilization (2026-06-25)

### 1. 스키마 검증 허용 타입 확장 (`LogicAnalyzer.ts`)
- `validNodeTypes` 화이트리스트에 `'doc'`, `'file'`, `'folder'` 추가.
- 클라이언트가 업로드한 파일 시스템 기반 노드 (`GEMINI.md`, `TEST_network.ts` 등)가 LLM 환각 오류로 오분류되던 문제 수정.
- 로직 디버깅 제외 대상(`nonLogicTypes`)에도 동일 타입 추가 → 문서/파일 노드는 로직 평가 대상에서 완전 배제.

### 2. Ghost Cluster 의존성 폭주 방지 (`LogicAnalyzer.ts`)
- `detectV0321Hints` 내 클러스터 간 의존성 검사에서 타겟이 `cluster_ghosts`, `doc_shelf`인 경우 `return` 처리.
- `folder_x → cluster_ghosts` 패턴이 수십 개 발생하여 Strong Dependency 힌트를 폭주시키던 원인 제거.

### 3. Pressure 계산식 정규화 (`LogicAnalyzer.ts`)
- **기존:** `criticalIssues.length * 15` (절대값 기반 → 노드 수 증가 시 무조건 100% 도달)
- **변경:** `Math.round(criticalIssues.length / totalAnalyzedNodes * 100)` (노드 수 비례 퍼센티지)
- 상태 단계:
  - 0~10% 🟢 Stable
  - 10~30% 🟡 Yellow Caution
  - 30~60% 🟠 Orange Warning
  - 60%+ 🔥 Critical Red-out

### 4. clientTimestamp + 다중 클라이언트 메타 전파
- `ClassifiedNode` 인터페이스에 `clientTimestamp` 추가.
- `RemoteLayerProjector.ts`에서 `snapshot.timestamp` → 노드 속성으로 주입.
- `GraphSnapshot`에도 `clientTimestamp`, `sessionId` 함께 전파.
- 향후 멀티클라이언트(Alice/Bob/Charlie) 구성 시 툴팁에서 `"Bob – Updated 7m ago"` 형태 즉시 표시 가능.

### 5. Stale Diagnostics 시각화 (`canvas-engine.js`)
- 노드에 `clientTimestamp` 존재 시 시간 경과에 따른 불투명도 자동 계산:
  - 0~5분: opacity 1.0 (Active)
  - 5~15분: opacity 0.7 (Stale)
  - 15분+: opacity 0.4 (Offline Candidate)
- 툴팁에 `👤 [username] Updated Xm ago` 정보 추가.

### 6. Soft Disconnect / 15분 Retention (`standalone.ts`)
- SSE 연결 해제 시 `clientPushData`, `clientDiagnostics` **즉시 삭제 없이** 15분 보존.
- `softDisconnected` Map에 타이머 등록 → 15분 경과 후 Hard Purge.
- 근거: 클라이언트 크래시 시 Architect가 "방금 죽은 이유"를 디버깅할 단서 보존.
- 재접속 시 기존 타이머 취소(clearTimeout) → 캐시 자동 복원.
