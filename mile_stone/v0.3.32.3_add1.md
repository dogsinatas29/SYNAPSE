# Objective

v0.3.32.3 Benchmark Harness는 현재 SYNAPSE의 실제 병목 위치를 드러냈다.

측정 결과:

* Backend Pipeline: 정상
* Layout Engine: 정상
* Community Detection: 정상
* Frontend Renderer FPS: 정상
* Webview Load: 병목

현재 문제는 렌더러가 아니라 Graph → JSON → IPC → Webview 전달 파이프라인이다.

본 문서는 v0.4.0 진입 전 반드시 수행해야 하는 마지막 검증 단계들을 정의한다.

목표는 추측을 제거하고 실제 측정 데이터 기반으로 다음 아키텍처 방향을 결정하는 것이다.

---

# Programming Principles

## 1. Think Before Coding

추측 금지.

모든 최적화는 측정값으로 입증되어야 한다.

## 2. Benchmark First

성능 문제를 수정하기 전에 반드시 측정한다.

## 3. Isolate Variables

한 번에 하나의 가설만 검증한다.

## 4. Regression Safety

기존 그래프 결과를 변경하지 않는다.

## 5. Evidence Driven Architecture

아키텍처 결정은 벤치마크 결과를 근거로 한다.
