# v0.3.32.3_add2.md

# Cluster Collapse & Language Segmentation Experimental Validation

## Goal

v0.3.32.3 Benchmark Phase 1 결과를 기반으로 SYNAPSE의 차세대 렌더링 아키텍처 방향을 데이터 기반으로 결정한다.

현재 병목은 다음과 같이 확인되었다.

```text
Graph Generation
    ↓
Layout
    ↓
Serialize
    ↓
IPC Transfer
    ↓
Deserialize
    ↓
Frontend Cache Build
    ↓
Render
```

Backend 계산 비용은 충분히 양호한 수준이며, 실제 병목은 대용량 Graph State 전달 및 초기 렌더링 과정으로 추정된다.

본 실험의 목적은 다음 두 가지 아키텍처 가설을 검증하는 것이다.

* Hypothesis A: Cluster Collapse
* Hypothesis B: Language Segmentation

---

# Experiment A

## Cluster Collapse Benchmark

### Objective

초기 로딩 시 모든 노드를 전송하지 않고 Cluster Header만 전송할 경우 성능 향상 폭을 측정한다.

---

### Baseline

현재 구조

```text
5000 Nodes
20000 Edges
50 Clusters

→ 전체 Graph 전송
```

---

### Experimental Mode

초기 상태

```text
Cluster Headers Only
```

예시

```text
cluster_core
cluster_ui
cluster_server
cluster_database
cluster_network
```

---

### Lazy Expand

사용자가 Cluster를 선택할 경우

```text
cluster_core
```

↓

해당 Cluster에 포함된

```text
Nodes
Edges
Metadata
```

를 동적으로 로드한다.

---

### Measurement

측정 항목

```text
Payload Size
Serialize Time
Transfer Time
Deserialize Time
Cache Build Time
Memory Usage
FPS
```

---

### Success Criteria

```text
Payload Size ≥ 50% 감소
Deserialize ≥ 50% 감소
Cache Build ≥ 50% 감소
Initial Render ≥ 50% 감소
```

---

# Experiment C

## Combined Architecture Benchmark

### Objective

Language Segmentation과 Cluster Collapse를 동시에 적용했을 때의 최종 효과를 측정한다.

---

### Structure

```text
TypeScript
 ├── UI
 ├── Core
 ├── Server

Rust
 ├── Runtime
 ├── Kernel

Python
 ├── Scripts
 ├── Tools
```

---

### Initial Load Target

현재

```text
5000 Nodes
20000 Edges
```

↓

목표

```text
300 ~ 500 Nodes
1000 ~ 2000 Edges
```

수준으로 축소

---

### Measurement

측정 항목

```text
Payload Size
Serialize Time
Transfer Time
Deserialize Time
Cache Build Time
Memory Usage
FPS
Expand Latency
```

---

### Success Criteria

```text
Payload ≥ 80% 감소

Initial Load ≥ 80% 감소

Memory ≥ 50% 감소

Expand Latency ≤ 100ms
```

# Exit Criteria

다음 질문에 수치로 답할 수 있어야 한다.

```text
1. Payload 병목의 실제 원인은 무엇인가?

2. Cluster Collapse는 몇 % 효과가 있는가?

3. Language Segmentation은 몇 % 효과가 있는가?

4. 둘을 합치면 초기 렌더 비용이 얼마나 줄어드는가?

5. v0.4.0에서 가장 먼저 구현해야 할 기능은 무엇인가?
```

위 질문에 대한 데이터 기반 결론이 도출되면 v0.3.32.3 성능 연구 마일스톤을 종료한다.
