# v0.3.32.3_add3.md

# Runtime Graph Architecture Transition Plan

## Purpose

v0.3.32.3_add2 실험 결과를 바탕으로 SYNAPSE의 차세대 Runtime Graph Architecture를 정의한다.

본 문서는 단순 성능 최적화 계획이 아니다.

Harvest, Interaction, Large Workspace 지원을 위한 구조적 전환 계획서이다.

---

# Background

Benchmark Phase 1 결과

```text
Backend
---------
Scan            9 ms
Layout         26 ms
Analyze        21 ms

Frontend
---------
Webview Load 1093 ms
```

분석 결과

```text
병목 = Backend

X

병목 = Graph Transfer + Frontend Initialization
```

으로 판정되었다.

# Architectural Goal

현재

```text
Workspace
    ↓
Full Graph Snapshot
    ↓
Webview
```

구조를

```text
Workspace
    ↓
Graph Runtime
    ↓
Incremental Graph State
    ↓
Webview
```

구조로 전환한다.

# Phase A

## Cluster First Architecture

### Current

```text
Graph
 ├─ Nodes
 ├─ Edges
 └─ Clusters
```

---

### New

```text
Graph
 ├─ Cluster Nodes
 ├─ Cluster Edges
 ├─ Real Nodes
 └─ Real Edges
```

---

### Rule

Cluster는 단순 시각적 그룹이 아니다.

Cluster는 Runtime Loading Unit이다.
