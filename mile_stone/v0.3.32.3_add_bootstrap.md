# Goal

## Why Are We Doing This?

현재 SYNAPSE는 기능적으로는 완성에 가까워졌지만 아키텍처적으로는 아직 Harvest 규모를 수용할 수 없다.

벤치마크 결과는 문제의 원인을 명확하게 보여주었다.

```text
5000 Nodes
20000 Edges
Payload 6.45MB

↓

Webview Load 1092ms
```

병목은 Layout이 아니다.

병목은 다음 구조이다.

```text
Full Graph
    ↓
Full Snapshot IPC
    ↓
Full Deserialize
    ↓
Full Cache Build
    ↓
Render
```

즉,

현재 구조는

"보이는 것만 렌더링"

이 아니라

"모든 것을 생성한 후 일부만 보여주는 구조"

이다.

---

## Primary Goal

SYNAPSE Runtime Graph를

```text
Static Snapshot Architecture
```

에서

```text
Runtime Streaming Architecture
```

로 전환한다.
