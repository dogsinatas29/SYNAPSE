## 🛠️ 기술적 변경 사항

### 1. 🔘 블랙리스트 토글 기능 반영 (VS Code Explorer Context)
- **File Changes:** `package.json`, `src/extension.ts`
- 기존 "Add to Blacklist" 명령어를 **"Toggle Blacklist"**로 통합 변경.
- 선택된 폴더/파일이 `synapse.config.json`의 blacklist 항목에 없다면 추가하고, 이미 있다면 배열에서 제거(`splice`)하도록 로직을 개편.
- 토글 직후 상태에 따라 팝업 메시지를 분리하여 직관적인 피드백을 제공.

### 2. 📝 커스텀 수동 노드 생성 시 중간 디렉토리(Directory) 누락 에러 해결
- **File Changes:** `src/webview/CanvasPanel.ts` (`handleCreateManualNode`)
- 기존에는 사용자가 존재하지 않는 중간 폴더 경로(예: `src/compile/test2.ts`)를 입력하면 VS Code `fs.writeFile` API에서 ENONET 오류를 발생시키며 조용히 실패함.
- 파일 작성 전에 먼저 `vscode.workspace.fs.createDirectory(dirUri)`를 호출하여, 부모 계층 디렉토리 구조가 완벽하게 확보된 후 파일 쓰기를 수행하도록 방어 로직 추가.

### 3. 📉 클러스터 연쇄 숨김(Cascade Collapse) 동기화 옵션 반영
- **File Changes:** `ui/canvas-engine.js`
- 클러스터의 `[-]` 토글 버튼(`toggleClusterCollapse`) 및 가시성 패널의 체크박스(`_clusterVisToggle`) 이벤트 호출 시, 대상 클러스터의 모든 직·간접 자식 클러스터(Descendant Clusters)를 찾아 상태를 동기화하는 로직 추가.
- 부모가 닫힐 때 자식도 논리적으로 함께 닫히고, 체크 해제 시 자식도 함께 체크 해제되므로 뷰어에서 클러스터의 상태가 어긋나지 않음.
- 기존에 적용한 "부모 클러스터가 닫혀있으면 소속된 자식/손자 노드도 무조건 렌더링을 건너뛰는(`drawNodes` 최적화)" 로직과 시너지를 내어, 부모 클러스터만 접으면 하위 구조가 깔끔하게 하나의 컴팩트 박스로 떨어짐.

### 4. 🗑️ 노드 일괄 삭제(Delete) 로직 안내 및 확인 (Notice)
- `CanvasPanel.ts`의 `handleDeleteNodes` 과정에서 물리 삭제(`deleteFiles`) 시 VS Code 알림 메시지(`🧹 완전 정리`)를 띄우도록 설계되어 있음. 
- 물리적 삭제 버튼을 누르지 않은 상태에서 리로드(Reload)될 경우 `DataPipeline`에 의해 노드가 복구되는 구조를 명확히 함. (해당 기능의 무결성 검증 완료)
