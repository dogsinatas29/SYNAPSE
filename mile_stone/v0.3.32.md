### 1. 감사(Audit) 완료

#### Contribution Lifecycle Audit
- SubmissionSnapshot, RemoteLayerProjector가 Dead Code임을 확인
- 실제 Entry Point는 `POST /api/client/push` (clientPushData)
- CompareEngine은 SSE로 직접 해시를 요청 (clientPushData 미사용)
- HarvestEngine은 SSE로 직접 파일을 요청 (clientPushData 미사용)

#### Canonical Identity 확정
- `(filePath, userId)`가 CompareResult와 HarvestCandidate 전 구간에서 고유키
- targetPath, sourcePath는 Metadata (Identity에 영향 없음)
- CompareResult ↔ HarvestCandidate는 1:1 lineage 관계

#### Lifecycle Boundary Decision
- Lifecycle이 아닌 Entity Graph로 문제 재정의
- Archived는 Persistence Event (Identity 손실)
- Flow Subject = Contribution Entity Relationship

### 2. ADR (Architecture Decision Record) 작성

#### Contribution Graph Decision
- Option A: Runtime Object Projection (Entity Listing)
- **Option B 선택**: Runtime Entity Relationship Projection
- Option C: Conceptual Workflow Projection (Rejected)
- Edge는 `derived_from` (Architect Selection 아님)

#### 핵심 결정
- Flow View projects runtime entity lineage, not workflow semantics
- User actions and workflow concepts are not modeled unless they exist as runtime objects

const filteredNodes = nodes.filter(n => {
    // 1. 파일 타입 필터
    const isDoc = fileName.endsWith('.md') || fileName.endsWith('.txt') || fileName.includes('license');
    const isGhost = n.status === 'ghost';
    
    // 2. 레이어 가시성 필터
    const isUser = n.layer === 'user' || n.data?.layer === 'user' || n.status === 'pending' || n.id?.startsWith('node_manual_');
    if (!isUser && !this.engine.showBaseLayer) return false;
    if (isUser && !this.engine.showUserLayer) return false;
    if (this.engine._isClientLayerVisible && !this.engine._isClientLayerVisible(n)) return false;
    
    // 3. 도달 가능성 필터
    return reachableIds.has(n.id) && n.type !== 'external' && !isDoc && !isGhost && !isContext;
});
