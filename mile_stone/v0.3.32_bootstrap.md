# Phase 4 — Edge Generation

## Runtime Evidence

- CompareEngine.compare() returns CompareResult[]
- HarvestEngine.harvest() receives HarvestCandidate[]
- CompareResult.filePath
- CompareResult.userId
- HarvestCandidate.filePath
- HarvestCandidate.userId

## Goal

동일 (filePath, userId)를 공유하는 Compared Node와 Harvested Node를 derived_from Edge로 연결

## Implementation

EdgeGenerator 클래스 추가

## Validation

1. compared.filePath == harvested.filePath
2. compared.userId == harvested.userId
3. Edge Count == Harvested Node Count
4. derived_from는 동일 Identity만 연결 가능
5. N:M 연결 금지
6. Compared Node without matching Harvested Node 허용
7. Harvested Node without matching Compared Node 경고

## Pass Criteria

Edge 생성 성공

## Fail Criteria

매칭 실패 또는 N:M 연결 발생

## Forbidden Assumptions

- ArchitectSelectionNode
- ApprovalState
- WorkflowStep
- LifecycleState
- DecisionEdge
