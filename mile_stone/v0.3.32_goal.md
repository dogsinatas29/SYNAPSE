# v0.3.32_goal.md

# SYNAPSE v0.3.32

## Network Flow Analysis

---

# Objective

v0.3.31에서 클라이언트 노드에 대한 Virtual Debugger 적용을 완성함으로써,
서버는 더 이상 단순한 그래프 집계기(Aggregator)가 아니라
분산 그래프를 이해할 수 있는 분석 엔진으로 진화한다.

v0.3.32의 목표는 분산 그래프 상의 실행 흐름(Execution Flow)을
단일 관점에서 추적할 수 있도록 만드는 것이다.

본 버전은 동기화(Synchronization)를 구현하지 않는다.

본 버전은 다음을 구현한다.

* Network-aware Flow View
* Cross Client Dependency Trace
* Distributed Call Path Analysis
* Protocol Route Visualization

---

# Philosophy

SYNAPSE는 Git을 대체하지 않는다.

SYNAPSE는 동기화 엔진이 아니다.

SYNAPSE는 코드 분석 및 협업 가시화 시스템이다.

따라서 v0.3.32는 파일 이동이나 병합이 아니라
정보 흐름(Information Flow)을 분석하는 데 집중한다.

---

# Problem

현재 Flow View는 로컬 그래프 기준으로만 동작한다.

즉,

Server Node
→ Server Node
→ Server Node

흐름은 정상적으로 분석 가능하지만,

Server Node
→ Client A Node
→ Client B Node

와 같은 네트워크 기반 실행 흐름은 분석할 수 없다.

결과적으로 분산 협업 구조에서는
실제 의존성이 존재함에도 불구하고
흐름이 중간에서 단절된다.

---

# Goal

Flow View가 서버와 클라이언트 경계를 넘어서
하나의 실행 트리로 연결되어야 한다.

예시:

Authentication
↓
Protocol Dispatch
↓
Client Push
↓
Harvest Validation
↓
Snapshot Archive

위 흐름이 실제 물리적 위치와 상관없이
하나의 실행 경로로 표현되어야 한다.

---

# Core Features

## 1. Network Flow View

클라이언트 그래프를 포함한 전체 그래프 기반 Flow View.

지원 대상:

* Server Node
* Client Node
* External Ghost
* Protocol Node

---

## 2. Dependency Trace

특정 노드 선택 시

Who calls me?
What do I call?

를 네트워크 범위까지 확장한다.

---

## 3. Distributed Call Path

실행 경로를 추적할 때

Server
↓
Client
↓
Server

형태의 왕복 호출을 포함하여 표시한다.

---

## 4. Protocol Route Visualization

SSE

REST

Harvest

Virtual Debugger

등 네트워크 계층이
Flow View 내부에서 명시적으로 표현된다.

---

# Non Goals

본 버전에서 구현하지 않는다.

* File Synchronization
* Auto Merge
* Conflict Resolution
* Git Replacement
* Shared Editing

---

# Success Criteria

다음이 모두 가능해야 한다.

1.

클라이언트 노드를 선택한다.

2.

Flow View를 연다.

3.

클라이언트 → 서버 → 클라이언트

흐름이 단절 없이 표시된다.

4.

Protocol Layer가 시각적으로 구분된다.

5.

Cross Client Dependency가 추적된다.

6.

Flow View가 기존 로컬 그래프 분석 성능을 저하시키지 않는다.
