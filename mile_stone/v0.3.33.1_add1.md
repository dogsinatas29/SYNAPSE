# v0.3.33.1_add1 — Architecture Telescope 구현 설계

---

# 목적

본 문서는 v0.3.33.1에서 정의된 Architecture Telescope 개념을 실제 Synapse에 어떻게 구현할 것인지를 정의한다.

v0.3.33.1의 목적은 단순한 계층 탐색 기능을 만드는 것이 아니다.

또한 단순한 렌더링 최적화 기능을 만드는 것도 아니다.

본 버전의 목적은 다음과 같다.

```text
아키텍트가

전체 구조(Context)를 유지하면서

특정 영역(Focus)을

점진적으로 확대할 수 있게 만든다.
```

---

# 최상위 설계 원칙

## Synapse는 파일 탐색기가 아니다

금지되는 방향

```text
Project
 ↓
src
 ↓
core
 ↓
runtime
 ↓
scheduler
```

---

이 방식은

```text
VSCode Explorer
```

와 다를 바 없게 된다.

---

사용자는

```text
현재 위치
```

만 알 수 있고

```text
전체 구조
```

를 잃어버린다.

---

## Synapse는 Architecture Telescope이다

사용자는 항상

```text
전체 구조
```

를 볼 수 있어야 한다.

---

동시에

```text
특정 영역
```

을 확대할 수 있어야 한다.

---

즉

```text
Context
+
Focus
```

를 동시에 유지한다.

---

# Focus + Context 모델

## Context

현재 확대 대상이 아닌 구조

---

예

```text
Project

 ├ Protocol
 ├ UI
 └ Test
```

---

Context는 항상 유지된다.

---

Context는 제거되지 않는다.

---

Context는 축약될 수는 있지만

사라지면 안 된다.

---

## Focus

사용자가 분석 중인 구조

---

예

```text
Core
 ├ Runtime
 ├ Graph
 └ Verify
```

---

Focus는 세분화된다.

---

즉

```text
Context
=
상위 추상화 유지

Focus
=
하위 구조 전개
```

---

# 최종 정의

v0.3.33.1은

```text
계층 탐색 기능
```

이 아니다.

---

v0.3.33.1은

```text
Architecture Telescope
```

의 첫 번째 구현이다.

---

사용자는

```text
전체 구조(Context)를 유지하면서

관심 영역(Focus)을

점진적으로 확대
```

이는 단순한 그래프 최적화가 아니라 Synapse의 아키텍처 탐색 모델 자체를 정의하는 기능이다.
