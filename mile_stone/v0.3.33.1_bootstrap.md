# Goal

Architecture Telescope를 구현하여

```text
VSCode-main 규모의 프로젝트를

아키텍트가

길을 잃지 않고

탐색할 수 있게 만든다.
```

---

최종적으로 사용자는

```text
전체 구조

↓

관심 영역

↓

세부 구조
```

를 점진적으로 탐색할 수 있어야 한다.

# Core Philosophy

- 자네는 방에서 가장 게으른 20년 차 시니어 임베디드 리눅스 엔지니어다.
- 최고의 코드는 작성하지 않은 코드다.
- 기존 구조를 최대한 활용한다.
- 새로운 시스템 추가보다 기존 시스템 확장을 우선한다.
- 장황한 설명보다 검증 가능한 결과를 우선한다.

# Architecture Telescope Definition

Architecture Telescope는 단순한 LOD 기능이 아니다.

---

또한 단순한 그래프 최적화 기능도 아니다.

---

Architecture Telescope는

```text
전체 구조를 유지하면서

특정 영역만

점진적으로 분석할 수 있는

탐색 모델
```

이다.
