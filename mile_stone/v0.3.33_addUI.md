# v0.3.33_addUI.md

# Interaction-Driven Frontend Virtualization UI Design

## 목적

v0.3.33의 UI 변경 목적은

새로운 버튼을 추가하는 것이 아니다.

사용자가

```text
현재 무엇을 보고 있는가
```

와

```text
현재 얼마나 계산하고 있는가
```

를 명확하게 이해할 수 있도록 만드는 것이다.

---

# 핵심 설계 원칙

## 원칙 1

View 와 Performance 를 분리한다.

---

잘못된 구조

```text
Edge Visibility

├ Hidden
├ Visible Area Only
└ All
```

---

문제

```text
무엇을 보여주는가

+

무엇을 계산하는가
```

가 섞여 있다.

---

올바른 구조

```text
View Strategy

+

Performance Policy
```

독립 관리

---

## 원칙 2

사용자는

```text
몇 개의 Edge가 있는가
```

보다

```text
지금 몇 개를 계산 중인가
```

를 알아야 한다.

---

## 원칙 3

대규모 프로젝트에서는

Full Graph

보다

Density

가 기본값이다.

---

# 2. Performance Policy

사용자가

```text
어떻게 계산할 것인가
```

를 결정

---

## Lazy Materialization

기본 활성화

---

활성 시

```text
필요한 순간에만 Edge 생성
```

---

비활성 시

```text
전체 Edge 생성
```

---

## Cache Virtualization

기본 활성화

---

활성 시

```text
Node Cache 우선 생성

Edge Cache 지연 생성
```

---

비활성 시

```text
모든 Cache 즉시 생성
```

---

## Visible Area Processing

기본 활성화

---

활성 시

```text

```

---

비활성 시

```text
전체 Graph 계산
```
