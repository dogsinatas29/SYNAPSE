# v0.3.33 Fix Pack #1
## Graph Consistency Stabilization

---

# Goal

LOD 작업 착수 전,

- Hide Noise
- External Reference Toggle
- Traffic Heatmap
- Cluster Visibility

가 동일한 그래프 상태를 바라보도록 정리한다.

현재는 각 시스템이 서로 다른 데이터셋을 사용하고 있어
사용자 입장에서 "보이지 않는 것이 존재하는 것처럼 동작"하는 문제가 발생한다.

본 Fix Pack의 목표는 기능 추가가 아니라

**Graph State Consistency 확보**

이다.
