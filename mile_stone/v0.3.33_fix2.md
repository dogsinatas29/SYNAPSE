# 5. Risk Analysis

---

## Risk-A

### Hide Noise가 Graph를 변경하는 경우

현재 원칙

```text
Hide Noise
=
View Filter
```

이어야 한다.

---

잘못 수정 시

```text
Hide Noise

↓

Node 삭제

↓

Edge 삭제

↓

Cluster 재생성

↓

Graph 변경
```

발생

---

결과

```text
View Filter

↓

Graph Mutation
```

전환

---

위험도

```text
CRITICAL
```

---

방지 규칙

Hide Noise는

```javascript
_visibleNodesCache
```

만 변경 가능

---

절대 수정 금지

```javascript
this.nodes

this.edges

this.clusters
```

---
