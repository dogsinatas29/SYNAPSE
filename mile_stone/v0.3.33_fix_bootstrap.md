# Ground Truth Rule

항상 원본 데이터가 진실이다.

```javascript
this.nodes
this.clusters
this.edges
```

는 절대 수정하지 않는다.

---

허용되는 것은

```javascript
visibleNodes
visibleClusters
visibleClusterFlows
```

와 같은 파생 데이터만 생성하는 것이다.

---

# Visibility Layer Principle

Visibility Layer는

그래프를 변경하는 시스템이 아니다.

그래프를 "보여주는 방식"만 변경한다.

---

금지

```javascript
this.nodes.splice(...)
this.clusters.splice(...)
this.edges.splice(...)
```

---

허용

```javascript
visibleNodes =
visibleClusters =
visibleClusterFlows =
```
