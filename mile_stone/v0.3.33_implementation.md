# 최종 목표

v0.3.33의 성공은

렌더링 최적화가 아니다.

그래프를 저장하고

그래프를 복원하고

그래프를 유지하면서도

사용자가 현재 필요한 정보만 Materialize 하는 구조를 완성하는 것이다.

전체 그래프는 존재한다.

그러나 전체 그래프를 한 번에 계산하지는 않는다.
