### 측정 항목

| 로그 키 | 측정 내용 |
|---|---|
| `[PERF] TransferTime` | IPC 수신 → loadProjectState 진입 |
| `[PERF] NodeCacheTime` | `updateNodeStats()` 소요 시간 |
| `[PERF] EdgeCacheTime` | `validateEdgesBatch` payload 준비 시간 |
| `[PERF] FirstInteractive` | loadProjectState 진입 → loading overlay 제거 |
| `[PERF] GraphBuildTime` | FirstInteractive 동일 (전체 빌드 시간) |

### 실측 베이스라인

| 환경 | Nodes | Edges | NodeCacheTime | FirstInteractive |
|---|---|---|---|---|
| 소형 프로젝트 | 209 | 612 | 2.3ms | 22.1ms |
| 중형 프로젝트 | 685 | 1,652 | 5.2ms | 54.1ms |
| **VSCode-main** | **12,193** | **69,677** | **1,238.6ms** | 수 초 |

### 핵심 발견 — 13배 단가 폭증

```
소형:   5.2ms  / 685nodes  = 0.0076ms/node
대형:  1238ms  / 12193nodes = 0.101ms/node

0.101 / 0.0076 ≈ 13배
```

→ O(N) 알고리즘이 아닌 **숨겨진 O(E × C) 복잡도** 확인

### 병목 원인 규명

**`getSemanticGroup(node)` 내부:**
```js
// 수정 전 — O(C) per call
(this.clusters || []).find(c => c.id === clusterId)
```

**엣지 루프에서 2회 호출:**
```
O(E × C) = 69,677 edges × ~200 clusters ≈ 14,000,000회 배열 탐색
→ NodeCacheTime 1238ms의 직접 원인
```

## Phase 0 핫픽스 — getSemanticGroup O(E×C) → O(E) ✅

### 변경 내용

**`ui/canvas-engine.js`**

`getSemanticGroup(node)` 시그니처에 `clusterLayerMap` 선택 인자 추가:
```js
// 수정 후
getSemanticGroup(node, clusterLayerMap) {
    const layer = clusterLayerMap
        ? clusterLayerMap.get(clusterId)   // O(1)
        : clusters.find(...)               // O(C) fallback
}
```

`updateNodeStats()` 엣지 루프에서 이미 구축된 `clusterLayerMap` 전달:
```js
// 수정 전
const tgtGroup = this.getSemanticGroup(tgtNode);        // O(C) × E

// 수정 후
const tgtGroup = this.getSemanticGroup(tgtNode, clusterLayerMap); // O(1) × E
```

### 이론적 예측

```
수정 전: O(E × C) ≈ 70K × 200 = 14M ops → 1238ms
수정 후: O(E)     ≈ 70K        = 70K ops  → ~6ms 수준 (200배 개선)
```

## 다음 단계

### Phase 2 — MaterializationPolicy 분리 (진입 예정)

**목표:** 뷰 전략별 노드/엣지 생성 정책을 인터페이스로 분리

```js
interface MaterializationPolicy {
    shouldMaterializeNode(node) → boolean
    shouldMaterializeEdge(edge) → boolean
}
```

정책별 동작:
- `Density` → Node: YES, Edge: NO
- `Focus`   → Neighborhood only
- `FullGraph` → Everything (현재 동작)

Exit Criteria: Density 모드 진입 시 `MaterializedEdgeCount === 0` 확인
