# R-07A BFS Structure Failure

Severity

```text
Critical
```

---

## Description

Propagation systems appear to be BFS.

Internally they become O(N²).

---

## Typical Causes

Bad:

```javascript
queue.shift()
```

Bad:

```javascript
visited.includes(id)
```

Bad:

```javascript
array.indexOf(id)
```

inside traversal loops.

---

## Consequence

Linux Kernel Scale:

```text
68K Nodes

378K Edges
```

causes traversal collapse.

---

## Required Structure

Queue:

```javascript
const queue = [];
let head = 0;

while (head < queue.length) {
    const current = queue[head++];
}
```

Visited:

```javascript
const visited = new Set();
```

---

## Applies To

```text
Blast Radius

Infection Analysis

Threat Analysis

Dependency Traversal
```

---

## Validation

All BFS systems must pass:

```text
Linux Kernel Scale Test
```

before approval.
