### 4-3. 발견된 버그

#### Bug 1: ReportVerifier 정규식 오탐 (False FAIL)
- **현상:** `intentRender: false`, `html: false`가 함께 FAIL로 기록됨.
- **원인:** Verifier가 SSOT 비교 단계(`throw new Error()`)에서 일찍 종료하여 HTML 검증 단계까지 도달하지 못함. 기본값 `false`가 그대로 JSON에 저장된 것.
- **수정:** 마크다운 헤더 정규식 패턴을 `\*\*Evidence Count\*\*`로 볼드체(`**`) 포함 방식으로 교정 완료.

#### Bug 2: Confidence 퍼센트 변환 SSOT Mismatch
- **현상:** `SSOT Mismatch: Avg Confidence (metrics=0.30, md=30.00)`.
- **원인:** `metrics.json`은 소수점(`0.30`)으로 저장하고, `MarkdownExporter`는 백분율(`30.00%`)로 렌더링하는데 Verifier가 변환 없이 1:1 비교함.
- **수정:** `expectedMdConfidence = (metrics.averageConfidence * 100).toFixed(2)` 변환 후 비교하도록 수정 완료.

#### Bug 3: Aggregator 병합 효과 없음 (구조적 특성)
- **현상:** `evidenceCount(8392) == intentEdgeCount(8392)` — Aggregator 병합이 발생하지 않음.
- **원인:** `FileScanner`가 이미 파일 레벨에서 중복 제거된 유니크 참조만 리턴하므로, RegexProvider가 뱉어내는 Evidence 자체가 이미 유니크 셋. Aggregator가 실제로 병합할 대상이 없는 구조.
- **결론:** RegexProvider Only 환경에서는 예상된 동작. VSCodeProvider가 Symbol 레벨 Evidence를 공급하기 시작하면 `evidenceCount >> intentEdgeCount` 형태로 전환됨.

### 4-4. 심각한 운영 문제: Exporter Data Dump

- **현상:** `linux-7.2-rc3` 기준 `logic_report.md = 186MB`, `logic_report.html = 435MB` 생성.
- **원인:** `MarkdownExporter`와 `HtmlReportGenerator`가 `bundle.intentEdges` 배열을 **전체(All)** 순회하여 출력함. 62,000개 이상의 노드 × 전체 데이터 = 메모리 덤프 수준의 산출물이 생성됨.
- **결론:** 현재 Exporter는 "보고서 생성기"가 아니라 사실상 "데이터 직렬화기"로 동작하고 있음.

### 4-5. Exporter Hotfix 계획 (Level 1 + Level 2 즉시 적용)

**목표 출력 크기:** `logic_report.md < 1MB`, `logic_report.html < 3MB`

#### Level 1 — 보고서 출력 제한 (Report Truncation)
- `MarkdownExporter`, `HtmlReportGenerator` 모두:
  - Intent Edge 목록: `Top 50`만 출력. 나머지는 링크 안내 문구로 대체.
  - Findings 목록: `Top 50`만 출력.
  - Hub/SCC/Bridge 목록: `Top 20`만 출력.

#### Level 2 — 원본 데이터 분리 (Raw Data Separation)
- `BatchRunner`가 PASS 시 `data/` 하위 디렉토리를 추가 생성하여 원본 전체 데이터를 분리 저장:
  ```
  synapse-test/<project>/
  ├── logic_report.md      ← 사람용 요약 (< 1MB)
  ├── logic_report.html    ← 사람용 UI   (< 3MB)
  ├── metrics.json         ← SSOT 핵심 수치
  ├── analysis_result.json
  ├── verification.json
  └── data/
      ├── evidence.json        ← 전체 Evidence 원본
      ├── intent_edges.json    ← 전체 IntentEdge 원본
      └── findings.json        ← 전체 Findings 원본
  ```
- **Rule:** Report = Human, JSON = Machine. 보고서에 원본 데이터 직접 포함 금지.
