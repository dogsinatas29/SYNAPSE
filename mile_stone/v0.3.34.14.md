# v0.3.34.14: Semantic Contract Layer 도입 (아키텍처 완성 버전)

## 한 문장 요약
**"Validation Engine → Raw JSON → Renderer" 에서 "Validation Engine → Raw JSON → Semantic Contract → Renderer" 로의 전환**

---

## 왜 이것은 "버그 fix"가 아니라 "아키텍처 전환"인가

### Facts vs Interpretation

B5가 처음 설계될 때 (v0.3.34.0~10):
```
Validation → Raw JSON → Renderer
```
이 구조로 충분했습니다.

하지만 B5가 성장하면서:
```
Validation → Raw JSON ←
├─ Surgery Options
├─ ROI Calculations  
├─ AI Prompts
├─ Evidence Vault
└─ Future Automation
```
모두가 같은 Raw JSON을 읽기 시작했습니다.

**문제: Raw JSON은 "Fact"일 뿐이다**

예:
```json
{
  "mesh": {
    "hit": 1,
    "runCount": 3,
    "confidence": 0.33
  }
}
```

이것은:
- "Detected" 일 수도
- "Probable" 일 수도
- "Unstable" 일 수도
- "Calibrated-Out" 일 수도 있습니다.

**필요한 것: Interpretation**

```
Fact: hit=1/3, confidence=0.33
  ↓ [Domain Logic]
Interpretation: "CALIBRATED_OUT" (threshold sweep에서 0이므로)
  ↓
Presentation: "Infrastructure Mesh is not reliably detected"
```

---

## 현재 구조의 치명적 결함

```
Validation Layer (Facts 생성)  ← 정상 ★★★★★
    ↓
Raw JSON (의미 없는 숫자들)
    ↓ Renderer가 동시에 여러 해석 시도
    ├─ "Detected" (hit=1이니까)
    ├─ "Probable" (confidence=0.33이니까)
    ├─ "Calibrated-Out" (threshold=0이니까)
    └─ "Unstable" (다른 기준이니까)
    ↓
모순 발생
```

**결과:**
- Section 2: 70% 감소
- Section 5: 56% 감소 (같은 데이터인데!)
- AI Prompt: 7500 가능성
- Evidence Radar: 0/3 (다른 필드에서)

---

## Semantic Contract Layer: "Domain Interpreter"

```
Raw Facts
  ↓ [NEW] Semantic Interpretation
  ↓
Semantic Contract (Facts + Meaning)
  {
    "infrastructure_mesh": {
      "state": "CALIBRATED_OUT",      ← Domain Concept
      "confidence": 0.33,
      "hitRate": "1/3",
      "decision": "EXCLUDE_FROM_SURGERY"
    },
    "surgery": {
      "optionA": {
        "externalEdgesBefore": 26478,
        "externalEdgesAfter": 7877,
        "reductionPercent": 0.702,      ← 한 번만 계산
        "confidence": "MEDIUM"
      }
    }
  }
  ↓
Renderer (Contract만 읽음)
  ↓
Report (일관된 출력)
```

**이것이 SSOT (Single Source of Truth)이다**

```
Validation JSON ≠ SSOT (Facts일 뿐)
Semantic Contract = SSOT (Facts + Interpretation)
```

## 핵심 설계 원칙 (절대 준수)

### Rule 1: Facts와 Interpretation의 명확한 분리
```typescript
// ❌ 나쁜 예: Facts가 여러 곳에서 다르게 해석됨
const interpretation1 = validation.mesh.hit > 0 ? "Detected" : "Not Detected";
const interpretation2 = validation.mesh.confidence > 0.5 ? "Probable" : "Unstable";

// ✅ 좋은 예: Interpretation은 한 곳에서만
const contract = normalizeSpecies(validation);  // mesh.state = "CALIBRATED_OUT"
```

### Rule 2: Contract는 Domain Concepts을 포함
```typescript
// ❌ Normalization만 (의미 없음)
contract.mesh.presenceHitCount = 1;
contract.mesh.presenceRunCount = 3;

// ✅ Domain Concepts (의미 있음)
contract.mesh.state = "CALIBRATED_OUT";
contract.mesh.decision = "EXCLUDE_FROM_SURGERY";
```

### Rule 3: Renderer는 Raw를 절대 직접 읽지 않음
```typescript
// ❌ Raw 직접 읽음
const report = `Mesh: ${validation.mesh.hit > 0 ? "Detected" : "Not"}`;

// ✅ Contract만 읽음
const report = `Mesh: ${contract.mesh.state}`;
```

### Rule 4: surgeryProjection은 한 번만 계산 (SSOT)
```typescript
// ❌ 여러 곳에서 계산
section2.reduction = (before - after1) / before;  // 70%
section5.reduction = (before - after2) / before;  // 56%

// ✅ Contract에서 한 번만 계산
contract.surgery.optionA.reduction = 0.702;  // 70.2%
// 모든 섹션이 참조
section2.use(contract.surgery.optionA.reduction);
section5.use(contract.surgery.optionA.reduction);
```

### Phase 1: Semantic Contract 정의 (1시간)

**File: `src/cli/semantic_contract.ts`**

```typescript
/**
 * Semantic Contract Layer
 * 
 * 목적: Raw Metrics를 정규화하여 단 하나의 최종 진실 객체 생성
 * 원칙: Renderer는 이 객체만 읽음 (Raw Metrics 절대 금지)
 */

interface SemanticContract {
  metadata: {
    generatedAt: string;
    validationRuns: number;
    astCoveragePercent: number;
  };

  species: {
    [speciesName: string]: {
      // 1. 상태 (의미 정규화)
      state: "STABLE" | "PROBABLE" | "UNSTABLE" | "CALIBRATED_OUT";
      
      // 2. 신뢰도 (Raw confidence 직접 전달)
      confidence: number;  // 0.0 ~ 1.0
      
      // 3. Hit rate (해석 금지, 문자열 그대로)
      hitRate: string;     // "4/5", "1/3" 등
      
      // 4. 의사결정
      decision: "INCLUDE_IN_SURGERY" | "EXCLUDE_FROM_SURGERY" | "INVESTIGATE_FURTHER";
      
      // 5. 근거 (무엇 때문인지)
      reason: string;
      
      // Raw Metrics (필요시 근거 설명용, Renderer는 읽지 않음)
      _raw?: {
        hit: number;
        runCount: number;
        status: string;
        thresholdSweepResults?: number[];
      };
    }
  };

  // 유일한 Surgery Projection (SSOT)
  surgeryProjection: {
    // Raw 값
    externalEdgesBefore: number;
    externalEdgesAfter: number;
    
    // 계산 결과
    reductionAbsolute: number;    // 26478 - 7877 = 18601
    reductionPercent: number;     // 0.702 (70.2%)
    
    // 신뢰도
    confidence: "LOW" | "MEDIUM" | "HIGH";
    confidencePercent: number;    // 0.85 (85%)
    
    // 근거
    reason: string;  // "Based on 4 STABLE species + 2 PROBABLE species"
  };

  // 전체 의사결정
  decision: {
    recommendedSurgeriesCount: number;   // INCLUDE 상태의 species 수
    riskLevel: "LOW" | "MEDIUM" | "HIGH";
    estimatedImpactLevel: "SIGNIFICANT" | "MODERATE" | "MINIMAL";
  };
}
```

### Phase 2: Normalization Engine (1.5시간)

**File: `src/cli/generate_semantic_contract.ts`**

```typescript
/**
 * Semantic Contract Generator
 * 
 * 역할: Validation JSON → SemanticContract 변환
 * 규칙: Raw Metrics를 의미 있는 상태로 정규화
 */

import type { SemanticContract, SemanticSpecies } from './semantic_contract';

export function generateSemanticContract(
  validationResult: ValidationLayerResult
): SemanticContract {
  const species: Record<string, SemanticSpecies> = {};

  // Step 1: 각 species를 정규화
  for (const [speciesName, metrics] of Object.entries(validationResult.presenceMatrix)) {
    species[speciesName] = normalizeSpecies(
      speciesName,
      metrics,
      validationResult.thresholdSweep[speciesName],
      validationResult.confidenceGates
    );
  }

  // Step 2: surgeryProjection 계산 (유일한 계산 소스)
  const includedSpecies = Object.values(species)
    .filter(s => s.decision === "INCLUDE_IN_SURGERY");
  
  const surgeryProjection = calculateSurgeryProjection(
    includedSpecies,
    validationResult
  );

  // Step 3: 최종 의사결정
  return {
    metadata: {
      generatedAt: new Date().toISOString(),
      validationRuns: validationResult.runs,
      astCoveragePercent: validationResult.astCoveragePercent
    },
    species,
    surgeryProjection,
    decision: deriveDecision(species, surgeryProjection)
  };
}

function normalizeSpecies(
  name: string,
  metrics: PresenceMetrics,
  thresholdSweepResult: ThresholdSweepResult,
  gates: ConfidenceGates
): SemanticSpecies {
  // 규칙 1: Threshold Sweep에서 calibrated-out 판정?
  if (thresholdSweepResult.allZero) {
    return {
      state: "CALIBRATED_OUT",
      confidence: metrics.confidence,
      hitRate: `${metrics.hit}/${metrics.runCount}`,
      decision: "EXCLUDE_FROM_SURGERY",
      reason: `Not detected at any threshold level (${formatThresholds(thresholdSweepResult)})`
    };
  }

  // 규칙 2: Confidence로 상태 판정
  if (metrics.confidence >= gates.stable) {
    return {
      state: "STABLE",
      confidence: metrics.confidence,
      hitRate: `${metrics.hit}/${metrics.runCount}`,
      decision: "INCLUDE_IN_SURGERY",
      reason: `Detected in ${metrics.hit}/${metrics.runCount} runs (confidence ${metrics.confidence.toFixed(2)})`
    };
  }

  if (metrics.confidence >= gates.probable) {
    return {
      state: "PROBABLE",
      confidence: metrics.confidence,
      hitRate: `${metrics.hit}/${metrics.runCount}`,
      decision: "INVESTIGATE_FURTHER",
      reason: `Intermittent detection: ${metrics.hit}/${metrics.runCount} (confidence ${metrics.confidence.toFixed(2)})`
    };
  }

  // 기타: unstable
  return {
    state: "UNSTABLE",
    confidence: metrics.confidence,
    hitRate: `${metrics.hit}/${metrics.runCount}`,
    decision: "EXCLUDE_FROM_SURGERY",
    reason: `Unreliable (confidence ${metrics.confidence.toFixed(2)} < ${gates.probable})`
  };
}

function calculateSurgeryProjection(
  includedSpecies: SemanticSpecies[],
  validationResult: ValidationLayerResult
): SurgeryProjection {
  // 현재 상태 계산
  const before = validationResult.currentExternalEdges;
  
  // After 계산 (포함된 species만 제거하면 얼마나 줄어드는지)
  const after = calculateWithSurgeriesApplied(
    includedSpecies.map(s => s._raw),
    validationResult
  );

  return {
    externalEdgesBefore: before,
    externalEdgesAfter: after,
    reductionAbsolute: before - after,
    reductionPercent: (before - after) / before,
    confidence: deriveProjectionConfidence(
      includedSpecies,
      validationResult.astCoveragePercent
    ),
    confidencePercent: deriveConfidenceScore(includedSpecies),
    reason: `Based on ${includedSpecies.filter(s => s.state === "STABLE").length} STABLE + ${includedSpecies.filter(s => s.state === "PROBABLE").length} PROBABLE species`
  };
}
```

## Section 6: Evidence Radar

\`\`\`
  `;
}

// Helper: 모든 섹션에서 동일한 surgeryProjection 사용
function buildRadarSection(species: Record<string, SemanticSpecies>): string {
  let radar = "";
  for (const [name, spec] of Object.entries(species)) {
    const emoji = spec.decision === "INCLUDE_IN_SURGERY" ? "✅" : "⚠️";
    radar += `- ${emoji} ${name}: ${spec.state} (${spec.hitRate})\n`;
  }
  return radar;
}
