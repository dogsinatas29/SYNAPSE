# SYNAPSE v0.3.34.16 ~ v0.3.35 작업 계획

## 📅 작업 정보 - **상태:** 🚧 In-Progress
- **관련 마일스톤:** v0.3.34.15
- **목표:** Layout=Reality 원칙을 지키면서 프론트엔드의 Camera Fit 로직을 시각적 바운드 기반으로 분리(Visible Bounds Engine)하고, 외부 종속성을 3단계 계층 구조로 압축(External Layer Compression)합니다.

## 🧠 상세 설계 및 로직

### 1. Visible Bounds Engine (v0.3.34.16)
- **철학 유지**: `computeWorldBounds()`는 원본 그대로 두어 `Layout = Reality` 원칙을 보존합니다. 향후 Export나 Analytics 기능에 영향을 주지 않아야 합니다.
- **새로운 함수 추가**: `computeVisibleBounds()`를 신설하여 오직 화면에 보여지는 노드와 클러스터의 시각적 박스 크기만 합산합니다.
- **상수 분리**: `COLLAPSED_CLUSTER_WIDTH = 250`, `COLLAPSED_CLUSTER_HEIGHT = 80` 상수를 도입하여 `canvas-engine.js` 내에서 시각적 계산의 정확도를 일치시킵니다.
- **카메라(Camera Fit)**: `fitView()` 호출 시 `computeWorldBounds()`를 대체하여 `computeVisibleBounds()`를 사용해 B+ 정책을 달성합니다.

### 2. External Layer Compression (v0.3.35)
- **3-Tier 계층**: `External Dependencies > Domain > Node` 형태로 외부 종속성을 압축합니다.
- **상세 변경**: `GhostExpander.ts`에서 단일 클러스터(`cluster_ghosts`)에 고정되었던 로직을 복구/고도화하여 `linux`, `asm`, `uapi` 등 서브 도메인 클러스터를 `parent_id: 'cluster_ghosts'` 구조로 생성합니다.

## 🛠️ 기술적 변경 사항
- **Node Update**: 고스트 노드의 `cluster_id`를 하위 도메인 클러스터로 할당.
- **Edge Update**: 변경 없음.
- **File Changes**: 
  - `ui/canvas-engine.js` (`computeVisibleBounds` 추가 및 `fitView` 참조 변경)
  - `src/core/GhostExpander.ts` (계층형 클러스터 생성 로직 복원)

## ⚠️ 예외 처리 및 주의 사항
- `computeWorldBounds()`의 사이드 이펙트를 최소화하기 위해 코드 수정을 분리.
- `collapsed: true`가 적용된 최상위 클러스터를 확장했을 때, 내부 서브 클러스터들도 기본적으로 닫힌 상태를 유지해야 점진적인 노출(Progressive Disclosure) UX가 달성됩니다.
