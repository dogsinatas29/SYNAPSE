### 4. Cluster Meta Edge 증발 버그 원인 분석 및 해결 (Hotfix)
- **증상**: VSCode, Linux Kernel 등 초거대 모노레포에서 `EDGE VISIBILITY`를 `CLUSTER (Meta Edges)`로 설정 시, 카메라를 확대/축소해도 엣지가 렌더링되지 않음.
- **원인 (Root Cause)**:
  - 거대 그래프 렌더링 시 가속 모드(WebGL Renderer)가 활성화되는데, WebGL은 엣지(Edge)의 LOD(Meta Edges) 렌더링 기능이 구현되어 있지 않음.
  - 가속 모드(`webglRenderer`) 활성화 시, 기존 2D 캔버스(`renderEdges2D()`) 호출 자체가 완전히 생략(bypassed)됨.
  - 따라서, `window.edgeVisibilityMode === 'CLUSTER'` 상태에서 WebGL은 일반 엣지 렌더링을 스킵하고, Canvas 2D는 호출되지 않으므로 어떠한 엣지도 그려지지 않는 블라인드 존(Blind Zone)이 발생.
- **해결 방안 (Fix)**:
  - `webglRenderer` 활성화 시점(`_performRender` 내부)에, 2D 백그라운드 캔버스 오버레이 레이어에 명시적으로 `this.renderEdgeBundles(this.transform.zoom)`을 주입.
  - WebGL 노드 렌더링 이전에 `this.ctx`에 변환 행렬을 적용한 뒤 2D 캔버스에 그어주어, 노드 아래에 정상적으로 Meta Edge 곡선이 위치하도록 물리적 분리 렌더링 구현 완료.

### 5. 카메라 줌(Zoom) 바운스 및 0.0 렌더링 증발 버그 해결 (Hotfix)
- **카메라 튀는 현상 (Zoom Bounce)**: 일반 마우스 휠(delta 100) 입력이 트랙패드용 지수 스케일(`Math.exp`)에 그대로 들어가면서 단 한 번의 휠 굴림으로 Zoom이 `5.0`이나 `0.001`로 폭주하던 수식 오류 수정 (delta clamp 적용).
- **0 이하 증발 현상**: Zoom이 `0.001` 극한으로 내려갈 경우 2D Canvas의 `lineWidth`가 15,000을 초과하게 되어 브라우저(Chrome/V8)가 기하학적 렌더링을 포기하고 도화지를 백지화하는 문제 수정 (lineWidth 최대 8000으로 clamp).

### 6. Meta Edge LOD 및 Fit View 줌 이탈 픽스
- **Meta Edge LOD 픽스:** 클러스터 병합(Collapse) 시 내부 노드들이 가시성(Visibility)에서 컷아웃되면서 메타 엣지 집계에서 누락되는 현상 해결. `this._clusterEdgeMap` 전체를 순회하여, 노드가 숨겨져도 리프 클러스터가 활성 상태면 트래픽이 정상적으로 집계되도록 렌더링 파이프라인 수정.
- **Fit View B+ Policy 파기:** Fit View 연산 시 접힌 클러스터가 시각적 위치(`cluster.position`)를 참조하여 원점(0,0)으로 바운딩 박스를 왜곡시키던 B+ Policy를 제거. 렌더러와 동일하게 실제 공간(Reality Bounds)을 참조하도록 수정하여 거대 줌 이탈(Jumping) 방지.

### 7. 극단적 Zoom 축소 시 GPU 메모리 오버플로우로 인한 화면 꺼짐 현상 해결 (Hotfix)
- **증상**: "Only cluster"로 모든 클러스터가 접힌 상태에서, `Fit View` 동작 시 노드/클러스터 카운트가 `0`으로 출력된 직후 갑자기 화면이 꺼지거나 캔버스가 멈추는(White Screen) 현상 발생.
- **원인 (Root Cause)**:
  - 6번 수정으로 인해 접힌 클러스터가 거대 모노레포(예: Linux Kernel) 전체의 광활한 픽셀 공간(Reality Bounds)을 잃지 않고 정상적으로 확보하게 됨.
  - 이에 따라 `Fit View` 시 카메라 Zoom이 `0.001` 극한까지 축소되며 전경을 담아내게 되었으나, `renderClusters`의 클러스터 라벨 폰트 크기 계산식인 `14 / this.transform.zoom`에 의해 폰트 사이즈가 **14,000px** 단위로 폭주함.
  - 브라우저 Canvas 2D 엔진이 14,000px 크기의 글리프 텍스처를 그리려다 GPU VRAM 메모리 한계(OOM)를 초과하여 즉각적인 렌더링 파이프라인 붕괴(Crash) 및 컨텍스트 손실을 유발함.
- **해결 방안 (Fix)**:
  - `this.ctx.font` 렌더링 폰트 사이즈에 `Math.min(14 / this.transform.zoom, 1000)` 제약(Clamp)을 걸어 하드웨어 한계선을 방어함.
  - 우주적 관점(0.001 줌)으로 멀리서 보더라도 폰트 텍스처 할당량이 폭주하지 않도록 원천 차단하여 완전한 렌더링 안정성 확보 완료.

### 8. 'Cluster Only' 모드에서 Meta Edge 증발 버그 해결 (Hotfix)
- **증상**: 노드 표시를 끈 상태인 "Cluster Only" 뷰 모드로 진입할 경우, 엣지 옵션이 `Cluster (Meta Edge)` 임에도 불구하고 클러스터 간의 엣지가 아예 그려지지 않는 현상 발견.
- **원인**: 
  - `this.currentMode === 'cluster'` 진입 시 노드 및 엣지 렌더링(`renderEdges2D`) 전체가 통째로 스킵(Bypass)되도록 하드코딩되어 있었음. 
  - 메타 엣지를 그리는 `renderEdgeBundles` 호출마저 해당 분기(Branch) 내부에 종속되어 함께 증발해 버림.
- **해결 방안**: 
  - `this.currentMode === 'cluster'` 분기 내에서, 노드와 일반 엣지는 스킵하더라도 `window.edgeVisibilityMode === 'CLUSTER'` 조건이 충족되면 명시적으로 2D 백그라운드 캔버스에 `renderEdgeBundles`를 그리도록 호출을 독립시킴.
