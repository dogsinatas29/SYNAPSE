# 🧠 Core Philosophy

분석기는 그래프를 수정하지 않는다.

분석기는 상태를 변경하지 않는다.

분석기는 증거만 생성한다.

```text
Graph
 ↓
Analyzer
 ↓
Finding
 ↓
EvidenceBundle
 ↓
Report / Overlay / AI
```

---

# 🔒 Read Only Rule

모든 Analyzer는 반드시 읽기 전용이다.

허용:

```typescript
state.nodes.get(id)
state.edges
context.findings
```

금지:

```typescript
node.status = ...
edge.status = ...
graph.nodes.push(...)
graph.edges.push(...)
```

원본 그래프 변경 시 즉시 실패.

---

# 🔒 Evidence Rule

모든 분석 결과는 Finding으로 반환한다.

예시:

```typescript
{
    type: 'boundary_violation',
    nodeId: 'A',
    reason: 'Direct Core Access'
}
```

분석 결과를 그래프에 기록 금지.

---

# 🔒 Single Engine Rule

모든 구조 분석은 반드시

ArchitectureAnalysisEngine

을 통해 수행한다.

직접 실행 금지.

예시:

```typescript
new LogicAnalyzer()
new VirtualDebugger()
```

신규 생성 금지.

# 🔒 Plugin Rule

분석기는 플러그인 형태만 허용.

```typescript

```

# 🔒 Deterministic Rule

동일 입력

↓

동일 결과

100% 보장

금지:

```typescript
Math.random()

Date.now()

Unordered iteration
```

Finding 출력 순서는 반드시 정렬.

---

# 🔒 Performance Rule

분석기 목표:

```text
O(N + E)
```

허용:

- Set
- Map
- Queue
- BFS
- DFS

금지:

```text
O(N²)
O(N³)
Nested Full Scan
```

# 🔒 Async Rule

분석 코어 내부:

허용:

```typescript

```

금지:

```typescript
await analyzer.run()

Promise

setTimeout

queueMicrotask
```
