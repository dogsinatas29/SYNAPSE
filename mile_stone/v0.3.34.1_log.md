## 🧠 상세 설계 및 로직
- **AST 격리 파이프라인 (Phase 1):** 정규식 기반의 가벼운 심볼/임포트 스캐너(`AstSymbolResolver`)를 도입하되, 파싱 결과가 원본 그래프(`ProjectState`)를 변조하지 않고 `AnalysisContext.astCache`에만 O(1) 해시맵으로 격리되도록 설계.
- **플러그인 분해 및 이관 (Phase 2~4):** 레거시 `LogicAnalyzer` 내부의 핵심 기능들을 `CycleAnalyzer`, `BoundaryGuardAnalyzer`, `DependencyPressureAnalyzer`, `SchemaViolationAnalyzer`, `DeadEndAnalyzer`, `IsolatedNodeAnalyzer`로 완벽 분해 이관.
- **Zero Mutation 및 통계 무결성 원칙 강제:** 엔진 실행 전후로 Node/Edge 객체의 메모리 참조값 보존(VP-02)과, 레거시 분석 결과와 신규 분석 결과가 100% 매칭됨(VP-01, VP-03, VP-04, VP-05, VP-06)을 증명하는 하드코어 록인 체계 확립.
- **ReportExporter 도입:** 분석과 출력을 디커플링하여, 어떠한 분석도 수행하지 않는 순수 렌더러가 `EvidenceBundle`을 `Unified Architecture Report` 포맷으로 1:1 직렬화하도록 구조 개편.

### 2. ASR 보고서 Audit 섹션 비어있음 문제 진단

#### 문제 발견
ASR 보고서에서 Healthy Hubs는 정상 출력되는데, Audit 섹션이 비어있는 현상 발견.

```
4. System Assembly Points (Healthy Hubs)

4.1 ASSEMBLY_POINT Audit
No candidates found.  ← 비어있음

4.2 CONTRACT_HUB Audit
No candidates found.  ← 비어있음
```

#### 독립 결함 2개 발견

**Bug A: `assemblyAudit` 생성 실패**

관측 로그 결과:
```
[PIPELINE_ASSEMBLY_AUDIT] assemblyAuditLength: 22  ← DataPipeline에서 정상 생성
[ASSEMBLY_AUDIT_SAVE] graphAnalysisLength: 0       ← ValidationEngine에서 0
```

즉, **동일 함수가 서로 다른 상태의 입력을 받고 있다**.

**Bug B: `architecturalFindings` report export 누락**

관측 로그 결과:
```
[VRB_ENTRY] ctxArchitecturalFindings: 50           ← ValidationReportBuilder 진입 시 존재
[VRB_REPORT] architecturalFindings: -1             ← report 객체에는 없음
JSON: architecturalFindings 키 없음                ← 최종 출력에도 없음
```

즉, **데이터는 존재하지만 report 객체에 포함되지 않음**.

#### Bug B 원인 확정

**증거 체인:**
```

  ↓

  ↓
ValidationReportBuilder
  ↓

  ↓
report.architecturalFindings = undefined ❌
  ↓
JSON.stringify(report)
  ↓
architecturalFindings 키 없음
```

**근본 원인:** `ValidationReportBuilder.ts` Line 300에서 `report.snapshot`이 설정되지 않음.

```typescript
// Line 300
const report = { ...ctx.metrics, subjectFingerprint: fingerprint, buildVersion: BUILD_VERSION } as any;
// ❌ report.snapshot 없음

// Line 508
const archFindings = report.snapshot?.metadata?.architecturalFindings || [];
// ❌ report.snapshot이 없으므로 archFindings = []
```

**수정 방향:**
```typescript
// Line 301 근처 추가
report.architecturalFindings = (ctx.snapshot as any).metadata?.architecturalFindings || [];

// Line 508 수정
const archFindings = report.architecturalFindings || [];
```
