# v0.3.34.22 Answer Engine Architecture

The **Answer Engine** is the final layer of SYNAPSE's reasoning stack. Its responsibility is to translate low-level technical `Findings` into high-level, human-readable, and explainable `Answers` to the 8 core architectural questions.

## Architecture

```text
Graph -> Evidence -> Rule -> Finding -> AnswerAggregator -> Answer
```

- **Rule:** Responsible for making judgments (e.g., "This node is a DOMINANT_AUTHORITY").
- **AnswerAggregator:** Responsible for compiling, ranking, and explaining those judgments into a structured answer for a human architect.

## The Answer Model

```typescript
export interface IAnswer {
    questionId: string;           // e.g., 'Q1', 'Q2'
    questionText: string;         // e.g., "누가 시스템을 지배하는가?"
    
    // The summarized, high-level answer for the user
    summary: string;              
    
    // Detailed breakdown mapping targets (nodes/paths) to human-readable explanations
    items: IAnswerItem[];         
}

export interface IAnswerItem {
    targetId: string;             // The core subject (Node ID or Path string)
    score: number;                // Optional ranking score
    explanation: string;          // Human-readable "Why"
    supportingEvidence: string[]; // Tracing back to raw evidence IDs
}
```

## The Aggregators
Each architectural question is handled by a dedicated `AnswerAggregator`.

### 1. `Q1EntryPointAggregator`
- **Reads:** `CONTROL_PIPELINE` Findings, `DOMINANT_AUTHORITY` Findings.
- **Logic:** Identifies the sources of control pipelines that terminate at or pass through authorities. Ranks them by the number of critical paths they initiate.

### 2. `Q2AuthorityAggregator`
- **Reads:** `DOMINANT_AUTHORITY` and `MAJOR_AUTHORITY` Findings.
- **Logic:** Sorts findings by score (Top 10). Maps underlying role and reachability evidence into a bulleted "Why" string.

### 3. `Q7DataFlowAggregator`
- **Reads:** `DATA_PIPELINE` Findings.
- **Logic:** Sorts by pipeline confidence. Dedupes similar sub-paths.

### 4. `Q8ControlFlowAggregator`
- **Reads:** `CONTROL_PIPELINE` Findings.
- **Logic:** Sorts by pipeline confidence.

## Explainability Rules
1. **No Opaque IDs in Summaries:** "ev-102" means nothing to a human. Aggregators must translate evidence into semantic terms (e.g., "Has 120 fan-in connections").
2. **Actionable Sorting:** Items must always be ranked by importance/confidence, not alphabetically.

## Validation 
The Answer Engine's output is directly evaluated against `v0.3.34.22_answer_validation.md`.
