# v0.3.34.22 Blast Radius Ontology

The Blast Radius Layer (Phase 8) is the ultimate synthesis layer. It combines Authority, Flow, Boundary, Criticality, and Extension findings to predict the structural impact of modifying or deleting a node.

## The Core Principle
> Authority = How many things reference it.
> Criticality = How essential it is to the domain.
> Blast Radius = How widely the destruction spreads if it is removed.

A node can have massive Authority but low Blast Radius (e.g., `Logger`), or low Authority but Critical Blast Radius (e.g., `GraphSchema`).

## Findings Ontology

To avoid Rule Explosion, we emit a single finding type:
### `BLAST_RADIUS`

The severity of the blast is encoded in the Evidence.

#### 1. `CRITICAL`
- **Impact:** Removal causes core pipeline collapse or severs communication between primary boundaries.
- **Criteria:** Node is a `CORE` pillar AND acts as a Boundary Crosser or governs a critical pipeline/extension ecosystem.

#### 2. `HIGH`
- **Impact:** Removal disables major features across multiple boundaries.
- **Criteria:** Node bridges multiple boundaries or is a heavily utilized Extension Point.

#### 3. `MEDIUM`
- **Impact:** Removal causes localized feature degradation within a single boundary.
- **Criteria:** Node is `SUPPORTING` and affects local flows.

#### 4. `LOW`
- **Impact:** Removal causes compile errors but no architectural structural shifts.
- **Criteria:** Node is a `UTILITY` (even with massive fan-in).

## Analysis Pipeline

```text
Phases 1~7 Findings
  ↓
BlastRadiusAnalyzer
  ↓
IBlastRadiusEvidence
  ↓
BlastRadiusRule
  ↓
BLAST_RADIUS (Severity)
```

### Evidence Structure
```typescript
interface IBlastRadiusEvidence {
    nodeId: string;
    affectedBoundaryIds: string[];
    affectedCoreNodeIds: string[];
    affectedPipelineIds: string[];
    affectedExtensionPointIds: string[];
    affectedBoundaryCount: number;
    affectedCoreCount: number;
    affectedPipelineCount: number;
    affectedExtensionPointCount: number;
    isBoundaryCrosser: boolean;
    isPipelineOwner: boolean;
    isPipelinePayloadDefinition: boolean;
    criticality: 'CORE' | 'SUPPORTING' | 'UTILITY';
    confidence: number;
}
```
