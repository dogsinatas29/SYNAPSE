# v0.3.34.22 Phase 6 Validation (Criticality Layer)

This document defines the strict validation criteria for the Criticality Layer, ensuring the engine mathematically separates structural necessity from naive reference counts.

## Required Validation Tests (`test/phase6_validation.test.ts`)

### 1. Utility Inflation Test
- **Scenario:** A `Logger` node has a massive fan-in (e.g., 100 incoming edges) from every layer in the system, but 0 outgoing edges to core domain logic. It sits in an isolated Boundary Island.
- **Expected Result:** The engine must classify `Logger` as `UTILITY`, completely ignoring its artificially inflated Authority/Reachability.
- **Fail Condition:** `Logger` is classified as `CORE` due to high fan-in.

### 2. Hidden Core Test
- **Scenario:** A `GraphSchema` node has very low fan-in (only 1 or 2 core managers read it), but it acts as the primary data payload in critical `DATA_PIPELINE`s.
- **Expected Result:** The engine must classify `GraphSchema` as `CORE` because it dictates the structure of the data pipeline.
- **Fail Condition:** `GraphSchema` is classified as `SUPPORTING` or `UTILITY` due to low reference counts.

### 3. Core Removal Simulation Test
- **Scenario:** The test verifies the rule logic: If a node is identified as a Boundary Crosser AND participates in a major Control Pipeline, it MUST be `CORE`.
- **Expected Result:** The rule correctly assigns `CORE` to nodes carrying structural weight.

### 4. Utility Removal Simulation Test
- **Scenario:** The test verifies that a node with high fan-in but no pipeline participation, no state ownership, and no boundary crossing is strictly `UTILITY`.
- **Expected Result:** The rule isolates it to `UTILITY`.

### 5. False Core Prevention Test
- **Scenario:** A `CacheManager` has high Authority (referenced often) and acts as a Boundary Crosser, but it does NOT own state, does NOT own policy, and does NOT participate in critical Data/Control pipelines.
- **Expected Result:** The engine must classify `CacheManager` as `SUPPORTING`.
- **Fail Condition:** `CacheManager` is classified as `CORE`.
