## 🧠 상세 설계

### 축 오염 금지 (가장 중요한 규칙)

```text
ViewState  ↔  LifecycleState  전이 금지
ViewState  ↔  HealthState     전이 금지
```

- `OUT_OF_SCOPE`는 `ViewState`. LifecycleState와 전이 불가.
- `CORE_RUNTIME`은 LifecycleState. ViewState와 전이 불가.
- 축이 다른 전이는 Rule 등록 전에 필터링.

---

### TransitionRule — 허용/금지 선언

```typescript
interface TransitionRule {
    from    : LifecycleState | HealthState;  // ViewState 전이 금지
    to      : LifecycleState | HealthState;
    allowed : boolean;
    reason  : string;
}
```

선언 예시:

```typescript
// 허용
{ from: UNCLUSTERED, to: CLUSTERED,   allowed: true  }
{ from: CLUSTERED,   to: CORRUPTED,   allowed: true  }
{ from: CLASSIFIED,  to: UNCLASSIFIED,allowed: true  }

// 금지
{ from: DISCOVERED,  to: CLASSIFIED,  allowed: false, reason: 'skips PARSED/REGISTERED/CLUSTERED' }
{ from: HEALTHY,     to: DISCOVERED,  allowed: false, reason: 'no backward transition' }
```

---

### TransitionChain — 경로 단위 검사

단순 A→B 검사가 아니라 경로 전체의 유효성 판정.

```typescript
interface TransitionChain {
    nodeId  : string;
    path    : (LifecycleState | HealthState)[];
    valid   : boolean;
    reason? : string;
}
```

`DISCOVERED → CLASSIFIED` 검사 시 중간 단계 누락(PARSED/REGISTERED/CLUSTERED) 탐지.

---

### TransitionGrammar — 검증기

```typescript
class TransitionGrammar {
    // A→B 단일 전이 유효성
    validate(from: NodeState, to: NodeState): TransitionValidation;

    // 현재 NodeState[]의 FSM 일관성 검사 (전이 이력 불필요)
    auditStateConsistency(nodes: NodeState[]): FSMAuditSummary;
}
```

> `audit(nodes)` → `auditStateConsistency(nodes)`
> 실제 하는 일은 "전이 검증"이 아니라 "FSM 일관성 검사"이기 때문.

---

### FSMAuditSummary

```typescript
interface FSMAuditSummary {
    missing    : number;   // 중간 단계 누락
    invalid    : number;   // 논리적 불가 전이
    uncharted  : number;   // 정의되지 않은 경로 (Unknown 아님)
    violations : TransitionViolation[];  // MAX 100개 cap
}

interface TransitionViolation {
    nodeId  : string;
    path    : string;   // "DISCOVERED→CLASSIFIED"
    type    : 'MISSING' | 'INVALID' | 'UNCHARTED';
    reason  : string;
}

const MAX_VIOLATIONS = 100; // 하드 cap — 커널 7만 노드 대응
```

## ⚠️ 예외 처리 및 주의 사항

| 항목 | 기준 |
|---|---|
| Violation cap | MAX 100개, 초과분 드롭 |
| 축 오염 | ViewState 전이 Rule 등록 시 compile-time reject |
| 역방향 전이 | LifecycleState 역방향은 CORRUPTED 경유 시만 허용 |
| 보고서 크기 | 인라인 증거 금지, 요약 + 링크만 |
