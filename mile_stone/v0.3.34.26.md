### 목표

> 그 노드가 깨지면 무엇이 영향을 받는가? (What if that node breaks?)

**단, 하지 않는 것: "실행 시 실제로 무엇이 발생하는가?"**

```text
Execution Simulation / Runtime Prediction  ❌  (Architecture Only 위반)
Failure Propagation Engine                 ✅  (State 기반 의존성 파급 계산)
```

현재 State + Dependency Graph만으로 결함이 어디까지 전파되는지 계산한다.

---

### 핵심 원칙

```text
Failure Propagation  ≠  Execution Simulation
```

#### 절대 금지 (KISS 위반 및 OOM 원인)
- 런타임 에러 예측 (스케줄러, 메모리 등 동적 추론 금지)
- Failure Cache, Impact Cache, Propagation Snapshot 등 일체의 전파 상태 저장/누적
- 무한 뎁스(Depth) 순회 탐색 (성능 폭발)

#### 필수 제약 (하드 스탑)
- `MAX_PROPAGATION_DEPTH = 3`
- `MAX_IMPACT_NODES = 1000` (리눅스 커널 등 대형 프로젝트 대응)
- **Compute → Report → Discard** (계산 후 즉시 폐기)

#### 허용
- 정적 의존성(Edge)을 통한 결함 전파 계산
- 전파 깊이(Depth) 제한 적용
- Failure Propagation 보고서 생성

## 🧠 상세 설계

### Propagation Grammar (전파 문법)

`HealthState`를 기준으로 결함 전파의 심각도를 정의한다.

```text
CORRUPTED (Hard Bug)
  ↓ [Modifies/Owns]
Target: CORRUPTED 전파 (강함)

UNCLUSTERED (Soft Bug)
  ↓ [DependsOn]
Target: UNCLASSIFIED 전파 (약함)
```

### 전파 제한 (Depth & Breadth Limit)

그래프 전체 순회(O(V+E))는 금지. 
```text
MAX_PROPAGATION_DEPTH = 3
MAX_IMPACT_NODES = 1000
```
