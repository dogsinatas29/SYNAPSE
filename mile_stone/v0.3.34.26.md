### 목표

> 그 노드가 깨지면 어떻게 되는가? (What if that node breaks?)

**단, 이 질문에 답하는 방법은 "예측"이 아니다.**

```text
Runtime Profiler / Prediction  ❌  (Architecture Only 위반)
Failure Propagation Engine     ✅  (State 기반 의존성 파급 계산)
```

현재 State + Dependency Graph만으로 결함이 어디까지 전파되는지 계산한다.

---

### 핵심 원칙

```text
Failure Propagation  ≠  Runtime Error Prediction
```

#### 절대 금지 (KISS 위반)
- 런타임 에러 예측
- 메모리 프로파일링
- 콜스택(Call stack) 동적 분석
- 무한 뎁스(Depth) 순회 탐색 (성능 폭발)

#### 허용
- 정적 의존성(Edge)을 통한 결함 전파 계산
- 전파 깊이(Depth) 제한 적용
- Failure Propagation 보고서 생성

---

### 산출물

```text
Failure Propagation Report

Critical Nodes       : N   (깨지면 많이 부서지는 놈)
Vulnerable Nodes     : N   (남이 깨지면 잘 부서지는 놈)
Propagation Paths    : N
```

## 🧠 상세 설계

### Propagation Grammar (전파 문법)

`HealthState`를 기준으로 결함 전파의 심각도를 정의한다.

```text
CORRUPTED (Hard Bug)
  ↓ [Modifies/Owns]
Target: CORRUPTED 전파 (강함)

UNCLUSTERED (Soft Bug)
  ↓ [DependsOn]
Target: UNCLASSIFIED 전파 (약함)
```

### 전파 깊이 (Depth Limit)

그래프 전체 순회(O(V+E))는 금지. O(k)로 제한.
```text
MAX_PROPAGATION_DEPTH = 3
```
