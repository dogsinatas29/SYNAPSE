🚀 Milestone v0.3.34.27 - Topology Mutation

## 📅 작업 정보 - **상태:** ✅ Completed
- **관련 마일스톤:** [v0.3.34.26](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/mile_stone/v0.3.34.26.md)
- **목표:** 원본 그래프 복제(Clone) 없이 가상 그래프(Topology Overlay)를 생성하여, 핵심 노드 결함 시나리오 시뮬레이션을 수행하고 변화된 파급력을 재계산한다. "Compute → Report → Discard" 원칙을 준수하여 OOM을 방어한다.

## 🧠 상세 설계 및 로직

- **Topology Overlay (가상 레이어)**:
  - 메모리 폭발을 막기 위해 70K 전체 노드를 복사하지 않고, 변경된 `removedNodes`, `removedEdges`, `addedEdges`만 추적하는 Delta 객체 사용.
  - 가상 레이어를 통해 `isNodeAlive`, `isEdgeActive`, `getActiveEdges` 인터페이스를 제공하여 원본 그래프를 안전하게 감싼다.
- **순수 구조적 변형 (No State Mutation)**:
  - 27버전의 목표는 "노드 제거, 엣지 절단" 등의 물리적 단절 시뮬레이션이다. 상태 전이(HealthState 변화)는 완전히 배제되었다.
- **26버전 엔진(FailurePropagator) 재사용**:
  - `TopologyMutator`는 자체적인 탐색 엔진을 가지지 않고, 위에서 생성한 가상 오버레이를 26버전의 엔진에 주입하여 재평가만 수행한다.
- **Simulation Target Selector**:
  - 리포트 계층과의 결합(Layer Leak)을 막기 위해, `Blast Radius == HIGH` 기준 대신 26버전 리포트에서 `Top N Impact Nodes`를 추출하여 시뮬레이션 대상을 한정한다.

## 🛠️ 기술적 변경 사항

  - `src/core/FailurePropagator.ts`: TopologyOverlay를 인자로 받아 투과적으로 BFS를 돌리도록 리팩토링

## ⚠️ 예외 처리 및 주의 사항
- **Memory Budget**:
  - Kernel 70K 환경에서 Mutation Overlay 수행 시 메모리 증가 타겟은 +10MB 이하, 하드 스탑은 +50MB로 고정. 
  - 생성된 `TopologyOverlay`는 시뮬레이션 후 리포트를 반환함과 동시에 폐기(GC)되어야 한다.
