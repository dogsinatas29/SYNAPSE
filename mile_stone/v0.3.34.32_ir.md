# Purpose

본 문서는 v0.3.34.32 Architectural Reasoning Layer의 내부 데이터 계약(IR)을 정의한다.

이 문서는 다음을 정의한다.

```text
무엇을 저장하는가
```

```text
무엇을 전달하는가
```

```text
무엇을 소비하는가
```

```text
무엇을 설명하는가
```

---

이 문서는 정의하지 않는다.

```text
알고리즘
```

```text
가중치
```

```text
수식
```

```text
점수 계산
```

```text
예측 모델
```

```text
실행 시뮬레이션
```

---

# Global Rules

## Rule 1

Immutable

---

IR 생성 후 수정 금지

허용:

```text
Read
```

```text
Create New Result
```

금지:

```text
Mutate Existing Result
```

---

## Rule 2

Evidence Required

모든 결과는 반드시

```text
EvidenceFlags[]
```

를 가진다.

---

모든 결과는 반드시

```text
EvidenceReferences[]
```

를 가진다.

---

금지:

```text
Conclusion

without

Evidence
```

---

## Rule 3

Traceable

모든 결론은

```text
Evidence
↓
Classification
↓
Conclusion
```

경로를 복원 가능해야 한다.

---

## Rule 4

Static Only

IR은

```text
Runtime
```

를 저장하지 않는다.

---

IR은

```text
Execution Order
```

를 저장하지 않는다.

---

IR은

```text
Call Sequence
```

를 저장하지 않는다.

---

## Rule 5

Possibility Based

Propagation과 Corridor는

```text
Potential Influence
```

를 설명한다.

---

다음을 의미하지 않는다.

```text
Will Execute
```

---

```text
Will Happen
```

---

```text
Guaranteed Outcome
```

# Success Criteria

IR은

```text
Evidence
```

를

```text
Classification
```

으로 전달한다.

---

IR은

```text
Reasoning Trace
```

를 보존한다.

---

IR은

```text
Calculation Engine
```

이 아니다.

---

IR은

```text
Prediction Engine
```

이 아니다.

---

IR은

```text
Evidence Transport Layer
```

이다.

---

v0.3.34.32의 모든 Reasoning 단계는

```text
Evidence

↓

Classification

↓

Conclusion
```

구조를 유지해야 한다.

# Final Principle

```text
Evidence Describes Reality

Reasoning Explains Evidence

Conclusion Explains Architecture
```

---

```text
Prediction Is Forbidden

Evidence Is Mandatory
```
