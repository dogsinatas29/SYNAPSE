# 🚀 Milestone v0.3.34.34 - Analyzer Re-engineering (Virtual Debugging)

## 📅 작업 정보 - **상태:** 🏗️ Planned
- **관련 마일스톤:** v0.3.34.33 (Analyzer Metrology)
- **최종 성공 기준 (Success Criteria):** 
  - **Amplification Reduction:** Target Amplification <20x (>80% reduction from 190x baseline)
  - **Misleading Reduction:** CII Reduction >50% (집단 착시/가짜 엣지 50% 이상 감소)
  - **Coverage Regression Guard:** Coverage Retention >90% (데이터를 단순 삭제하여 증폭률을 낮추는 꼼수 원천 차단)
  - *이 목표들을 동시에 달성하지 못하면 다른 모든 결과가 좋아도 실패로 간주한다.*

## 🧠 상세 설계 및 로직
v0.3.34.33의 관측 데이터를 기반으로, 가장 치명적인 생존 위협(객체 폭발)부터 도려낸다.

### Phase 1: Amplification Surgery (객체 폭발 억제)
- **목표:** "어디서 폭발했는가"를 넘어 "어떤 경로와 원인으로 증폭했는가"를 추적한다.
- **Amplification Path Analyzer** 도입:
  - 단계별 입출력을 추적하고 증폭률을 계산.
  - 증폭 원인을 다음의 `AmplificationCause` Enum으로 정형화하여 식별한다:
    - `CROSS_PRODUCT` (교차 생성 방치)
    - `DUPLICATE_TRAVERSAL` (중복 순회)
    - `RECURSIVE_EXPANSION` (재귀 폭발)
    - `VALIDATION_FANOUT` (검증 단계 확장)
    - `STATE_REPLICATION` (상태 복제)
    - `CACHE_MISS_STORM` (캐시 부재로 인한 재생산)
    - `UNKNOWN`
- **산출물:** `Amplification Path Report` (Top 증폭 경로 및 원인 식별)
- **수술 결정:** 식별된 원인(Cause)에 따라 즉각적인 대응 수술(Actuation)을 단행한다. (예: `VALIDATION_FANOUT` → dedupe, `CACHE_MISS_STORM` → cache, `CROSS_PRODUCT` → limiter)

### Phase 2: Misleading Edge Surgery (착시 엣지 제거)
- **목표:** 단순한 오탐 제거를 넘어 가장 위험한 **집단 착시(Consensus False Positive)** 타격
- `BlindSpotMapper`와 v33에서 수집된 CII 데이터를 기반으로, **False Positive Filter Layer**를 도입한다.
- **CII 기반 타격:** 단순 AST 검증 실패 제거뿐만 아니라, `CII High + Ground Truth Low` (모두가 동의하지만 정답이 아닌) 조합을 최우선으로 차단(Discard)한다.
- 버릴 때는 반드시 **Reject Reason**을 기록하여 추적 가능성(Attribution)을 보장한다.

### Phase 3: Recoverability Layer (맹점 복구)
- **목표:** 가장 저렴한 비용으로 사각지대(Blind Spot) 복구
- 추출 실패 시 `RecoverabilitySource`를 활용한 Fallback 파이프라인 구현 (예: Regex 실패 → AST 시도 → Semantic 시도).
- **절대 원칙 (Fail-Closed):** 모르는 건 용납 가능, 틀리게 아는 건 치명적이다 (Blind > Misleading). 복구 실패 시 가짜 합성을 금지하고 확실하게 차단(Closed)한다.

### Phase 4: Governance Engine (우선순위 자동 산출)
- **상태:** P1 (v34.34 Deliverable 아님. Design Prepared: Yes)
- 생존이 확보된 이후, 남은 이슈들을 스코어링하는 엔진은 후순위(v34.1 등)로 이관.
