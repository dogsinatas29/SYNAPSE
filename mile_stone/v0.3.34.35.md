## 🧠 상세 설계 및 로직

### Phase 1: Amplification & Runtime Stability
- **목표:** 반복 실행 시 증폭률과 실행 시간의 변동성이 통제 범위를 넘지 않음을 증명.
- **방법:** Linux, VSCode, AntennaPod 각 **Warm-up 1회 + N=30회 반복 실행** 후 `Amplification Factor` 및 `Execution Time`의 Coefficient of Variation 계산. (Run0는 캐시 워밍업용으로 버림)
- **CV Formula:** `CV = sampleStdDev / mean` (using N-1)
- **성공 기준:** Amplification CV < 1%, Execution Time CV < 5%

### Phase 2: Coverage & CII Stability
- **목표:** 허수 제거 수치와 유효 데이터 보존율이 매 런타임마다 출렁이지 않음을 증명.
- **방법:** `Coverage Retention`과 `CII Reduction`의 N=30회 런타임 최대 편차(Drift) 측정.
- **성공 기준:** Coverage Drift < 1%, CII Drift < 2%

### Phase 3: Snapshot Drift Analysis
- **목표:** 버전 간 비교를 통해 회귀(Regression) 여부 확인.
- **방법:** 런타임 간 `BenchmarkSnapshot`을 대조하여 예측 불가능한 편차 식별.
- **Expected Drift (허용):** Timestamp, Runtime UUID
- **Unexpected Drift (차단):** Node Count, Edge Count, Validation Result, Coverage, Amplification, CII
- **성공 기준:** Unexpected Drift = 0

### Phase 4: Deterministic State Verification (Hash)
- **목표:** 동일 입력에 대해 내부 그래프 상태가 비결정성에 오염되지 않음을 수학적으로 입증.
- **방법:** 매 런마다 `project_state.json`, `validation_context.json`, `graph_snapshot.json` 등의 Canonical JSON Hash(SHA256)를 계산하여 비교.
- **Canonical JSON Rules:**
  1. Object Key Sort (Lexicographic)
  2. Stable Array Ordering (if order is not semantically meaningful)
  3. Remove Timestamp
  4. Remove Runtime UUID
  5. UTF-8 normalized stringify
- **성공 기준:** 
  - 각 파일별 Hash Match Rate = 100%
  - All Artifacts Match = PASS

## ⚠️ 예외 처리 및 주의 사항
- **비결정성(Non-determinism) 타격:** 만약 분산(Variance)이 임계치를 초과한다면, 이는 아직도 Set, Map 순회 순서 의존성이나 비동기 Race Condition이 남아있다는 뜻이다. 이 경우 해당 병목을 추적하여 결정론적 코드로 리팩토링해야 한다.
- **Deterministic Gate (Governance 자격 심사):**
  - PASS only if:
    - `Amplification CV < 1%`
    - `Execution Time CV < 5%`
    - `Coverage Drift < 1%`
    - `CII Drift < 2%`
    - `Hash Match Rate = 100%`
    - `Unexpected Drift = 0`
  - Otherwise: Governance Engine entry prohibited. (측정이 흔들리면 Governance 점수는 쓰레기가 된다)
- **Deterministic Failure Report 규격:** 
  - 실패 시 디버깅을 위해 아래 포맷으로 리포트 출력 강제:
    ```text
    Deterministic Failure Report
    Category: HASH_MISMATCH (또는 AMPLIFICATION_VARIANCE 등)
    Artifact/Metric: validation_context.json
    Run: 17
    Expected: sha256:xxxx
    Actual: sha256:yyyy
    ```
  - `Unexpected Drift Report` 규격 (Snapshot Drift 발생 시):
    ```text
    Unexpected Drift Report
    Artifact: graph_snapshot.json
    Run A:
    Node Count = 63,281
    Edge Count = 1,245,881
    
    Run B:
    Node Count = 63,281
    Edge Count = 1,245,879
    
    Delta:
    Edge -2
    
    Affected IDs:
    edge_11451
    edge_99122
    ```
