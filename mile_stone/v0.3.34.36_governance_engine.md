```

│                                             │
│  RootCauseAggregator                        │
│          ↓                                  │
│  RiskClassifier        → RiskType axis      │
│          ↓                                  │

│          ↓                                  │
│  ParetoFrontier        → dominance axis     │
│                                             │
│  Output: FrontierResult (untruncated)       │
└──────────────────┬──────────────────────────┘
                   │

│                                             │

                   │
                   ▼
              DTO / Report
```

## Pipeline

```
RootCauseAggregator → RiskClassifier → RiskVectorBuilder → ParetoFrontier → FrontierPartitioner → DTO
```

Two orthogonal axes:

```
RiskType  = WHAT kind of risk (classification)
Frontier  = WHERE in dominance space (dominance)
```

## Pareto Dominance

```
A dominates B ⟺ ∀ dim: A[dim] ≥ B[dim] ∧ ∃ dim: A[dim] > B[dim]
Frontier = { x | ¬∃ y : y dominates x }
```

## Special Rules

- **INTENDED_HUB**: Frontier 제외 (설계 의도 ≠ 위험)
- **UNKNOWN_HUB**: 일반 참여자, 예외 없음
- **Frontier**: 절대 자르지 않음 (Preservation Invariant)
- **Display Window**: Report Layer 책임
