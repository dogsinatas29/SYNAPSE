## Root Cause Analysis

### 발견된 원인

**예상과 달랐던 점:**

예상:
- src/server → REJECT_WEAK (cohesion 부족)
- src/webview → WRAPPER (submodule coupling 낮음)

실제:
- **모두 REJECT_SMALL**
- Boundary 승격 알고리즘 문제가 아님
- **Candidate Generation 단계에서 이미 members가 축소됨**

### 핵심 문제

1. **Candidate Generation Issue**
   - src/webview가 실제 폴더에는 수십 개 파일이 있지만, 후보 생성 시 Members=1로 들어옴
   - src/server도 Members=4로 축소됨
   - BoundaryDetector가 폴더 전체를 보지 못하고 개별 파일만 봄

2. **MIN_INTERNAL_EDGES Threshold**
   - src/core/collaboration: Members=17, Internal=14 → 탈락 (MIN_INTERNAL_EDGES=20 미만)
   - src/core/metrology: Members=25, Internal=13 → 탈락 (같은 이유)
   - 실제로는 의미 있는 subsystem이지만 internal edges 기준 때문에 탈락

3. **Internal Edges = 0 문제**
   - src/server, src/bootstrap, src/webview 모두 Internal Edges=0
   - 후보 생성 시 edge가 제대로 집계되지 않는 것으로 보임
