# Core Philosophy

Simulation is not execution.

Simulation is not runtime emulation.

Simulation is not code interpretation.

Simulation is:

```text
Topology Transformation

```

performed against:

```text
Projected Architectural State

```

derived from:

```text
project_state.json

```

# Simulation Architecture

## Old Assumption (Rejected)

Previous design assumed:

```text
project_state.json
↓
Deep Clone
↓
simulation_state.json
↓
Simulation

```

This design is now rejected.

Reason:

```text
Linux Kernel Snapshot
≈ 250 MB

Deep Clone
↓
Heap Explosion
↓
OOM
↓
Exit 133

```

Historical evidence already exists.

# New Architecture

## Phase 1

### Projection Layer

```text
project_state.json
↓
SimulationProjectionBuilder (Non-blocking Stream / Chunk Slicing)
↓
Simulation Working Set

```

---

Purpose:

Extract only the required simulation scope without blocking the Node.js event loop or triggering V8 heap exhaustion.

---

Supported scopes:

```text
Project

Cluster

Node

```

---

Examples

### Project Scope

```text
Entire Snapshot

```

---

### Cluster Scope

```text
fs/

```

Only:

```text
fs/

Files inside fs/

Dependencies crossing fs/

```

---

### Node Scope

```text
inode.c

```

Only:

```text
inode.c

Dependencies connected to inode.c

```

---

Result:

```text
Simulation Working Set

```

---

# Phase 2

## Isolation Layer

Simulation never touches runtime graph objects.

---

Forbidden:

```text
GraphModel

GraphNode

GraphEdge

BoundaryStore

```

---

Instead:

```text
SimulationSnapshot

SimulationNode

SimulationEdge

SimulationBoundary

SimulationCluster

```

are created.

---

Purpose:

```text
Hard Isolation

```

between:

```text
Production State

```

and

```text
Simulation State

```

---

# Phase 3

## Boundary Resolution Layer

Simulation consumes boundaries.

Simulation never creates boundaries.

---

Allowed:

```text
Boundary Lookup

Boundary Selection

Boundary Evaluation

```

---

Forbidden:

```text
Boundary Promotion

Boundary Creation

Boundary Rewrite

```

---

Output:

```text
Simulation Boundaries

```

---
