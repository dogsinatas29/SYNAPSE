# Goal

Implement a Scenario-Driven Architecture State Transition Simulation Layer on top of the existing SYNAPSE reporting pipeline.

```text

Support Architecture Simulation

Remain Fully Isolated

Remain Deterministic

```

---

# Guiding Principle

Simulation is not:

```text
Graph Generation

Boundary Generation

Runtime Execution

Process Emulation

```

Simulation is:

```text
Architecture State Analysis

```

performed against:

```text
Projected Snapshots

```

derived from:

```text
project_state.json

```

# Phase 1

## Simulation Projection Layer

### Objective

Prevent heap explosion and V8 out-of-memory (OOM) errors.

Never load or deep-clone entire multi-hundred megabyte repositories into memory via blind monolithic `JSON.parse`.

---

### New Components

```text
SimulationProjectionBuilder.ts

```

---

### Responsibilities

Transform:

```text
project_state.json

```

into:

```text
Simulation Working Set

```

using **Node.js built-in `fs.createReadStream` combined with pre-indexed byte-offset slice reads (`index.idx`)** (Zero external dependencies to maintain strict KISS adherence) to prevent Node.js single-threaded event loop blocking.

---

### Supported Projections

```text
Project Scope

Cluster Scope

Node Scope

```

---

### Output

```text
simulation_projection.json

```

---

### Validation

Verify:

```text
Projection Size
< Snapshot Size

```

for cluster and node simulations.

---

### Failure Condition

```text
Full Snapshot Deep Clone or Blocking Monolithic JSON.parse

```

detected.

---

### If Fail

```text
STOP

```

---

# Phase 8

## State Transition Engine & Hierarchical Bubbling Pass

### Objective

Apply architecture state transitions while enforcing a sequenced execution order where structural container bubbling runs independently prior to topological propagation.

---

### Components

```text
StateTransitionEngine.ts

```

---

### Execution Sequencing

* **Pass 0 (Bottom-Up Container Rollup)**: Hierarchical container bubbling executes first to roll up child sub-boundary state changes into parent wrapper boundaries, completely isolated from and prior to topological depth cutoffs.
* **Pass 1 (Topological Expansion)**: Propagation engine runs with circular dependency protection.

---

### States

```text
NORMAL

DIRTY

AFFECTED

CRITICAL

```

---

### Validation

Transitions match model, ensuring Pass 0 container bubbling executes reliably before Pass 1.

---

# Phase 10

## Propagation Guard Layer (with Mandatory Default Limits)

### Objective

Prevent propagation explosion and infinite recursive expansion by strictly enforcing hard limits.

---

### Components

```text
PropagationGuard.ts

```

---

### Responsibilities & Mandatory Default Thresholds

Enforce:

```text
MAX_PROPAGATION_DEPTH = 5

MAX_AFFECTED_BOUNDARIES = 100

MAX_AFFECTED_CLUSTERS = 200

MAX_PROPAGATION_SCORE = 1000

Visited Set Tracking (Cycle Breaker)

```

---

### Example

```text
Depth > 5 OR Affected Boundaries > 100 OR Visited Check Hit

```

↓

```text
Stop Expansion

```

---

### Validation

Large repository stress test.

---

### Failure Condition

Unbounded graph expansion or missing guard limits.

---
