### 19. Phase 12: End-to-End Simulation Harness (구현 종결 검증)
- **일시:** 2026-09-02
- **내용:**
  - **E2E 통합 파이프라인 구축**: `Failure -> Recovery -> Validation`으로 이어지는 3대 엔진의 라이프사이클을 대통합하여 시뮬레이션 동작.
  - **5대 Invariant(불변식) 증명**:
    1. **Determinism Invariant**: 랜덤/시간 종속성을 제거(`Date.now()` -> `scenario.id`)하여 100회 실행 간 트랜잭션, 해시, 스냅샷 100% 동일.
    2. **State Machine Invariant**: 전체 라이프사이클 로그를 조회하여 금지된 전이(`BROKEN->NORMAL` 등)가 0건 발생함을 확인.
    3. **Registry Invariant**: 스냅샷 노드/엣지 상태(`BROKEN`, `DIRTY`, `NORMAL`)에 따른 `activeCauses` 유무 완전 일치 증명.
    4. **Ownership Invariant**: Phase 6.6 계약에 따라 모든 상태 소유자가 `NODE`와 `EDGE`로 제한되며 `Cluster`/`Boundary` 상태 침범이 없음을 확인.
    5. **Transaction Invariant**: 트랜잭션 진행 중 고의 예외 주입 시 `Snapshot Before === Snapshot After`로 원자적 롤백(100%) 증명.
- **결과:**
  - 5개의 불변식 테스트를 완벽히 통과하며, 엔진이 "Closed Deterministic State Machine + Atomic Transaction Model + Failure Cause Consistency + Ownership Consistency"를 만족함을 수학적으로 증명 완료. SYNAPSE 시뮬레이션 엔진 코어 구현 단계 최종 종결.

### 35. Registry Schema Evolution & Philosophy Shift
- **일시:** 2026-09-06
- **내용**:
  - `ValidationStudy` 스키마에 `evidenceSource: 'measured' | 'simulated' | 'mock'` 필드 추가.
  - 모든 모의(Mock) 연구 데이터를 향후 유입될 실제(Measured) 관측 데이터와 혼동 없이 분리하여 Validation Registry를 장기 연구 자산으로 확립.
  - 연구 설계가 "가설 중심(X 때문일 것이다)"에서 "증거 중심(어떤 엣지를 제거했을 때 어떻게 붕괴하였는가)"으로 한층 더 성숙해짐.
  - 향후 J2.6b(Repeatability), J2.7(Candidate Discovery), J2.8(Claim Promotion 및 대체 설명 기각) 체인을 통해 철저히 Evidence에 기반한 최종 원인 도출을 강제.
