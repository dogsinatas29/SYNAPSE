# 🚀 Milestone v0.3.34.43 - Tree-sitter AST Migration

## 📅 작업 정보
- **상태:** 🏗️ Planned
- **관련 마일스톤:** v0.3.34.42 (Regex Scanner Deprecation)
- **목표:** 정규식 기반 C/C++ 파서의 한계를 극복하기 위해 `tree-sitter` 기반 AST 스캐너로 아키텍처를 전면 교체하여, 오염 없는 순수한 함수 및 의존성 추출 파이프라인을 구축한다.

## 🧠 상세 설계 및 로직
- 정규식 스캐너(`CppScanner.ts`) 폐기
- `web-tree-sitter` 및 `tree-sitter-c/cpp` 도입
- AST 노드 타입(`function_definition`, `declaration` 등) 기반 정밀 추출

## ⚠️ 이전 마일스톤(v0.3.34.42) 결론 및 분석 요약
- V5 Audit 계측 결과, 정규식 기반 스캐너가 전체 추출된 함수의 75% 이상을 오염시키고 있음이 수학적으로 증명됨.
- `if`, `for` 등의 제어문이 함수로 추출되고(`DEF_CTRL`), `DEVICE_ATTR_RO`, `DEFINE_MUTEX` 등의 매크로가 `DEF_COMPOUND` 카테고리로 대거 잘못 잡힘.
- 즉, 정규식은 C 문법의 맥락을 전혀 이해하지 못하고 괄호 패턴만으로 추출을 수행하는 근본적 한계를 지님. 따라서 예외 처리를 지속하는 대신 AST 기반 파서로 아키텍처를 전환하기로 의결함.
