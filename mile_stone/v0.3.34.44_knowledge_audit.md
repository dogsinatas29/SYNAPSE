# 🚀 SYNAPSE Knowledge vs Cache Audit (Phase 6.5)

## 📌 개요
우리는 앞선 Phase 6(Persistence Audit)에서 `Blast Radius`, `SCC`, `Boundary Crossings`를 Evidence(근거) 형태로 `project_state.json`에 저장해야 한다고 결론지었습니다. 

하지만 이 문서는 그 결론을 뒤집는 가장 근본적인 철학적 질문을 던집니다.
**"우리가 영구 보존하려는 그것들은 잃어버리면 영원히 복구할 수 없는 진짜 지식(Knowledge)인가, 아니면 언제든 소스 코드(그래프)만 있으면 다시 똑같이 계산해 낼 수 있는 캐시(Cache)에 불과한가?"**

SYNAPSE의 진정한 목적은 아키텍처를 압축하여 보여주는 것(Visual Architecture Engine)이며, 파일 크기 비대화를 감수하면서까지 Cache를 Knowledge인 것처럼 속여 저장하는 것을 배격합니다.

---

## ⚖️ 지식 존재론 (Ontology) 감사: 3계층 구조

판별 기준은 단 하나입니다: **"그래프 구조(Source Code)만으로 100% 동일하게 재생성할 수 있는가?"**

| 데이터 유형 | 재생성 여부 | Ontology 판정 | 설명 |
| :--- | :---: | :---: | :--- |
| **Rule, Layer Assignment, User Tag** | NO | 🟢 **Knowledge (지식)** | 코드에 명시되지 않은 인간의 맥락. 잃어버리면 복구 불가한 Source of Truth. |
| **Vocabulary Mapping (계약)** | NO | 🟢 **Knowledge (지식)** | 진단 언어적 약속. |
| **Change Amplifier, Domain Core 등** | YES/NO | 🔵 **Derived Knowledge (파생 지식)** | `Rule + Vocabulary + Pattern`이 결합되어 도출된 '해석(Interpretation)'. 기계가 추론한 상태면 재생성 가능하나, **사용자가 수동으로 확정(Human Curated)하면 영구적인 Knowledge(Tier 0)로 승격됨.** |
| **Blast Radius, SCC, Boundary** | YES | 🟡 **Cache (비싼 캐시)** | 재생성 가능하나, 연산 비용이 매우 비싼 그래프 탐색/알고리즘 결과물. **(모든 Pattern은 본질적으로 Cache의 하위 집합임)** |
| **Fan-In, Fan-Out, Edge Count** | YES | ⚪ **Cache (싼 캐시)** | 연산 비용이 0에 수렴하는 기초 데이터. **(원시 Pattern ⊂ Cache)** |

## 🎯 감사 결론: SYNAPSE의 진짜 Source of Truth

위 판정 결과, 충격적인 사실이 드러납니다.
그토록 중요하게 다뤘던 `Blast Radius`, `SCC` 같은 **모든 패턴(Pattern)들은 아무리 저장 비용이 비싸고 무효화 반경이 넓다 한들 본질적으로는 'Cache(캐시)'의 하위 집합(Pattern ⊂ Cache)**입니다. 날아가도 시간만 주면 다시 복구할 수 있습니다. 

반면, `Rule`, `Layer`, `Vocabulary`는 파일이 날아가면 시스템이 절대 스스로 추론할 수 없는 진짜 **'Knowledge(지식)'**입니다. 

따라서 `project_state.json` (Persistence Layer)의 역할은 과거 "분석 결과 덤프(Analysis Dump)"에서 **"지식 저장소(Knowledge Repository)"**로 전면 격상되며, 저장 우선순위 역시 "계산이 비싼 것"에서 **"잃어버리면 복구가 안 되는 것"**으로 철학이 전면 수정됩니다.

### 💾 New Persistence Layer Priority (새로운 저장 원칙)

1. **Tier 0 (절대 저장 - Source of Truth):** 
   - `Rules`, `Layer Assignment`, `Vocabulary Contract`, `User Mapping`, `Manual Tag`
   - 절대 유실되어서는 안 되는 인간의 맥락.
2. **Tier 1 (선택 저장 - 속도 최적화용):** 
   - `Blast Radius`, `SCC`, `Boundary Crossings`, `Derived Knowledge`
   - 재생성 가능하지만 렌더링 성능을 위해 캐싱하는 "비싼" 값들.
3. **Tier 2 (저장 금지 - 실시간 연산):** 
   - `Fan-In`, `Fan-Out`, `Edge Count`, `Control Score`
   - 파일 공간만 차지할 뿐 연산 비용이 없어 실시간 처리가 정답인 값들.

이로써 0.3.34.44 마일스톤이 도달해야 했던 진정한 결론이 내려졌습니다.
SYNAPSE는 단순한 '분석기'가 아니라, **패턴을 획득하고(Cache), 의미를 맵핑하여(Knowledge), 진단 언어를 생성(Derived Knowledge)해 내는 "진단 언어 엔진(Diagnostic Language Engine)"**임이 공식 선언되었습니다.
