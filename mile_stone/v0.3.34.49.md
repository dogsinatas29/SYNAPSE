## 📋 P0 / P1 / P2 Priority Matrix

### 🔴 P0 (49버전 반드시 해결 대상: 대체 경로 우선 원칙)

**P0-1. PatternFinding Pipeline Skeleton**
- `Detector ↓ PatternFinding ↓ Report` 로 이어지는 최소 인터페이스(인프라) 배선 구축. (실 탐지 로직 없이 뼈대만 우선 세움)

**P0-2. EntryPointDetector Migration**
- 유일하게 가동 중인 `EntryPointDetector`를 신규 PatternFinding 계약으로 이전. (최초 성공 사례 확보)

**P0-3. Report Adapter Layer**
- Report가 Metric 대신 PatternFinding을 소비할 수 있도록 Adapter 작성. (안전을 위해 구형 Metric 방식과 임시 동시 지원)

**P0-4. V001 Direct Metric Access Removal (37건 철거)**
- 대체 경로(P0-3)가 완벽히 증명된 후, 비로소 불법 접근 코드 전면 철거 개시 (`OnboardingAnalyzer` → `InsightEngine` → `RootCauseAggregator` → `ValidationReportBuilder` 순서)

**P0-5. SystemCore / Amplifier / Cascade Wiring**
- 방치된 3개 Detector를 파이프라인에 연결하여 V002(Detector Not Wired) 위반 박멸.
