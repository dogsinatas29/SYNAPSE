## Contract Restoration Initiative

---

# Executive Summary

v0.3.34.49는 새로운 기능 개발 마일스톤이 아니다.

이 버전의 목적은
Pattern Detection Architecture를
처음 설계 의도대로 복원하는 것이다.

---

# Background

SYNAPSE는 원래 다음 구조를 목표로 설계되었다.

Source
→ Resolver
→ Graph
→ Metrics
→ Dictionary
→ Pattern Detector
→ Pattern Finding
→ Report

Report는
Architect Pattern을 설명하는 최종 출력 계층이다.

---

# Discovery (v0.3.34.48)

대규모 Audit 결과,
실제 시스템은 위 구조로 동작하지 않았다.

실제 구조는 다음과 같았다.

Source
→ Resolver
→ Graph
→ Metrics
→ Report

Dictionary Layer
Pattern Layer
Detector Layer

사실상 우회(Bypass)되고 있었다.

# Root Cause

The problem is NOT:

❌ Regex

The problem is NOT:

❌ AST

The problem is NOT:

❌ Graph

The problem is:

❌ Contract Collapse

Reports directly consume Metrics.

Architectural meanings are never formally produced.

---

# Mission

Restore the original architecture.

---

# Desired Architecture

Source
→ Resolver
→ Graph
→ Metrics
→ Detector
→ PatternFinding
→ Report

Report MUST consume PatternFinding only.

Report MUST NOT consume Metrics directly.

---

# Scope

This milestone does NOT attempt:

- AST integration
- Runtime analysis
- AI enhancement
- New Pattern invention
- New Report types

Those are postponed.

---

# Scope of v0.3.34.49

Focus exclusively on:

Contract Restoration

---

# Success Criteria

The milestone is complete when:

1.

All report claims originate from PatternFinding.

2.

No report accesses raw metrics directly.

3.

Detector output becomes the single source of truth.

4.

Dictionary → Detector → Finding → Report

traceability is demonstrable.

5.

Evidence preservation remains intact.
