# 📖 SYNAPSE Architect Dictionary v1.0

## 목적

이 문서는 SYNAPSE의 공식 아키텍처 용어 사전이다.

SYNAPSE의 모든 분석은 다음 순서를 따라야 한다.

```text
Question
 ↓
Dictionary
 ↓
Pattern
 ↓
Evidence
 ↓
Detector
 ↓
Finding
 ↓
Report
```

어떤 Detector도 Dictionary에 정의되지 않은 용어를 생성해서는 안 된다.

어떤 Report도 Dictionary에 정의되지 않은 용어를 출력해서는 안 된다.

---

# Domain: Entry

---

## Root Entry Point

### Question

시스템의 제어 흐름은 어디서 시작되는가?

### Definition

시스템이 초기화되고 주요 실행 흐름이 시작되는 최초 진입 지점.

사용자가 시스템을 실행했을 때 가장 먼저 활성화되는 구조적 시작점.

### What It Is Not

* 단순 설정 파일
* 단순 상수 파일
* 단순 타입 정의 파일
* 우연히 fanIn이 0인 파일

### Required Evidence

아직 미확정

후보:

* Runtime bootstrap
* Startup sequence
* Assembly point
* Entry registration

### Status

E. Dynamic Gap

---

## Learning Hub

### Question

새로운 개발자가 가장 먼저 이해해야 하는 곳은 어디인가?

### Definition

시스템의 주요 개념과 구조를 가장 빠르게 이해할 수 있도록 도와주는 학습 관문.

### What It Is Not

* 단순히 fanIn이 높은 파일
* 단순히 fanOut이 높은 파일
* 단순히 큰 파일

### Required Evidence

미정

후보:

* 구조 중심성
* 개념 연결성
* 문서 밀도

### Status

D. Definition Gap

---

# Domain: Core

---

## System Core

### Question

시스템 동작을 실질적으로 관장하는 중심 구성요소는 어디인가?

### Definition

여러 기능 흐름을 조율하며 시스템 동작에 광범위한 영향을 미치는 핵심 제어 구성요소.

### What It Is Not

* 단순 타입 저장소
* 단순 DTO
* 단순 Registry
* 단순 Utility

### Counter Example

```text
types.ts
constants.ts
```

### Required Evidence

후보:

* Control Flow
* Command Dispatch
* Workflow Coordination
* Authority Reach

### Status

C. Source Signal Gap

---

## Peripheral Component

### Question

시스템과 가장 느슨하게 결합된 주변부 구성요소는 어디인가?

### Definition

시스템 핵심 동작과의 연결성이 낮고 독립적으로 존재 가능한 구성요소.

### What It Is Not

* 단순 fanIn 저수치 노드
* 단순 fanOut 저수치 노드

### Required Evidence

미정

후보:

* Core Distance
* Structural Isolation
* Dependency Reach

### Status

D. Definition Gap

---

# Domain: Boundary

---

## Boundary Fortress

### Question

도메인 간 접근을 통제하는 공식 관문은 어디인가?

### Definition

서브시스템 사이의 상호작용을 의도적으로 제한하거나 조율하는 경계 인터페이스.

### What It Is Not

* 단순 중간 노드
* 단순 fanOut 증가 노드
* 우연한 연결 지점

### Required Evidence

후보:

* Export Boundary
* Public Interface
* Access Restriction

### Status

C. Source Signal Gap

---

## Boundary Candidate

### Question

미래에 명확한 경계로 분리될 가능성이 높은 곳은 어디인가?

### Definition

구조적으로 응집성이 높고 외부 결합이 상대적으로 제한된 독립 가능 영역.

### What It Is Not

* 이미 Boundary임이 증명된 영역
* 단순 폴더

### Required Evidence

후보:

* Cohesion
* Coupling
* Modularity

### Status

B. Evidence Derivable

---

## Weak Boundary

### Question

경계 역할을 수행해야 하지만 실제로는 과도하게 침범당하는 곳은 어디인가?

### Definition

도메인 분리 의도와 달리 외부 의존성이 과도하게 집중된 취약 경계.

### What It Is Not

* 단순 인기 있는 모듈
* 단순 재사용 모듈

### Required Evidence

후보:

* Cross Cluster Traffic
* Boundary Violations
* External Dependency Density

### Status

B. Evidence Derivable

# Domain: Blast

---

## Change Amplifier

### Question

작은 변경이 큰 구조적 영향을 발생시키는 곳은 어디인가?

### Definition

변경이 의존성 네트워크를 따라 확산되며 영향 범위를 증폭시키는 구성요소.

### What It Is Not

* 단순 fanIn 증가
* 단순 fanOut 증가

### Required Evidence

후보:

* Reachability
* Blast Radius
* Dependency Propagation

### Status

B. Evidence Derivable

---

## Architectural Chokepoint

### Question

구조적 흐름이 집중되는 병목 지점은 어디인가?

### Definition

다수의 구조적 경로가 필수적으로 통과하는 집중 연결 지점.

### What It Is Not

* 단순 Utility
* 단순 공용 타입 파일

### Required Evidence

**확정 (2026-09-25 설계 감사): Betweenness Centrality**

~~Routing Concentration~~, ~~Dependency Transit~~ — 정의/계산식 부재로 폐기.

### Status

B. Evidence Derivable (그래프 위상 데이터만으로 계산 가능, 미구현 상태 — Brandes 알고리즘 필요, 대규모 그래프 성능 검토 선행)

# Domain: Simulation

---

## Cascade Failure Point

### Question

장애가 발생할 경우 연쇄적 파급을 일으키는 지점은 어디인가?

### Definition

구성요소의 실패가 연속적인 구조적 장애를 유발하는 위험 지점.

### What It Is Not

* 단순 오류 발생 위치
* 단순 큰 모듈

### Required Evidence

후보:

* Failure Propagation
* Dependency Collapse
* Reachability Loss

### Status

B / E Mixed

정적 분석 범위:
B. Evidence Derivable

런타임 장애:
E. Dynamic Gap

---

## Safe Refactoring Zone

### Question

변경하더라도 다른 영역에 영향을 주지 않는 곳은 어디인가?

### Definition

구조적 의존성이 거의 없거나 영향 범위가 극도로 제한된 안전 구역.

### What It Is Not

* 단순 작은 파일
* 단순 테스트 코드

### Required Evidence

후보:

* Zero Fan-In
* Zero Consumers
* Minimal Reachability

### Status

A. Evidence Sufficient

# Evidence Classification

## A. Evidence Sufficient

현재 데이터만으로 증명 가능

---

## B. Evidence Derivable

현재 데이터에서 계산 가능

---

## C. Source Signal Gap

필요한 증거가 Source에는 존재하나 Resolver가 수집하지 못함

---

## D. Definition Gap

정의 자체가 충분히 공식화되지 않음

---

## E. Dynamic Gap

정적 분석만으로는 증명 불가

---

# Final Principle

SYNAPSE는 Metric을 보고 용어를 만드는 시스템이 아니다.

```text
Metric
 ↓
Vocabulary
```

는 금지된다.

SYNAPSE는 질문에서 시작한다.

```text
Question
 ↓
Dictionary
 ↓
Evidence
 ↓
Answer
```

모든 Detector, Finding, Report는 이 Dictionary를 기준으로만 생성된다.
