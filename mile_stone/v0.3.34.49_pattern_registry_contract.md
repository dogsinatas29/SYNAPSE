# 🏛️ Milestone v0.3.34.49 - Pattern Registry Contract

## 목적
이 문서는 Dictionary의 자연어 용어들을 시스템이 소비 가능한 1급 객체(First-class Citizen)인 `Pattern ID`로 승격하여 고정한다.
`Report`, `Detector`, `Finding`, `Dictionary` 등 파이프라인의 전 계층이 오직 이 문서에 정의된 고유 식별자(`Pattern ID`) 하나만을 공통 언어로 사용하도록 통제한다.

---

## ⚖️ Registry Authority Rule (레지스트리 헌법)

49버전의 최상위 목표인 **Dictionary Authority Coverage 100%** 달성을 위해 다음 규칙을 파이프라인 전반에 엄격히 강제한다.

1. **Report는 Pattern ID를 임의로 생성할 수 없다.**
   - 오직 전달받은 `PatternFinding` 내부의 `patternId`를 읽어 렌더링할 뿐이다.
2. **Detector는 Registry에 없는 Pattern ID를 생성할 수 없다.**
   - 오타 방지 및 무분별한 식별자 생성을 막기 위해 타입 시스템(Enum/Type)으로 컴파일 타임에 강제되어야 한다.
3. **Dictionary에 없는 Pattern은 존재할 수 없다.**
   - 파이프라인 흐름은 오직 `Dictionary → Registry → Detector → Finding → Report` 의 단방향 권위만 허용된다.

---

## 🏗️ Registry Entry 규격 (예시)

모든 등록된 패턴은 아래와 같은 메타데이터 구조를 코드 또는 설정 파일 수준에서 명시해야 한다.

```yaml
patternId: ROOT_ENTRY_POINT
displayName: Root Entry Point
domain: ENTRY
status: IMPLEMENTED
gapType: E
detector: EntryPointDetector
targetScope: NODE
evidenceClass: 
  - DEPENDENCY
  - FILE_NAMING
reports: 
  - ONBOARDING
dictionaryAuthority: true
```

## 📊 11개 공식 Pattern 상태표 (Master Table)

v0.3.34.49 기준, 시스템이 인식해야 하는 유일한 11개의 공식 Pattern ID이다.

| Pattern ID | Domain | Status | Gap | Scope |
| :--- | :--- | :--- | :--- | :--- |
| **ROOT_ENTRY_POINT** | ENTRY | IMPLEMENTED | E | NODE |
| **LEARNING_HUB** | ENTRY | DEFINITION_GAP | D | NODE |
| **SYSTEM_CORE** | CORE | IMPLEMENTED | C | NODE |
| **PERIPHERAL_COMPONENT** | CORE | DEFINITION_GAP | D | NODE |
| **BOUNDARY_FORTRESS** | BOUNDARY | PARTIAL | C | CLUSTER |
| **BOUNDARY_CANDIDATE** | BOUNDARY | DERIVABLE | B | CLUSTER |
| **WEAK_BOUNDARY** | BOUNDARY | DERIVABLE | B | CLUSTER |
| **CHANGE_AMPLIFIER** | BLAST | IMPLEMENTED | B | CLUSTER |
| **ARCHITECTURAL_CHOKEPOINT**| BLAST | DEFINITION_GAP | D | NODE/CLUSTER |
| **CASCADE_FAILURE_POINT** | SIMULATION | IMPLEMENTED | E | NODE |
| **SAFE_REFACTORING_ZONE** | SIMULATION | SUFFICIENT | A | NODE |

*(※ 위 테이블은 49버전의 최종 스펙이며, `Gap`이 D(Definition Gap)인 패턴들은 49버전에서 구동 및 배선 대상이 아님을 확인한다.)*
