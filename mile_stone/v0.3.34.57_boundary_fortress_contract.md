# 🚀 SYNAPSE Pattern Contract: BOUNDARY_FORTRESS

## 📋 개요 (Overview)
`BOUNDARY_FORTRESS`는 프로젝트 내에서 **가장 독립적이고 자립성이 높은 핵심 도메인 블록**을 식별하기 위한 아키텍처 패턴입니다. 외부 의존성이 낮고 내부 응집도가 극도로 높거나, 시스템의 기초(Foundation) 역할을 하여 수많은 모듈로부터 호출(Fan-in)되는 모듈 군(Cluster)이 이 패턴에 해당합니다.

---

## 📥 입력 (Input)
- **대상:** `ProjectState` 내의 계층 구조가 적용된 `nodes` 및 `edges` (Platform Header, Architecture Header 등은 필터링 됨)
- **단위:** 디렉터리/서브폴더 (Cluster)

---

## ⚙️ 연산 규칙 (Rule)
탐지기(`BoundaryGraphBuilder`)는 각 Cluster 단위로 다음 메트릭을 계산합니다.

1. **`size` (멤버 수):** 해당 Cluster에 포함된 노드(파일/모듈)의 총 개수
2. **`internalEdges` (내부 결합):** 출발지와 목적지가 모두 해당 Cluster 내부에 있는 엣지의 수
3. **`structuralExternalUniqueDeps` (외부 의존성 타겟 수):** 해당 Cluster 내부에서 **외부**로 향하는 엣지들의 고유 타겟(Node) 개수
4. **`inboundEdges` (Fan-in):** **외부**에서 해당 Cluster 내부로 향하는 엣지의 총 개수

이를 기반으로 **Cohesion(응집도)** 를 산출합니다:
* `cohesion = internalEdges / (internalEdges + structuralExternalUniqueDeps)`
*(단, 전체 엣지가 0인 경우 cohesion은 0)*

---

## 🎯 임계값 (Threshold)
어떤 Cluster가 `BOUNDARY_FORTRESS` (Strong Boundary)로 승격되기 위해서는 다음 **3가지 조건 중 하나 이상을 만족**해야 합니다.

### 조건 1. 자립형 코어 (High Cohesion)
* **공식:** `strengthVal >= 0.75`
* **설명:** 모듈의 전체 의존성 중 내부 의존성의 비율이 75% 이상이어야 함.
* **패널티:** 만약 `size < 5` (멤버가 5개 미만인 초소형 모듈)라면 `strengthVal`에 `-0.15` 패널티가 부여됩니다. 즉, 초소형 모듈은 Cohesion이 **90% 이상**이어야 Fortress로 인정받습니다.

### 조건 2. 시스템 파운데이션 (Massive Fan-In)
* **공식:** `inboundEdges >= 100`
* **설명:** 내부 응집도가 다소 낮더라도, 외부 모듈로부터 100회 이상의 호출(Fan-in)을 받는다면 시스템의 근간(Foundation)을 이루는 강력한 경계로 간주하여 Fortress로 승격시킵니다.

### 조건 3. 거대 컴포넌트 (Massive Block)
* **공식:** `size >= 100` AND `internalEdges >= 1000` (단, PassThrough가 아닐 것)
* **설명:** 단일 디렉터리 내에 100개 이상의 파일과 1000개 이상의 내부 결합이 존재하는 초거대(Massive) 블록의 경우, 그 규모 자체로 하나의 확고한 성채(Fortress)로 인정합니다.

---

## 📤 출력 (Output)
위 조건 중 하나를 만족하면 해당 Cluster는 `strength: 'Strong'` 메타데이터를 부여받으며, 이후 `BoundaryPatternDetector`에 의해 **`BOUNDARY_FORTRESS`** Pattern Finding 객체로 변환됩니다.

```json
{
  "patternId": "BOUNDARY_FORTRESS",
  "targetScope": "CLUSTER",
  "targetId": "src/core/reasoning",
  "confidence": 1.0,
  "evidence": [
    {
      "type": "STRUCTURAL_METRIC",
      "description": "Strength: Strong, Cohesion: 0.972, Size: 62"
    }
  ]
}
```

해당 결과는 이후 `ARCHITECT_REPORT.md`의 [Architectural Findings] 섹션에 `DELIVERED` 됩니다.
