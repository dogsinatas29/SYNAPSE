- **결과**:
  - `AP_local`은 X의 직접 이웃 간 우회로만 검사하므로, 이웃을 건너뛰는 "원격 우회로(G2c)"를 감지하지 못하고 0을 반환함 (FAIL). `AP_local`은 `AP`의 최적화 구현체가 아닌 `LocalNeighborRobustness`라는 이질적 메트릭임이 증명됨.
  - `DC3_reachability`는 G3(순환 참조)에서 실제 경로가 1개임에도 2개를 반환(FAIL)하며 인플레이션을 일으킴.

### 2. Oracle Audit (수학적 정당성 확립) (`.61e`)
- **결과 적용**: Contract Inversion(내 구현에 정답을 맞추는 현상)을 방지하기 위해, 오라클의 수학적 정당성을 엄밀하게 재정의함.
- **Measurement Unit**: 모든 메트릭 쌍 연산은 Node나 Domain 단위가 아닌 **`Cluster Pair`**를 기본 단위로 함. (Dedup 규칙 고정)
- **DC3 Semantics**: 단순 볼륨(트래픽 양)이 아닌 **"다양한 도메인(클러스터) 간의 브릿지 역할을 하는가?(Distinct Bridge Pair Count)"**를 의미함.
- **Cycle SCC Collapse**: 순환 구조 시 무한 루프 인플레이션을 막기 위해 SCC를 단일 노드로 병합(Collapse)하는 원칙 도입. 이에 따라 G3(순환 구조) 내부의 노드는 외부를 브릿지하지 않으므로 **DC3 = 0**으로 정답 수정.
- **Graph & Cluster Fidelity Assumption**: 어떠한 완벽한 메트릭도 엉터리 그래프/클러스터 위에서는 무용지물이므로, 이 메트릭들의 정확성은 Resolver와 클러스터링 알고리즘의 완전성에 완벽히 종속됨을 대전제로 선언.

### 3. Chokepoint Scoring Semantics (`.61f`)
- **명칭 변경**: 사용자의 오해를 방지하기 위해 `AP_count`를 **`RetainedPairs`**로 직관적 명칭 변경.
- **실질 병목 수량화**: 노드 제거 시 영구 단절되는 클러스터 쌍의 수를 **`CriticalPairs = DC3 - RetainedPairs`**로 정의하여 Chokepoint의 코어 척도(Primary Rank)로 승격.
- **Ranking Contract (최종 수식)**:
  - 1순위 (Primary Rank): `CriticalPairs` (단절 강도)
  - 2순위 (Tie Breaker): `SR` (구조적 파급력 - Blast Radius)
  - 이를 통해 SR은 직접 곱연산이 아닌, 동점자 발생 시에만 보조 척도로 작용하도록 수정하여 "Chokepoint" 본질적 정의와의 정합성을 완벽히 맞춤.

### 4. Oracle Freeze Finalization (수학적 빈틈 보완)
- **Identity of X (평가 대상 확정)**: X는 원본 그래프 $G$의 개별 File(Node)로 확정함. 단, 거대한 순환 구조(SCC)에 갇힌 노드는 거시적 아키텍처 브릿지가 아니라 모듈 내부의 복잡도이므로 본 탐지기의 대상에서 원천 제외함. (즉, $X$는 $G_{scc}$에서 단일 노드로 존재해야 함)
- **수학적 정합성 강화**: `DC3(X)`라는 스칼라 값에 집합 연산을 하던 오류를 수정하고, $X$를 관통하는 고유 클러스터 쌍의 집합을 $P_X$로 정식화함. 
- **RetainedPairs 판별 조건**: 우회 경로의 존재 여부는 반드시 $G_{scc} \setminus \{X\}$ 위에서 판별되어야 함을 명문화하여, 우회 경로 자체가 다시 X를 통과하는 수학적 모순을 차단함.
- **SPOF 의미 축소 (CriticalPairs)**: `CriticalPairs`는 시스템 전체 장애를 확정하는 SPOF가 아니라, "X 제거 시 소실되는 구조적 도달성(X-removal-critical cluster pair)의 수"로 엄밀하게 의미를 축소함.
- **SR 의미 한정 (Tie Breaker)**: `SR`은 Failure에 의한 Blast Radius가 아니라, 평상시 노드의 도달 범위(Structural Breadth)일 뿐이므로 오직 동점자 처리를 위한 Tie Breaker로만 강등함.
- **DC3 Semantic Alias**: `DC3`는 Legacy Name이며, 실제 의미는 **Distinct Cross-Cluster Bridge Breadth** 임을 명시.
- **Scale Control Oracle (G6, G7)**: 볼륨 팽창(G6)과 도메인 분산(G7) 시나리오를 추가하여, 단순히 노드가 많다고 DC3가 증가하지 않음을 통제하는 완벽한 Regression Control 확립.
