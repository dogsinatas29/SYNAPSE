## 1. DC3 (Dependency Concentration 3)

| 항목 | 내용 |
| :--- | :--- |
| **Metric ID** | `DC3` |
| **Name** | Cross-Boundary Dependency Concentration |
| **Semantic Definition** | 노드 X가 매개하는 서로 다른 Cluster Pair 관계 수 |
| **Input** | Directed graph, Cluster assignment |
| **Directionality** | Directed |
| **Preconditions** | Source Cluster($C_s$) $\neq$ Target Cluster($C_t$), $C_s \neq Cluster(X)$, $C_t \neq Cluster(X)$ |
| **Algorithm** | 노드 X를 관통하는 고유한 $C_s \rightarrow C_t$ 클러스터 쌍의 수. (실제 측정 시 Path-based 연산과 Reachability 근사 간의 Fidelity 검증 필요) |
| **Output** | Integer |
| **Complexity** | 구현 방식(정밀 탐색 vs 도달성 근사)에 따라 $O(V+E)$에서 지수 시간까지 변동 가능 |
| **Known Limitations**| Cluster 분할 품질(Quality)에 의존. 구현 방식에 따라 과대평가(Inflation) 위험 존재. |

## 2. AP (Alternative Path Availability)

| 항목 | 내용 |
| :--- | :--- |
| **Metric ID** | `AP` |
| **Name** | Alternative Path Availability |
| **Semantic Definition** | 노드 X 제거 후, X가 매개하던 교차 클러스터 관계가 대체 경로를 통해 유지되는 정도 |
| **Input** | Directed graph, Cluster assignment |
| **Directionality** | Directed |
| **Preconditions** | Source Domain $\neq$ Target Domain. |
| **Algorithm** | **구현 후보 (Implementation Candidates):**<br>- `AP_global`: 전역 Min-Cut / Node-Disjoint 검사<br>- `AP_boundary`: 경계 노드 간의 우회로 검사<br>- `AP_local`: 1-hop(직접 이웃) 클러스터 간의 검사<br>- `AP_sampled`: 샘플링 기반 검사 |
| **Output** | Integer (대체 경로가 유지되는 쌍의 수) 또는 Ratio |
| **Complexity** | 채택되는 구현 후보에 따라 다름 ($O(V+E)$ ~ $O(V E^2)$) |
| **Known Limitations**| 전역 정밀도(Global Min-Cut)와 연산 비용 간의 트레이드오프가 극심함. |

## 3. SR (Structural Reach)

### 3.1. SR_F (Forward Structural Reach)
| 항목 | 내용 |
| :--- | :--- |
| **Metric ID** | `SR_F` |
| **Name** | Forward Structural Reach (Blast Radius) |
| **Semantic Definition** | 노드 X에서 의존성 방향(Forward)으로 도달 가능한 고유 클러스터 수 |
| **Algorithm** | BFS/DFS를 이용한 Forward reachable distinct clusters 계산 |
| **Output** | Integer |
| **Complexity** | $O(V + E)$ |

### 3.2. SR_R (Reverse Structural Reach)
| 항목 | 내용 |
| :--- | :--- |
| **Metric ID** | `SR_R` |
| **Name** | Reverse Structural Reach (Fan-In Base) |
| **Semantic Definition** | 역방향(Reverse) 탐색을 통해 노드 X에 도달 가능한 고유 클러스터 수 |
| **Algorithm** | BFS/DFS를 이용한 Reverse reachable distinct clusters 계산 |
| **Output** | Integer |
| **Complexity** | $O(V + E)$ |

### 3.3. Normalized SR (`SR_F_norm`, `SR_R_norm`)
- **설명**: 실제 데이터의 Graph-size sensitivity를 제어하기 위한 정규화 지표.
- **수식**: `SR_F_norm` = `SR_F` / Total Clusters (결과값 범위: `[0.0, 1.0]`)

## 4. DA (Directional Topology Descriptor)

| 항목 | 내용 |
| :--- | :--- |
| **Metric ID** | `DA` |
| **Name** | Topology Descriptor |
| **Semantic Definition** | 노드의 위상적 방향성 불균형(Directional imbalance)을 설명하는 이차적 서술자(Secondary Descriptor) |
| **Directionality** | Directed |
| **Algorithm** | `SR_F_norm`과 `SR_R_norm` 간의 비율(Ratio) 및 임계값 비교 |
| **Output** | Classification String (e.g., `Forward-dominant`, `Reverse-dominant`, `Balanced`) |
| **Known Limitations**| 이 자체로 Semantic Role(Source, Sink, Transit)을 확정할 수 없음. Entry Point나 Chokepoint 검증을 위한 참고 지표(Descriptor)로만 사용되어야 함. |
