### Phase 1: Naive Reference Implementation (완료)
- **목표**: 오라클 수학적 계약(`.61e`, `.61f`)을 일체의 최적화 없이 1:1로 직역하여 실행 가능한 정답지 코드를 작성.
- **결과**: `scratch/d6_naive_chokepoint_detector.ts` 구현 완료. SCC 응집, `P_X` 및 `G_{scc} \setminus \{X\}` 기반 `RetainedPairs` 연산, 그리고 불변식(Invariant) 검사를 원시적인 Graph 순회(BFS)로 구현함.

### Phase 2: Oracle G1~G7 Exact Verification (완료)
- **목표**: 구현된 Naive Reference가 G1~G7 합성 그래프에서 정확한 DC3, RetainedPairs, CriticalPairs 값을 도출하는지 비교.
- **결과 (ALL PASS)**:
  - G1(Single Path): DC3=1, Retained=0, Critical=1
  - G2(Bypass): DC3=1, Retained=1, Critical=0
  - G3(Giant SCC): 예상대로 거시적 브릿지가 아님을 판단하고 `Skip` 처리 완벽 매칭
  - G4(Bypassable): CBDC=4, Retained=4, Critical=0
  - G5(Strict Cut Vertex): CBDC=4, Retained=0, Critical=4
  - G6(Volume Expansion): 노드가 만 개여도 클러스터가 하나면 CBDC=1, Critical=1
  - G7(Domain Distribution): 여러 클러스터를 매개하면 1노드여도 CBDC=4, Critical=4
- **결론**: 두 그래프(G4, G5)가 동일한 CBDC(4)를 가지더라도 CriticalPairs 분포(0 vs 4)가 다르게 측정됨을 기하학적으로 증명. Scale Control(G6, G7) 역시 의도한 수치로 통제됨. Oracle 측정 로직 검증 완료.
