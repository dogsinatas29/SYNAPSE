## 🧠 현재 사용 가능한 질문 리스트 (VERIFIED)
실제 코드의 Metric, Scope, Classification Rule이 의미론적 계약(Semantic Contract)을 수학적으로 충족하여, 현재 당장 사용할 수 있는 질문과 패턴입니다.

### 1. A1: 구조적 중심성
- **Question:** 어디서 구조적 중심성이 관측되는가?
- **Supporting Pattern:** `SYSTEM_CORE`
- **Scope:** `BoundaryGraphBuilder`가 묶어낸 `BOUNDARY_NODE` 집단 내부
- **Metric:** `Control Score (fanIn × 10 + blastRadius × 2)`
- **Classification:** Median-based Relative Classification (중앙값 이상)
- **허용된 주장:** "현재 분석 범위의 Boundary Node 집단에서 Control Score 기준 중앙값 이상으로 분류된 모듈이다."

### 2. A3: 구조적 경계
- **Question:** 어디서 구조적 경계가 관측되는가?
- **Supporting Pattern:** `BOUNDARY_FORTRESS`, `BOUNDARY_CANDIDATE`
- **Scope:** Directory-based Module (하향식 디렉터리 기반 모듈)
- **Metric:** `size`, `internalEdges`, `inboundEdges`, `cohesion`, `targetConcentration`
- **Classification:** Absolute Threshold (OR 조건에 따른 강도 분류)
- **허용된 주장:** "해당 디렉터리 기반 모듈에서 정의된 cohesion 및 외부 의존성 관련 지표가 Boundary 분류 임계치를 충족한다."

### 3. A5: 구조적 병목 / 의존성 집중
- **Question:** 어디서 의존성 집중/병목 패턴이 관측되는가?
- **Supporting Pattern:** `ARCHITECTURAL_CHOKEPOINT`
- **Scope:** Directory-level Aggregation (개별 노드 계산 후 단순 상위 디렉터리 문자열 기준으로 합산된 클러스터)
- **Metric:** `Betweenness Centrality` (최단 경로 매개 중심성)
- **Classification:** Top-N Absolute (`alphaScore` 기준 무조건 상위 20개 추출)
- **허용된 주장:** "현재 분석 범위의 정적(Static) 구조에서 최단 경로 매개 빈도 가중치 합산 상위 20개 디렉터리로 관측된다."

## ⚠️ 현재 사용 불가 / 재설계 대기 질문 (CONTRACT MISMATCH / PENDING)
의미론적 이름(Pattern Name)과 실제 계산(Metric)이 불일치하거나 아예 로직이 존재하지 않아, 현재 답변할 수 없는 질문입니다.

### 1. A2: 구조적 매개 (CONTRACT MISMATCH)
- **Question:** 무엇이 구조적으로 연결을 매개하는가?
- **기존 Pattern:** `LEARNING_HUB`
- **사유:** 기존 로직은 '경로 매개'를 계산하지 않고 파일 검색 빈도(finding frequency)와 이름 휴리스틱에 의존함. (오히려 A5의 Betweenness 로직이 이 질문에 더 부합함)

### 2. A4: 구조적 결합 이상 (PENDING / MISMATCH)
- **Question:** 어디서 구조적 결합 이상이 관측되는가?
- **기존 Pattern:** `EROSION`, `Boundary Leakage` (미구현), `ui-core-coupling` 등
- **사유:** 실제 경계 누수를 측정하는 로직은 없으며, 기존 SmellDetector는 `ui`, `core` 등 파일 경로 문자열에 의존하는 '가치 판단(Value Judgment)' 휴리스틱이므로 기각됨.
