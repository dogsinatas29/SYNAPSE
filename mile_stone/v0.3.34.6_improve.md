# Milestone v0.3.34.x Suite - Architecture Analysis Pipeline

이 계획서는 사용자님께서 제시하신 철학을 바탕으로, SYNAPSE의 34.x 시리즈를 하나의 완결된 아키텍처 분석 스위트로 정립한 최종 로드맵입니다.
전체 파이프라인은 **`Truth(진단) → Measure(측정) → Predict(예측) → Inspect(정밀조사)`**의 흐름을 가집니다.

## 🧠 핵심 철학
> **SYNAPSE의 본질은 "AST 분석기"가 아니라 "아키텍처 분석기"입니다.**

- **주역 (Graph Telescope):** 파일/클러스터 간 의존성, 프레임워크 경계, SCC, Hub Stability.
- **조연 (AST Microscope):** 거시 분석(Graph)에서 발견된 문제를 확대하는 도구.
- **절대 원칙:** AST 결과는 항상 Graph 결과에 종속됩니다. (`Graph → 문제 영역 발견`, `AST → 문제 영역 확대`)

---

## 🛠️ 단계별 로드맵 (Architecture Scanner)
**34.x 시리즈는 현재 상태를 진단하는 "Architecture Scanner (CT 촬영)" 역할을 수행합니다.**

### 📊 v0.3.34.5: Runtime Truth (진단)
보이는 그래프와 실제 런타임 그래프가 다르다는 것을 증명합니다.
- TYPE_ONLY 제거 및 진짜 런타임 의존성 파악 완료.

### 🚀 v0.3.34.6: Coupling Measurement (측정)
결합의 질(Quality)과 양(Quantity)을 동시에 측정하여 본질적인 결합 위험도를 파악합니다.
- **Coupling Strength (질):** 엣지 가중치 기반 Score (얼마나 강하게 묶여있는가)
- **Coupling Density (양):** 브릿지 엣지의 절대 개수 (얼마나 많은 경로로 묶여있는가)

### ⚙️ v0.3.34.7: Intervention Simulator (예측)
추천 엔진(Advisor)이 아닌 예측 엔진(**Flight Simulator**)입니다. "이 엣지를 끊어라"가 아닌 **"끊으면 무슨 일이 생기나"**를 팩트 기반으로 시뮬레이션합니다.
- `Current SCC Size` → Edge 제거 시뮬레이션 → `New SCC Size`
- `Current Blast Radius` → Edge 제거 시뮬레이션 → `New Blast Radius`

### 🔬 v0.3.34.8: AST Microscope (정밀조사)
Graph에서 도출된 문제를 함수 레벨로 확대합니다. (TS/JS 전용, 선택된 범위만)
- **Complexity Hotspot Ranking:** `Function -> Class -> File` 3단계 집계 후 Top 10 순위화.
- **Micro Blast Radius (Function Call Graph):** 클러스터 수준의 파급 효과를 함수 수준으로 확대하여 추적.
- **Local Unused Candidate:** 파일 내 미사용 후보 색출.

## ⏸️ v0.4.x (이후 확장 - Architecture Observatory)
**4.x 시리즈는 시간 축을 더한 "Architecture Observatory (MRI)" 역할을 수행합니다.**

## 📝 리포트 출력 구조 개편안 (`LOGIC_REPORT.md`)
아키텍트가 '무엇이 위험한가'보다 **'어디부터 봐야 하는가'**를 가장 먼저 파악할 수 있도록 구성합니다.

1. **Executive Summary**
   1. Highest Risk Hub (가장 위험한 허브)
   2. Strongest Cluster Bridge (최강 결합 브릿지)
   3. Largest SCC (최대 순환 참조 그룹)
   4. Highest Complexity Hotspot (최고 복잡도 핫스팟 - 34.8 추가 예정)
   5. **Recommended Investigation Order (권장 조사 순서)**
2. **Macro Architecture (Graph)**
   - SCC Size, Hub Stability, Coupling Strength & Density, Boundary Violation
3. **Micro Structure (AST)**
   - Complexity Hotspot Ranking, Micro Blast Radius, Local Unused Candidate
4. **Appendix**
