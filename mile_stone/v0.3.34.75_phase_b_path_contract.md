## 1. 개요 및 목적 (Overview & Purpose)

Phase B의 핵심 목적은 SSoT(`project_state.json`)의 그래프 생성기(`NodeBuilder.ts`)에 잔존하는 **2대 부채(경로 비정규화, 테스트 소스코드 Role 왜곡)**를 안전하게 해소하는 것입니다:
1. **경로 표준화 (`normalizePath`)**: 플랫폼(Windows/POSIX) 간의 역슬래시(`\`), 연속 슬래시(`//`), 반복 점 세그먼트(`./`, `/./`)를 안전하게 POSIX 규격으로 표준화하고, UNC(`//server/share`) 및 드라이브 레터(`C:/`), 상위 경로(`..`)를 원본 그대로 보존.
2. **역할 판정 교정 (`determineNodeRole`)**: `tests/*` 또는 `test/*` 루트 디렉터리에 위치한 테스트 코드가 `relPath.includes('/test/')` 식의 슬래시 선행 조건으로 인해 `RUNTIME` 및 `RUNTIME_ENTRY`로 왜곡 기록되던 문제를 완벽한 세그먼트 경계(`/(^|\/)(test|tests|unit_tests)(\/|$)/i`)로 교정.

본 v1.0.2 계약서는 마스터 감사에서 제기된 **L3 검증기의 자기 참조 비교 결함(P0-1), 그래프 위상 불변성 수학적 증명 결함(P0-2), 모집단 불일치(P0-3), UNC 경로 구현 모순(P1-1), 상대 경로 정규화 불완전(P1-2), Role 우선순위 불일치(P1-3), 테스트 파일명 패턴 범위 혼합(P1-4)**을 전수 해결하고 실측 증거로 무결성을 입증한 최종 구현 계약서입니다.

### 2.1. [P0-1 & P0-2] 독립적 L3 Differential 검증 및 불변성 수학적 증명
기존 검증 스크립트의 "변환 객체 자기 복사 후 비교" 방식을 완전히 폐기하고, **원본 SSoT의 동결 스냅샷(Frozen Snapshot)에 대한 독립 1:1 대조 검증기**를 구축하였습니다.

- **수학적 불변성 정의 (Graph Invariant)**:
  $$\forall e \in E, \quad e' = (M(e.\text{from}), M(e.\text{to}), e.\text{id}, \text{attributes}(e))$$
  - 여기서 $M$은 노드 ID 매핑 함수 ($M: V \to V'$).
  - $\text{attributes}(e) = \{ \text{type}, \text{weight}, \text{provenance}, \text{data} \}$.
- **독립 검증 6단계 파이프라인 ([simulate_l3_differential.ts](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/scripts/validation/simulate_l3_differential.ts))**:
  1. **Pre-Validation**: 원본 노드 및 엣지 배열 내의 중복 ID 사전 검사 (Godot 0건, VS Code 0건 확인).
  2. **Frozen Snapshot**: 원본 엣지 100%를 독립 메모리 맵에 deep copy로 동결 보관.
  3. **Node Transformation**: `NodeBuilder` 생성 물리 노드만 $M$을 적용하여 변환 및 충돌(Collision) 검사.
  4. **Endpoint Existence**: 모든 변환 엣지의 끝점($e'.\text{from}$, $e'.\text{to}$)이 변환 노드 집합 $V'$ 내에 실존하는지 검증 ($\text{Broken Endpoints} = 0$).
  5. **Mapping Accuracy**: $e'.\text{from} \equiv M(e.\text{from}) \land e'.\text{to} \equiv M(e.\text{to})$ 일대일 일치 전수 검증 ($\text{Mismatched Endpoints} = 0$).
  6. **Independent Attribute Preservation**: 변환 엣지 $e'$와 동결 스냅샷 $e$ 간의 ID, 타입, 가중치, 출처, 데이터 페이로드를 독립 JSON deep-equal로 전수 대조 ($\text{Mismatched Attributes} = 0$).

### 3.2. normalizePath(rawPath: string): string
```typescript
export function normalizePath(rawPath: string): string {
    if (!rawPath) return rawPath;
    if (rawPath.startsWith('ghost://') || rawPath.startsWith('external://') || rawPath.startsWith('builtin://')) {
        return rawPath;
    }

    const isUNC = rawPath.startsWith('\\\\') || rawPath.startsWith('//');
    let p = rawPath.replace(/\\/g, '/');

    let prefix = '';
    if (isUNC) {
        prefix = '//';
        p = p.substring(2);
    }

    p = p.replace(/\/+/g, '/');

    const parts = p.split('/');
    const resolvedParts: string[] = [];
    for (const part of parts) {
        if (part === '' || part === '.') continue;
        resolvedParts.push(part);
    }
    p = resolvedParts.join('/');

    if (isUNC) {
        return prefix + p;
    }

    return p;
}
```

### 3.3. determineNodeRole(filePath: string): { role: NodeRole, category: string }
```typescript
export function determineNodeRole(filePath: string): { role: NodeRole, category: string } {
    const relPath = filePath.replace(/\\/g, '/');
    const basename = path.posix.basename(relPath);
    const ext = path.posix.extname(relPath).toLowerCase();
    const baseNameLower = basename.toLowerCase();

    // Priority 1: Grammar
    if (ext === '.json' && basename.includes('.tmLanguage')) {
        return { role: NodeRole.GRAMMAR, category: 'Grammar' };
    }

    // Priority 2: Config
    if (['package.json', 'tsconfig.json', 'webpack.config.js', 'vite.config.ts', '.eslintrc.js', '.prettierrc'].includes(basename) || ext === '.yaml' || ext === '.yml' || ext === '.json' || ext === '.toml') {
        return { role: NodeRole.CONFIG, category: 'Config' };
    }

    // Priority 3: Build or Packaging Asset
    if (isBuildOrPackagingAsset(relPath)) {
        return { role: NodeRole.TOOLING, category: 'Tooling' };
    }

    // Priority 4: Document
    if (ext === '.md' || ext === '.txt') {
        return { role: NodeRole.DOCUMENT, category: 'Document' };
    }

    // Priority 5: Asset
    if (['.png', '.jpg', '.jpeg', '.webp', '.svg', '.gif', '.ico', '.woff', '.woff2', '.ttf', '.eot'].includes(ext)) {
        return { role: NodeRole.ASSET, category: 'Asset' };
    }

    // Priority 6: Test
    const isTestSegment = /(^|\/)(test|tests|unit_tests)(\/|$)/i.test(relPath);
    const isTestFile = (
        baseNameLower.includes('.test.') ||
        baseNameLower.includes('.spec.') ||
        baseNameLower.startsWith('test_') ||
        baseNameLower.endsWith('_test.cpp') ||
        baseNameLower.endsWith('_test.h') ||
        baseNameLower.endsWith('_test.py') ||
        baseNameLower === 'test-utils.ts'
    );
    if (isTestSegment || isTestFile) {
        return { role: NodeRole.TEST, category: 'Test' };
    }

    // Priority 7: Tooling
    if (relPath.includes('/scripts/') || relPath.includes('/build/') || relPath.includes('/tools/')) {
        return { role: NodeRole.TOOLING, category: 'Tooling' };
    }

    // Priority 8: Domain Model
    if (['schema.ts', 'types.ts', 'interfaces.ts', 'constants.ts'].includes(basename) || basename.endsWith('.d.ts')) {
        return { role: NodeRole.DOMAIN_MODEL, category: 'Domain' };
    }

    // Priority 9: Runtime Entry
    if (['extension.ts', 'main.ts', 'index.ts', 'activate.ts'].includes(basename)) {
        return { role: NodeRole.RUNTIME_ENTRY, category: 'Entry' };
    }

    // Priority 10: Runtime
    return { role: NodeRole.RUNTIME, category: 'Source' };
}
```
