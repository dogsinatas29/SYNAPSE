## 1. 개요 및 목적 (Overview & Purpose)

Phase B의 핵심 목적은 SSoT(`project_state.json`)의 그래프 생성기(`NodeBuilder.ts`)에 잔존하는 **2대 부채(경로 비정규화, 테스트 소스코드 Role 왜곡)**를 안전하게 해소하는 것입니다:
1. **경로 표준화 (`normalizePath`)**: 플랫폼(Windows/POSIX) 간의 역슬래시(`\`), 연속 슬래시(`//`), 반복 점 세그먼트(`./`, `/./`)를 안전하게 POSIX 규격으로 표준화하되, **POSIX 절대 경로(`/home/...`), 엄격한 UNC(`//server/share`), Windows 드라이브 루트(`C:/`) 및 드라이브 상대 경로(`C:foo`), 상위 경로(`..`)의 선두 구분자와 고유한 의미를 온전히 보존**.
2. **역할 판정 교정 (`determineNodeRole`)**: `tests/*` 또는 `test/*` 루트 디렉터리에 위치한 테스트 코드가 `relPath.includes('/test/')` 식의 슬래시 선행 조건으로 인해 `RUNTIME` 및 `RUNTIME_ENTRY`로 왜곡 기록되던 문제를 완벽한 세그먼트 경계(`/(^|\/)(test|tests|unit_tests|specs|__tests__)(\/|$)/i`)로 교정.

본 v1.0.15 계약서는 마스터 감사에서 제기된 **Windows 드라이브 루트 보존(P1-1), 엣지 endpoint 매핑과 비대상 속성 보존의 수학적 분리(P1-2), 테스트 디렉터리 범위 완결(P1-3: `specs/`, `__tests__/` 포괄), Non-NodeBuilder 불변성의 JSON 직렬화 기준 명시(P1-4), 원본 SSoT 선행 불변식(Step 1 Pre-condition)과 변환 후 사후 불변식(Step 4 Post-condition)의 완전한 책임 분리, 원본 스냅샷 기반 기준선 참조 무결성(P1-6 Baseline Reference Integrity)**을 전수 해결하고 엄격한 정합성을 완결한 최종 구현 계약서입니다.

### 2.2. [P0-2] 매핑 전단사(Bijectivity) 수학적 완결
검증기에서 다음 4대 전단사 불변식을 엄격한 Assertion으로 강제하였습니다:
1. $\text{dom}(M) \equiv V_{\text{orig}}$ (`idMapping.size === originalNodeIds.size` 및 원본 ID 전수 키 포함 검증)
2. $\text{ran}(M)$ 충돌 부재 (서로 다른 원본 ID가 동일한 변환 ID로 매핑되는 Collision 0건 단언)
3. $\text{ran}(M) \equiv V_{\text{trans}}$ (매핑 값 집합과 변환 노드 ID 집합의 양방향 일치 검증)
4. $|V_{\text{orig}}| = |V_{\text{trans}}|$ (노드 수 불일치 시 즉시 `throw Error` 실패 처리).

### 2.5. [P1-1, P1-5 & Item 4] 결정적 다대일 정규화(Deterministic Many-to-One Canonicalization) 및 경계 명세
- **수학적 성질 정의:**
  경로 정규화 함수 $f_{\text{norm}}: \Sigma^* \to \Sigma_{\text{canon}}^*$는 **결정적 다대일 정규화(Deterministic Many-to-One Canonicalization)**입니다.
  단사(Injective) 함수가 아니며, 서로 다른 입력 경로(`a/b`, `a//b`, `a/./b`)가 동일한 표준 경로 `a/b`로 결정론적으로 축약됩니다.
  (참고: 특정 SSoT 데이터셋에서 노드 ID 충돌이 0건인 사실은 해당 데이터셋에 대한 실측 불변식이며, 정규화 함수 자체의 전역 단사성을 의미하지 않습니다.)

- **규칙 적용 및 평가 우선순위 (Strict Precedence Hierarchy):**
  1. **가상 스키마 최우선 우회 (Virtual Schema Bypass):**
     `ghost://`, `external://`, `builtin://`로 시작하는 경로는 파일시스템 정규화 대상이 아니므로 어떠한 문자열 변형(슬래시 축약, 점 세그먼트 해석 등)도 가하지 않고 원본 그대로 즉시 반환.
     *(단, 대소문자나 오탈자가 있는 비정규 스킴(예: `GHOST://`, `ghost:/`)은 일반 경로로 간주되어 표준화 처리됨)*
  2. **엄격한 UNC 판독 (Strict UNC Detection):**
     선두가 정확히 `//`로 시작하고 유효한 서버명 및 공유명 세그먼트가 단일 구분자(`/`) 또는 문자열 끝(`$`)으로 종료되는 경로(`/^\/\/[^\/\s]+\/[^\/\s]+(?:\/|$)/` 이며 `!startsWith('///')`)에 한하여 UNC 접두어(`//`)를 보존하고 후속 세그먼트를 표준화.
     - `//server/share` $\to$ `//server/share` (Strict UNC 만족, 보존)
     - `//server//share` $\to$ `/server/share` (서버명 직후 연속 슬래시 `//`로 인해 Strict UNC 형식 불일치 $\to$ POSIX 절대 경로 분기로 진입하여 슬래시 축약 후 `/server/share`)
     - `///server/share` $\to$ 선두 3개 슬래시 $\to$ UNC 판정 배제 $\to$ POSIX 절대 경로로 간주되어 `/server/share`로 축약
     - `//server` $\to$ 공유명 세그먼트 부재 $\to$ UNC 판정 배제 $\to$ POSIX 절대 경로로 간주되어 `/server`로 축약
     - `//server/share/..` $\to$ `//server/share/..` (Strict UNC 네트워크 루트 보존 + 상위 참조 `..` 세그먼트 보존)
     - `//server/share name` $\to$ `/server/share name` (공유명 뒤 공백 문자로 인해 `(?:\/|$)` 종료 조건 불일치 $\to$ Strict UNC 판정 실패 $\to$ POSIX 절대 경로 분기로 진입하여 축약)
     - `//server/share?name` $\to$ `//server/share?name` (구문 판정 정책: `?`는 `[^\/\s]+`에 포함되므로 구문 축약 수준에서 불투명 문자열로 보존되나, 플랫폼 파일시스템 수준의 경로 유효성을 보장하는 것은 아님)
     - `//server/./share` $\to$ `//server/share` (중간 `.` 세그먼트 축약)
     - `//./share` $\to$ 정책 명문화: Windows 디바이스 네임스페이스(`\\.\...`, `//./...`) 및 확장 접두어(`\\?\...`, `//?/...`)는 SYNAPSE 소스 트리 분석의 입력 도메인에서 지원하지 않음(Out-of-Domain). 정규화 함수는 이를 특수 경로로 별도 인식하거나 거부하지 않으며 일반 문자열 세그먼트 규칙을 적용(단독 `.`가 현재 디렉터리로 소거되어 `//share`로 변환)함. 이러한 경로는 그래프 생성 단계에서 지원 대상이 아님.
  3. **Windows 드라이브 절대 경로 (Drive Absolute with Slash):**
     `/^[a-zA-Z]:\//` 정규식 매칭 시 드라이브 문자 및 슬래시(`C:/`)를 루트 접두어로 보존.
     - `C:/`, `C:\`, `C:/./` $\to$ 루트 후행 슬래시를 온전히 보존하여 `C:/`로 표준화
     - `C:/foo/` $\to$ `C:/foo`
     - `C://foo///bar` $\to$ `C:/foo/bar`
  4. **Windows 드라이브 상대 경로 (Drive Relative):**
     `/^[a-zA-Z]:/` 정규식 매칭 시 드라이브 문자 및 콜론(`C:`)만을 접두어로 유지하며 임의의 슬래시를 삽입하지 않음.
     - `C:foo` $\to$ `C:foo`
     - `C:./foo` $\to$ `C:foo`
     - `C:../a` $\to$ `C:../a`
  5. **POSIX 절대 경로 (POSIX Absolute):**
     `p.startsWith('/')` 매칭 시 선두의 연속 슬래시(`^\/+`)를 단일 슬래시 `/`로 축약.
     - `/home//user/./src` $\to$ `/home/user/src`
  6. **상위 디렉터리(`..`) 보존 규약 (Parent Directory Preservation):**
     SYNAPSE는 아키텍처 토폴로지 상위 참조 무결성을 위해 `..`를 선행 세그먼트와 상쇄하거나 임의 소거하지 않고 온전히 보존.
     - `../a` $\to$ `../a`
     - `a/../b` $\to$ `a/../b` (의미적 상위 해석은 Resolver 계층의 책임이며 NodeBuilder 경로 문자열에서는 온전히 보존)
     - `/../a` $\to$ `/../a` (POSIX 루트 기준 상위 경로 보존)
     - `C:../a` $\to$ `C:../a` (드라이브 상대 상위 경로 보존)
     - `C:/../a` $\to$ `C:/../a` (드라이브 루트 기준 상위 경로 보존)
     - `../../src/./index.ts` $\to$ `../../src/index.ts`

### 4.1. normalizePath(rawPath: string): string
```typescript
export function normalizePath(rawPath: string): string {
    if (!rawPath) return rawPath;
    if (rawPath.startsWith('ghost://') || rawPath.startsWith('external://') || rawPath.startsWith('builtin://')) {
        return rawPath;
    }

    let p = rawPath.replace(/\\/g, '/');

    // Strict UNC detection: Starts with exactly two slashes and valid segments
    const isStrictUNC = /^\/\/[^\/\s]+\/[^\/\s]+(?:\/|$)/.test(p) && !p.startsWith('///');

    let prefix = '';
    let isDriveWithSlash = false;

    if (isStrictUNC) {
        prefix = '//';
        p = p.substring(2);
    } else if (/^[a-zA-Z]:\//.test(p)) {
        // Windows drive with slash root/path (e.g. C:/ or C:/foo)
        prefix = p.substring(0, 2) + '/';
        p = p.substring(3);
        isDriveWithSlash = true;
    } else if (/^[a-zA-Z]:/.test(p)) {
        // Windows drive-relative (e.g. C:foo)
        prefix = p.substring(0, 2);
        p = p.substring(2);
    } else if (p.startsWith('/')) {
        prefix = '/';
        p = p.replace(/^\/+/, '');
    }

    p = p.replace(/\/+/g, '/');

    const parts = p.split('/');
    const resolvedParts: string[] = [];
    for (const part of parts) {
        if (part === '' || part === '.') continue;
        resolvedParts.push(part);
    }
    const resolved = resolvedParts.join('/');

    // Preserve drive root C:/ when remaining segments are empty
    if (isDriveWithSlash && resolvedParts.length === 0) {
        return prefix;
    }

    if (prefix.endsWith('/')) {
        return prefix + resolved;
    }
    if (prefix) {
        return resolved ? prefix + (prefix.endsWith(':') ? '' : '/') + resolved : prefix;
    }
    return resolved;
}
```

### 4.2. determineNodeRole(filePath: string): { role: NodeRole, category: string }
```typescript
export function determineNodeRole(filePath: string): { role: NodeRole, category: string } {
    const relPath = filePath.replace(/\\/g, '/');
    const basename = path.posix.basename(relPath);
    const ext = path.posix.extname(relPath).toLowerCase();
    const baseNameLower = basename.toLowerCase();

    // Priority 1: Grammar
    if (ext === '.json' && basename.includes('.tmLanguage')) {
        return { role: NodeRole.GRAMMAR, category: 'Grammar' };
    }

    // Priority 2: Config
    if (['package.json', 'tsconfig.json', 'webpack.config.js', 'vite.config.ts', '.eslintrc.js', '.prettierrc'].includes(basename) || ext === '.yaml' || ext === '.yml' || ext === '.json' || ext === '.toml') {
        return { role: NodeRole.CONFIG, category: 'Config' };
    }

    // Priority 3: Build or Packaging Asset
    if (isBuildOrPackagingAsset(relPath)) {
        return { role: NodeRole.TOOLING, category: 'Tooling' };
    }

    // Priority 4: Document
    if (ext === '.md' || ext === '.txt') {
        return { role: NodeRole.DOCUMENT, category: 'Document' };
    }

    // Priority 5: Asset
    if (['.png', '.jpg', '.jpeg', '.webp', '.svg', '.gif', '.ico', '.woff', '.woff2', '.ttf', '.eot'].includes(ext)) {
        return { role: NodeRole.ASSET, category: 'Asset' };
    }

    // Priority 6: Test Code & Runner (Includes specs and __tests__)
    const isTestSegment = /(^|\/)(test|tests|unit_tests|specs|__tests__)(\/|$)/i.test(relPath);
    const isTestFile = (
        baseNameLower.includes('.test.') ||
        baseNameLower.includes('.spec.') ||
        baseNameLower.startsWith('test_') ||
        baseNameLower.endsWith('_test.cpp') ||
        baseNameLower.endsWith('_test.h') ||
        baseNameLower.endsWith('_test.py') ||
        baseNameLower === 'test-utils.ts'
    );
    if (isTestSegment || isTestFile) {
        return { role: NodeRole.TEST, category: 'Test' };
    }

    // Priority 7: Tooling Scripts (Preserve exact NodeBuilder.ts rule)
    if (relPath.includes('/scripts/') || relPath.includes('/build/') || relPath.includes('/tools/')) {
        return { role: NodeRole.TOOLING, category: 'Tooling' };
    }

    // Priority 8: Domain Model
    if (['schema.ts', 'types.ts', 'interfaces.ts', 'constants.ts'].includes(basename) || basename.endsWith('.d.ts')) {
        return { role: NodeRole.DOMAIN_MODEL, category: 'Domain' };
    }

    // Priority 9: Runtime Entry
    if (['extension.ts', 'main.ts', 'index.ts', 'activate.ts'].includes(basename)) {
        return { role: NodeRole.RUNTIME_ENTRY, category: 'Entry' };
    }

    // Priority 10: Runtime Default
    return { role: NodeRole.RUNTIME, category: 'Source' };
}
```
