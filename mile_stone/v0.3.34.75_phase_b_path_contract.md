Phase A(Scope Exclusion & Determinism)는 리포트 생성 계층에서 Scope 선언을 기반으로 노이즈를 성공적으로 통제하였습니다 (Zero-Diff 6/6 통과, 멤버 단위 2,230개 무결성 통과).  
그러나 SSoT(`project_state.json`)의 원천 그래프에는 다음과 같은 2가지 구조적 결함이 잔존합니다:
1. **역할 판정 결함 (Role Inversion)**: `tests/*` 또는 `test/*` 루트 디렉터리에 위치한 테스트 러너, 테스트 소스코드들이 `includes('/test/')` 식의 슬래시 선행 조건으로 인해 `RUNTIME` 및 `RUNTIME_ENTRY`로 왜곡 기록됨.
2. **경로 표현 불일치 (Path Inconsistency)**: POSIX 표준 슬래시 정규화 부재로 인해 윈도우 역슬래시(`\`), 다중 슬래시(`//`), 선행 슬래시(`/b.md`) 등 비표준 경로가 잔존할 위험.

### 3.2. 정규화 함수 계약 (normalizeNodePath)
```typescript
export function normalizeNodePath(rawPath: string): string {
    if (!rawPath) return rawPath;
    // 1. Virtual schema protection
    if (rawPath.startsWith('ghost://') || rawPath.startsWith('external://') || rawPath.startsWith('builtin://')) {
        return rawPath;
    }
    // 2. Normalize separators & redundant dots
    let p = rawPath.replace(/\\/g, '/');
    p = p.replace(/\/+/g, '/');
    p = p.replace(/\/\.\//g, '/');
    if (p.startsWith('./')) p = p.substring(2);
    if (p.startsWith('/')) p = p.substring(1);
    if (p.length > 1 && p.endsWith('/')) p = p.substring(0, p.length - 1);
    return p;
}
```
