순환적 승인 구조(프로덕션 검증을 해야 D8을 승인하지만 D8을 승인해야 구현할 수 있는 문제)를 해소하기 위해 검증 단계와 D8 재심사 간의 관계를 다음과 같이 명문화합니다:

| 검증 단계 | 검증 대상 및 성격 | D8 재심사와의 거버넌스 관계 | 비고 |
|---|---|---|---|
| **Gate A** | **Transformer 사전 시뮬레이션 검증**<br>(비실행 스크립트 기반 불변식 검증) | **D8 심사 필수 자료**<br>(D8 종료 전 통과 필수) | 현재 완료 보고된 시뮬레이션 단계 |
| **Gate B** | **실제 `NodeBuilder.buildNodes()` 결과 검증**<br>(프로덕션 코드 국소 수정 후 사후 검증) | **별도 Implementation Authorization 이후**<br>(D8 선결 조건으로 요구하지 않음) | 프로덕션 코드 동결 해제 후 실행 |

### 2.3. [보완 3] `filePath` 불변식 및 입력 예외 처리 정책
- **수학적 불변식 정의**:
  $$\forall n \in V_{\text{NodeBuilder}}, \quad n'.filePath \equiv \text{auditComputeExpectedPath}(\text{resolveInputPath}(n))$$
- **입력 상태별 기대 처리 정책 (Input Status Matrix)**:

| 입력 상태 | 기대 처리 및 검증 동작 | 판정 기준 |
|---|---|:---:|
| **$n.id \equiv n.filePath$ (유효 문자열)** | 독립 정규화 함수 $M_{path}$ 결과와 $n'.filePath$ 및 $n'.id$가 1:1 일치 | **PASS** |
| **$n.filePath$ 누락 (`undefined`)** | 계약에 명시된 Fallback: $M_{path}(n.id)$ 적용 | **PASS** |
| **$n.filePath \equiv \text{null}$** | 비정상 SSoT 노드로 판정, 즉시 거부(`throw Error`) | **FAIL** |
| **$n.id \neq n.filePath$** | 사전 조건(Pre-condition) 위반으로 즉시 거부(`throw Error`) | **FAIL** |
| **$n.id$ 빈 문자열 (`""` 또는 공백)** | 입력 경계 위반으로 파이프라인 진입 즉시 거부(`throw Error`) | **FAIL** |
| **$n.id$ 비문자열 (`typeof !== 'string'`)** | 타입 무결성 위반으로 즉시 거부(`throw Error`) | **FAIL** |

- **독립 비교 강제**: $n'.id$와 $n'.filePath$가 둘 다 정규화되어 같다는 사실만으로 통과하지 않고, 각각 Auditor의 기대 정규화 경로와 독립적으로 대조합니다.

### 2.4. [보완 4] Role 전이 인과관계의 반사실적 비교 (Counterfactual Causality)
단순 세그먼트 포함 여부가 아닌, **"해당 규칙이 존재하지 않았더라면 Role이 바뀌었을 것인가?"**를 입증하는 반사실적 비교(Counterfactual Analysis) 프로토콜을 수립합니다:

- **4대 독립 분류기 정의**:
  1. $R_{\text{seg\_only}}(p)$: 파일명 패턴을 배제하고 오직 세그먼트 규칙만 적용한 판정기.
  2. $R_{\text{file\_only}}(p)$: 세그먼트 규칙을 배제하고 오직 파일명 패턴만 적용한 판정기.
  3. $R_{\text{full}}(p)$: 세그먼트와 파일명 패턴을 모두 포함한 완전 판정기.
  4. $R_{\text{base}}(p)$: 테스트 규칙 전체를 배제했을 때의 기본 판정기.
- **인과관계 판정 기준 (Causality Determination)**:
  - **순수 세그먼트 원인 (Pure Segment Causality)**:  
    $R_{\text{seg\_only}}(p) \equiv \text{TEST} \land R_{\text{file\_only}}(p) \neq \text{TEST}$  
    $\to$ 세그먼트 규칙이 단독으로 승격을 유발함이 수학적으로 증명됨.
  - **순수 파일명 패턴 원인 (Pure File-Pattern Causality)**:  
    $R_{\text{file\_only}}(p) \equiv \text{TEST} \land R_{\text{seg\_only}}(p) \neq \text{TEST}$  
    $\to$ 파일명 패턴이 단독으로 승격을 유발함이 수학적으로 증명됨.
  - **복합 기여 (Dual Causality)**:  
    $R_{\text{seg\_only}}(p) \equiv \text{TEST} \land R_{\text{file\_only}}(p) \equiv \text{TEST}$  
    $\to$ 두 규칙이 모두 승격 조건을 만족함.
- **실측 검증 시 적용**:
  위 4대 분류기를 실제 실행하여 Godot(188개)과 VS Code(93개)의 전이 노드가 어떤 인과 범주에 속하는지 정량적으로 도출하고 산출 근거를 로그로 보존합니다.
