## 3. P0: 경로 정규화 알고리즘 및 Oracle 입력 계약 (§2 보강)

### 3.1. `auditNormalize` 입력 계약 및 8단계 결정적 알고리즘

#### 1) 엄격한 입력 계약 (Fail-Closed Input Contract)
- `typeof rawPath !== 'string'`: 즉시 치명적 예외 (`throw Error("INVALID_PATH_TYPE: Input must be a string")`).
- `rawPath === null || rawPath === undefined`: 즉시 치명적 예외 (`throw Error("NULL_OR_UNDEFINED_PATH_REJECTED")`).
- `rawPath === ""`: 빈 문자열 `""` 반환 (허용).

#### 2) 8단계 결정적 정규화 알고리즘
```typescript
export function auditNormalize(rawPath: string): string {
    // 1. Input Validation
    if (typeof rawPath !== 'string') throw new Error("INVALID_PATH_TYPE");
    if (rawPath === '') return '';

    // 2. Virtual URI Bypass Check (대소문자 무관, 원본 100% 보존)
    if (/^(ghost|external|builtin):\/\//i.test(rawPath)) {
        return rawPath;
    }
    // file:// 스킴은 로컬 절대 경로로 정규화
    let p = rawPath.replace(/^file:\/\//i, '');

    // 3. Separator Normalization
    p = p.replace(/\\/g, '/');

    // 4. Windows Drive Relative Error Check
    // 예: C:foo/bar (드라이브 루트가 누락된 상대 경로는 비정상 경로로 거부)
    if (/^[a-zA-Z]:[^/]/.test(p)) {
        throw new Error("UNSUPPORTED_DRIVE_RELATIVE_PATH: " + rawPath);
    }

    // 5. Prefix Extraction & UNC Detection
    let prefix = '';
    // Strict UNC: 정확히 2개의 선행 슬래시와 유효한 서버명/공유명 세그먼트
    if (/^\/\/[^\/\s]+\/[^\/\s]+/.test(p) && !p.startsWith('///')) {
        prefix = '//';
        p = p.substring(2);
    } else if (p.startsWith('/')) {
        prefix = '/';
        p = p.replace(/^\/+/, '');
    }

    // 6. Windows Drive Letter Normalization
    if (/^[a-zA-Z]:/.test(p)) {
        // 드라이브 문자 대소문자 유지, 콜론 직후 슬래시 표준화
        prefix = p.substring(0, 2);
        p = p.substring(2).replace(/^\/+/, '/');
    }

    // 7. Consecutive Slash Collapse
    p = p.replace(/\/+/g, '/');

    // 8. Segment Filtering & Parent Directory Preservation
    const parts = p.split('/');
    const resolvedParts: string[] = [];
    for (const part of parts) {
        if (part === '' || part === '.') {
            continue; // 빈 세그먼트 및 현재 디렉터리 축약
        }
        resolvedParts.push(part); // ".."를 포함한 모든 의미 세그먼트 순서 보존
    }
    p = resolvedParts.join('/');

    if (prefix === '/' && p === '') return '/';
    if (prefix === '//' && p === '') return '/';
    return prefix + p;
}
```

#### 3) 워크스페이스 경로 이탈(Path Traversal) 검증 규약
- 정규화된 상대 경로 $p_{\text{rel}}$이 `../`로 시작하거나 워크스페이스 상위로 탈출하는 경우:
  `p_rel.startsWith('../') || p_rel === '..'` $\to$ **즉시 거부 (`throw Error("WORKSPACE_ESCAPE_DETECTED")`)**.

### 3.2. Oracle 입력 경로 및 외부 경로 단일 결정 정책 (Deterministic Policy)

1. **상대화 계약 ($p_{\text{rel}}$)**:
   - 워크스페이스 루트를 $W_{\text{root}}$라 할 때, $p$가 $W_{\text{root}} + '/'$로 시작하면 해당 접두사를 제거하여 $p_{\text{rel}}$을 획득.
   - $p$가 이미 상대 경로인 경우 $p_{\text{rel}} = p$.
2. **외부 절대 경로 단일 정책: `REJECT`**:
   - $p$가 절대 경로이면서 $W_{\text{root}}$ 내부에 속하지 않는 경우, 모호하게 `EXTERNAL`로 분류하지 않고 **즉시 거부(`throw Error("EXTERNAL_ABSOLUTE_PATH_REJECTED")`)**합니다. SYNAPSE는 워크스페이스 외부 파일을 물리 노드로 수집하지 않으므로 오염 진입을 차단합니다.
   - 단, `ghost://`, `external://` 등 명시적 가상 스키마 URI는 가상 노드로서 예외적으로 수용되어 해당 스키마 Role을 부여받습니다.

### 3.3. `TOOLING_SCRIPT` 최상위 디렉터리 세부 정책 확정

최상위 디렉터리(`^(scripts|build|tools|ci)/`) 내부의 일반 소스 오분류를 방지하기 위해 다음 3중 필터를 강제합니다:
1. **상위 우선순위 선취**: 도구 디렉터리 내부라도 `config.json` 등 설정 파일은 Priority 2 CONFIG로, `README.md` 등은 Priority 4 DOCUMENT로 우선 분류.
2. **스크립트/코드 확장자 한정**:
   최상위 디렉터리 내부에서 오직 다음 확장자 및 실행 파일만 `TOOLING_SCRIPT`로 분류:
   `/\.(ts|js|py|sh|bash|zsh|bat|cmd|ps1|rb|pl)$/i`
3. **루트 전용 파일**: 루트 경로(`!p_rel.includes('/')`)에서는 `SConstruct`, `setup.py`, `Makefile`, `Dockerfile` 및 루트 셸 스크립트만 인정.
4. **일반 소스 디렉터리 보존**: `src/` 또는 `lib/` 하위에 위치한 파일은 폴더명이 `tools`이더라도 절대 `TOOLING_SCRIPT`가 되지 않으며 일반 소스 Role로 보존.

### 3.4. `filePath` 1/2단계 검증의 완전 연결 (§2.2 보강)

#### 1) Stage 1: 입력 무결성 전수 검증 (Input Validation)
- `typeof id !== 'string' || id.trim() === ""`: 즉시 치명적 예외 (`EMPTY_OR_NON_STRING_ID`).
- `filePath === null`: 즉시 치명적 예외 (`NULL_FILE_PATH_REJECTED`).
- `filePath !== undefined && typeof filePath !== 'string'`: 즉시 치명적 예외 (`INVALID_FILE_PATH_TYPE`).
- `typeof filePath === 'string' && id !== filePath`: 즉시 치명적 예외 (`ID_FILE_PATH_MISMATCH`).

#### 2) Stage 2: 정규화 및 결과 검증 (Output Invariant Verification)
변환 대상 노드 $u \in V_{\text{target}}$에 대해:
- **원본에 `filePath`가 존재했던 경우**:
  - $filePath' \equiv \text{auditNormalize}(filePath)$
  - $id' \equiv \text{auditNormalize}(id)$
  - $filePath' \equiv id'$ 전수 대조.
- **원본에 `filePath === undefined`였던 경우**:
  - **생성 불변식**: 변환 노드 $u'$에 **반드시 `filePath` 필드가 생성되어야 함** (`u'.filePath !== undefined`).
  - **값 불변식**: $u'.filePath \equiv \text{auditNormalize}(u.id) \land u'.id \equiv \text{auditNormalize}(u.id)$.
- **비대상 노드 ($u \in V \setminus V_{\text{target}}$)**:
  - 어떠한 필드도 변경되지 않고 원본과 100% 동일 (`deepEqualJSON`).

     \text{Pure Segment Causality} &\iff R_{\text{base}} \neq \text{TEST} \land R_{\text{file\_only}} \neq \text{TEST} \land R_{\text{seg\_only}} \equiv \text{TEST} \land R_{\text{full}} \equiv \text{TEST} \\

     \end{aligned}$$

## 5. P1: 전체 사상 $M^*$ 전역 ID 충돌 방지 및 Edge 집합 보존 (§2.1 보강)

### 5.1. 전역 ID 충돌 방지 불변식 (Global Disjointness & Invariant)
전체 노드 집합 $V$에 대해 $M^*$가 단사성(Injectivity)을 유지함을 보장하기 위해 다음 조건을 추가 강제합니다:

1. **대상-비대상 ID 상호 배타성 (Global Disjointness)**:
   $$M_{\text{id}}(V_{\text{target}}) \cap (V \setminus V_{\text{target}}) = \varnothing$$
   - 변환 대상 노드의 새 ID가 비대상 노드의 기존 ID와 단 1건도 겹치지 않음을 집합 교집합 검사로 증명.
2. **전역 단사성 (Global Injectivity of $M^*$)**:
   $$\forall u, v \in V, \quad u \neq v \implies M^*(u) \neq M^*(v)$$
   - 전체 노드 수 보존: $|V'| \equiv |V|$.

### 5.2. Edge ID 원본 유일성 및 양방향 집합 일치 (Bidirectional Edge Set Equivalence)
기수 일치($|E'| = |E|$)에 더하여, 엣지 집합의 완전한 1:1 보존을 증명합니다:

1. **원본 Edge ID 유일성 선행 조건**:
   $$\forall e_1, e_2 \in E, \quad e_1 \neq e_2 \implies e_1.\text{id} \neq e_2.\text{id}$$
2. **양방향 Edge ID 집합 일치**:
   $$\text{IDs}(E') \equiv \text{IDs}(E) \land |E'| \equiv |E|$$
3. **엣지 변환기 함수 (`transformEdge`) 명세**:
   ```typescript
   function transformEdge(e: Edge): Edge {
       return {
           ...e, // 비-endpoint 모든 메타데이터 100% 보존
           from: M_star(e.from),
           to: M_star(e.to)
       };
   }
   ```
4. **Endpoint 사상 일치**:
   $$\forall e \in E, \quad e'.\text{from} \equiv M^*(e.\text{from}) \land e'.\text{to} \equiv M^*(e.\text{to})$$
