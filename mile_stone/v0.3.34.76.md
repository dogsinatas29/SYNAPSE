## 🧠 상세 설계 및 로직

### 1. 세 개념의 독립 분리
| 개념 | 정의 | 담당 | 현 상태 |
| :--- | :--- | :--- | :--- |
| `Execution Entry Point` | 프로그램의 실제 실행 시작 위치 (`main()` 등) | E3 (`Execution Entry Detector` 후보) | 현재 범위 제외 (미래 후보) |
| `Static Dependency Root` | 정적 의존성 그래프의 관측된 Root (`inDegree=0 && outDegree>0`) | O2 ([EntryPointDetector.ts](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/src/core/analysis/patterns/detectors/EntryPointDetector.ts)) | **현행 유지** |
| `Architecture Exploration Candidate` | 코드 탐색을 시작할 때 참고할 후보 | Onboarding ([FindingReportAdapter.ts](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/src/core/reporting/FindingReportAdapter.ts)) | **현재 개선 대상** |

- O2의 결과는 온보딩 탐색 후보(`Architecture Exploration Candidates`)로 활용할 수 있지만, 실제 런타임 실행 진입점이나 최적의 코드 독해 순서를 의미하지 않는다.
