# The 6-Step Brake

Before writing code:

---

## Step 1

YAGNI Check

```text
Is this required now?
```

If not:

```text
Do not implement.
```

---

## Step 2

Standard Library Check

```text
Can stdlib solve this?
```

If yes:

```text
Use stdlib.
```

---

## Step 3

Platform Feature Check

```text
Can browser or OS solve this?
```

If yes:

```text
Use native feature.
```

---

## Step 4

Existing Dependency Check

```text
Can existing dependency solve this?
```

If yes:

```text
Use existing dependency.
```

---

## Step 5

One-Line Check

```text
Can this be simplified?
```

If yes:

```text
Simplify.
```

---

## Step 6

Minimal Implementation

Only now:

```text
Implement minimum code.
```

# BFS Discipline

All traversal systems must avoid:

```javascript

```

---

Avoid:

```javascript

```

---

Required:

```javascript

let head = 0;

while (head < queue.length) {
    const current = queue[head++];
}
```

---

Required:

```javascript
const visited = new Set();
```

Applies to:

```text
Blast Radius

Infection Analysis

Threat Analysis
```
