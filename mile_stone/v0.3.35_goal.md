````markdown
# 1. Mission

v0.3.35의 목표는 SYNAPSE를 "노드 시각화 도구"에서 "아키텍처 흐름 분석 도구"로 진화시키는 것이다.

지금까지의 SYNAPSE는 다음 질문에 답했다.

- 어떤 파일이 존재하는가?
- 어떤 클러스터가 존재하는가?
- 어떤 구조로 구성되어 있는가?

v0.3.35는 다음 질문에 답해야 한다.

- 실제로 어디가 중요한가?
- 어떤 영역이 시스템 중심부인가?
- 어떤 영역이 병목인가?
- 어떤 영역이 변경 리스크가 높은가?
- 프로젝트의 에너지가 어디로 흐르는가?

---

# 2. Core Principle

v0.3.35는 노드 기반 시각화가 아니다.

v0.3.35는 Heatmap 기반 시각화다.

사용자는 더 이상 수만 개 노드와 수십만 개 엣지를 읽지 않는다.

사용자는 흐름(Flow)을 읽는다.
````

# 6. Heatmap First Strategy

초거대 프로젝트에서는:

* 노드 = 노이즈
* 엣지 = 노이즈

가 된다.

예시:

### Linux Kernel

* Nodes ≈ 68,000
* Edges ≈ 379,000

### Unreal Engine

* 수십만 노드
* 수백만 참조

이 규모에서는 노드와 엣지를 아무리 최적화해도 인간은 읽을 수 없다.

---

