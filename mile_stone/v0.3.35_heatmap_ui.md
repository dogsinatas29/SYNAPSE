## SYNAPSE v0.3.35
### HeatMap Visibility UI Separation

---

# 목표

Traffic Heatmap을 기존 Layer Visibility 패널에서 완전히 분리한다.

v0.3.35부터 Heatmap은 더 이상 그래프 렌더링 옵션이 아니다.

Heatmap은 SYNAPSE의 새로운 분석 시스템(Analysis Layer)의 일부로 취급한다.

따라서 Node Visibility, Edge Visibility, Cluster Visibility와 동일한 영역에 존재해서는 안 된다.

---

# 설계 철학

## 기존

```text

☑ Nodes
☑ Edges
☑ Clusters
☑ External References
☑ Traffic Heatmap
````

문제:

Traffic Heatmap은

* 노드가 아님
* 엣지가 아님
* 클러스터가 아님

분석 결과(View)임

즉 데이터 가시성과 분석 가시성이 섞여 있음

# 동작 규칙

## Rule 1

Heatmap은 독립적으로 켜고 끈다.

```text
Nodes OFF
Edges OFF
Clusters ON

Architectural Attention ON
```

가능

---

## Rule 2

Heatmap은 여러 개 동시에 켤 수 없다.

v0.3.35

```text
Single Active Heatmap
```

정책 사용

예)

```text
Architectural Attention ON
```

선택 시

```text
Dependency Density OFF
Coupling OFF
Hub Score OFF
```

자동 처리

---

## Rule 3

Heatmap은 Overlay Layer

그래프 구조를 수정하지 않는다.

금지:

* 노드 생성
* 엣지 생성
* 클러스터 생성
* 좌표 변경

허용:

* 색상 변경
* 투명도 변경
* 강조 효과

# v0.3.35 범위

포함

* HeatMap Visibility 패널 신설
* Traffic Heatmap 버튼 제거
* activeHeatmapType 도입
* Single Active Heatmap 정책
* Architectural Attention 연결

---

포함하지 않음

* Node 렌더러 수정
* Edge 렌더러 수정
* Cluster 렌더러 수정
