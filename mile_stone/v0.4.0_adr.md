# SYNAPSE v0.4.0 Architecture Decisions (ADR)

---

### ADR-001: Fact Sourcing adopted
**Reason:** Future reinterpretation is guaranteed by preserving the raw state.
**Rejected:** Snapshot-only model, traditional Event Sourcing (which stores derived meaning).

---

### ADR-002: CAS (Content Addressed Storage) adopted
**Reason:** 100% deterministic AST rebuilds years later, regardless of parser changes.
**Rejected:** Diff-only persistence (too fragile for structural rebuilding).

---

### ADR-003: Harvest ordering adopted
**Reason:** Single-user VSCode runtime naturally provides guaranteed linear time.
**Rejected:** Lamport Clock, Vector Clock (over-engineering for this context).

---

### ADR-004: Referenced Blob Immutability
**Reason:** Historical reconstruction requires permanent access to all RawFact references.
**Decision:** A RawFact reference creates a permanent retention obligation for the referenced CAS blob. Any blob referenced by a RawFact is immutable and must remain available. Orphan blobs created by failed or interrupted writes may be garbage collected.
**Rejected:** Mutating existing blobs. Deleting RawFact-referenced blobs.

---

### ADR-005: Workspace Is Source Of Current Truth
**Reason:** The authoritative current codebase already exists on disk.
**Decision:** Cold Boot reconstructs current state directly from Workspace Scan. Historical RawFacts are reserved for historical reconstruction and are not replayed during normal startup.
**Rejected:**
- Rebuilding current state through RawFact replay.
- Event replay as the primary runtime mechanism.

---

### ADR-006: Projection Is Disposable
**Reason:** ProjectionSnapshot is a performance artifact.
**Decision:** ProjectionSnapshot may be deleted at any time. System must recover solely from Workspace Scan.
**Rejected:** Treating ProjectionSnapshot as authoritative state.
