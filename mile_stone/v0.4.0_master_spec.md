# SYNAPSE v0.4.0 Master Specification
## Project Evolution Platform

---

## 1. Fact Sourcing Philosophy

**Axiom 1:** Historical truth is represented by the Raw Fact Log and Referenced CAS Blobs. Neither alone is sufficient.
**Axiom 2:** Workspace is the only authoritative current truth.
**Axiom 3:** All other artifacts (structural, architectural, projections) are disposable caches.
**Axiom 4:** Evolution Engine interprets current state vs previous projection; it is not a stream processor.

---

## 2. CAS (Content Addressed Storage) Blob Store

**Structure:**
`history/blobs/<sha256_hash>`

**Rule:**
Store actual file content chunks. Do not store only path differences.

**Why:**
Guarantees 100% deterministic AST rebuilds 10 years later regardless of parser changes.

---

## 3. Harvest Sequence Model

**Global Ordering:**
Uses `Harvest Sequence ID` (e.g., `Harvest #123`).

**Why:**
Harvest Sequence ID provides sufficient ordering guarantees for the SYNAPSE execution model.

---

## 4. Raw Fact Schema

**Layer 1: The Only Truth**

```typescript
interface RawFact {
  schemaVersion: 1;
  id: string; // UUID
  harvestId: number; // Global sequence
  timestamp: number;
  type: 'FILE_CREATED' | 'FILE_MODIFIED' | 'FILE_DELETED' | 'GIT_COMMIT';
  payload: {
    path: string;
    beforeHash: string | null; // CAS Blob Hash
    afterHash: string | null;  // CAS Blob Hash
    diff?: string; // Optional fast-path hint
  };
}
```

---

## 7. Evolution Engine & Replay Algorithm

**Interpreter, not Stream Processor.**

**Input:**
`Current Codebase AST` + `projection.snapshot (Layer 4)`

**Logic:**
Compare current AST with previous projection. 
Extract delta. 
Map delta to `StructuralFact` and `ArchitecturalFact`.

**Output:**
Updates to caches.

---

## 8. Projection & Snapshot Refresh Policy

**Trigger:** `Estimated Rebuild Cost`
**Inputs:**
- Source file count
- AST node count
- Topology complexity

If `Estimated Rebuild Cost > Threshold (Target 100ms boot)`:
  1. Bake new `projection.snapshot`.

**Projection Snapshot Schema:**
```typescript
interface ProjectionSnapshot {
  schemaVersion: 1;
  harvestId: number;
  topology: {
    nodes: Node[];
    edges: Edge[];
    clusters: Cluster[];
  };
  workspaceManifest: Record<string, string>; // path -> sha256 blob hash
  metadata: {
    createdAt: number;
    sourceFileCount: number;
    topologyVersion: number;
  };
}
```

---

## 9. Extension Cold Boot Sequence

1. Attempt to load `history/projection.snapshot`.
2. If unavailable, create empty projection state.
3. Read workspace current file state.
4. Build current AST.
5. Detect drift (Current Workspace vs Previous `workspaceManifest`).
6. Emit RawFacts (if drift exists) to create new Harvest.
7. Run Evolution Engine.
8. Generate ProjectionSnapshot.
9. Ready.

*Do not read `structural.cache` or `architectural.cache` on boot.*

---

## 10. Animator Data Contract

**Browser Application.**
Read-only. Consumes projections, visualizes interpretations.

**API Contract:**
```text
GET /api/history/timeline -> Returns array of Harvest IDs
GET /api/history/projection/:harvestId -> Returns computed Layer 4 state
GET /api/history/insights/:harvestId -> Returns calculated Layer 6 insights (Gravity, Necrosis)
```

---

## 11. Validation Harness

**Constraint 1:** No writes to `project_state.json` or `synapse_history.json` by Animator.
**Constraint 2:** `RawFact` must contain `beforeHash` and `afterHash` mapped to existing CAS blobs.
**Constraint 3:** Cold boot latency must be `< 100ms` for up to 10,000 facts.

---

## 12. Implementation Phases

**Phase 1: CAS & Raw Fact Log**
- Implement blob store.
- Implement `FILE_MODIFIED` extraction to CAS.
- **Gate:** Raw Fact Log correctly records `beforeHash` and `afterHash`.

**Phase 2: Semantic Promotion Engine**
- Implement `Current AST vs Projection` comparator.
- Map to Layer 2 & Layer 3 Facts.
- **Gate:** `MODULE_SPLIT` accurately detected from isolated Harvests.

**Phase 3: Projection Snapshot System**
- Implement ProjectionSnapshot bake policy.
- Implement Workspace Scan pipeline.
- Implement Projection Recovery path.
- **Gate:** System boots under 100ms with large workspaces.

**Phase 4: Animator Browser Independence**
- Launch external browser.
- Wire `/api/history` REST endpoints.
- **Gate:** Animator runs detached from VSCode process.

**Phase 5: Playback & Timeline**
- Implement seek, play, pause.
- **Gate:** Frames match exact historical projections.

**Phase 6: Read-Only Verification**
- Disconnect write permissions.
- **Gate:** Zero disk writes triggered by browser UI.
