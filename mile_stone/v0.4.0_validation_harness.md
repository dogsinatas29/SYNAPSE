# SYNAPSE v0.4.0 Validation Harness
## Quality Gates & Verification Rules

---

### HARNESS-001: RawFact beforeHash Validation
**Condition:** Every `FILE_MODIFIED` Raw Fact must contain valid `beforeHash` and `afterHash` references.
**Check:** The hashes must perfectly match blobs physically present in `history/blobs/`.

---

### HARNESS-002: CAS Blob Integrity
**Condition:** Blob content must perfectly reproduce the AST.
**Check:** Hashing the retrieved blob must strictly match its filename (SHA-256).

---

### HARNESS-003: Evolution Determinism
**Condition:** Cold Boot output must equal continuous runtime output.
**Check:**
State A: Continuous runtime after Harvest #10
State B: Cold Boot
  -> Load Projection
  -> Scan Workspace
  -> Build AST
  -> Run Evolution Engine

`assert.deepEqual(State A, State B)`

---

### HARNESS-004: Cold Boot Performance Budget
**Condition:** Realistic latency targets based on Workspace Size.
**Dataset:**
- 5,000 source files workspace
- 500,000 AST nodes
**Check:**
- Load Projection
- Scan Workspace
- Build AST
- Run Evolution Engine
**Goals:**
- Phase 3: < 500ms
- Phase 5: < 250ms
- Production: < 100ms

---

### HARNESS-005: Animator Read-Only Verification
**Condition:** Absolute zero disk mutation from the browser.
**Check:** 
- Spy on `fs.writeFile` and `fs.appendFile` during Animator operations.
- Ensure no writes target `project_state.json` or `synapse_history.json`.
- Fail hard if any write is intercepted.

---

### HARNESS-006: Historical Reconstruction Correctness
**Condition:** Historical reconstruction must perfectly rebuild the file ASTs.
**Check:**
Given: RawFact Log
When: Harvest #103 Workspace reconstructed from CAS blobs.
Then: AST must match original Harvest #103 AST.

---

### HARNESS-007: Projection Loss Recovery
**Condition:** System must survive complete projection loss.
**Check:**
1. Delete projection.snapshot
2. Restart SYNAPSE
3. Scan Workspace
4. Generate new ProjectionSnapshot
5. Run Evolution Engine
**Assert:**
- Current topology reconstructed successfully
- No RawFact loss
- Historical reconstruction remains available

---

### HARNESS-008: Workspace Truth Recovery
**Condition:** Workspace alone must recover current topology.
**Check:**
1. Delete projection.snapshot
2. Delete structural.cache
3. Delete architectural.cache
4. Restart SYNAPSE
5. Scan Workspace
6. Build AST
7. Run Evolution Engine
**Assert:**
- Current topology reconstructed
- System operational
- Historical layer unaffected

---

### HARNESS-009: Workspace Drift Detection
**Condition:** Workspace state and latest Harvest state diverged unexpectedly.
**Check:**
Given: Projection @ Harvest #100, Workspace manually edited outside Harvest (e.g., vim, git checkout).
When: Cold Boot
Then: Evolution Engine must detect drift and emit new RawFacts representing current workspace state.
**Assert:**
- No crash
- No history corruption
- New Harvest generated
- Projection updated

---

### HARNESS-010: Referenced Blob Protection
**Condition:** Any Blob referenced by a RawFact must be protected from garbage collection.
**Check:**
Given: A RawFact references Blob A.
When: GC runs.
**Assert:** Blob A is not deleted.
