# 🚀 Milestone v0.3.09_fix - 2D/3D Rendering Engine Synchronization & Bug Fixes

## 📅 작업 정보 
- **상태:** 🚧 In-Progress
- **관련 마일스톤:** v0.3.09
- **목표:** 2D 모드와 3D(WebGL) 모드 간의 좌표 및 렌더링 불일치를 통합/강제 동기화하고, 시스템 잠금(Phase Lock) 버그 등을 해결하여 랜더링 안정성을 확보.

## 🧠 상세 설계 및 로직 
- **논리 좌표계 통합 (Logical Grid):** 2D 브라우저가 인식하는 CSS 픽셀 좌표를 부동의 기준으로 삼고, WebGL은 이 기준 좌표를 받아 전용 좌표(-1.0 ~ 1.0)로 변환하도록 시스템 일원화.
- **데이터 소스 단일화:** RendererCore가 필터링한 결과를 2D와 3D가 동기화하여 사용하여 2D/3D 간 데이터 불일치 상황 원천 봉쇄.
- **뱃지(아이콘) 위치 계산 식 교체:** 3D WebGL 뱃지 위치가 2D의 곡선 곡률과 불일치했던 문제를, 2D의 중앙 지점 고정 공식으로 통일 중.

## 🛠️ 기술적 변경 사항
- **Node Update / Edge Update:**
  1. 가속 기능(Accel OFF, 2D모드) 해제 시 노드와 엣지가 예측 불가능하게 소실되거나 아예 렌더링되지 않는 문제점 기록.
  2. 2D 상태에서 특정 노드 선택 시 연결되지 않은 전역 엣지가 표시되거나 줌인아웃 시 렌더링이 깨지는 현상 기록 (Accel ON 웹지엘 모드에서는 정상적으로 렌더링 됨).
- **File Changes (ui/canvas-engine.js):** 
  - `createManualEdge` 실행 시점에서의 Phase 충돌 `[SYNAPSE] Interaction BLOCKED: System is LOCKED.` 수정: RENDER Phase 도중 `saveState`를 발생시켜 PhaseManager(Phase 5) 단에서 블락되던 로직을 `setTimeout(() => this.saveState(), 100)`으로 지연 실행하여 해결.

## ⚠️ 예외 처리 및 주의 사항 
- 2D Canvas의 렌더 루프 안정성 확보 시, 불필요한 상태 초기화 누락이 없는지 디버깅 시 중점 점검 필요.
- PhaseManager의 RENDER Phase(Phase 5)에서 발생하는 강제 락(`assertPhase`) 방지를 위해 UI 이벤트 내 State 변경은 반드시 비동기 태스크로 양도하여 시스템 중단을 막음.
