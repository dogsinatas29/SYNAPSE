# 🚀 Release Notes: v0.2.17 (Unified & Finalized)
[Status: Verified by Commander]

## [ENG]
**SYNAPSE v0.2.17 is a monumental update that crystallizes system stability, canvas UX, intelligent AI orchestration, and the 'Logic Edit' workflow.**

### 1. AI Orchestration & DTR Control
- **DTR Visualization:** By calculating the Deep-Thinking Ratio of the codebase, high-density AI reasoning nodes instantly emit a purple glow (#8A2BE2) across the canvas.
- **Inference Pressure Gauge:** Monitor and control AI DTR depth directly from the VS Code status bar. The tension and thickness of the node connection edges pulse dynamically to reflect the current analytical pressure.
- **AiOrchestrator Integration:** Dynamically adjusts LLM parameters depending on the node's required DTR.

### 2. WYSIWYG Logic Editing & Auto-Imports
- **Drawing equals Coding:** Adding/deleting nodes and connecting edges on the physical canvas directly manipulates the workspace files and internal logic architecture.
- **Auto-Injected Imports:** Confirming a manual edge connection (via the large `!` badge) natively triggers `import` or `require()` injection corresponding to the file's language (`.ts`, `.js`, `.py`) at the very top of the source file.
- **Safe File Deletion:** Replaces destructive file deletion with a `// [SYNAPSE_DELETED]` wrapper, heavily monitored by auto-snapshots to allow pain-free file resurrections.

### 3. Cluster Automation & UI Streamlining
- **Logic Edit Master Switch:** The destructive `Node` creation and `Connect` tools are now strictly hidden by default. They only appear when the `Edit Logic` (red) toggle is activated, enforcing a clean observer mode.
- **Buffer Cluster Spawn:** Newly created manual nodes are no longer orphaned across the canvas. They automatically drop directly into the `Buffer Cluster` coordinates (-1100, 1000) with a smooth camera auto-focus.
- **Reserved Cluster Promotion:** When a node in the Buffer Cluster is manually connected to an existing architectural node, the visual visualizer instantly promotes and shifts the node's properties into the `Reserved Cluster` to signal it is actively participating in the logic tree.

### 4. Stability, Data Hygiene, and UX
- **Enlarged Validation Badges:** Made the `?` and `!` click-to-confirm edge badges significantly larger for greatly improved readability and faster workflow interactions.
- **Anti-Resurrection Logic:** Uses `SequentialTaskQueue` and forced state snapshots to seal deletions, completely preventing ghost nodes from returning via stale cache.
- **Smart Documentation Layout:** Overhauled the `Documentation Shelf` to be collapsed by default to save significant canvas space, and enforced semantic overlap prevention (150px/100px padding) for all loaded nodes.

## [KOR]
**SYNAPSE v0.2.17은 시스템 안정성, 캔버스 UX, 구조 설계 편의성 및 로직 편집(Logic Edit) 워크플로우를 완벽하게 집대성한 대규모 업데이트 버전입니다.**

### 1. AI 오케스트레이션 및 DTR 제어
- **DTR (Deep-Thinking Ratio) 시각화:** AI가 분석한 코드 논리의 밀도와 깊이를 보라색 발광(Glow) 효과로 캔버스에 즉각 투영합니다.
- **인퍼런스 압력 게이지:** 상태바에서 AI의 사고 깊이를 동적으로 제어하며, DTR 값에 따라 연결선의 두께와 긴장감이 실시간으로 변화하여 아키텍처의 부하를 시각화합니다.
- **AiOrchestrator 통합:** 추론 수치에 따라 LLM의 파라미터(Temperature, Top_P)를 가변적으로 조절하여 최적의 코딩 컨텍스트를 유지합니다.

### 2. 혁신적인 시각적 편집 (Logic Edit Mode) 및 자동 임포트
- **WYSIWYG 설계:** 캔버스에서 노드를 직접 생성/삭제하고 선을 잇는 드래그 행위만으로 실제 파일 시스템과 소스 코드가 즉시 수정됩니다.
- **엣지 승인 및 자동 임포트:** 엣지 연결 후 노출되는 배지를 클릭하여 확정하면, 언어별(`py`, `ts`, `js`) 최적화된 `import` 문이 대상 소스 코드 최상단에 자동 주입됩니다.
- **안전한 삭제 (Safe Deletion):** 물리적 파일 삭제 시 파괴적 방식 대신 `// [SYNAPSE_DELETED]` 주석 처리와 촘촘한 자동 스냅샷 백업을 병행하여 불상사를 100% 차단합니다.

### 3. 클러스터 자동화 및 UI 편의성 극대화
- **마스터 스위치 적용:** 노드 생성(`Node`) 및 연결(`Connect`) 버튼은 평소에 숨겨져(display: none) 있으며, `Edit Logic`이 켜진 상태에서만 노출되어 완벽하게 안전한 관측 모드를 보장합니다.
- **Buffer Cluster 자동 진입:** 새로 만든 수동 노드는 더 이상 캔버스 공중에 뜨지 않고 지정된 `Buffer Cluster` 영역(-1100, 1000)에 즉시 위치하며, 카메라가 자동으로 새로 만들어진 노드를 확대(Auto-Focus)해 줍니다.
- **Reserved Cluster 예비 승격:** 버퍼 구역의 잉여 노드를 상위 설계상의 노드와 엣지로 연결하면 해당 노드는 자동으로 `Reserved Cluster(예비 편입 구역)`로 승격/이동됩니다.

### 4. 시스템 안정성 및 데이터 위생 (Data Hygiene)
- **검증 배지 시인성 대폭 향상:** 사용자가 엣지를 이은 후 승인/거절을 제어하는 `?` 및 `!` 배지의 디스플레이 반경을 대폭 키워 시각적 피로도를 현저히 낮췄습니다.
- **좀비 노드 부활 방지:** 파일 삭제 후 캐시에 의해 노드가 다시 살아나는 현상을 상태 강제 각인으로 완벽히 통제했습니다.
- **스마트 레이아웃 최적화:** `Documentation Shelf`를 기본 접힘 상태로 로드해 공간 활용을 높이고, 화면 내 겹침 방지 로직을 도입하여 쾌적한 아키텍처 환경을 자동 구성합니다.
