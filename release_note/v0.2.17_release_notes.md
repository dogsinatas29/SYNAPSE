### 1. AI 오케스트레이션 및 DTR 제어
- **DTR (Deep-Thinking Ratio) 시각화:** AI가 분석한 코드 논리의 깊이를 보라색 발광(Glow) 효과로 캔버스에 즉각 투영합니다.
- **인퍼런스 압력 게이지:** 상태바에서 AI의 사고 깊이를 동적으로 제어하며, DTR 값에 따라 연결선의 두께와 발광 강도가 실시간으로 변화합니다.
- **AiOrchestrator 통합:** DTR 수치에 따라 LLM의 파라미터(Temperature, Top_P)를 가변적으로 조절하여 최적의 코딩 컨텍스트를 유지합니다.

## 🏁 v0.2.17: Stability & Integrity (Patch 7-10)

**"Aesthetics meet Logic: Robust Connections and Manual Control."**

v0.2.17 focused on hardening the architecture engine while introducing "External Bridges" for cross-language support.

### 🛠️ Key Changes (Finalized)
- **🛡️ Hierarchical Clustering**: Confirmed nodes in the **Buffer Cluster** are now locked via `priority_cluster`, preventing automatic relocation.
- **🔗 Strict Connection Validation**: Invalid edges (to extensionless virtual nodes) are blocked during the creation gesture.
- **👻 Ghost Edge Elimination**: Refined node resolution to prioritize exact filename matches, preventing redundant edges during cross-language bridging.
- **🛡️ Robust Re-import Logic**: Improved matching for commented-out imports, ensuring reliable state restoration during edge deletion/re-connection.
- **🎨 Premium UI Polish**: Atomic high-visibility scrollbar implemented for the history list (Full external window deferral planned for Patch 11+).

### 2. 혁신적인 시각적 편집 (Logic Edit Mode)
- **WYSIWYG 설계:** 캔버스에서 노드를 생성/삭제하고 엣지를 잇는 행위가 실제 파일 시스템과 소스 코드에 즉시 반영됩니다.
- **엣지 승인 및 자동 임포트:** 엣지 연결 시 생성되는 `?` 배지를 클릭하여 확정하면, 언어별(`py`, `ts`, `js`) 최적화된 `import` 문이 소스 코드 최상단에 자동 주입됩니다.
- **안전한 삭제 (Safe Deletion):** 물리적 파일 삭제 시 파괴적 방식 대신 `// [SYNAPSE_DELETED]` 주석 처리와 자동 스냅샷 백업을 병행하여 코드 유실을 원천 차단합니다.

### 3. 시스템 안정성 및 데이터 위생 (Data Hygiene)
- **좀비 노드 부활 방지:** 파일 삭제 후 캐시나 구형 서머리에 의해 노드가 다시 살아나는 현상을 `SequentialTaskQueue`와 `Snapshot` 기반 상태 강제 각인으로 해결했습니다.
- **무결성 ID 시스템:** 엣지 ID에 해시값과 타임스탬프를 도입하여 다중 연결 시 발생하던 ID 충돌 및 증발 문제를 해결했습니다.
- **오토 디스커버리 강화:** `GEMINI.md` 파서의 정규식을 개선하여 볼드체나 인라인 백틱이 포함된 파일명도 누락 없이 스캔합니다.

### 4. 사용자 경험 (UX) 및 퍼포먼스
- **히트 박스 영역 확장:** 노드 선택 판정 기준에 `HIT_PADDING = 12px`을 추가하고 엣지 클릭 정밀도를 개선하여 조작감을 향상했습니다.
- **스마트 레이아웃:** `Documentation Shelf` 초기 접힘 처리 및 노드 중첩 방지 로직(150px/100px)으로 쾌적한 캔버스 환경을 제공합니다.
- **히스토리 스크롤바:** 누적되는 스냅샷을 편리하게 탐색할 수 있도록 히스토리 패널에 전용 스크롤바를 추가했습니다.

## [ENG]
**SYNAPSE v0.2.17 is a major update consolidating system stability, canvas UX, and AI orchestration features.**

### 1. AI Orchestration & DTR Control
- **DTR Visualization:** Instantly projects AI reasoning depth via purple glow effects on high-density nodes.
- **Inference Pressure Gauge:** Monitor and control AI DTR depth from the status bar. Edge thickness and pulse animations respond dynamically to DTR levels.
- **AiOrchestrator Integration:** Dynamically adjusts LLM parameters (Temperature, Top_P) based on DTR values to ensure optimal coding reasoning.

### 2. WYSIWYG Logic Editing
- **Drawing equals Coding:** Adding/deleting nodes and connecting edges on the canvas directly manipulates the workspace files and internal logic.
- **Auto-Injected Imports:** Confirming an edge (via the `?` badge) triggers native `import` or `require()` injection at the top of the source file.
- **Safe File Deletion:** Replaces destructive deletion with a `// [SYNAPSE_DELETED]` wrapper and automated snapshots, supporting secure file resurrection.

### 3. Stability & Data Hygiene
- **Anti-Resurrection Logic:** Prevents deleted nodes from reappearing due to stale summaries or cache. Uses `SequentialTaskQueue` and forced state snapshots to seal deletions.
- **Unique ID Integrity:** Implements salted hashing (Source+Target+Time) for edge IDs to prevent collisions and vanishing artifacts during high-speed editing.
- **Improved Parsing:** Enhanced `GEMINI.md` regex to correctly identify nodes even when styled with markdown bold or backticks.

### 4. UX & Performance
- **Expanded Hit Padding:** Added `12px` hit-padding to all nodes and loosened edge-click requirements for smoother interaction.
- **Smart Layouts:** Introduced auto-correction for node overlaps and set the `Documentation Shelf` to be collapsed by default to save space.
- **History Scrollbar:** Added a dedicated vertical scrollbar to the snapshot history panel for easier navigation.
