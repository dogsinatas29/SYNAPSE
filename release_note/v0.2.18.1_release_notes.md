# 🚀 v0.2.18.1 Release Notes - Iron Guard Protocol

---

## 🇰🇷 Korean Version

### 🏁 개요
본 버전은 시스템의 복잡도를 제어하기 위한 **문서 모듈화(Modularization)**와 사용자 인터페이스의 **시각적 정교화(UI Refinement)**, 그리고 LLM의 잠재적 가설을 다루는 **Ghost Node logic**을 도입했습니다.

### 🛠️ 주요 변경 사항

#### 1. 🏛️ 문서 모듈화 (Modularization)
- `architecture.md`를 마스터 허브로 유지하되, 상세 설계를 4개의 전문 도메인(`core_synapse.md`, `vega_agent.md`, `reporting.md`, `data_scheme.md`)으로 분리하여 인지 부하를 줄였습니다.

#### 2. 🎨 계층형 메뉴 및 디자인 고도화
- 상단 툴바를 `View`, `System`, `Protocol` 등 계층형 메뉴로 개편하여 캔버스 공간을 확보하고 시각적 안정성을 높였습니다.
- 버튼 디자인을 프리미엄 룩(Premium Look)으로 개선하고 클릭 시 레이아웃 흔들림 현상을 수정했습니다.

#### 3. 👻 Ghost Node & Reserved Cluster 전이 모델
- LLM이 제안하는 잠재적 노드를 `Ghost` 상태로 시각화하고, 승인 시 실제 파일로 실체화(Materialize)하는 워크플로우를 정립했습니다.
- `Reserved Cluster` 자동 도약 기능을 통해 설계 진행 상황을 명확히 시각화합니다.

#### 4. 📦 컨텍스트 공간 격리 (Context Vault Isolation)
- 비대한 컨텍스트 노드들을 외부 패널로 격리하여 아키텍처 형상에 집중할 수 있는 쾌적한 환경을 조성했습니다.

#### 5. 🛡️ 예외 사살 기초 작업 (Panic Isolation - Foundation)
- [v0.2.18.1] 향후 완벽한 **결정론적 사고(Deterministic Thinking)**를 시스템에 이식하기 위한 기초 작업으로, 언어 간 경계를 넘나들 때 발생하는 예외 상황을 에러 코드로 변환하여 격리하는 Panic Isolation 기틀을 마련했습니다.

#### 6. 🛡️ 경량 스키마 가드 (Lightweight Schema Guard)
- 데이터 무결성을 보장하기 위해 `project_state.json` 저장/로드 시 핵심 필드(ID, Type 등)를 즉각 검증하는 LOD(Level of Detail) 방식의 검증 엔진을 도입했습니다.

## 🇺🇸 English Version

### 🏁 Overview
This version introduces **Modularization** to control system complexity, **UI Refinement** for a more sophisticated user experience, and **Ghost Node Logic** for handling potential LLM hypotheses.

### 🛠️ Key Changes

#### 1. 🏛️ Documentation Modularization
- Maintained `architecture.md` as the Master Hub while splitting detailed designs into four specialized domains (`core_synapse.md`, `vega_agent.md`, `reporting.md`, `data_scheme.md`) to reduce cognitive load.

#### 2. 🎨 Hierarchical Menus & UI Design Refinement
- Restructured the top toolbar into hierarchical menus (`View`, `System`, `Protocol`) to free up canvas space and improve visual stability.
- Enhanced button designs for a premium look and fixed layout shifting issues during interaction.

#### 3. 👻 Ghost Node & Reserved Cluster Transition
- Implemented visualization for LLM-proposed nodes as `Ghost` states, with a workflow for materialization upon approval.
- Enhanced visual feedback for design progress with the automated jump to the `Reserved Cluster`.

#### 4. 📦 Context Vault Isolation
- Isolated bulky context nodes into an external panel, creating a clean environment focused on the core architecture.

#### 5. 🛡️ Panic Isolation (Foundation for Deterministic Thinking)
- Established the foundation for **Panic Isolation** by converting cross-language exceptions into error codes. This serves as the groundwork for implementing full deterministic logic in future updates.

#### 6. 🛡️ Lightweight Schema Guard (LOD Validation)
- Introduced a Level of Detail (LOD) based validation engine that performs real-time integrity checks on essential fields (ID, Type, etc.) during `project_state.json` save/load operations.
