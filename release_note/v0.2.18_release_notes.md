# 🚀 SYNAPSE Visual Architecture Engine v0.2.18 Release Notes

## 📢 What's New in v0.2.18 (English)

Version 0.2.19 brings critical stability improvements and deepens the WYSIWYG connection between the visual canvas and the underlying codebase. This release focuses on eradicating the "Ghost Node Resurrection" bug, improving the collision radius of connection badges, and solidifying explicit Edge Direction Semantics (A ➔ B).

### Bug Fixes & Stability
- **Ghost Node Resurrection Blocked**: Implemented an explicit validation check during the `saveState` sequence (`CanvasPanel.ts`). Nodes deleted in the UI can no longer be resurrected by stale cache or race conditions. Only nodes created via precise `createManualNode` commands are saved if they don't exist in the backend.
- **Edge Badge Hitbox Expansion**: The clickable radius for Edge confirmation (`?`) and Edge deletion (`trash`) badges has been dramatically enlarged (from `1.5x` to `2.5x` radius) and globally scaled up, solving the issue where clicks would "miss" the target when zoomed in tightly.
- **Cluster Assignment Lock**: Fixed a bug where a newly created node assigned to the `Buffer Cluster` would lose its affiliation (`cluster_id = null`) when physically dragged by the user. Dragged nodes now fall back to their `priority_cluster` lock, allowing them to correctly upgrade to the `Reserved Cluster` upon connection.

### Features & DX Enhancements
- **Strict Edge Import Semantics (A ➔ B)**: Formalized the rule that connecting Node A to Node B explicitly means "Node A depends on (imports) Node B". 
- **Auto-Import Status Notification**: When an edge is connected, the UI now displays a 5-second VS Code notification explicitly stating: `"Edge A ➔ B connected: Injecting pending import."`
- **Safe Import Injection**: The Edge Code Refactorer now strictly guards against duplicate module injections for Javascript, Typescript, and Python, ensuring imported libraries rest cleanly at the top of the target file.
- **Physical Reserved Cluster Leap**: When a node is successfully connected and promoted from the `Buffer Cluster` to the `Reserved Cluster`, it now physically teleports to the `-1500, 1000` coordinate space, providing immediate visual feedback of its new operational status.

## 📢 v0.2.18 릴리즈 노트 (한국어)

버전 0.2.19는 시각적 캔버스와 소스 코드 간의 WYSIWYG 연결성을 더욱 견고하게 다지고, 치명적인 안정성 이슈들을 해결한 핫픽스 성격의 릴리즈입니다. 이번 업데이트는 "좀비 노드 부활" 현상을 차단하고, 엣지(Edge)의 방향성에 대한 정의(A ➔ B)를 명확히 하는 데 집중했습니다.

### 🐛 버그 수정 및 안정성 향상
- **좀비 노드(Ghost Node) 부활 현상 차단**: 사용자가 명시적으로 삭제한 노드가 비동기 저장 타이밍 오류로 인해 캔버스에 다시 렌더링되던 치명적인 버그를 수정했습니다. 이제 백엔드는 명시적인 생성 명령(`createManualNode`)이 아닌 이상, 웹뷰 캐시에 떠도는 유령 노드를 절대 직렬화(JSON Save)하지 않습니다.
- **배지 클릭 반경 대폭 상향**: 줌-인 상태에서 엣지의 확정(`?`) 버튼이나 삭제(휴지통) 아이콘이 잘 눌리지 않던 현상(클릭 씹힘)을 해결했습니다. 배지의 기본 크기를 키우고, 보이지 않는 클릭 허용 반경(Hit Radius)을 기존 1.5배에서 **2.5배로 대폭 확장**했습니다.
- **클러스터 소속 이탈(Lock) 방지**: 새로 만든 노드를 `Buffer Cluster` 밖으로 드래그할 경우 소속이 박탈(`cluster_id = null`)되어 고아가 되던 문제를 수정했습니다. 이제 노드는 `priority_cluster` 기억 장치를 통해 소속을 유지하며, 선을 연결했을 때 올바르게 `Reserved Cluster`로 승급될 수 있습니다.

### ✨ 기능 및 UX 개선
- **엄격한 엣지 Import 방향성(A ➔ B) 확립**: A 노드에서 출발하여 B 노드로 선을 긋는 시각적 행위가 곧 "A 소스 파일이 B 모듈을 Import 한다"는 물리적 코딩 규칙으로 완전히 공식화되었습니다.
- **상태바 Import 실시간 알림**: 선을 연결하는 즉시, VS Code 우측 하단 상태바에 `"Edge A ➔ B connected: Injecting pending import."`라는 명확한 피드백이 5초간 팝업되어 작업자의 인지 능력을 돕습니다.
- **스마트 Import 중복 방지**: JS/TS, Python 파일 간에 선을 여러 번 긋더라도, 소스 코드 최상단에 주입되는 `import` 구문이 절대 중복 생성되지 않도록 코드 주입 파서의 안전성을 극대화했습니다.
- **물리적 Reserved Cluster 도약**: `Buffer Cluster`에 대기하던 노드가 선이 연결되어 `Reserved Cluster`로 승격되는 순간, 단순히 소속만 바뀌는 것이 아니라 **물리적인 화면 좌표계(-1500, 1000) 구역으로 즉시 점프**하여 시각적 직관성을 극대화했습니다.
