# 🚀 v0.2.18 Release Notes - SSoT Enforcement & Edge UX

---

## 🇰🇷 Korean Version

### 🏁 개요
본 버전은 시스템의 무결성을 보장하는 **SSoT(Single Source of Truth) 강화**와 사용자 경험을 대폭 개선하는 **Edge Interaction 최적화**에 집중했습니다. 특히 비동기 저장 과정에서 발생하던 '좀비 노드' 문제를 근본적으로 해결했습니다.

### 🛠️ 주요 변경 사항

#### 1. 👻 좀비 노드(Ghost Node) 부활 방지 로직 적용
- **현상**: 노드 삭제 후 비동기 `saveState` 타이밍에 웹뷰 캐시의 노드가 백엔드 JSON으로 재유입되어 다시 나타나는 현상.
- **해결**: 백엔드(`CanvasPanel.ts`) 저장 로직에 방어적 필터링을 도입. 이제 `createManualNode` 커맨드 없이 UI에서 임의로 제안된 신규 노드는 직렬화 과정에서 자동으로 제외됩니다.

#### 2. 🎯 Edge 배지(Badge) 히트박스 개선
- **현상**: 캔버스 줌 레벨에 따라 확정(`?`) 및 삭제(휴지통) 버튼이 잘 클릭되지 않는 문제.
- **해결**: 클릭 허용 반경(Hit Radius)을 기존 대비 **2.5배 확장**하여 쾌적한 조작감을 제공합니다.

#### 3. 🏗️ Reserved Cluster 자동 도약 기능
- **변경**: `Buffer Cluster`의 노드가 선으로 연결되는 즉시 `Reserved Cluster` 소속으로 변경되며, 물리적인 해당 구역(좌표계)으로 자동 점핑하여 설계의 진행 상황을 시각적으로 명확히 보여줍니다.

#### 4. 📢 실시간 상태 피드백 강화
- **추가**: 선 연결 시 VS Code 상태바에 방향성 및 Import 주입 상태(`Edge A ➔ B connected`)를 실시간으로 출력합니다.

## 🇺🇸 English Version

### 🏁 Overview
This version focuses on strengthening **SSoT (Single Source of Truth)** to ensure system integrity and optimizing **Edge Interaction** to significantly improve user experience. Specifically, it fundamentally resolves the 'Zombie Node' issue that occurred during asynchronous saving.

### 🛠️ Key Changes

#### 1. 👻 Zombie Node (Ghost Node) Prevention Logic
- **Issue**: Deleted nodes reappearing in the backend JSON due to webview cache re-injection during asynchronous `saveState`.
- **Solution**: Defensive filtering introduced in the backend (`CanvasPanel.ts`) save logic. New nodes proposed by the UI are now automatically excluded from serialization unless explicitly created via the `createManualNode` command.

#### 2. 🎯 Edge Badge Hitbox Improvements
- **Issue**: Confirmation (`?`) and deletion (trash can) buttons being difficult to click depending on the canvas zoom level.
- **Solution**: The click hit radius has been expanded by **2.5x**, providing a smoother and more responsive interaction.

#### 3. 🏗️ Automatic Jump to Reserved Cluster
- **Change**: Nodes in the `Buffer Cluster` now automatically transition to the `Reserved Cluster` upon connection. They also physically jump to the designated cluster coordinates, providing clear visual feedback on design progress.

#### 4. 📢 Real-time Status Feedback
- **Feature**: Real-time feedback on edge direction and import injection status (`Edge A ➔ B connected`) is now displayed in the VS Code status bar for 5 seconds.
