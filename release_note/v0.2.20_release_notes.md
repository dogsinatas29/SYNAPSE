## 🛡️ [NEW] Iron Guard Protocol & Sovereign Principles
이제 SYNAPSE는 단순한 시각화 명세서를 넘어선 '아키텍처 관제탑'으로 활약합니다.
SYNAPSE now acts as an 'architecture control tower' beyond a simple visual specification.

- **Real-time Edge Validation (실시간 엣지 검증)**:
  - `LogicAnalyzer.ts`를 경유하는 실시간 엣지 검증 엔진. (Real-time edge validation engine via `LogicAnalyzer.ts`.)
  - 구조적 위반 시 캔버스에 즉각적인 시각적 경고(💀)를 렌더링합니다. (Renders immediate visual warnings (💀) on the canvas upon structural violations.)
- **Sovereign Principles (원칙 강제화)**:
  - `GEMINI.md`의 `# Principles` 섹션을 엔진의 핵심 가이드로 인식합니다. (Recognizes the `# Principles` section in `GEMINI.md` as the core guide of the engine.)
  - 작업 원칙 위반 시 알림 시스템이 작동하며, 아키텍처 룰을 적극적으로 보호합니다. (Activates a notification system upon violation of principles, actively protecting architectural rules.)

## ✨ [NEW] Promotion Awareness System
설계의 진화를 살아 숨 쉬는 애니메이션으로 체감하십시오.
Experience the evolution of design through living animations.

- **Ghost to Active 전이 (고스트 승격 연출)**:
  - 가제안된(Ghost) 노드가 실제 파일(Active)로 전환될 때 생동감 있는 컬러 모핑을 제공합니다. (Provides vivid color morphing when a proposed (Ghost) node transitions to an actual file (Active).)
- **Particle Animation (파티클 애니메이션)**:
  - 승격되거나 활성화된 엣지를 따라 파티클 애니메이션이 흐르며 데이터 방향을 시각화합니다. (Particle animations flow along promoted or active edges to visualize data direction.)
- **Space Optimization (공간 최적화)**:
  - 기존 캔버스 영역 내에 있던 사이드 패널(History, Context Vault)들을 외부로 분리하여 캔버스 가독성을 극대화했습니다. (Maximized canvas readability by moving side panels out of the main canvas area.)

## 🎨 [NEW] Visual Impact & Logical Reporting
아키텍처의 결함이 시각적으로 '타격'을 주며, 상세한 진단 리포트를 제공합니다.
Architectural flaws now provide visual 'impact' and detailed diagnostic reports.

- **Visual Impact (시각적 타격)**:
  - **Node Necrosis (괴사)**: 에러가 있는 노드는 검은색 노이즈 괴사 효과로 표시됩니다. (Nodes with errors are displayed with a black noise necrosis effect.)
  - **Edge Fracture (골절)**: 논리 단절 엣지는 지그재그 골절 효과로 시각화됩니다. (Broken edges are visualized with a zigzag fracture effect.)
  - **System Red-out (레드아웃)**: 시스템 압박이 임계치를 넘으면 배경이 붉게 점멸합니다. (Background pulses red when system pressure exceeds thresholds.)
- **LOGIC_REPORT.md**:
  - 기존 리포트를 대체하는 정교한 아키텍처 진단 엔진 탑재. (A sophisticated logic reporting engine replacing the legacy report.)

## 🛠️ UX Hardening & Stability
- **Jitter Tracking (마우스 떨림 방지)**: 마우스 클릭 시 발생하는 미세 떨림(5px 이하 임계점)으로 인한 렌더링 폭주 버그를 원천 봉쇄했습니다. (Completely blocked rendering spikes caused by micro mouse jitters under 5px.)
- **Multi-select Fixes (다중 선택 버그 수정)**: 여러 노드 드래그(Select-box) 시 메모리 내 참조가 소실되어 그룹 이동이 막히던 치명적 로직 버그를 제거했습니다. (Fixed critical bugs where memory references were lost during multi-node dragging, causing frozen groups.)
- **Cluster Drag Priority (클러스터 드래그 제어)**: 클러스터 타이틀 박스 부분 클릭 시 다른 자식 노드보다 픽킹 우선순위를 높여 그룹 전체의 안정적인 이동을 보장합니다. (Prioritizes cluster title clicks over child nodes to ensure reliable group full movement.)
- **Interaction Wake-Up (스마트 프레임 제어)**: Idle (0 FPS) 상태에서 조작 발생 시 즉시 60 FPS로 복구되는 웨이크업 시스템을 적용하여 자원을 아낍니다. (Instant wake-up to 60 FPS upon interaction from 0 FPS Idle state to save OS resources.)
- **Safe Evaluation UX (로직 엣지 뱃지 강화)**: `?`, `!` 뱃지 및 연결 삭제(X) 히트박스의 크기를 눈에 띄게 대폭 키워 접근성을 향상시켰습니다. (Significantly enlarged hitboxes and visibility for evaluation badges and trash icons.)
