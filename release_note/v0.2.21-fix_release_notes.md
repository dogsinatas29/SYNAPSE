## 🇰🇷 한국어 릴리즈 노트

### 개요

v0.2.21-fix는 이전 릴리즈에서 발견된 WebGL 가속 렌더러의 구조적 결함과 디버그 메뉴 반응성 문제를 수정하고, GPU 렌더링 파이프라인을 올바르게 재설계한 핫픽스 릴리즈입니다.

---

### 🔧 버그 수정

#### 1. WebGL `render()` 시그니처 정직화 (`webgl-renderer.js`)
- **이전**: `render(nodes, edges, transform)` — `edges` 파라미터가 선언되어 있었지만 **단 한 번도 사용되지 않음**
- **수정**: `render(nodes, transform, isDataDirty)` — 실제로 사용하는 파라미터만 남김
- **이유**: Edge Shader, Edge Buffer, Edge Draw Call 모두 미구현 상태. 엣지 렌더링은 Canvas 2D에서 처리

#### 2. WebGL 활성 시 엣지가 완전히 사라지는 문제 (`canvas-engine.js`)
- **이전**: WebGL 활성 시 `render()`에서 `early-return` → Canvas 2D 렌더링 전체 건너뜀 → **엣지, 라벨, 선택 UI 모두 비표시**
- **수정**: WebGL 활성 시 `early-return` 제거. WebGL(stars+nodes)이 먼저 그린 후, Canvas 2D가 엣지·UI·배지를 오버레이로 렌더링하도록 수정

#### 3. Canvas 2D 배경이 WebGL 출력을 덮는 문제 (`canvas-engine.js`)
- **이전**: `fillRect('#1e1e1e')` 가 WebGL이 그린 stars와 node quads를 완전히 덮음
- **수정**: WebGL 활성 시 `fillRect` → `clearRect` 로 대체. WebGL 배경(별 + 노드)이 보존됨

#### 4. `btn-webgl` 가속 버튼 무응답 문제 (`canvas-engine.js`)
- **이전**: 이벤트 리스너가 `setupEventListeners()` 내부 (이벤트 발생 후 등록 가능성)에 위치
- **수정**: 리스너를 `setupToolbarListeners()` 로 이동. DOM 준비 즉시 등록되도록 수정

---

### ⚡ 성능 최적화

#### 5. Pan/Zoom 시 GPU 버퍼 재업로드 제거 (`webgl-renderer.js`)
- **이전**: 매 프레임마다 `gl.bufferData(... DYNAMIC_DRAW)` 호출 → 노드 개수 × 매 프레임 CPU→GPU 데이터 전송
- **수정**: `isDataDirty` 플래그 도입
  - **`isDataDirty = true`**: 노드 이동, 드래그, 데이터 로드 시에만 버퍼 갱신
  - **`isDataDirty = false`**: Pan/Zoom 시 `uniform` 행렬만 갱신, buffer 재업로드 없음
- **효과**: Pan/Zoom 시 GPU 전송 비용 제거 → 렌더링 병목 해소

#### 6. GL 상태 초기화 최적화 (`webgl-renderer.js`)
- **이전**: `gl.enable(BLEND)` + `gl.blendFunc(...)` 매 프레임 호출
- **수정**: 생성자에서 **1회만** 설정
  ```javascript
  gl.disable(gl.DEPTH_TEST);  // 2D 그래프 — depth test 불필요
  gl.enable(gl.BLEND);
  gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA);
  gl.clearColor(0, 0, 0, 0);  // 투명 배경
  ```

## 🇺🇸 English Release Notes

### Overview

v0.2.21-fix is a hotfix release that addresses structural defects in the WebGL acceleration renderer, fixes the unresponsive acceleration button, and correctly redesigns the GPU rendering pipeline to properly composite with Canvas 2D.

---

### 🔧 Bug Fixes

#### 1. Honest WebGL `render()` signature (`webgl-renderer.js`)
- **Before**: `render(nodes, edges, transform)` — `edges` parameter declared but **never used internally**
- **Fixed**: `render(nodes, transform, isDataDirty)` — only parameters that are actually used remain
- **Reason**: Edge Shader, Edge Buffer, and Edge Draw Calls were never implemented. Edge rendering belongs to Canvas 2D

#### 2. Edges disappearing entirely when WebGL is active (`canvas-engine.js`)
- **Before**: When WebGL was active, `render()` did `early-return` → entire Canvas 2D rendering skipped → **edges, labels, selection UI all invisible**
- **Fixed**: Removed early-return in WebGL branch. WebGL renders stars+nodes first, then Canvas 2D overlays edges, labels, and UI elements on top

#### 3. Canvas 2D background covering WebGL output (`canvas-engine.js`)
- **Before**: `fillRect('#1e1e1e')` fully covered WebGL-drawn stars and node quads
- **Fixed**: When WebGL is active, `fillRect` replaced with `clearRect`. WebGL background (stars + nodes) is now preserved

#### 4. `btn-webgl` acceleration button unresponsive (`canvas-engine.js`)
- **Before**: Event listener was registered inside `setupEventListeners()`, which could be too late
- **Fixed**: Moved listener registration to `setupToolbarListeners()`, guaranteed to run immediately when DOM is ready

---

### ⚡ Performance Optimizations

#### 5. Eliminated GPU buffer re-upload on Pan/Zoom (`webgl-renderer.js`)
- **Before**: `gl.bufferData(... DYNAMIC_DRAW)` called every frame → `nodes.length × frames` CPU→GPU transfers
- **Fixed**: Introduced `isDataDirty` flag
  - **`isDataDirty = true`**: Triggered on node drag, load, or data change → buffer is updated
  - **`isDataDirty = false`**: Pan/Zoom only updates the projection `uniform` matrix — zero buffer re-upload
- **Impact**: Eliminates GPU transfer cost during navigation → removes pan/zoom rendering bottleneck

#### 6. GL state initialization moved out of render loop (`webgl-renderer.js`)
- **Before**: `gl.enable(BLEND)` + `gl.blendFunc(...)` called every frame
- **Fixed**: Set once in constructor:
  ```javascript
  gl.disable(gl.DEPTH_TEST);  // 2D graph — depth testing unnecessary
  gl.enable(gl.BLEND);
  gl.blendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA);
  gl.clearColor(0, 0, 0, 0);  // transparent background
  ```
