# 🚀 SYNAPSE v0.2.21 Release Notes

**"Visibility is the first step to architectural control."**
**"시각화는 아키텍처 통제의 첫 걸음입니다."**

[Status: Deployment Ready - The Definitive v0.2.21 Edition]

---

## 📚 [NEW] Externalized Documentation Shelf
기존 캔버스 위에 오버레이되던 **Documentation Shelf**를 독립적인 드래그 가능 패널로 리팩토링했습니다.
- **Wider Canvas**: 시각화에 집중할 수 있도록 캔버스 공간을 대폭 확보했습니다.
- **Independent Control**: `View` 메뉴나 툴바를 통해 필요할 때만 열고 닫을 수 있습니다.
- **Search Support**: 패널 내 전용 검색바를 통해 수많은 파일 중 원하는 문서를 즉시 찾을 수 있습니다.

## 🔍 [NEW] FZF-style Fuzzy Search
모든 검색 인터페이스에 강력한 퍼지 매칭 알고리즘을 도입했습니다.
- **Efficient Discovery**: 글자 순서만 맞으면 검색 결과에 반영됩니다 (예: `dct` 입력 시 `Documentation` 검색).
- **Global Application**: **Context Vault**와 **Documentation Shelf** 모두에 적용되어 탐색 속도가 비약적으로 향상되었습니다.

## 🖱️ [NEW] Refined Selection Interface
- **Navigation vs. Editing Separation**: 단일 클릭은 '탐색 및 선택', 더블 클릭은 '파일 열기'로 역할을 명확히 구분하여 조작의 안정성을 높혔습니다.
- **Edge Hitbox Expansion**: 곡선 형태의 엣지 선택 임계값을 최적화하여 고배율 줌에서도 안정적인 클릭이 가능합니다.
- **Group Selection**: 클러스터 헤더 클릭 시 해당 그룹의 모든 노드를 일괄 선택 및 이동할 수 있습니다.

---

## ⚡ WebGL-based GPU Acceleration
대규모 프로젝트에서도 끊김 없는 60 FPS 부드러움을 경험하십시오.
- **High-Performance Rendering**: 10,000개 이상의 노드와 20,000개 이상의 엣지를 성능 저하 없이 실시간으로 핸들링합니다.
- **Interactive Fluidity**: 복잡한 아키텍처 맵 내에서도 지연 없는 줌(Zoom)과 팬(Pan) 기능을 제공합니다.

## 🛡️ Virtual Debug Engine Enhancement
LSP와 연동하여 코드의 '물리적 결함'을 시각적으로 진단합니다.
- **Static Analysis Visualization**: 에러와 경고를 캔버스에 즉시 투영하며, **Node Necrosis** 및 **Edge Fracture** 효과를 통해 직관적으로 결함을 인지합니다.
- **Architecture Health Score**: 구조적 엔트로피를 결합하여 아키텍처의 상태를 정량화합니다.

---

## 🖼️ Image Compatibility & UX Optimization
- **SVG to PNG Conversion**: VS Code 마켓플레이스 제한 사항을 준수하기 위해 모든 아이콘을 고해상도 PNG로 업데이트했습니다.
- **Latest v0.2.21 Screenshots**: 새로워진 GUI와 렌더링 품질을 반영한 최신 스크린샷으로 README를 갱신했습니다.
