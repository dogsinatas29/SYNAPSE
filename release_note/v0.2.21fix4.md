## 🛠️ [Major Fix] Context Vault Storage Logic Refinement
## 🛠️ [중요 수정] 컨텍스트 볼트 저장 로직 정교화 및 버그 픽스

This version (v0.2.21fix4) focuses on a complete overhaul of the Context Vault's data collection logic to ensure 100% reliable audit logs.
이번 버전(v0.2.21fix4)은 컨텍스트 볼트의 데이터 수집 로직을 전면 개편하여 100% 신뢰할 수 있는 감사 로그를 보장하는 데 집중했습니다.

- **[Fix] Zero Contamination (Contamination = 0)**:
  - Removed all unreliable fallbacks such as clipboard reading, terminal content, and editor selections. 
  - **수정: 오염도 Zero**: 클립보드 읽기, 터미널 내용, 에디터 선택 영역 등 불확실한 폴백 로직을 완전히 제거했습니다.
  - No more accidental logging of external copied text. Only pure LLM events are recorded.
  - 외부에서 복사된 텍스트가 섞이는 현상을 차단하고 오직 순수 LLM 이벤트만 기록합니다.

- **[Fix] Robust Chat Extraction**:
  - Fixed an issue where chat history couldn't be correctly located in specific environments (e.g., Extension Development Host).
  - **수정: 견고한 채팅 추출**: 테스트 환경(Development Host) 등 특정 환경에서 채팅 기록 경로를 찾지 못하던 문제를 해결했습니다.
  - Now extracts the **full conversation sequence** across all VS Code forks.
  - 모든 VS Code 포크 버전에서 **전체 대화 흐름**을 정확하게 추출합니다.

- **[Logic] Always-on Real-time Audit Log**:
  - Replaced manual "REC" toggle with an event-driven "Always-on" streaming system.
  - **로직: 실시간 상시 감사 로그**: 수동 레코딩 토글 대신, 이벤트 기반의 '상시 대기' 스트리밍 시스템으로 전환했습니다.
  - Events are appended to the `.synapse_contexts/session_YYYY-MM-DD_HH-mm.md` file as they happen.
  - 대화와 작업이 발생하는 즉시 해당 세션 파일에 실시간으로 추가(Append)됩니다.

- **[Logic] File-Only Action Tracking**:
  - Refined to log only the filenames of file operations (read/modify/create), excluding any code content to keep logs concise.
  - **로직: 파일 중심 액션 추적**: 파일 작업(읽기/수정/생성) 시 코드 내용 없이 **파일명**만 기록하여 로그의 가독성과 보안을 높였습니다.
