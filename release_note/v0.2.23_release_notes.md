# Release Notes - v0.2.23

## 🧠 렌더링 파이프라인 최적화 / Rendering Pipeline Optimization (v0.2.23)

### [Highlights]
- **Layer-based Dirty System**: Implemented a caching mechanism that only re-renders modified layers.
- **FBO (Framebuffer Object) Integration**: Each renderable layer (Stars, Nodes) now has its own off-screen buffer.
- **Improved GPU Efficiency**: Reduced draw calls and state switches during transform changes (pan/zoom).
- **Smooth Compositing**: Layer textures are merged using a high-performance full-screen quad shader.
- **Node Selection Hitbox Fix**: Resolved a coordinate mismatch where click detection was offset by half-node width. Selection is now pixel-perfect.
- **Snapshot Noise Reduction**: Increased drag threshold from 10px to 30px to filter out micro-jitters and reduce redundant auto-backups.

### [Changes]
- **ui/webgl-renderer.js**:
  - Refactored `WebGLRenderer` to support independent layers.
  - Added FBO/Texture management and resizing logic.
  - Introduced `composite` shader and buffer for final screen pass.
  - Implemented smart dirty tracking based on transform and data updates.
- **ui/index.html**:
  - Updated WebGL toggle logic and status display.
- **package.json**:
  - Updated version to `0.2.23`.

### [Details] (Korean / English)
#### 1. 레이어 기반 더티 시스템 (Layer-based Dirty System)
- `background`: 별밭 배경은 캐시되며 트랜스폼(pan/zoom) 변화 시에만 갱신됩니다.
- `middle`: 노드 레이어는 캐시되며 노드의 위치/색상 업데이트 혹은 트랜스폼 변화 시에만 갱신됩니다.
- 향후 계획: 호버/선택 UI를 위한 `overlay` 레이어를 추가하여 베이스 레이어 갱신을 더욱 최소화할 예정입니다.

#### 2. FBO 캐싱 (FBO Caching)
- 뷰 이동 시 인스턴스 렌더링 등 복잡한 Draw call을 제거하여 불필요한 연산을 방지합니다.
- 렌더링 프레임의 결정론적 품질(Deterministic quality)을 높이고 CPU/GPU 부하를 낮췄습니다.
