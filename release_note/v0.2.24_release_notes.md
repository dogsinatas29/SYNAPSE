# Release Notes - v0.2.24

## [v0.2.24] - 2026-03-21

### 🛡️ Highlights: Robust Loop Protection & Debugging Visibility
이번 릴리즈는 시냅스 엔진의 렌더링 안정성을 획기적으로 개선합니다. 예기치 못한 예외 상황(Exception) 발생 시에도 루프가 생존하도록 설계되었으며, 렌더링 각 단계별 로그(Segmented Logging)를 통해 크래시 포인트(Crash Point)를 즉각 식별할 수 있습니다.

### 🛡️ Loop Guard & Robustness
- **`startLoop` 도입**: `try-catch` 가드를 사용하여 렌더링 루프의 영속성 확보.
- **Fail-safe Logic**: 특정 프레임에서 에러가 발생하더라도 다음 프레임이 정상적으로 실행되어 디버깅 로그 수집 극대화.

### 🔬 Segmented Rendering Logs
- 렌더링 각 모듈 통과 시 로그 출력:
  - `frame start` (WebGL 이전)
  - `after webgl` (Canvas 2D 시작 전)
  - `after edges` (Edges 출력 후)
  - `after labels` (Labels 출력 후)
- 결과에 따른 즉각적인 원인 분석(Case 1: Overlay 문제 / Case 2: WebGL 내부 문제) 지원.

### 🛠 Fixes & Improvements
- **Direct Rendering Optimization**: (v0.2.24-base) FBO 레이어 캐싱 제거로 즉각적인 화면 갱신 및 지연 제거.
- **Debug Overlay Override**: `this.debugDisableOverlay` 플래그를 통한 2D 오버레이 강제 Skip 기능 추가.
- **Unified State Management**: 애니메이션 오프셋 및 파티클 업데이트 주기를 `render()` 메서드로 통합 관리.
