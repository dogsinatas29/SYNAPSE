# Release Note - v0.2.24 (Interaction Fixed)

## 🚀 주요 개선 사항

### 1. WebGL 인터랙션 완벽 동기화 (CRITICAL FIX)
- **줌/팬 좌표 불일치 해결**: 고해상도(DPI) 모니터 대응을 위해 WebGL 투영 행렬에 `window.devicePixelRatio`를 통합했습니다. 이제 CSS 좌표와 GPU 렌더링 위치가 1:1로 일치합니다.
- **성능 스파이크(Stutter) 제거**: `Pre-baked Layout` 방식을 도입하여 매 프레임 발생하던 문자열 연산을 제거하고, 60fps를 안정적으로 유지합니다.

### 2. 안정성 및 최적화
- **안전한 위치 체크**: 노드 데이터 로드 시 `position` 객체가 없는 예외 상황에서도 엔진이 멈추지 않도록 Crash Guard를 추가했습니다.
- **레이어 가시성 연동**: `Accel: ON` 상태에서도 'Base Logic'과 'User Logic' 필터링이 즉시 적용됩니다.
- **IDLE 투명성 보장**: 조작이 없을 때도 2D 레이어가 WebGL을 가리지 않도록 배경 처리 순서를 최적화했습니다.
