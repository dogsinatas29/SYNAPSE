# 🚀 SYNAPSE Release Notes - v0.2.25
## Semantic Visual Alignment & 3D Acceleration Refinement

**Main Change: Final Architectural Visual Synchronization**
[KOR] 이번 버전은 노드와 엣지의 시각적 컨벤션을 SYNAPSE 설계 규격에 맞춰 완전히 동기화했습니다. 특히 WebGL 고속 모드에서도 노드 상태와 발광(Glow) 효과를 명확하게 확인할 수 있도록 개선되었습니다.
[ENG] This release fully synchronizes node and edge visual conventions with SYNAPSE architectural specifications. Specifically, WebGL 3D acceleration now correctly renders node statuses and emissive glow effects.

---

### 1. 🇰🇷 시각적 엔티티 타입 동기화 (Entity Selection)
- **[KOR]**: 컴포넌트 아이콘을 🧩(Component)로 변경하고, 노드 상태(Active, Ghost, Deleted, Warning, Necrosis, Tombstone)에 따른 전용 테두리 색상과 스타일을 적용했습니다. 
- **[ENG]**: Changed the logic component icon to 🧩 and applied dedicated border colors and styles for various node statuses (Active, Ghost, Deleted, Warning, Necrosis, Tombstone).

### 2. 🇰🇷 엣지 & 라인 컨벤션 적용 (Edge Conventions)
- **[KOR]**: 의존성(#ebdbb2), 데이터 흐름(#83a598 3px), 이벤트(#fe8019), 조건부(#d3869b) 등 명시된 색상과 스타일(실선/점선/두께)을 2D 및 WebGL 엔진 전체에 적용했습니다.
- **[ENG]**: Applied documented colors and styles (solid/dashed/thickness) for Dependency (#ebdbb2), Data Flow (#83a598 3px), Event (#fe8019), and Conditional (#d3869b) across 2D and WebGL engines.

### 3. 🇰🇷 3D 가속 모드 발광 효과 (WebGL Emergence)
- **[KOR]**: WebGL 모드에서 상태/Glow가 보이지 않던 문제를 해결하고, 고밀도(High DTR) 노드에는 보라색(#8a2be2) 에미시브 블룸 효과를 추가했습니다.
- **[ENG]**: Fixed missing status/glow effects in WebGL mode and added a purple (#8a2be2) emissive bloom for High DTR (density) nodes.

### 4. 🇰🇷 노드 히트 영역 결함 수정 (Hit Box Precision)
- **[KOR]**: 노드의 선택 영역 여백(HIT_PADDING)을 0px로 조정하여, 시각적으로 보이는 박스 이외의 공간에서 엣지 선택을 방해하던 간섭을 완전히 제거했습니다.
- **[ENG]**: Adjusted the node hit padding (HIT_PADDING) to 0px, ensuring selection is strictly limited to the visual bounding box and preventing interference with edge selection.

### 5. 🇰🇷 운영 안정화 및 빌드 (Packaging)
- **[KOR]**: 대용량 파일 저장 시 발생할 수 있는 데이터 손상(Corruption) 가능성을 차단하기 위해 렌더링 엔진 로직의 정합성을 수동 검수한 후 최종 배포본을 빌드했습니다.
- **[ENG]**: Verified logic consistency in the rendering engine to prevent data corruption during large saves and finalized the production build.
