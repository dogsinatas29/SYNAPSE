# v0.2.25 릴리즈 노트 (Release Notes) - Interaction Stability & Fidelity

## 🚀 하이라이트 (Highlights)
- **UI 조작 안정성 대폭 개선 (Extreme Interaction Fidelity)**
- **화면 깜박임 및 노드 소실 문제 해결 (Zero-Flicker Rendering)**
- **정밀한 노드 선택 및 드래그 (Pixel-Perfect Selection)**

## 🛠️ 주요 변경 사항 (Major Changes)

### 1. 🇰🇷 인터랙션 트리거 우선순위 교정 (Core Interaction Fix)
- **[KOR]**: 노드 위에 엣지 확정(?/!) 배지가 겹친 상황에서 노드를 잡을 때 엣지 메뉴가 뜨던 현상을 해결했습니다. 이제 노드 클릭이 최우선되며, 배지는 빈 공간 클릭일 때만 작동합니다.
- **[ENG]**: Fixed an issue where clicking a node with an overlapping edge badge triggered the edge menu instead of dragging. Node selection now takes priority over edge badges.

### 2. 🇰🇷 제로-플리커 렌더링 (Zero-Flicker Optimization)
- **[KOR]**: WebGL 렌더링 시 버퍼를 중복으로 비우던 로직을 제거하여 줌/팬 또는 조작 시 발생하는 화면 깜박임을 90% 이상 줄였습니다.
- **[ENG]**: Reduced WebGL screen flickering by over 90% by eliminating redundant clear calls and deferring the screen clear until just before drawing.

### 3. 🇰🇷 노드 사라짐 현상 근절 (Persistence Guard)
- **[KOR]**: 유휴(IDLE) 상태로 진입할 때 WebGL 가속 노드들이 사라지던 버그를 수정했습니다. 가속 모드에서는 항상 노드가 가시성을 유지하도록 렌더링 루프를 보완했습니다.
- **[ENG]**: Resolved a bug where WebGL nodes disappeared during idle periods. The rendering loop now ensures constant visibility for all nodes while acceleration is active.

### 4. 🇰🇷 정밀한 히트 테스트 (Precision Selection)
- **[KOR]**: 노드 선택 영역 겹침 현상을 막기 위해 탐색 순서를 역순으로 변경하여 시각적으로 위에 있는 노드가 먼저 선택되게 하고, 클릭 패딩을 12px로 정밀화했습니다.
- **[ENG]**: Improved selection accuracy by reversing the hit-test search order (favoring top-most nodes) and refining the click padding to 12px to prevent overlapping selection issues.

### 5. 🇰🇷 조작 규칙 완화 (Fluid Interaction)
- **[KOR]**: 'Edit Logic' 모드가 활성화되지 않은 상태에서도 마우스 왼쪽 버튼으로 노드를 즉시 잡고 이동할 수 있도록 조작 제약을 완화했습니다.
- **[ENG]**: Eased interaction constraints, allowing nodes to be dragged with the left mouse button even when 'Edit Logic' mode is not explicitly active.
