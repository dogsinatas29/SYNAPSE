# 🚀 SYNAPSE Release Notes - v0.2.26
## Rendering Context Isolation Guard & WebGL Accel Restoration

**Main Change: Total Separation of Render Layers**
[KOR] 이번 버전은 뷰(Graph, File, Flow) 전환 시 발생하는 WebGL의 잔상과 가속 모드의 치명적인 조작 결함을 해결하는 데 집중했습니다. 렌더링 파이프라인의 격리를 통해 시각적 간섭을 완전히 제거했습니다.
[ENG] This release focuses on resolving WebGL persistence issues (ghosting) during view mode transitions and critical control bugs in acceleration mode. Rendering pipeline isolation ensures zero visual interference.

---

### 1. 🇰🇷 렌더링 격리 가드 도입 (Isolation Guard)
- **[KOR]**: 그래프 부에서 다른 뷰(File/Tree)로 전환 시 WebGL 상태를 강제 초기화(`forceResetGLState`)하여 배경에 그래프 레이어가 남는 현상을 해결했습니다.
- **[ENG]**: Implemented `forceResetGLState` to ensure WebGL contexts are explicitly cleared when switching from Graph to other views (File/Tree), eliminating background ghosting.

### 2. 🇰🇷 가속 모드 조작 정상화 (Control Restoration)
- **[KOR]**: WebGL 렌더러의 인자 불일치(NaN) 문제를 수정하여, 가속 모드에서도 노드 선택, 드래그 이동, 화면 줌 기능이 2D 모드와 동일하게 작동하도록 복구했습니다.
- **[ENG]**: Fixed WebGL argument mismatch issues, restoring node selection, dragging, and zooming functionality in acceleration mode to mirror 2D performance.

### 3. 🇰🇷 2D 모드 노드 가시성 복원 (Visibility Fix)
- **[KOR]**: 2D 모드에서 특정 상태의 노드가 배경에 묻혀 흐릿하게 보이던 문제를 해결하기 위해 `Active` 노드의 불투명도를 1.0으로 고정했습니다.
- **[ENG]**: Addressed an issue in 2D mode where certain nodes appeared faint; `Active` nodes now have a fixed opacity of 1.0 for maximum visibility.

### 4. 🇰🇷 WebGL 시각 효과 강화 (Enhanced Visuals)
- **[KOR]**: WebGL 엔진의 엣지 셰이더를 개선하여 SYNAPSE 컨벤션 색상을 적용하고, 화살표와 선의 식별성을 높였습니다. 
- **[ENG]**: Upgraded the WebGL edge shaders to include SYNAPSE convention colors, improving the visibility and identification of paths and arrows.

### 5. 🇰🇷 하드 리셋 프로토콜 준수 (GPU Hygiene)
- **[KOR]**: 매 렌더링 사이클이 끝날 때마다 GPU 자원을 명시적으로 해제하여 Context 오염을 방지하고 메모리 효율을 극대화했습니다.
- **[ENG]**: Added explicit GPU resource unbinding at the end of every render cycle to prevent context contamination and improve overall memory efficiency.
