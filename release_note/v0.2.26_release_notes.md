# 🚀 SYNAPSE Release Notes - v0.2.26

## 📅 Release Date: 2026-03-22
## 🏷️ Version: v0.2.26 (Final Stabilization & Logic Fixes)

### 🛠️ 주요 수정 및 개선 사항 (Key Fixes & Improvements)

#### 1. 3D 가속 레이어 안정화 (WebGL Engine Fixes)
- **Shader Compilation Repair**: `vIsSelected` 변수 선언 누락으로 인한 WebGL 쉐이더 컴파일 오류를 해결하여 3D 가속 기능을 정상화했습니다.
- **Node Aesthetics (Sub-Glow)**: WebGL 노드에 **Sub-Glow(내부 광원 효과)** 및 그루브박스(Gruvbox) 테마 기반의 정밀한 테두리를 적용하여 2D 모드와 시각적 감성을 일치시켰습니다.
- **Coordinate System Unification**: 2D 캔버스와 3D WebGL 레이어의 좌표 변환 공식을 단일화하여 줌 인/아웃 시 레이어 간의 어긋남을 제거했습니다.

#### 2. 사용자 경험 및 인터랙션 (UX & Interaction)
- **Auto-Load Last Snapshot**: 이제 캔버스 최초 로딩 시 `project_state.json` 대신 **마지막으로 저장된 스냅샷(History)**을 우선적으로 검색하여 가장 최근의 작업 상태를 자동으로 복원합니다.
- **Edge Double-Click Support**: 엣지를 더블 클릭하면 즉시 **로직 확정(Confirm)** 메뉴가 트리거되도록 수정하여 작업 효율을 극대화했습니다.
- **View Persistence**: `project_state.json`에 현재 화면의 **줌(Zoom)**과 **위치(Offset)** 정보를 포함하여 저장하므로, 재시작 시에도 보고 있던 화면 그대로 열립니다.

#### 3. 성능 및 안정성 (Performance & Stability)
- **Flickering Elimination**: 애니메이션 루프(`startLoop`)의 렌더링 조건을 최적화하여 화면 깜박임 현상을 해결했습니다. 이제 실제 변화가 있을 때만 프레임을 그리도록 개선되었습니다.
- **Auto-Sleep Optimization**: WebGL 모드에서도 장시간 미사용 시 불필요한 GPU 점유를 방지하는 절전(Eco-mode) 로직을 강화했습니다.

#### 4. 상태 결정성 강제 (Forced Determinism - Critical)
- **Deterministic State Factory**: `loadProjectState` 진입 시 입력 데이터를 ID순으로 정렬하고 Deep Clone하여 참조를 완전 분리했습니다.
- **Pure Layout Algorithm**: `resolveOverlaps`가 현재 수정 중인 좌표가 아닌, 계산 시작 시점의 Snapshot 좌표만 참조하도록 수정하여 순회 순서에 따른 결과 차이를 근본적으로 차단했습니다.
- **Precision Fingerprinting**: 노드 좌표를 소수점 2자리까지 추적하는 Hash Logging 시스템을 도입하여 2D/3D 레이어 간의 상태 불일치를 수치적으로 증명하고 해결했습니다.
