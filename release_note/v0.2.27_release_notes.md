# v0.2.27 Release Notes: Rendering Parity & State Synchronization

## 🚀 Overview
Fixed visual discrepancies between Standard (2D) and Accelerated (3D) rendering modes. Unified color logic and visibility states to ensure consistent user experience across different performance modes.

## 🛠️ Key Changes
### 1. Rendering Logic Unification
- **Standard (2D) Mode**: Updated `getNodeStyle` to prioritize `node.data.color`. This fixes "missing" nodes that were previously drawn with extremely dark background colors on a dark canvas.
- **Accelerated (3D) Mode**: Updated WebGL color mapping to match standard `bgColor` rules instead of hardcoding status colors.

### 2. State Synchronization
- **Cluster Collapsed Filter**: WebGL now correctly respects the `collapsed` state of clusters, hiding nodes inside them just like standard mode.
- **Opacity Support**: WebGL now respects `node.visual.opacity`, ensuring that ghost nodes or dimmed elements look identical in both modes.

### 3. Visibility Improvements
- Synchronized layer filtering (Base/User) between both rendering paths.
- Improved contrast for `proposed` status nodes by allowing explicit data-driven colors to shine through.

## ✅ Verification Results
- [x] Nodes in collapsed clusters are hidden in both modes.
- [x] Node colors match exactly between Canvas and WebGL.
- [x] Ghost nodes and disabled layers are consistently dimmed in 3D mode.
- [x] Toggling acceleration no longer causes major visual shifts in node density.
