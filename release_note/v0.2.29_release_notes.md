# 🚀 Release Notes - v0.2.29

## 📅 날짜: 2026-03-29

## 🛠️ 주요 변경 사항
- **Antigravity 대화 로그 엔진 탑재 (Critical Fix)**:
    - VS Code 표준 로그(`jsonl`) 외에 Antigravity IDE 전용 Protobuf(`pb`) 형식의 대화 로그를 실시간 탐지 및 파싱하는 로직 추가.
    - `~/.gemini/antigravity/conversations/` 디렉터리 자동 감시 및 동기화.
- **[Emergency Surgery] LOB Sniffer (Binary Scan Filter) 가동**:
    - **단순 UTF-8 변환 실패 해결**: 기존의 단순 문자열 변환 방식에서 벗어나, 데이터 블록에서 [0x20-0x7E](출력 가능한 ASCII) 및 한글 유니코드 범위가 연속되는 구간만 추출하는 **'바이너리 스캔 필터'** 도입.
    - **중첩 압축 해제 (Decompression)**: 파일 내부에 숨겨진 `zlib/gzip` 압축 블록을 브루트포스 방식으로 찾아내어 해제 후 파싱하는 로직 탑재.
- **세션 안정화 (Session Guard)**:
    - 동일 세션 내에서 불필요한 중복 로그 파일 생성을 방지하고 기존 세션 파일 재사용성 강화.
- **SQLite 기반 맥락 복구 도구 강화**:
    - `state.vscdb`의 `trajectorySummaries` 분석 로직에 동일한 바이너리 스캔 필터를 적용하여 복구율 극대화.

## ✅ 수정된 사항
- 대화 기록이 `.synapse_contexts/`에 저장되나 외계어로 나오던 현상(Encoding Mismatch) 해결.
- Antigravity IDE의 비표준 대화 API 및 바이너리 로그 포맷 대응 완료.
- `.pb` 파일 파싱 시 발생하는 예외 처리 강화.
