# 🚀 Release Notes - v0.2.31

## 📅 Release Date: 2026-03-29

## 🛡️ 핵심 변경 사항
본 버전은 대화 로그 추출 시의 데이터 정밀도를 높이고, 여러 소스로부터 대화를 누락 없이 수집하는 데 집중했습니다.

### 1. [정제] 'LOB Sniffer' 텍스트 추출 로직 고도화
- **바이너리 노이즈 제거:** 기존의 단순 바이트 스캔 방식에서 정규식(Regex) 기반의 텍스트 추출 방식으로 전환했습니다.
- **깨진 글자 차단:** UTF-8 디코딩 실패 시 발생하는 대치 문자(``)와 무의미한 바이너리 찌꺼기를 세션 로그에서 배제합니다.
- **다국어 지원:** 한글(가-힣, 자모음) 및 영문 대화만 정교하게 추출하도록 필터를 강화했습니다.

### 2. [아키텍처] MultiAdapter 기반 다중 소스 수집
- **병렬 수집:** 안티그래비티의 `.pb` 로그와 실시간 에이전트 스트림을 동시에 캡처합니다.
- **SeenHashes 필터:** 다중 어댑터 사용 시 발생할 수 있는 메시지 중첩을 해시 기반으로 자동 필터링합니다.

### 3. [안정성] 세션 관리 강화
- **Session Guard:** 이미 생성된 세션 파일의 정합성을 체크하고 중복 생성을 방지합니다.
- **포렌식 복구:** SQLite(`state.vscdb`)의 과거 궤적 요약본을 더 깨끗한 형태로 복구하여 `.synapse_contexts/`에 기록합니다.
