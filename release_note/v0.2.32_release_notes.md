# v0.2.32 Release Notes — Dialogue Persistence Overhaul (v2nd Generation)

## 🚀 Overview
Antigravity 기반의 VS Code 환경에서 대화가 누락되거나 메타데이터만 남는 현상을 해결하기 위해, **현존하는 모든 수집 채널을 최적화하고 이중화(Redundancy)**했습니다.

## 🛠️ Key Improvements

### 1. 🔍 PbSessionWatcher: Heuristic Sniffing 도입
- 바이너리(`.pb`) 파일의 델타가 감지되면, 해당 시점을 즉시 추적하여 인가된 **평문 문자열(ASCII/한글 파편)을 추출** 및 기록합니다.
- 단순 화자 추정(Turning)뿐만 아니라, 실제 텍스트 스니핑 결과를 Audit Log에 병합하여 즉각적인 가독성을 확보했습니다.

### 2. 📋 ClipboardScraperAdapter: Stealth Scraping 범위 확장
- **Speaker Detection Expansion**: `User`, `Assistant`, `Gemini`, `Bard`, `You` 등 다양한 화자 식별자를 지원하도록 개선되었습니다.
- **Fail-safe Logic**: 정규식 매칭에 실패하더라도 수집된 텍스트가 유효할 경우 `[Unparsed Response]` 섹션에 담아 정보를 보호합니다.
- **Diagnostic Dump**: `.synapse_contexts/last_scrape_raw.txt`를 생성하여 실시간 수집 원본을 검증 가능하게 되었습니다.

### 3. Guardrail & Stability
- **Infection Filter**: `isLikelyHumanReadable` 메커니즘을 통해 바이너리 쓰레기 데이터 유입을 3% 이하로 억제했습니다.
- **CPU Protection**: 파일 감시 주기를 500ms 디바운스로 안정화하여 시스템 성능 저하를 방지했습니다.
