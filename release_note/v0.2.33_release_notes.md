# v0.2.33 Release Notes — Content Persistence Restoration

## 🚀 Overview
대화 내역이 메타데이터(크기, 턴)만 기록되고 실제 텍스트 내용이 누락되는 현상을 해결하기 위해 **Scraper와 Sniffer의 정합성을 대폭 강화**했습니다.

## 🛠️ Key Improvements

### 1. 🔍 PbSessionWatcher: Direct Buffer Sniffing
- `buffer.toString('utf-8')` 방식에서 발생하던 바이너리 데이터 간섭 문제를 해결하기 위해 **Direct Buffer Scanning** 방식을 도입했습니다.
- 인가된 ASCII 및 한글 시퀀스를 원본 바이너리에서 직접 추출하여, 암호화되지 않은 텍스트 조각을 더 정확하게 포착합니다.

### 2. 📋 ClipboardScraperAdapter: Robustness & Expansion
- **Speaker Expansion**: `Antigravity`, `Secretary` 등의 내부 화자 레이블을 추가 지원합니다.
- **Improved Parsing**: 정규식 매칭 실패 시에도 유효한 텍스트가 있다면 `[Unparsed Response]` 섹션에 보존하는 로직을 강화했습니다.
- **Fail-safe Sync**: 대용량 응답(100KB+) 시 UI 렌더링 지연을 고려하여 스크레이핑 트리거 지연 시간을 **1.5초**로 확장했습니다.

### 3. ⌨️ Manual Control
- **`synapse.forceScrape` 명령어 추가**: 자동 수집이 실패하거나 즉각적인 캡처가 필요한 경우 사용자가 직접 클립보드 스크레이핑을 트리거할 수 있습니다.
