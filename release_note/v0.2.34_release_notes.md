# 🚀 Release Notes - v0.2.34 (Dialogue Integrity Fix)

## 📅 날짜: 2026-03-29

## 🎯 핵심 변경 사항 (Key Changes)

### 1. 바이너리 노이즈 완전 제거 (No More PB Sniping)
- `.pb` 파일에서 깨진 텍스트를 억지로 추출하던 `extractReadableStrings` 로직을 폐기했습니다.
- 대화 로그에 `[pb:...]` 형태로 남던 이진 데이터를 제거하여 로그의 가독성을 대폭 향상시켰습니다.

### 2. UI 기반 지능형 스크레이퍼(Scraper) 도입
- IDE의 채팅창에 렌더링된 "정상 텍스트"를 직접 복사하는 스텔스 스크레이핑 방식을 확립했습니다.
- **`workbench.panel.chat.view.focus`** 명령을 선제적으로 수행하여 복사 명령이 항상 채팅 패널을 향하도록 고도화했습니다.
- 다양한 VS Code 테마 및 레이블 형식(예: `[User]`, `User:`, `User -` 등)을 모두 수용하는 **유연한 화자 레이블 정규식**을 도입했습니다.
- `workbench.action.chat.copyAll` 명령어 수행 시 발생할 수 있는 포커스 문제와 지연을 해결하기 위해 **재시도(Retry) 및 적응형 대기(Adaptive Delay) 메커니즘**을 강화했습니다.

### 3. 정적 턴 구분 폐기 및 화자 식별(Attribution) 강화
- 기존의 홀수/짝수(`modCount % 2`) 기반 기계적 역할을 삭제했습니다.
- 텍스트 내의 화자 레이블(`User:`, `Assistant:`, `Antigravity:`, `Gemini:`, `Secretary:` 등)을 정규식으로 직접 파싱하여 누가 한 말인지 정확하게 분류합니다.
- 중복 방지를 위한 **메시지별 해시(Hash) 시스템**을 구축하여 동일한 메시지가 반복 기록되지 않도록 했습니다.

### 4. Linux 환경 트리거 안정화 (Hotfix.2)
- 리눅스의 `fs.watch`가 디렉토리 내 파일 변경을 감시하지 못하는 결함을 해결하기 위해 **3초 간격의 하이브리드 폴링(Polling)**을 도입했습니다.
- 파일 크기뿐만 아니라 **수정 시간(mtime)**을 정밀 체크하여, 내용이 바뀌었으나 크기가 동일한 경우에도 트리거가 누적되도록 개선했습니다.
- [v0.2.34-hotfix] 적용으로 리눅스 환경에서의 대화 누락 문제를 원천 차단했습니다.
 
 ### 5. 구글 제미나이(Google Gemini) 명령어 대응 및 리눅스 클립보드 안정화 (Hotfix.3)
 - 구글 제미나이 공식 확장 프로그램의 명령어(`google.gemini.chat.focus`, `google.gemini.chat.copyAll` 등)를 포커스 및 복사 리스트에 추가했습니다.
 - 리눅스 환경에서 포커스 전환 및 클립보드 동기화 지연 문제를 해결하기 위해 **전략적 대기 시간(Adaptive Delay)**과 **재시도 횟수(5회)**를 상향 조정했습니다.
 - 포커스가 상실되더라도 블라인드 복사(Blind Copy)를 시도하는 폴백 로직을 구현하여 데이터 수집 무결성을 높였습니다.

### 6. 명령어 전수 조사(Diagnostic Probe) 도입
- 실제 설치된 VS Code 명령어 중 AI 관련 명령어를 모두 찾아 로그에 기록하는 **Diagnostic Probe** 로직을 심었습니다.
- 이를 통해 사용자 환경마다 다른 '진짜' 포커스/복사 명령어 ID를 100% 정밀 타격하여 식별할 수 있습니다.
- 로그 확인 후, 발견된 정확한 ID를 다음 패치에 즉시 반영할 예정입니다.

## 🛠️ 기술적 세부 사항
- **`PbSessionWatcher`**: 이제 내용 파싱을 하지 않고 오직 "대화 데이터 변경" 신호만 발생시키는 순수 트리거 역할만 수행합니다. (3s Polling & mtime check 적용)
- **`ClipboardScraperAdapter`**: 복사된 텍스트를 화자 단위로 블록화하고, 정규화(Normalization)를 거쳐 `PromptLogger`로 전달합니다.
- **`extension.ts`**: 세션 파일 변경 감지 시 즉시 스크레이퍼를 구동하는 하이브리드 파이프라인으로 통합되었습니다.
