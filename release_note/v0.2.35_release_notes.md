# 🚀 Release Notes - v0.2.35 (Precision Strike Update)

## 📅 날짜: 2026-03-29

## 🎯 핵심 변경 사항 (Key Changes)

### 1. 진성(Real) 포커스 명령어 탐지 및 적용
- `v0.2.34-debug` 버전에서 도입된 명령어 전수 조사(Diagnostic Probe)를 통해, Antigravity 확장이 실제로 사용하는 '진짜' 포커스 명령어를 식별했습니다.
- **`antigravity.toggleChatFocus`** 및 **`workbench.panel.chat.view.copilot.focus`** 등, 추측이 아닌 실측 데이터를 기반으로 한 **정밀 타격(Precision Strike)** 리스트를 구축했습니다.
- 이를 통해 리눅스 환경에서 사이드바만 단순히 열리는 문제를 해결하고, 실제 채팅 패널에 포커스를 정확하게 위치시킬 수 있게 되었습니다.

### 2. 포커스 폴백(Fallback) 강화
- 총 7단계의 계층형 포커스 시도 메커니즘을 적용했습니다:
    1. `antigravity.toggleChatFocus` (최우선)
    2. `workbench.panel.chat.view.copilot.focus`
    3. `workbench.action.chat.focus`
    4. `workbench.view.extension.google-gemini` (강제 활성화)
    5. `inlineChat.focus`
    6. `workbench.action.focusChat`
    7. `workbench.action.focusSideBar` (마지막 수단)

### 3. 클립보드 스크레이핑 100% 성공률 목표
- 정확한 포커스 타격으로 인해 복사 명령(`copyAll`)이 타겟 패널을 빗나갈 확률을 최소화했습니다.
- 리눅스 클립보드 동기화 딜레이(600ms) 및 재시도(5회) 로직과 시너지를 일으켜, 데이터 캡처의 무결성을 확보했습니다.

## 🛠️ 기술적 세부 사항
- **`ClipboardScraperAdapter`**: 진단 로그 기반 `focusCommands` 리스트 전면 개편.
- **`Diagnostic Probe`**: 여전히 명령어를 모니터링하여 환경별 차이를 자동으로 로그에 남기도록 유지.
