🚀 Release Note v0.2.36 - Direct Reading Evolution

## 📅 작업 정보 - **상태:** ✅ Completed
- **버전:** v0.2.36
- **대상의 핵심:** 클립보드를 거치지 않는 '직독직해(Direct Reading)' 방식의 대화 데이터 탈취 도입.

## 🛠️ 기술적 변경 사항
- **Clipboard-Free Strategy:** 
    - 리눅스 하드웨어 가속 및 클립보드 병목으로 인한 'No text captured' 문제를 해결하기 위해 클립보드 의존성을 완전히 제거했습니다.
    - `ClipboardScraperAdapter`를 `DirectChatScraper`로 진화시켰습니다.
- **포커스 마당발 차단 (Focus Pruning):** 
    - 난무하는 토글 기반 명령어를 모두 쳐내고, 현재 가장 신뢰할 수 있는 `workbench.panel.chat.view.copilot.focus` 및 `antigravity.toggleChatFocus`만 남겼습니다.
- **데이터 탈취 경로 다각화:** 
    - 기존 클립보드 기반의 'Blind Copy' 대신, `VSCDB` (VS Code Database) 스캔을 1순위로 격상했습니다.
    - `state.vscdb`의 `antigravity.chat.state` 및 `trajectorySummaries` 영역을 직접 렌더링 영역으로 인식합니다.
- **성능 최적화:** 
    - 클립보드 백업 및 복구 과정이 제거되어 시스템 리소스 소모가 대폭 감소했습니다.
- **안티그래비티(Antigravity) 최적화 (Hotfix):**
    - **지갑 경로 수정:** `~/.config/Antigravity/` 경로를 1순위로 격상하여 전용 환경에서의 데이터 탈취 정확도를 높였습니다.
    - **WAL 동기화:** SQLite의 WAL(Write-Ahead Logging) 특성을 고려하여 `-wal`, `-shm` 파일을 세트로 복제함으로써 실시간 미커밋 대화까지 완벽하게 포착합니다.
    - **쿼리 커버리지 확장:** `%session%`, `%request%` 키워드를 추가하여 다양한 세션 저장 형식을 전수 조사합니다.

## ⚠️ 예외 처리 및 주의 사항
- `Direct Reading` 방식은 DB 기록의 지연(Commit timing)이 발생할 수 있으므로, `VscdbAdapter`의 복사본 생성을 통한 스캔 주기를 최적화했습니다.
