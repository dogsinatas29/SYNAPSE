🚀 Release Note v0.2.37 - Senior's Intervention: API Sniffing & WAL Conquer

## 📅 작업 정보 - **상태:** ✅ Completed
- **버전:** v0.2.37
- **대상의 핵심:** DB 커밋 지연을 우회하는 API Sniffing 및 바이너리 데이터 내 한글 추출(RawTextMiner) 도입.

## 🛠️ 기술적 변경 사항
- **[Action 1] API Sniffing (Memory-Direct Extraction):** 
    - VS Code 내부의 `chat` API를 직접 스니핑하여 DB 기록 여부와 상관없이 실시간 대화 정보를 메모리에서 즉시 획득합니다.
- **[Action 2] Commit Latency Resolution:** 
    - 리눅스 환경의 파일 I/O 지연을 극복하기 위해 트리거 발생 후 2초의 지연 대기(Retry) 로직을 추가했습니다.
    - `-wal`, `-shm` 파일의 복제 및 원본 DB와의 병합 스캔을 통해 데이터 정합성을 보장합니다.
- **[Action 3] RawTextMiner (Hangeul Scouter):** 
    - DB나 API가 모두 응답하지 않을 경우를 대비하여, PB 및 바이너리 파일 내부의 '외계어' 사이에서 한글(가-힣)만 정밀하게 추출해내는 Fail-safe 메커니즘을 실장했습니다.

## ⚠️ 예외 처리 및 주의 사항
- `DirectChatScraper`는 이제 API -> DB -> Binary(Miner) 순의 3단 필터링 체계를 갖추어 어떠한 환경에서도 대화 내역 누락을 최소화합니다.
