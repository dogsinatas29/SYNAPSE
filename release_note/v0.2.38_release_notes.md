🚀 Release Note v0.2.38 - Precision Sniper: Noise Suppression

## 📅 작업 정보 - **상태:** ✅ Completed
- **버전:** v0.2.38
- **대상의 핵심:** 불필요한 VS Code 내부 데이터(노이즈) 제거 및 실제 대화 텍스트의 정밀 추출.

## 🛠️ 기술적 변경 사항
- **[Action 1] Targeted Session Scoping:** 
    - 변경이 발생한 특정 세션(`sessionId`)의 PB 파일을 우선적으로 추적하여, 수집 효율을 극대화하고 오버헤드를 최소화했습니다.
- **[Action 2] Precision Noise Filtering:** 
    - `workbench.*`, `antigravity.*`, `ItemTable` 등 VS Code 내부 설정값과 DB 스키마 노이즈를 99% 차단하는 정밀 필터를 실장했습니다.
    - 식별자(ID) 형태의 문자열과 실제 '말(Speech)'을 구분하는 휴리스틱을 강화했습니다.
- **[Action 3] Role Detection Accuracy:**
    - 질문 키워드와 문장 구조를 분석하여 User와 Assistant의 역할을 더욱 정확하게 분류합니다.

## ⚠️ 예외 처리 및 주의 사항
- 이제 컨텍스트 볼트에 "Assistant: ItemTable"과 같은 시스템 노이즈가 더 이상 기록되지 않습니다. 오직 순수한 대화 내용만 정밀하게 타격하여 기록합니다.
