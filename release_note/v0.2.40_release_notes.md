# 🚀 v0.2.40 Release Notes

## 🚧 핵심 변경 사항 (Inception 루프 차단 패치)

**1. 로그 인셉션 원천 차단**
- 채팅창 포커스 실패 시 열려 있는 에디터(로그 파일 등) 전체를 복사해 버리던 `BLIND_COPY_FALLBACK` 로직을 영구 제거했습니다.
- **예외 처리:** 만약 활성화된 에디터가 `.synapse_contexts/` 안에 있는 파일이라면 복사 시도 자체를 진행하지 않도록 보호 필터가 적용되었습니다.

**2. 강제 개문(Force Open) 전략 적용**
- Gemini 관련 명령어가 잡히지 않는 상황에 대비, 순수 VSC 채팅 UI 명령어인 `workbench.action.chat.open`을 먼저 실행하여 채팅 패널을 강제로 열고 0.5초 대기합니다.
- 창이 열린 상태에서 개별 포커스 명령어를 차례로 타격하여 채팅창에 정확히 초점이 맞도록 설계했습니다.

**3. 클립보드 데이터 오염 차단 2차 검증**
- 만일 어떤 이유로 복사된 데이터에 `# Session `이라는 로그 시그니처가 존재할 경우, 곧장 탈락(Reject)시켜 오염된 데이터가 기록되는 루프 사태를 철벽 차단했습니다.

## ⚠️ 다음 단계 (Test Process)
패치가 완료되었습니다.
테스트를 위해 **채팅창을 수동으로 마우스 클릭하여 직접 포커스를 맞춘 채로 채팅을 진행**해 보시기 바랍니다.
만약 수동 포커스에서도 복사가 안된다면 시스템적 복사 명령어 제한이므로, 주저없이 `SQLite BLOB Parsing (VscdbAdapter)` 로직으로 돌아가 '금고를 부수는' 작전으로 선회하겠습니다.
