# 🚀 Release Notes - v0.2.40

## 🎯 **새로운 기능 및 주요 변경 사항 (Key Features)**
- **채팅 스크래퍼(DirectChatScraper) 버그 수정 및 안정화 보장**
  - PB 트리거 이후 UI 하드카피 파이프라인에서 발생하던 "No text captured" 버그 등 심각한 오류 해결.

## 🔧 **기술적 세부 사항 및 패치 (Technical Details)**
- **Focus Hijacking 방지**:
  - 기존에는 Copilot 채팅 패널이 우선 포커스를 가져가던 문제를 수정하여, `antigravity.toggleChatFocus` 및 `workbench.view.extension.google-gemini` 명령을 1순위로 배정. 타 확장이 설치된 환경에서도 목표 채팅을 올바르게 포집할 수 있도록 변경했습니다.
- **Blind Copy Fallback 탑재**:
  - `gemini.chat.copyAll` 등 전용 복사 커맨드가 환경에 따라 작동하지 않는 경우에 대비해 `editor.action.selectAll` + `editor.action.clipboardCopyAction` 조합의 Blind Copy Fallback 프로세스를 도입하여, 극한의 상황에서도 반드시 텍스트를 클립보드로 긁어오도록 조치했습니다.
- **Linux 동기화 지연 해결**:
  - 명령어 실행 사이의 대기 딜레이를 각 명령의 사이클(포커싱, 렌더링, 컨텍스트 스위칭, 클립보드 동기화 타임)에 맞춰 150ms ~ 800ms 범위로 세밀하게 튜닝, Linux X11 기반 시스템에서의 클립보드 손실률을 제거했습니다.

## ⚠️ **알려진 문제 및 주의 사항 (Known Issues)**
- 포커스 우회가 동작한 후 `editor.action.selectAll` Fallback이 작동할 때, 패널의 위치(하단, 좌측, 우측 편입 등)에 따라 일시적 깜빡임이 있을 수 있으나 기존 클립보드는 복원 메커니즘을 통해 완벽히 무결 상태로 되돌아갑니다.
