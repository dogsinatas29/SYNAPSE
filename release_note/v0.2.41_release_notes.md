# 🚀 SYNAPSE Release Notes v0.2.41 
## 🎯 주요 변경 사항 (DirectReading)
- **The PB Miner 도입 (`DirectPbExtractor`)**: 더 이상 복사를 위해 채팅 패널을 포커스하거나 UI 기반의 매크로를 돌리지 않습니다. 변경된 `.pb` 파일을 즉시 바이너리로 열어 텍스트 데이터만 추출하는 강력한 광부(Miner)를 투입했습니다.
- **SQLite WAL Fallback**: DB 쿼리로 놓칠 수 있는 백그라운드 데이터를 낚아채기 위해, `.vscdb-wal` (Write-Ahead Log) 파일 자체를 로우 레벨로 덤프하여 휴리스틱 파싱하는 Fallback 전략을 `VscdbAdapter`에 심었습니다.

## 🛠️ 기술적 픽스
- `DirectChatScraper` 컴포넌트 완전 폐쇄 및 `PbSessionWatcher` 구조 전면 개편.
- Hangeul/Alphanumeric 정규식을 사용한 바이너리 잡음 필터(Noise Filter) 적용.
- `vsce package`를 통해 `synapse-visual-architecture-v0.2.41.vsix` 생성 완료.

👨‍💻 **마침내 Webview의 족쇄를 풀고 데이터 원천지(바이너리 파일)에 직결했습니다. 이제 방해 요소 없이 100% 무결한 스크래핑이 가능합니다.**
