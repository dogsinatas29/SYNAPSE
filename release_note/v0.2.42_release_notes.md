# v0.2.42_hotfix Release Notes

## 🛠️ 긴급 수리 및 개선 사항
- **[Fix 1] Async/Await 정합성 확보**: `extension.ts`에서 `DirectPbExtractor.extractAndLog` 호출 시 `await`를 누락하여 비동기 작업이 중간에 유실되거나 에러가 무시되던 현상을 수정하였습니다.
- **[Fix 2] PB Miner 로깅 강화**: 파일 존재 여부 및 읽기 시도 시점에 명시적인 시스템 메시지를 남기도록 하여, '광부'의 작업 상태를 실시간으로 추적 가능하게 했습니다.
- **[Fix 3] 필터 완화**: `antigravity` 키워드가 포함된 대화 내용이 시스템 노이즈로 오인되어 삭제되던 로직을 제거하여, 관련 대화도 정상 추출되도록 개선했습니다.
- **[New] Manual PB Scan 명령어 추가**: 트리거를 기다리지 않고 즉시 모든 `.pb` 파일을 재스캔할 수 있는 `SYNAPSE: Manual PB Scan` 명령어를 도입했습니다.

## 🚀 적용 방법
1. 기존 확장 프로그램 제거 후 `synapse-visual-architecture-v0.2.42.vsix`를 다시 설치하십시오.
2. **Reload Window** (Ctrl+R)를 수행하십시오.
3. `Ctrl+Shift+P` -> **SYNAPSE: Manual PB Scan**을 실행하여 과거의 대화를 강제로 긁어오십시오.
4. `.synapse_contexts/` 폴더의 로그 파일에서 `PB Miner: Reading ...` 메시지를 확인하십시오.
