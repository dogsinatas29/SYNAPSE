# v0.2.43 Release Notes - "Open Deep Mining"

## 🛠️ 주요 변경 사항
- **[Debug] Force Log Raw Islands**: 필터링 이전에 추출된 모든 문자열 조각을 `DEBUG: Raw Island Candidate: ...` 로그로 강제 출력합니다. 이를 통해 실제 데이터의 형태를 직접 육안으로 확인할 수 있습니다.
- **[Relax] Island Finder Regex 해제**: 연속된 유효 문자의 최소 길이를 15글자에서 **5글자**로 대폭 완화하여, 짧은 명령어와 단답형 대화도 누락 없이 수집합니다.
- **[Relax] Conversation Filter 완화**:
    - 한글 비중 제한: 5% -> **1%**
    - 최소 공백 개수 제한: 3개 -> **1개** (50자 미만인 경우에만 적용)
    - 최소 텍스트 길이: 25자 -> **5자**
- **[Debug] Rejection Reason 로깅**: 특정 문자열이 필터에 의해 거부될 경우 `DEBUG: Rejected Island (Filter): ...` 로그를 남겨 필터의 적정성을 판단할 수 있게 했습니다.

## 🚀 적용 및 테스트
1. `synapse-visual-architecture-v0.2.43.vsix`를 재설치하십시오.
2. **Reload Window** 후 **SYNAPSE: Manual PB Scan**을 실행하십시오.
