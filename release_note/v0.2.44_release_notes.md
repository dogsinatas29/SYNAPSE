# v0.2.44 Release Notes - "The Interceptor" 🚀

## 📅 Release Date: 2026-03-30
## 🚀 Version: v0.2.44

### 🧠 핵심 요약: "바이너리 지옥에서 메모리 천국으로"
기존의 불안정한 `.pb` 및 `.vscdb-wal` 바이너리 파싱 방식에서 완전히 탈피하여, 사용자가 엔터를 치는 그 찰나의 **평문 대화(Plain Text)**를 메모리 상에서 직접 요격(Intercept)하는 혁신적인 아키텍처로 전환했습니다.

### 🛠️ 주요 변경 사항

1. **Memory Interceptor Hooking (Memory 요격)**
   - `google.gemini.chat.send` 및 `antigravity.action.chat.send` 명령어를 런타임에 요격하는 `CommandInterceptor.ts` 도입.
   - 바이너리 노이즈 없이 100% 무결한 프롬프트 및 답변 추출 성공.

2. **Activation Hoisting (초기화 최적화)**
   - 익스텐션 활성화 시 로깅 인프라(`PromptLogger`, `ChatExtractor`)를 최우선적으로 로드하여 첫 번째 명령어 실행부터 누락 없이 기록.

3. **MultiAdapter Delegation (위임 구조 개선)**
   - 여러 어댑터 간의 데이터 전달 인터페이스(`ChatAdapter`)를 개선하여 하위 스트림 어댑터로의 데이터 흐름 안정화.

4. **Self-Diagnostic Mode (자가 진단)**
   - `commands_diagnostics.json`을 통한 명령어 매핑 분석 기능 및 세션 로그 내 실시간 진단 태그(`[INTERCEPT DIAG]`) 추가.

### ⚠️ 주의 사항 / 개선 필요 사항
- **원본 기능 무결성**: 현재 'Passive Hook' 방식을 사용하여 원본 안티그래비티 기능에 영향을 주지 않으면서 데이터만 안전하게 획득합니다.
- **세션 동기화**: 스트리밍 대화의 경우 2초 이상의 Idle 타임 발생 시 자동으로 버퍼를 플러시하여 기록의 실시간성을 보장합니다.
