# v0.2.45 Release Notes — "The Wildcard" (전수 요격 모드)

## 📅 배포 정보
- **날짜:** 2026-03-30
- **버전:** v0.2.45
- **상태:** ✅ Completed

## 🚀 주요 변경 사항

### 1. CommandInterceptor: Wildcard Hooking 활성화
- 특정 명령어 ID(`antigravity.sendPromptToAgentPanel` 등)에 의존하던 기존 방식에서 탈피하여, `antigravity.*` 네임스페이스로 시작하는 모든 명령어를 실시간으로 가로채는 'Wildcard Hook'을 도입했습니다.
- 이제 안티그래비티가 어떤 이름으로 명령어를 은닉하더라도 접두사만 일치하면 모든 페이로드를 포착합니다.

### 2. Deep Recursive Scan (심층 탐색기) 구현
- `executeCommand`의 인자(`args`)가 복잡한 중첩 객체나 배열 형태일 때도 데이터를 놓치지 않도록 최대 Depth 5까지 재귀적으로 탐색하는 `recursiveScan` 로직을 구현했습니다.
- JSON 구조 깊숙이 숨겨진 사용자 질문(Prompt)과 응답 데이터를 평문으로 추출해냅니다.

### 3. GOLDEN_DATA 자동 판독 시스템
- 추출된 문자열 중 한글(`/[가-힣]/`)이 포함된 데이터를 감지하면 즉시 `[GOLDEN_DATA]` 태그를 부여합니다.
- 한국어 사용자의 대화 흐름을 최우선적으로 식별하여 '진짜 데이터가 흐르는 파이프'가 어디인지 명확하게 증명합니다.

### 4. 물리적 블랙박스 로깅 (intercept_hits.log)
- 시스템 메인 로그 외에 `.synapse_contexts/intercept_hits.log`라는 독립된 물리 파일에 모든 요격 데이터를 기록합니다.
- `[timestamp] HIT [commandId] -> Content` 형식을 통해 어떤 명령어 ID가 실제 대화 내용을 품고 가는지 영구적으로 보존합니다.

## 🛠️ 기술적 세부 사항
- **Namespace Coverage:** `antigravity.*`, `gemini.*`, `chat.*`
- **Recursive Depth:** 5
- **Status Indicator:** `$(shield) WILDCARD` (Gold Color)
