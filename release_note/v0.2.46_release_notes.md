# 🚀 SYNAPSE Release Notes - v0.2.46 "The Surgical Strike"
## 🧬 Module: Webview Vein Piercer (Activated)

## 📅 Release Date: 2026-03-30
## 🛡️ Focus: Boundless Interception & Hangeul Fingerprinting

이번 버전은 안티그래비티의 혈관(Webview Protocol)을 직접 찔러 정보를 낚아올리는 **'The Surgical Strike'** 패치를 완료했습니다. 더 이상 실패한 스크래핑 방식에 의존하지 않고, 화면에 비치는 그 찰나의 데이터를 평문으로 요격합니다.

---

### 💉 1. Point 1: Input 요격 ([VEIN_HIT][1])
- **Pure Prompt Capture**: 웹뷰에서 호스트로 나가는 모든 `onDidReceiveMessage`를 감시하여, 서버로 날아가기 전의 오염되지 않은 사용자 입력을 요격합니다.
- **Hangeul 지문 검사**: 사용자의 목소리가 담긴 한글 데이터를 탐지하는 즉시 감사 로그로 전송합니다.

### 💉 2. Point 7: Output 요격 ([VEIN_HIT][7])
- **Final Response Sniffing**: 호스트에서 웹뷰로 전달되는 `postMessage`를 가로채어, LLM이 내뱉는 최종 응답을 화면에 뿌려지기 직전에 낚아챕니다.
- **Recursive Argument Sniffer**: 복잡하게 포장된 객체 내부를 재귀적으로 스캔하여 숨겨진 텍스트 데이터를 끝까지 추적합니다.

### 🛡️ 3. Isolation & Mirror Loop Guard
- **Self-Exclusion (자가 보호)**: `synapse` 뷰타입을 포함한 모든 시스템 내부 통신은 인터셉터 매커니즘에서 제외하여 무한 루프를 원천 차단했습니다.
- **Selective Interception**: `antigravity` 뿐만 아니라 한국어가 흐르는 모든 웹뷰 통신을 'Golden Data'로 간주하여 수집 대상을 확장했습니다.

### 🛠️ 4. System Stability
- **Scraping 방식 공식 폐기**: 무겁고 불안정한 `.pb` 파일 마이닝 대신 경량화된 실시간 메모리 요격 방식으로 전환하여 성능과 정확도를 동시에 잡았습니다.
- **Status Bar Integration**: `$(pulse) VEIN PIERCER` 아이콘을 통해 인터셉터의 가동 상태를 실시간으로 확인할 수 있습니다.
