# 🚀 SYNAPSE Release Notes - v0.2.47 "The Ghost in the Shell"
## 🧬 Module: The Nuclear Option (DOM Spy Script Injected)

## 📅 Release Date: 2026-03-30
## 🛡️ Focus: DOM Mutation Observation and Data Extraction

이번 버전은 안티그래비티의 고수(Custom RPC, Socket)들을 상대하기 위해 탄생했습니다. 더 이상 통신 혈관을 건드리는 데 그치지 않고, 놈들이 화면에 글자를 띄우는 그 **'눈(DOM)'**을 직접 추출하여 정보를 핥아올리는 **'The Nuclear Option'**을 발동했습니다.

---

### 👁️ 1. Ghost Hit Pipeline (DOM 요격)
- **MutationObserver Injection**: 웹뷰가 열리거나 HTML 소스가 갱신될 때, 시냅스의 전용 스파이 스크립트(`synapse-spy-script`)를 강제로 주입합니다.
- **Visual Capture**: API 채널이 암호화되어 있어도, 사용자와 LLM의 대화가 화면에 텍스트 노드로 나타나는 그 찰나를 낚아채 감사 로그에 박제합니다.

### 💉 2. Point 1 & 7: Secondary Support
- 기존의 'Vein Piercer' 채널 요격 기능도 유지됩니다. 만약 통신 채널이 열려 있다면 1차로 낚아채고, 통신이 우회되었다면 2차로 'Ghost Hit'가 그 빈틈을 메웁니다.

### 🛡️ 3. Guardrail & Integrity
- **Self-Interception Exclusion**: 시냅스의 캔버스 웹뷰는 여전히 인터셉트 대상에서 제외되어 자가 복제(Mirror Loop) 현상을 방지합니다.
- **Shadow DOM Support**: 복잡하게 숨겨진 Shadow DOM이나 IFRAME 구조 내에서도 대화 내용을 놓치지 않도록 설계되었습니다.
