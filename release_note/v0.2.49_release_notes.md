# 🚀 Release Notes - v0.2.49 "The Neuro-Link"

## 🛡️ 핵심 변경 사항: 프로토타입 기반 전역 요격 (Global Prototype Interception)
Antigravity의 "심층 조기 기동(Deep Early Activation)"을 우회하기 위해, 개별 인스턴스 추적이 아닌 **클래스 프로토타입 레벨**에서의 요격 시스템을 도입했습니다.

### 1. 전역 웹뷰 프로토타입 포이즈닝 (Prototype Poisoning)
- `createWebviewPanel`이나 `deserializeWebviewPanel`을 놓쳤더라도, 시스템에 존재하는 모든 `Webview` 객체는 동일한 부모 프로토타입을 공유합니다.
- `synapseCanvas`가 로드되는 즉시 부모 프로토타입의 `html` setter와 `postMessage`를 장악하여, Antigravity가 언제, 어떤 방식으로 웹뷰를 띄웠든 상관없이 통신 채널을 강제로 개방합니다.

### 2. 렌더러단 딥 후킹 (Renderer-level Deep Hooking)
- [Option C] 전략의 일환으로, 모든 웹뷰 내부에 주입되는 스파이 스크립트가 `acquireVsCodeApi`를 감시합니다.
- 웹뷰 내부 JS 환경에서 발생하는 모든 `postMessage`를 렌더러 레벨에서 가로채어 기록합니다.

### 3. 자가 정화 및 무한 루프 가드 강화
- 전역 프로토타입 변조에 따른 부작용을 최소화하기 위해 `synapse` 관련 트래픽에 대한 엄격한 필터링을 유지합니다.

## 🛠️ 수정된 파일
