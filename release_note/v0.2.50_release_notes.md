# 🚀 Release Notes - v0.2.50 "The Ghost Protocol"

## 🛡️ 핵심 변경 사항: CDP 기반 강제 런타임 주입 (Ghost Protocol)
v0.2.50 Phase 1(HTML 주입)이 CSP(Content Security Policy) 및 Webview 격리에 의해 차단됨에 따라, **Chrome DevTools Protocol(CDP)**을 직접 활용하는 "Ghost Protocol"을 도입했습니다.

### 1. CSP 무력화 (Bypassing Security Policies)
- HTML Setter를 통한 스크립트 삽입이 아닌, 브라우저 디버깅 채널을 통한 직접 실행(`Runtime.evaluate`)을 수행합니다.
- 이는 웹뷰 내부의 CSP 설정을 무시하고 런타임 객체에 직접 접근할 수 있게 합니다.

### 2. Zero-Dependency 런타임 패치
- 외부 라이브러리(`ws` 등) 없이 Node.js 표준 `net` 및 `crypto` 모듈만을 사용하여 Minimal WebSocket Client를 구현했습니다.
- 보안 마스킹 프레임(Masked Frame)을 생성하여 VS Code 내부 디버깅 포트에 직접 명령을 전달합니다.

### 3. Upstream 채널 강제 확보
- 웹뷰 내부의 `window.acquireVsCodeApi`를 CDP 레벨에서 후킹하여, 웹뷰에서 호스트로 전달되는 모든 메시지를 가로채고 기록합니다.
- 한국어 텍스트 및 대화 데이터를 `[SYNAPSE][UPSTREAM]` 태그와 함께 실시간 덤프합니다.

## 🛠️ 추가/수정된 파일
- `src/core/CDPManager.ts`: CDP 타겟 탐색 및 WebSocket 명령 송신 엔진 (신규)
- `src/core/WebviewInterceptor.ts`: CDP 기반 Ghost Protocol 연동 및 후킹 트리거 강화
- `mile_stone/v0.2.50.md`: Phase 2 전략으로 업데이트

## 🚀 검증 방법
1. v0.2.50 VSIX 빌드 및 설치.
2. **필수사항**: VS Code 실행 시 `--remote-debugging-port=9222` 옵션 확인 (또는 기본 포트 가용성 확인).
3. `antigravity-chat` 등 타겟 웹뷰가 열린 후 1.5초 내에 `[SYNAPSE][CDP] Ghost Injection SUCCESSFUL` 로그가 찍히는지 확인.
4. 웹뷰에서 메시지 전송 시 `[SYNAPSE][UPSTREAM]` 로그가 발생하는지 확인.
