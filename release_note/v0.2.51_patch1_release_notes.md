# 🚀 Release Notes - v0.2.51-patch1 "Ghost in the Shell: IFrame Breach"

## 🛡️ 핵심 변경 사항: CDP 타겟 매칭 정격화 (IFrame Targeting)
Antigravity(Electron)의 9222 포트가 성공적으로 개방된 상태에서, 실제 Synapse Canvas 렌더러가 `page` 타입이 아닌 `iframe` 타입으로 식별되어 요격에 실패하던 문제를 해결했습니다.

### 1. IFrame 지원 & Context 정밀 타겟팅
- **타켓 매칭 로직 (v0.2.51-patch1)**:
    - 매칭 필터를 확장하여 `type === 'iframe'`인 타겟도 명시적으로 수용합니다.
    - `vscode-webview://` 프로토콜로 시작하는 URL을 최우선 순위로 탐색합니다.
- **Context-Aware Injection (Phase 4)**:
    *   단순 `Runtime.evaluate`가 아닌, `Runtime.enable`을 통해 모든 Execution Context를 스캔합니다.
    *   `origin`이 `vscode-webview://`인 컨텍스트를 동적으로 식별하여 **Isolated World** 내부로 정확히 스크립트를 주입합니다.
    *   `acquireVsCodeApi`가 정의되지 않는 문제를 완벽하게 해결했습니다.

### 2. HTTP 클라이언트(httpGet) 안정성 강화
- **SSE(Server-Sent Events) 방어**: MCP(Chrome DevTools MCP) 스캔 시 응답 헤더에 `text/event-stream`이 포함된 경우, synchronous read를 중단하고 즉시 연결을 종료하여 행(Hang) 현상을 방어합니다.
- **Header 정규화**: `Accept: application/json` 및 `User-Agent` 헤더를 명시하여 일부 보안 정책이 적용된 CDP 엔드포인트와의 호환성을 높였습니다.

### 3. 디버깅 가시성 개선
- **타겟 식별 로그**: 매칭된 타겟의 타이틀이 길 경우 생략 표시를 추가하고, 타입(`page` vs `iframe`)을 로그에 명시하여 연결 상태를 직관적으로 파악할 수 있도록 개선했습니다.

## 🛠️ 수정된 파일
- `src/core/CDPManager.ts`: 타겟 매칭 및 HTTP GET 로직 고도화

## 🚀 검증 방법
1. Antigravity를 `--remote-debugging-port=9222` 인자와 함께 실행.
2. `lsof -i :9222` 명령어로 LISTEN 상태 확인.
3. Synapse Canvas를 연 후 출력 채널(Output Channel)에서 다음과 같은 로그 확인:
   - `[SYNAPSE][CDP] High-Confidence Target Found: ... (WebView)`
   - `[SYNAPSE][CDP] Ghost Injection SUCCESSFUL`
4. 이제 모든 Webview-to-Host 트래픽이 캡처 가능 상태가 됩니다.
