# 🚀 Release Notes - v0.2.52 "Persistent Veil: The Unending Eye"

## 🛡️ 핵심 변경 사항: Webview 새로고침 완벽 대응 (Persistence)
이전 버전(v0.2.51)에서 CDP를 통한 강제 주입에는 성공했으나, Webview가 새로고침되면 주입된 스크립트가 유실되는 문제가 있었습니다. v0.2.52에서는 Chromium의 `Page.addScriptToEvaluateOnNewDocument`를 사용하여 어떠한 상황에서도 도청 상태가 유지되도록 고도화했습니다.

### 1. Eternal Ghost Protocol (Persistence)
- **자동 재주입 (v0.2.52)**:
    - `Page.enable` 명령을 활성화하여 브라우저의 페이지 이벤트를 구독합니다.
    - `Page.addScriptToEvaluateOnNewDocument`를 통해 Webview가 새로고침되거나 다른 URL로 이동하더라도, 모든 문사가 로드되기 직전에 Ghost 스크립트를 자동으로 실행합니다.
- **중복 주입 방지 (Injection Guard)**:
    - 한 페이지에 여러 번 스크립트가 주입되더라도 충돌이 발생하지 않도록 `window.__synapse_ghost_active` 가드를 추가했습니다.

### 2. 가시성 및 안정성 개선
- **버전 동기화**: 모든 로그 및 상태 표시줄의 버전을 `v0.2.52`로 일괄 업데이트했습니다.
- **Handshake 로직 최적화**: 렌더러와 호스트 간의 동기화 상태를 더 정확하게 파악할 수 있도록 Handshake 타이밍을 조절했습니다.

## 🛠️ 수정된 파일
- `package.json`: v0.2.52 버전 범핑
- `src/core/CDPManager.ts`: Page 도메인 활성화 및 자동 재주입 로직 구현
- `src/core/WebviewInterceptor.ts`: 전역 가드 추가 및 버전 업데이트

## 🚀 검증 방법
1. Synapse Canvas를 열고 출력 채널에서 `[SYNAPSE][CDP] Ghost Injection sequence COMPLETED` 확인.
2. **Webview에서 `Ctrl+R` (또는 새로고침)**을 수행.
3. 다시 출력 채널을 확인했을 때, 별도의 명령 없이도 `[SYNAPSE][CDP] Ghost Protocol Active (v0.2.52)` 로그가 다시 찍히는지 확인.
4. 이제 사용자가 Webview를 수동으로 새로고침하더라도 도청 기능이 유실되지 않습니다.
