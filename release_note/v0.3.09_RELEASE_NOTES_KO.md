## 🐛 버그 수정 (3가지 심각한 문제)

### **문제 #1: Canvas 높이 = 0 (2D 모드 노드 미표시)**

**증상**:
- 2D 모드로 전환했을 때 캔버스가 검은색으로만 표시됨
- 노드와 엣지가 렌더링되지 않음

**근본 원인**:
```javascript
// 수정 전: WebGL 비활성화 후 canvas height = 0
const height = this.container.clientHeight;  // 0px (DOM 리플로우 전)
canvas.height = height;  // 🔴 0으로 설정됨
```

WebGL을 비활성화하는 과정에서 DOM이 아직 리플로우되기 전에 `clientHeight`를 읽으면 0이 반환됨.

**해결책**:
```javascript
// ✅ 수정: 최소 높이 보증 + DOM 리플로우 강제
let height = this.container.clientHeight;
if (height === 0 || height < 100) {
    height = 400;  // 최소값 폴백
}

// DOM 리플로우 트리거 (50ms 딜레이)
setTimeout(() => this.resizeCanvas(true), 50);
```

**커밋**: `ui/canvas-engine.js` 1890-1900줄, 1860-1870줄

### **문제 #2: 3D 모드 아이콘이 알파벳으로 표시됨**

**증상**:
```
예상: 📄 ⚡ 🧪 🧩 📁  (이모지 아이콘)
실제: D  B  F  Ω  I    (알파벳)
```

**근본 원인**:
WebGL의 TextAtlas가 "Inter" 폰트만 사용하는데, **Inter는 이모지를 지원하지 않습니다**.

```javascript
// 수정 전: Inter 폰트만 사용
ctx.font = '12px Inter, sans-serif';
ctx.fillText(ch, this.x + 1, this.y + 2);  // ❌ 이모지 글리프 없음 → 알파벳으로 폴백
```

**작동 메커니즘**:
1. Inter 폰트에서 이모지 글리프 검색 → **없음**
2. 자동 폴백되는 폰트 없음 → 기본 ASCII 문자로 대체
3. TextAtlas에 미리 렌더링됨 → 복구 불가능

**해결책**:
```javascript
// ✅ 수정: 이모지 감지 + 크로스 플랫폼 폰트 스택
const isEmoji = /\p{Emoji}/u.test(ch);
if (isEmoji) {
    // 우선순위: Google(Noto) → Apple → Microsoft(Segoe)
    ctx.font = '14px "Noto Color Emoji", "Apple Color Emoji", "Segoe UI Emoji", sans-serif';
} else {
    ctx.font = '12px Inter, sans-serif';
}

// 이모지 최소 크기 보증
if (isEmoji && w < 16) w = 18;
if (isEmoji && h < 16) h = 18;
```

**OS별 폰트 지원**:
| OS | 기본 폰트 | 대체 폰트 1 | 대체 폰트 2 |
|----|----------|-----------|-----------|
| Linux | Noto Color Emoji (apt install fonts-noto-color-emoji) | Google fonts | 시스템 폰트 |
| macOS | Apple Color Emoji (기본 내장) | Noto Color Emoji | - |
| Windows 10+ | Segoe UI Emoji (기본 내장) | Noto Color Emoji | - |

**설치 가이드**:
```bash
# Linux
sudo apt install fonts-noto-color-emoji

# macOS & Windows: 사전 설치됨
# (선택) Noto Color Emoji 전역 설치
```

**커밋**: `ui/webgl-renderer.js` 45-65줄

### **문제 #3: Eco-모드 렌더링 중단**

**증상**:
- 약 2초의 유휴 시간 후 렌더링이 멈춤
- 마우스를 움직여야 다시 시작됨

**근본 원인**:
```javascript
// 수정 전: Rendering 중에도 유휴 타이머 증가
startLoop() {
    if (Date.now() - this.lastActivityTime > 2000) {
        console.log('[Eco-mode] 절전모드 진입');
        return;  // ❌ 렌더링 중에도 절전모드 진입 가능
    }
}
```

Eco-모드가 렌더링 중인지 감지하지 못해 렌더링을 중단함.

**해결책**:
```javascript
// ✅ 수정 1: Rendering 상태 확인
startLoop() {
    const isRenderingActive = this.isRendering;
    if (Date.now() - this.lastActivityTime > 2000 && !isRenderingActive) {
        console.log('[Eco-mode] 절전모드 진입');
        return;
    }
}

// ✅ 수정 2: Rendering 중 유휴 타이머 리셋
render() {
    this.lastActivityTime = Date.now();  // Eco-모드 유휴 타이머 리셋
    // ... 렌더링 로직
}
```

**커밋**: `ui/canvas-engine.js` 1705-1715줄, 1750-1760줄
