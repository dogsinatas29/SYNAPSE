# Release Notes - v0.3.09_fix (Phase 1)

## 🚀 Phase 1: Rendering Stability & Budget Adjustment
v0.3.09에서 발생한 요소 사라짐 현상을 해결하기 위해 렌더링 예산 및 임계치 로직을 최적화했습니다.

### 🛠️ 주요 변경 사항
- **RendererCore.ts**:
    - **Rendering Budgets**: 노드 및 엣지 가용 예산을 대폭 상향 조정하여 대규모 그래프에서도 요소가 갑자기 사라지는 현상 방지.
        - Nodes: 200/500 → 500/1000
        - Edges: 500/1000 → 1000/3000
    - **Dynamic Threshold**: 엣지 필터링 임계치를 완화(0.9 → 0.8, 0.7 → 0.6, 0.5 → 0.3)하여 초기 렌더링 시 시각적 손실 최소화.
- **CanvasEngine.js**:
    - `resizeCanvas`: 컨테이너 높이가 0일 경우 발생하는 렌더링 영역 오류 방지를 위해 최소 높이(400px) 보증 로직 추가.
    - 2D 모드 전환 시 DOM 리플로우 및 리사이즈 강제 트리거로 화면 갱신 안정성 확보.

### 📦 결과물
- **VSIX 파일**: `synapse-visual-architecture-0.3.09_fix.vsix` 생성 완료.
