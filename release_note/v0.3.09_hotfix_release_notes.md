# 🚀 SYNAPSE Release Notes - v0.3.09_fix_Hotfix_PhaseLock

## 📅 날짜: 2026-04-05
## 🛠️ 수정 사항 요약
시스템이 Phase 5 (RENDER) 또는 Phase 6 (DEBUG) 상태에서 락(LOCK)이 걸려 사용자 인터렉션(세이브, 노드 생성 등)이 불가능했던 치명적인 회귀 버그를 수정하였습니다.

## 🧠 상세 수정 내용
### 1. PhaseManager: 유연한 상태 전이 허용
- `advancePhase`의 엄격한 순차 검증 로직을 완화하여, 이미 진행된 Phase로의 재진입이나 비순차적 전이 시 시스템 락이 걸리지 않도록 수정하였습니다.
- `setPhase` 메서드를 추가하여 치명적 상황 발생 시 특정 Phase로 안전하게 복구할 수 있는 수단을 마련하였습니다.

### 2. ControlSystem: 인터렉션 허용 범위 확대
- `verifyInteraction` 로직을 개선하여 Phase 3 (CONTROL)뿐만 아니라 Phase 5 (RENDER) 및 Phase 6 (DEBUG) 상태에서도 사용자 명령을 정상적으로 수용하도록 수정하였습니다.

### 3. CanvasPanel: Atomicity 및 동기화 개선
- `handleMessage` 콜백 내에서 Phase 5/6 상태일 때 명령이 거부되던 문제를 해결하였습니다.
- `sendProjectState` 실행 시 이미 RENDER 단계 이상인 경우 불필요한 시스템 리셋(reset)을 방지하여 UI 깜빡임과 상태 유실을 차단하였습니다.

## ⚠️ 확인된 사항
- 이제 노드 생성, 좌표 저장, 엣지 컨펌 등의 모든 컨트롤 명령이 RENDER 모드에서도 정상 작동합니다.
- 시스템 락(SYSTEM LOCKED) 메시지가 출력되며 UI가 굳는 현상이 해소되었습니다.
