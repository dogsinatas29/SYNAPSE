# 🚀 SYNAPSE Release Notes - v0.3.09_fix_Hotfix_PhaseLock

---

## 🇺🇸 English Version

### 📅 Date: 2026-04-05
### 🛠️ Summary of Fixes
Resolved a critical regression where the system could become "LOCKED" during Phase 5 (RENDER) or Phase 6 (DEBUG), preventing user interactions such as state saving or node creation.

### 🧠 Technical Improvements
#### 1. PhaseManager: Flexible State Transitions
- Relaxed the strict sequential validation in `advancePhase`.
- Non-sequential or backward transitions now trigger a warning instead of a system-wide lock.
- Added `setPhase()` to allow manual recovery to a stable state if necessary.

#### 2. ControlSystem: Expanded Interaction Scope
- Updated `verifyInteraction` to approve commands during Phase 5 (RENDER) and Phase 6 (DEBUG), in addition to Phase 3 (CONTROL).

#### 3. CanvasPanel: Atomic Synchronization
- Fixed a bug in `onDidReceiveMessage` where commands were rejected if the system was already in a rendering phase.
- Prevented redundant `reset()` calls in `sendProjectState` when the engine is already running, ensuring UI stability and data persistence.

## 🇰🇷 Korean Version (한국어)

### 📅 날짜: 2026-04-05
### 🛠️ 수정 사항 요약
시스템이 Phase 5 (RENDER) 또는 Phase 6 (DEBUG) 상태에서 "LOCKED"가 걸려 세이브, 노드 생성 등의 사용자 인터렉션이 불가능했던 치명적인 회귀 버그를 수정하였습니다.

### 🧠 상세 수정 내용
#### 1. PhaseManager: 유연한 상태 전이 허용
- `advancePhase`의 엄격한 순차 검증 로직을 완화하였습니다.
- 순서가 맞지 않거나 이전 단계로의 전이 시 시스템 락 대신 경고를 출력하며 상태를 유지합니다.
- `setPhase` 메서드를 추가하여 필요시 특정 단계로 안전하게 복구할 수 있는 수단을 마련하였습니다.

#### 2. ControlSystem: 인터렉션 허용 범위 확대
- `verifyInteraction` 로직을 개선하여 Phase 3 (CONTROL)뿐만 아니라 Phase 5 (RENDER) 및 Phase 6 (DEBUG) 상태에서도 사용자 명령을 정상적으로 수용하도록 수정하였습니다.

#### 3. CanvasPanel: 원자적 동기화 개선
- `onDidReceiveMessage` 콜백 내에서 시스템이 이미 렌더링 단계일 때 명령이 거부되던 문제를 해결하였습니다.
- `sendProjectState` 실행 시 이미 엔진이 가동 중일 경우 불필요한 리셋(`reset`)을 방지하여 UI 깜빡임과 상태 영속성을 확보하였습니다.
