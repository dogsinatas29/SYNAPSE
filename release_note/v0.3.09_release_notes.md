# 🚀 SYNAPSE v0.3.09 Hotfix Release Notes

## 🇬🇧 English: Critical Rendering & View Transition Hotfix

### 🐛 Bug Fixes
- **Edge Rendering Sync (2D/3D)**: Resolved an issue in 2D mode where the warning badge (⚠️) would span across all healthy edges incorrectly. Also fixed a defect in 3D WebGL mode where internal type icons (e.g. 🔗) completely disappeared whenever a validation badge was present.
- **Rendering Isolation (Rule 8)**: Fixed a visual artifact issue where navigating away from the 'Graph' view would leave old WebGL frame ghosting on the screen. The engine now strictly enforces `endFrame()` and `gl.clear()` during view transitions, fully respecting Rendering Isolation principles.

### ⚙️ Adjustments
- Fixed and optimized visual anchor calculations for rendering complex interactive badges.
- Documentation mapping in `README.md` updated to reflect the new visual fixes and dependencies.

## 🇰🇷 한국어: 렌더링 동기화 및 뷰 전환 시각 격리 핫픽스

### 🐛 버그 픽스
- **엣지 렌더링 동기화 (2D/3D)**: 2D 캔버스에서 에러가 없는 정상적인 엣지들까지 모두 ⚠️ 배지가 스팸 렌더링되는 문제를 해결했습니다. 또한, 3D WebGL 모드에서 검증 라벨(⚠️ 또는 ❌) 표시 시 엣지 타입 아이콘(🔗 등) 자체가 통째로 렌더링에서 제거되어 버리는 설계 결함을 완벽히 개선했습니다.
- **렌더링 뷰 격리 위반 개선 (규칙 8)**: 그래프(Graph) 뷰에서 다른 모드로 탭 화면 전환 시, 기존 WebGL 비디오 버퍼가 초기화되지 않아 잔상이 남는(Ghosting) 문제를 해결했습니다. 이제 엔진 레벨에서 뷰 이동 시 강제로 `gl.clear()`를 호줄하여 시각적 간섭을 원천 차단합니다.

### ⚙️ 시스템 조정
- 여러 개의 인터랙티브 배지들이 동시에 겹쳐서 표시될 때의 오프셋 렌더링 좌표가 겹치지 않게 수정했습니다.
- 마크다운 문서(`README.md`, `README.ko.md`)에 위 시각적 수정 내용들을 추가 공식 기록 및 통합했습니다.
