## 🐛 Bug Fixes (3 Critical Issues)

### **Issue #1: Canvas Height = 0 (2D 모드 노드 미표시)**

**Symptom**:
- 2D 모드로 전환했을 때 캔버스가 검은색으로만 표시됨
- 노드와 엣지가 렌더링되지 않음

**Root Cause**:
```javascript
// Before: WebGL 비활성화 후 canvas height = 0
const height = this.container.clientHeight;  // 0px (DOM reflow 전)
canvas.height = height;  // 🔴 0으로 설정
```

WebGL을 끄는 과정에서 DOM이 아직 리플로우되기 전에 `clientHeight`를 읽으면 0이 반환됨.

**Solution**:
```javascript
// ✅ Fix: 최소 높이 보증 + DOM reflow 강제
let height = this.container.clientHeight;
if (height === 0 || height < 100) {
    height = 400;  // Minimum fallback
}

// DOM reflow 트리거 (50ms 딜레이)
setTimeout(() => this.resizeCanvas(true), 50);
```

**Commit**: `ui/canvas-engine.js` lines 1890-1900, 1860-1870

### **Issue #2: 3D 모드 아이콘이 알파벳으로 표시됨**

**Symptom**:
```
Expected: 📄 📐 ⚡ 🧪 🧩  (emoji icons)
Actual:   D  ◈ B  F  Ω    (alphabets)
```

**Root Cause**:
WebGL의 TextAtlas가 "Inter" 폰트만 사용하는데, **Inter는 이모지를 지원하지 않음**.

```javascript
// Before: Inter 폰트만 사용
ctx.font = '12px Inter, sans-serif';
ctx.fillText(ch, this.x + 1, this.y + 2);  // ❌ 이모지 글리프 없음 → 알파벳으로 폴백
```

**Mechanism**:
1. Inter 폰트에서 이모지 글리프 찾음 → **없음**
2. 자동 폴백되는 폰트 없음 → 기본 ASCII 문자로 대체
3. TextAtlas에 미리 렌더링됨 → 복구 불가능

**Solution**:
```javascript
// ✅ Fix: 이모지 감지 + 크로스 플랫폼 폰트 스택
const isEmoji = /\p{Emoji}/u.test(ch);
if (isEmoji) {
    // 우선순위: Google(Noto) → Apple → Microsoft(Segoe)
    ctx.font = '14px "Noto Color Emoji", "Apple Color Emoji", "Segoe UI Emoji", sans-serif';
} else {
    ctx.font = '12px Inter, sans-serif';
}

// 이모지 최소 크기 보증
if (isEmoji && w < 16) w = 18;
if (isEmoji && h < 16) h = 18;
```

**Platform Coverage**:
| OS | Primary Font | Fallback 1 | Fallback 2 |
|----|--------------|-----------|-----------|
| Linux | Noto Color Emoji (apt install fonts-noto-color-emoji) | Google fonts | System font |
| macOS | Apple Color Emoji (built-in) | Noto Color Emoji | - |
| Windows 10+ | Segoe UI Emoji (built-in) | Noto Color Emoji | - |

**Installation Guide**:
```bash
# Linux
sudo apt install fonts-noto-color-emoji

# macOS & Windows: Pre-installed
# (Optional) Install Noto Color Emoji globally
```

**Commit**: `ui/webgl-renderer.js` lines 45-65

### **Issue #3: Eco-mode 렌더링 중단**

**Symptom**:
- 약 2초의 유휴 시간 후 렌더링이 멈춤
- 마우스를 움직여야 다시 시작됨

**Root Cause**:
```javascript
// Before: Rendering 중에도 idle timer 증가
startLoop() {
    if (Date.now() - this.lastActivityTime > 2000) {
        console.log('[Eco-mode] Sleep');
        return;  // ❌ 렌더링 중에도 sleep 가능
    }
}
```

Eco-mode가 렌더링 중인지 감지하지 못해 렌더링을 중단함.

**Solution**:
```javascript
// ✅ Fix 1: Rendering 상태 확인
startLoop() {
    const isRenderingActive = this.isRendering;
    if (Date.now() - this.lastActivityTime > 2000 && !isRenderingActive) {
        console.log('[Eco-mode] Sleep');
        return;
    }
}

// ✅ Fix 2: Rendering 중 idle timer 리셋
render() {
    this.lastActivityTime = Date.now();  // Eco-mode idle timer 리셋
    // ... rendering logic
}
```

**Commit**: `ui/canvas-engine.js` lines 1705-1715, 1750-1760
