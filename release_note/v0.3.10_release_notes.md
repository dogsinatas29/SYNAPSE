# 🚀 SYNAPSE Release Notes - v0.3.10

## 📦 Version: 0.3.10
**상태:** ✅ Completed [Status: Verified by Commander]
**일시:** 2026-04-06

## 🛠️ 주요 변경 사항

### 1. 📂 클러스터 가시성 복원 (External Ghosts Restoration)
- `BootstrapEngine`의 프로젝트 자동 발견 및 초기화 로직을 수정하여 `Project Root`, `External Ghosts`, `Documentation Shelf` 시스템 클러스터를 항상 생성하도록 복원했습니다.
- 클러스터 데이터 스키마(`Cluster` interface)에서 필수 필드 누락으로 인한 타입 불일치 문제를 해결했습니다.

### 2. 🎨 렌더링 파이프라인 및 데이터 무결성 강화 (Blank Canvas Fix)
- **노드 좌표 자동 생성**: 노드 생성 시 좌표(`position`)가 누락되어 화면에 그려지지 않던 문제를 해결하기 위해 `StateManager`에서 스냅샷 생성 시 자동 좌표 할당(Random Layout)을 적용했습니다.
- **데이터 정규화 (Hygiene)**: `LogicAnalyzer` 분석 및 UI 렌더링 시 노드의 `data.label` 필드 유무를 엄격히 체크하고 없을 경우 자동 생성하도록 `CanvasPanel` 정규화 로직을 강화했습니다.
- **Type Mismatch 해결**: Engine state(Record-based)와 UI/File state(Array-based) 간의 변환 오류를 수정하여 대규모 프로젝트(145+ 노드)에서도 상태가 유실되지 않도록 했습니다.

### 3. 👁️ 뷰포트 응답성 개선 (Viewport Interaction)
- `Fit View`, `Reset View` 시 화면이 즉시 갱신되지 않고 클릭이 필요하던 현상을 해결하기 위해 `requestRender()` 호출을 뷰 조작 핸들러에 통합했습니다.
- Eco-mode 렌더링 루프가 뷰 포트 변경 시 즉시 동면에서 깨어나도록 수정했습니다.

### 4. 🛡️ 논리 분석기(LogicAnalyzer) 안정화
- 배치 검증(`handleValidateEdgesBatch`) 중 발생하던 런타임 예외를 해결하기 위해 입력 데이터의 정규화 과정을 추가했습니다.

### 5. 🧱 데이터 영속성 보장 및 엣지 연결 100% 무결성 (The Persistence Lock)
- **The Eraser Bug 근절**: 분석 엔진(`BootstrapEngine`) 가동 시 `pending_confirm` 상태인 매뉴얼 엣지 데이터를 지우지 않고 **Deep Merge** 하도록 수정하여 사용자 설계 유실을 원천 차단했습니다.
- **Ghost ID 추적 완전 해결**: 생성 시점과 확정 시점의 ID 미스매칭을 해결하기 위해 `trim().toLowerCase()` 기반의 퍼지 매칭(Fuzzy Matching)을 도입했습니다.
- **메모리(SSOT) 엣지 동기화**: 엣지 확정 시에 파일을 디스크에서 다시 읽던 비정상적인 로직을 파기하고, 엣지 생성 즉시 `CONNECT_EDGE` 인텐트를 발행하여 **메모리의 최신 스냅샷**을 우선 참조하도록 엔진 데이터를 완전 동기화했습니다.
- **정규화 화이트리스트 도입**: 저장 시 핵심 시스템 변수(`_fromFile`, `_toFile`)가 필터링되어 유실되지 않도록 보존 절차를 마련했습니다.

## ⚠️ 확인사항
- 프로젝트 초기 로딩 시 노드들이 (0,0) 근처 또는 임의의 위치에 뭉쳐 있을 수 있습니다. `Fit View` 버튼을 사용하여 전체를 한눈에 확인하세요.
- `Edit Logic`이 ON 상태여야 실시간 분석 및 엣지 제안이 활성화됩니다.
