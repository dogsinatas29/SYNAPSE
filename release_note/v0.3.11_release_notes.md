# SYNAPSE Release Notes - v0.3.11
[Status: Verified by Commander]

## Highlights
- **Absolute Data Persistence**: Resolved "Ghost Node" and "Cluster Evaporation" issues via robust state synchronization and reality-check merging.
- **Cluster Position Guard**: [v0.3.11] Cluster coordinates are now fully persisted, preventing layout collapse during rollback or project reload.
- **Layout Drift Guard**: Hardened the 2D rendering engine to respect saved coordinates, preventing unwanted node movement upon project reload.
- **Transactional Core Freeze**: Enforced strict single-source-of-truth architecture where all disk files are scanned and merged without destructive overwriting.
- **Label Integrity**: Forced synchronization between all label/name/text fields to eliminate "undefined" visual artifacts.
- **Input Protection**: Blocked global keyboard shortcuts (Backspace/Delete) when input modals are active to prevent accidental node deletion.

## Fixed Issues
- **Persistence**: Fixed manual nodes disappearing during background self-healing scans by implementing `mergeState`.
- **Clustering**: Fixed cluster position stripping in `saveState` which caused messy layouts after snapshot restoration.
- **Layout**: Fixed `resolveOverlaps` triggering incorrectly when nodes have valid saved positions.
- **Visuals**: Standardized label extraction across `GraphModel` and `StateManager` to prevent "undefined" labels.
- **Path Resolution**: Improved cross-platform (Linux/Windows) path normalization in `TreeRenderer`.
