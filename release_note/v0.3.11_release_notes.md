# Release Notes - v0.3.11 (Structural Normalization & Stability Release)

## 🚀 Summary
사용자 생성 노드 및 승인된 노드가 재로드 시 증발하는 "Ghost Purge" 문제를 해결하기 위해, 노드 생성 시점에서 `layer: 'user'` 속성을 강제로 주입하도록 수정하였습니다.

## 🛠️ Changes

### 🔧 CanvasPanel.ts 수정
- **`handleCreateManualNode`**: `ADD_NODE` 디스패치 시 `layer: 'user'`를 최상위 필드와 `data` 객체 내부에 이중으로 주입.
- **`handleApproveNode`**: AI 제안 노드 승인 시 `layer: 'user'`를 주입하여 영속성 계층으로 편입.
- **Node ID Normalization**: 수동 노드 생성 시 `node_manual_` 접두어를 강제하여 레이어 판정 가독성 및 안정성 확보.

### 🔧 StateManager.ts & EdgeCodeRefactorer.ts 수정
- **Node Deduplication & Promotion**: `mutateAddNode` 시 동일한 파일 경로를 가진 노드가 감지되면 새로운 ID를 생성하는 대신 기존 노드를 '승격(User Layer로 전환)' 처리합니다. 이를 통해 중복 노드로 인한 시각적 혼란과 데이터 불일치를 해결했습니다.
- **Orphan Node Preservation**: `getSnapshot`에서 `filePath`가 없는 노드(방금 생성된 수동 노드 등)가 누락되던 로직 수정.
- **Reserved Cluster Shield/Persistence**: `getSnapshot` 및 `getRawSnapshot` 양측에 `sys_cluster_reserved` 자동 보호 로직 적용. 엣지 연결 시 생성되는 임시 클러스터가 저장 시 유실되는 현상 방지.

### 🔧 CanvasPanel.ts 수정
- **Path Normalization**: 노드 생성 시 `asRelativePath`를 사용하여 절대 경로 사용을 억제하고 프로젝트 마스터 데이터와의 일관성을 확보했습니다.
- **Manual Node ID Guard**: 수동 생성 노드에 `node_manual_` 접두어를 부여하여 판정 안정성을 높였습니다.
- [x] 수동 노드 생성 시 'User' 레이어 카운트 즉시 반영 확인.
- [x] VSCode 재시작/리로드 후에도 사용자 노드가 삭제되지 않고 유지됨 확인.
- [x] `project_state.json`에 `layer: 'user'` 속성이 정상적으로 기록됨 확인.

### 🍱 2026-04-11 (Night) Final RC Update
- **Identity-Based Layer Authority**: 노드를 옮겨도 정체성(AI/User)이 변하지 않도록 `filePath` 기반 판정 로직으로 전면 개편.
- **External Ghosts Cluster Restored**: 흩어져 있던 외부 고스트 노드들을 다시 전용 박스(`👻 External Ghosts`)로 통합하여 가독성 증대.
- **Auto-Clustering Restricted to User Nodes**: AI 파일 노드가 연결 여부에 따라 멋대로 움직이는 현상 방지. 오직 사용자 노드만 `Buffer`와 `Reserved` 사이를 지능적으로 이동.
- **Legacy Cluster Clean-up**: `Project Root` 거대 컨테이너를 영구 삭제하여 보다 유연하고 직관적인 폴더 중심의 아키텍처 완성.
- **Self-Healing State Recovery**: 잘못 저장된 레이어 정보를 로딩 시점에 자동으로 교정하는 자가 치유 로직 탑재.
