- **버전:** v0.3.11

## 🧠 주요 변경 사항 (Core Architecture)

### 1. Core Freeze (사실 계층 고정)
- `GraphModel.ts`의 모든 가변 메서드를 제거하여 런타임 중 데이터 변조를 원천 차단했습니다.
- 그래프 생성 로직을 `graphBuilder.ts`로 수렴시켜 결정론적 정렬 및 원자적 동결을 보장합니다.

### 2. Transactional Commit Pipeline
- **Commit Contract** 도입: 모든 데이터 영속화 시 `Draft -> Validate -> Plan -> Execute -> Verify`의 5단계를 거칩니다.
- **Atomic Rollback**: 파일 시스템 쓰기 도중 에러 발생 시 즉시 감지하여 생성된 파일들을 롤백(삭제)함으로써 정합성을 보호합니다.

### 3. Projection & Rule Engine
- **Resolution Control**: FILE(파일 단위), FUNCTION(함수 단위)의 결정론적 시각화 전환 기능을 탑재했습니다.
- **RuleStore**: 엣지 압축(Edge Compression) 및 레이어 격리(Layer Isolation) 규칙을 별도의 엔진으로 분리했습니다.

### 4. Interaction & Isolation
- **Scope Isolation**: 특정 노드 더블 클릭 시 서브 캔버스 오버레이로 진입하여 격리된 분석 환경을 제공합니다.
- **Buffer Management**: 모든 미확정 사용자 조작은 `StateManager`의 메모리 버퍼에서 관리되며, 명시적인 "Confirm" 시에만 트랜잭션이 실행됩니다.
- **Continuous Self-Healing (상시 자가 치유) 🔄**: 노드가 0개일 때만 스캔하던 방식을 탈피하여, 모든 상태 전송 시 백그라운드 스캔을 병행합니다. 이를 통해 실수로 삭제된 노드나 루트에 새로 생성된 파일을 엔진이 스스로 발견하고 복구합니다.
