# 🚀 Release Notes: v0.3.12 - Zen Sovereignty Edition

**Release Date:** 2026-04-12  
**Status:** 🏗️ Stable / Buffer-less Architecture

---

## 🔥 Zen Sovereignty: Buffer-less Deterministic Engine

**v0.3.12** marks the transition to a **Zen (Buffer-less)** state management architecture. We have eliminated heuristic-based merging and complex transient buffers, replacing them with a deterministic classification engine that enforces absolute sovereignty based on physical code signatures.

### 🏛️ Architectural Highlights

#### 1. Signature-Exclusive Sovereignty
Nodes are no longer promoted to the User layer based on vague movement heuristics. 
- **The Truth Hierarchy**: Physical File Signature (`# [SYNAPSE]`) > Manual Draft (`node_manual_`) > Manual Grouping (`up/down` clusters).
- Non-signature files are strictly isolated in the AI Domain (Folder hierarchy) to prevent layout "hijacking".

#### 2. Documentation Anchors (SSoT)
Resolved the "Missing Docs" issue in the Documentation Shelf.
- Architectural documents (GEMINI.md, RULES.md, etc.) are now treated as **Immutable System Assets**.
- They are automatically anchored to the `doc_shelf` cluster and protected from AI-layer demotion.

#### 3. Authoritative Movement Logic
Fixed a critical regression where nodes would snap back to `0,0` during movement.
- The engine now implements **"Buffer-First" priority** during the merge pass.
- Active user session movements (Authoritative State) always overwrite static disk snapshots.

#### 4. GUI & UX Polishing
- **Decluttered Visibility Panel**: Removed redundant versioning and debug labels.
- **External Ghost Visibility**: Explicitly assigned `cluster_ghosts` to the AI layer, ensuring external dependencies remain visible in the Basic Logic view.

---

## 🛠️ Technical Improvements
- **STATE-DETERMINISM**: Implemented strict hash-based state verification before/after merge cycles.
- **StateManager Refactor**: Simplified `generateMergedState` from a complex multi-pass loop to a single, authoritative classification pass.
- **FileScanner Ruggedness**: Hardened regex detection for `# [SYNAPSE] Atomic Logic Entry` markers.

This release completes the **Zen Sovereignty Stabilization** phase.

### 🔥 Zen 주권(Zen Sovereignty): 버퍼리스 결정론적 엔진

**v0.3.12**는 'Zen(버퍼리스)' 상태 관리 아키텍처로의 전환을 의미합니다. 모호한 휴리스틱 병합과 복잡한 임시 버퍼를 제거하고, 물리적 코드 시그니처에 기반하여 절대적 주권을 부여하는 결정론적 분류 엔진으로 교체되었습니다.

#### 🏛️ 아키텍처 주요 변경 사항

1. 시그니처 배타적 주권 (Signature-Exclusive Sovereignty)
- 노드는 이제 모호한 이동 추측이 아니라, 물리적 코드 시그니처에 의해서만 사용자 레이어로 승격됩니다.
- **진실 계층**: 물리 파일 시그니처(`# [SYNAPSE]`) > 수동 드래프트(`node_manual_`) > 수동 그룹화(`up/down` 클러스터).
- 시그니처가 없는 파일은 AI 도메인(폴더 계층)으로 엄격히 격리되어 레이아웃 '하이재킹'을 방지합니다.

2. 문서 보관함 고착 (Documentation Anchors)
- Documentation Shelf에서 마크다운 문서들이 사라지던 문제를 해결했습니다.
- 아키텍처 문서(GEMINI.md, RULES.md 등)는 이제 **불변 시스템 자산**으로 취급됩니다.
- 이들은 자동으로 `doc_shelf` 클러스터에 고착되어 AI 레이어 강등으로부터 보호받습니다.

3. 권위적 이동 로직 (Authoritative Movement)
- 노드 이동 중 좌표가 `0,0`으로 리셋되던 치명적인 결함을 수정했습니다.
- 병합 엔진에 **'버퍼 우선(Buffer-First)'** 우선순위를 도입하여, 현재 세션의 이동 상태가 디스크 스냅샷보다 항상 우선하도록 보장합니다.

4. UI/UX 폴리싱
- **가시성 패널 정돈**: 불필요한 버전 태그와 디버그 라벨을 제거하여 화면을 단순화했습니다.
- **외부 고스트 가시성**: `cluster_ghosts`를 AI 레이어로 명시 배정하여 기본 로직 보기에서 외부 종속성이 정상적으로 노출되도록 개선했습니다.

### 🛠️ 기술적 개선 사항
- **상태 결정론(STATE-DETERMINISM)**: 병합 전후의 엄격한 해시 기반 상태 검증 구현.
- **StateManager 리팩토링**: `generateMergedState`를 복잡한 다중 패스 루프에서 단일 패스 결정론적 분류 프로세스로 간소화.
- **FileScanner 강화**: `# [SYNAPSE] Atomic Logic Entry` 마커 탐지를 위한 정규표현식 신뢰도 극대화.
