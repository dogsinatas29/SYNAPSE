# 🚀 SYNAPSE v0.3.13 "Kinetic Stability" Release Notes

## 📅 Release Date: 2026-04-12
## 🏷️ Version: v0.3.13
## 🏗️ Status: ✅ Completed

---

## 🚀 Key Improvements

### 1. 🧬 Auto-Purge & Emergency Stabilization (Post-Explosion Fix)
- **Problem**: Accidental scanning of `node_modules` caused an explosion to 4,499+ nodes, polluting the User layer with thousands of README.md files.
- **Solution**: 
  - Implemented a **Hardened RuleEngine** that initializes exclusion rules immediately in the constructor.
  - Injected an **Emergency Purge Pipeline** in `StateManager` that automatically discards nodes from ignored paths (like `node_modules`), even if they were previously saved.
  - Fixed `BootstrapEngine.autoDiscover` to explicitly enforce exclusion rules before scanning.

### 2. ⚡ Kinetic Layout: Overlap Resolution
- **New Feature**: Added a **Grid-based Overlap Resolver** in the rendering engine.
- Automatically nudges nodes apart when they overlap in dense clusters (126+ nodes).
- Optimized for performance with O(N) grid checks and O(1) frame loop damping.

### 3. 🛡️ Icon Legacy Restoration
- Restored the classic **'B' (Broken)** and **'D' (Dependency)** signature badges on edges.
- Improved architectural clarity by verifying file signatures against visual markers.

### 4. 🔗 Global Context & TDZ Fixes
- Resolved a potential **Temporal Dead Zone (TDZ)** reference error in `renderEdge`.
- Reinforced **WebGLRenderer** global availability for seamless UI button interaction.

## 🇰🇷 한국어 릴리즈 노트

### 1. 🧬 자동 정화 및 긴급 안정화 (노드 폭주 해결)
- **문제**: `node_modules` 스캔 오류로 인해 노드 수가 4,499개로 폭증하고, 수천 개의 마크다운 파일이 사용자 레이어를 오염시켰습니다.
- **해결**:
  - `RuleEngine` 생성 시 제외 규칙을 즉시 활성화하여 방어선을 구축했습니다.
  - `StateManager`에 **긴급 정화 파이프라인**을 삽입하여, 이미 저장된 노드라도 `node_modules` 등 제외 경로에 속해 있다면 자동으로 삭제하도록 조치했습니다.
  - `autoDiscover` 루틴이 스캔 시작 전 반드시 규칙을 로드하도록 강제했습니다.

### 2. ⚡ 키네틱 레이아웃: 노드 겹침 해결
- **신규 기능**: 렌더링 엔진에 **격자 기반 노드 반발 로직**을 추가했습니다.
- 노드가 밀집된 구역(126개 이상)에서 노드들이 서로 겹치지 않도록 지능적으로 밀어내어 가시성을 확보합니다.

### 3. 🛡️ 레거시 아이콘 복구
- 엣지(Edge)에서 사용되던 기존의 **'B' (Broken)** 및 **'D' (Dependency)** 시그니처 배지를 복구했습니다.

### 4. 🔗 전역 컨텍스트 및 TDZ 오류 수정
- `renderEdge` 함수 내의 변수 참조 순서를 조정하여 TDZ 에러를 방지했습니다.
- `WebGLRenderer`의 전역 가시성을 강화하여 UI 버튼과의 연동 안정성을 높였습니다.
