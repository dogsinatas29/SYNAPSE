# 🚀 v0.3.14 Release Notes - Emergency Rendering & Purification Patch

## 📅 Released: 2026-04-13

---

### [English] 🛡️ Key Changes & Fixes

#### 1. System Purification (Context Vault Removal)
- **Feature Deprecation**: Completely removed the deprecated **Context Vault** (`.synapse_contexts`).
- **Data Hygiene**: Eliminated automatic logging of chat sessions and diagnostic bloat to harden architectural integrity. Purged legacy logic from `PromptLogger` and removed associated extraction tools.

#### 2. UI Rendering Recovery (SyntaxError Fix)
- **Critical Fix**: Resolved `Uncaught SyntaxError: Identifier 'cpX' has already been declared` in `canvas-engine.js`. 
- **Impact**: Restored the main rendering loop, fixing the "Blank Canvas" issue.

#### 3. State Synchronization Stability (TypeError Fix)
- **Robustness**: Fixed a `TypeError` occurring during self-healing synchronization when modifying frozen system cluster objects.
- **Implementation**: Updated `GraphModel.loadFrom` to use immutable object spreading for safe state updates.

#### 4. Ghost & Documentation Purification
- **Intelligent Routing**: Documentation files (Milestones, Release Notes) are now automatically routed to the `doc_shelf` cluster and hidden by default on the canvas to reduce noise.
- **Node Resolution**: Improved extension-aware logic to link ghost references (e.g., `canvas-engine`) to active physical files (`.js`).

#### 5. Visual Specification (Standardized Markers)
- **Standardization**: Formalized the 9-category visual marker system.
- **New Markers**: 
    - 💀 **Necrosis**: Fatal architectural violations (circular dependencies).
    - 🪦 **Tombstone**: Persistent deterministic failures.
    - 💣 **Mine**: High-hazard points with extreme destructive potential.

---

### [한국어] 🇰🇷 주요 변경 및 수정 사항

#### 1. 시스템 정화 (컨텍스트 볼트 제거)
- **기능 폐기**: 더 이상 사용되지 않는 **컨텍스트 볼트**(.synapse_contexts) 기능을 완전히 제거했습니다.
- **데이터 위생 격상**: 자동 채팅 로깅 및 진단용 가비지 데이터를 삭제하여 아키텍처의 순수성을 강화했습니다. `PromptLogger`의 레거시 로직을 제거하고 관련 추출 도구들을 삭제했습니다.

#### 2. UI 렌더링 복구 (SyntaxError 해결)
- **치명적 오류 수정**: `canvas-engine.js` 내 `renderEdge` 함수에서 발생하던 `cpX`, `cpY` 중복 선언 오류(`SyntaxError`)를 해결했습니다.
- **영향**: 메인 렌더링 루프를 복원하여 "빈 화면" 현상을 제거했습니다.

#### 3. 상태 동기화 안정화 (TypeError 해결)
- **안정성 강화**: 셀프 힐링 동기화 중 Frozen 상태의 시스템 클러스터 객체를 수정하려 할 때 발생하던 `TypeError`를 해결했습니다.
- **구현**: `GraphModel.loadFrom` 내에서 직접 수정 대신 객체 스프레드(spread) 방식을 사용하여 불변성을 유지하며 상태를 갱신하도록 처리했습니다.

#### 4. Ghost 및 문서 노드 정화 (Purification)
- **지능형 라우팅**: 마일스톤, 릴리즈 노트 등 문서 파일을 `doc_shelf` 클러스터로 자동 분류하고 캔버스에서 기본적으로 숨김 처리하여 시각적 노이즈를 제어합니다.
- **노드 해결 능력 향상**: `canvas-engine` 등 확장자가 생략된 참조를 실제 소스 파일(`.js`)로 지능적으로 연결합니다.

#### 5. 시각적 규격 통합 (표준 마커)
- **규격화**: 9개 카테고리의 통합 시각적 마커 시스템을 확립했습니다.
- **특수 마커 도입**:
    - 💀 **Necrosis (괴사)**: 순환 참조 등 아키텍처 치명적 위반 지점.
    - 🪦 **Tombstone (묘비)**: 복구 불가능한 결정론적 설계 오류 기록.
    - 💣 **Mine (지뢰)**: 수정 시 파급력이 매우 큰 위험 지점 경고.
