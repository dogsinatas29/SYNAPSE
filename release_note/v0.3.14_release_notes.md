# 🚀 v0.3.14 Release Notes - Emergency Rendering & Sync Patch

## 📅 Released: 2026-04-13

---

### [English] 🛡️ Key Fixes

#### 1. UI Rendering Recovery (SyntaxError Fix)
- **Problem**: The canvas was blank because of an `Uncaught SyntaxError: Identifier 'cpX' has already been declared`.
- **Solution**: Removed redundant variable declarations in `renderEdge` function within `canvas-engine.js`. This restores the main rendering loop and allows the UI to load correctly.

#### 2. State Synchronization Stability (TypeError Fix)
- **Problem**: "Self-healing sync failed" occurred because the system tried to modify read-only properties of frozen cluster objects.
- **Solution**: Updated `GraphModel.loadFrom` to use immutable update patterns (object spreading) when synchronizing system clusters. This prevents crashes during background data healing.

---

### [한국어] 🇰🇷 주요 수정 사항

#### 1. UI 렌더링 복구 (SyntaxError 해결)
- **문제**: `canvas-engine.js` 내에서 `cpX`, `cpY` 변수가 중복 선언되어 `SyntaxError`가 발생하고 화면에 아무것도 나오지 않는 현상이 있었습니다.
- **해결**: 중복된 선언을 제거하여 렌더링 루프를 정상화했습니다. 이제 캔버스가 다시 정상적으로 로드됩니다.

#### 2. 상태 동기화 안정화 (TypeError 해결)
- **문제**: 시스템 클러스터 정보를 업데이트할 때 Frozen된 객체의 속성을 직접 수정하려다 `TypeError`가 발생하여 백그라운드 동기화가 중단되었습니다.
- **해결**: `GraphModel.loadFrom` 로직을 개선하여 객체 직접 수정 대신 불변성 유지 방식(Object spread)으로 클러스터 정보를 갱신하도록 수정했습니다.
