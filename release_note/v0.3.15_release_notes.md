# 🚀 SYNAPSE v0.3.15 Release Notes

## 🇰🇷 Korean (한국어)

### 🔍 Documentation Shelf fzf (Fuzzy Search)
문서 노드를 빠르게 찾고 이동할 수 있는 고속 탐색 시스템을 도입했습니다.
- **단축키**: `/` 키를 눌러 어디서든 문서 검색창을 바로 띄울 수 있습니다.
- **Center-on**: 검색 결과 클릭 시 해당 노드로 시점이 즉시 이동하며, 황금색 글로우(Gold Glow) 하이라이트 효과가 발생합니다.
- **Enter Selection**: 검색창에서 `Enter` 입력 시 첫 번째 결과로 즉시 이동합니다.
- **Fuzzy Matching**: 오타나 부분 검색어만으로도 관련 문서를 정확하게 찾아냅니다.

### 🔳 Grid Sovereignty (좌표 규격화) & Kinetic Repulsion (수직 압축)
캔버스의 시각적 질서를 확립하기 위해 전면적인 그리드 스냅 시스템을 적용했습니다.
- **40px Grid Snap**: 모든 노드 드래그 종료 시 좌표가 40px 단위로 자동 보정됩니다.
- **Zero Entropy**: 미세하게 비뚤어진 노드 배치를 방지하여 아키텍처의 정갈함을 유지합니다.
- **Snap-back Stalemate Resolution**: 노드 자동 겹침 방지(Repel) 로직이 동작할 때 밀려난 거리가 무효화되어 제자리로 튕겨오는 버그를 수정하여, 그리드 정렬과 레이아웃 분산이 완벽히 호환되도록 구성했습니다.
- **Vertical Compression (80px)**: 겹침 방지 세로 간격을 80px로 축소하여, 40px 그리드 정렬을 유지하면서 세로 공간을 33% 더 밀도 있게 사용하도록 개선했습니다.
- **Two-Way Implementation**:
  - **Frontend**: 드래그 종료 시 UI에서 즉시 그리드 좌표로 보정하여 시각적 피드백 제공.
  - **Extension Host**: `project_state.json` 저장 시 최종 좌표를 다시 한번 검증하여 데이터 무결성 보장.

### 🛠️ Internal Changes
- `src/webview/CanvasPanel.ts`: 상태 저장 로직(`handleSaveState`)에 그리드 시스템 통합.
- `ui/canvas-engine.js`: 
  - `GRID_SNAP_SIZE` 상수 도입 및 상호작용 로직 최적화.
  - `resolveOverlaps`의 `MIN_DISTANCE` 변수(X: 160, Y: 80) 최적화로 버그 수정.
  - `renderDocShelfList` 고도화 및 하이라이트 파이프라인 추가.
  - `toggleSearchShelf` 및 `/` 경로 단축키 핸들러 구현.
- `src/extension.ts`: `synapse.searchShelf` 전역 명령 등록.

## 🇺🇸 English

### 🔍 Documentation Shelf fzf (Fuzzy Search)
Introduced a high-speed navigation system to rapidly locate and teleport to documentation nodes.
- **Shortcut**: Press `/` anywhere to instantly open the documentation search bar.
- **Center-on**: Clicking or selecting a search result instantly teleports the view to that node, alongside a 2-second Gold Glow highlight.
- **Enter Selection**: Pressing `Enter` in the search bar immediately selects and teleports to the top result.
- **Fuzzy Matching**: Accurately finds relevant documents even with typos or partial keywords.

### 🔳 Grid Sovereignty & Kinetic Repulsion
Applied a comprehensive grid snapping system to establish visual order across the canvas.
- **40px Grid Snap**: Node coordinates are automatically normalized to a 40px grid upon dropping.
- **Zero Entropy**: Maintains architectural neatness by preventing microscopic misalignments.
- **Snap-back Stalemate Resolution**: Fixed a bug where nodes would bounce back to their original overlapped coordinates during automatic collision resolution, ensuring that grid snapping and layout spreading now work in perfect harmony.
- **Vertical Compression (80px)**: Tightened the vertical repel distance to 80px. This allows nodes to be packed 33% denser vertically while perfectly snapping to the 40px grid.
- **Two-Way Implementation**:
  - **Frontend**: UI immediately snaps coordinates on drag-end for visual feedback.
  - **Extension Host**: Redundantly verifies and enforces grid coordinates before saving to `project_state.json` to guarantee data integrity.

### 🛠️ Internal Changes
- `src/webview/CanvasPanel.ts`: Integrated the grid system into the state persistence logic (`handleSaveState`).
- `ui/canvas-engine.js`: 
  - Introduced `GRID_SNAP_SIZE` constant and optimized interaction logic.
  - Optimized `resolveOverlaps` logic with grid-aware `MIN_DISTANCE` constants (X: 160, Y: 80) to fix the snap-back bug.
  - Enhanced `renderDocShelfList` and added the highlight pipeline.
  - Implemented `toggleSearchShelf` and bounded the `/` shortcut handler.
- `src/extension.ts`: Registered the `synapse.searchShelf` global command.
