# 🚀 SYNAPSE Release Notes - v0.3.16

## [v0.3.16] - 2026-04-14 - Minimalist Logic View

### 🇺🇸 English
#### "If you can't see it, it doesn't overlap."
This version introduces the **Minimalist Logic View**, allowing users to reclaim canvas clarity by toggling edge and badge visibility. It focuses on the architectural principle that visual silence enhances analytical focus.

- **Edge Visibility Control**: New 'View' menu options to toggle "All Visible", "Badges Hidden", and "Edges Hidden".
- **Path Highlighting**: Even when edges are hidden, selecting or hovering over a node reveals its incoming/outgoing connections with a subtle 0.3 alpha transparency.
- **O(1) Rendering Performance**: Optimized the WebGL and 2D Canvas render loops to bypass hidden elements without complex array filtering, ensuring 60FPS even in dense graphs.
- **Badge Unification**: Fixed the "Doubled Icons" bug by consolidating multiple redundant edge markers into a single, high-density info capsule (`🔗 ✅`).
- **Hybrid Sync**: Synchronized 2D overlay and WebGL text layering to prevent visual flickering during semantic zoom transitions.

---

### 🇰🇷 한국어
#### "보이지 않으면 겹치지도 않는다."
이번 버전에서는 사용자가 엣지와 배지의 가시성을 직접 제어할 수 있는 **미니멀리스트 로직 뷰**를 도입했습니다. 시각적 침묵이 분석적 집중력을 높여준다는 아키텍처 원칙을 반영했습니다.

- **엣지 가시성 제어**: 'View' 메뉴를 통해 "모두 보기", "배지 숨김", "엣지 숨김" 모드를 자유롭게 전환할 수 있습니다.
- **경로 하이라이트**: 엣지가 숨겨진 상태에서도 특정 노드를 선택하거나 호버링하면, 해당 노드와 연결된 선들이 0.3 투명도로 부드럽게 나타나 논리적 연결성을 유지합니다.
- **O(1) 렌더링 성능**: 숨겨진 요소들을 WebGL 및 2D Canvas 루프에서 배열 재할당 없이 즉시 스킵하도록 최적화하여 밀집도가 높은 그래프에서도 60FPS를 유지합니다.
- **배지 통합 (Unification)**: 기존의 여러 아이콘이 중복으로 출력되던 버그를 수정하고, 하나의 고밀도 정보 캡슐(`🔗 ✅`)로 통합하여 시각적 간섭을 제거했습니다.
- **하이브리드 동기화**: 2D 오버레이와 WebGL 텍스트 레이어를 동기화하여 시맨틱 줌 전환 시 발생하는 깜빡임(Flickering) 현상을 해결했습니다.
