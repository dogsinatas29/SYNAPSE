## 🇰🇷 Korean Version

### 📦 주요 변경 사항

#### 1. 노드 요약 정보 출력 (Node Summary Tooltip) 🔍
- 특정 노드에 마우스 호버 시 해당 노드의 연결성 지표를 실시간으로 요약하여 보여주는 툴팁 기능을 추가했습니다.
- **출력 항목:**
  - **Node:** 노드 이름 (Label)
  - **Connections:** 중복을 제외한 고유 연결 노드 수 (Unique Degree)
  - **IN:** 해당 노드로 들어오는 의존성 수 (In-degree)
  - **OUT:** 해당 노드에서 나가는 의존성 수 (Out-degree)

#### 2. 성능 최적화 (Performance & Caching) ⚡
- **O(E) 단일 순회 알고리즘:** 모든 노드의 통계를 엣지 데이터 1회 순회로 계산하여 연산 비용을 최소화했습니다.
- **상태 기반 캐싱:** `loadProjectState` 시점에 전체 통계를 미리 계산하여 `nodeStatsMap`에 캐싱함으로써, 마우스 이동 시의 오버헤드를 제거했습니다. (KISS 원칙 준수)

#### 3. 시각적 가독성 개선 🎨
- 4줄의 간결한 텍스트 구성을 통해 복잡한 그래프 내에서 특정 노드의 역할(책임 집중 vs 의존 집중)을 즉각적으로 파악할 수 있도록 개선했습니다.

## 🇺🇸 English Version

### 📦 Key Changes

#### 1. Node Summary Tooltip 🔍
- Added a tooltip feature that summarizes connectivity metrics for a specific node in real-time when hovered.
- **Display Items:**
  - **Node:** Node name (Label)
  - **Connections:** Number of unique connected nodes (Unique Degree)
  - **IN:** Incoming dependency count (In-degree)
  - **OUT:** Outgoing responsibility count (Out-degree)

#### 2. Performance & Caching ⚡
- **O(E) Single-pass Algorithm:** Calculated stats for all nodes by traversing edge data once to minimize computational cost.
- **State-based Caching:** Pre-calculated all stats during `loadProjectState` and cached them in `nodeStatsMap` to eliminate overhead during mouse movement. (Adhering to KISS principle)

#### 3. Visual Readability Improvements 🎨
- Improved the ability to instantly identify a node's role (responsibility focus vs. dependency focus) within complex graphs through a concise 4-line text layout.

## 🛠️ 기술적 세부 사항 / Technical Details
- `CanvasEngine` class: Added `nodeStatsMap` property.

## ⚠️ 주의 사항 / Precautions
- Initial stat calculation might cause a slight delay if massive edge data (10,000+) is loaded, but hover interaction remains O(1) using the cache.
