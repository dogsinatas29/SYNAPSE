# 🚀 v0.3.18 Release Notes - Diagnostic Hint Engine

## 📅 Release Date: 2026-04-17
## 🎯 주요 업데이트

### 1. Diagnostic Hint Engine 구현
- 노드의 연결 수치와 레이어 분포를 분석하여 아키텍처 개선 힌트를 제공하는 엔진을 구현했습니다.
- **Rule 기반 진단**:
    - **R1 (Multi-Domain)**: 관심사 분리 실패 감지 (연결 그룹 ≥ 3)
    - **R2 (Concentration)**: 특정 레이어 강결합 감지 (집중도 ≥ 70%)
    - **R3 (High Fan-out)**: 책임 과다 감지 (출력 비율 ≥ 70%)
    - **R4 (High Fan-in)**: 병목 지점 감지 (입력 비율 ≥ 70%)
    - **R5 (Super Node)**: 복잡도 임계점 감지 (연결 수 ≥ 30)

### 2. 레이어 분포 분석 (Distribution Analysis)
- 노드가 어떤 레이어(Cluster)와 주로 소통하는지 실시간으로 집계합니다.
- 상위 3개 주요 분포 레이어를 요약 UI에 표시합니다.

### 3. Node Summary UI 개선
- 기존의 단순 연결 수치 표시에서 **Top Distribution** 및 **Hints** 섹션을 추가했습니다.
- 시각적 가독성을 위해 색상 구분 및 레이아웃을 최적화했습니다.

## 🛠️ 기술적 세부 사항
- `src/analysis/hintEngine.ts`: 진단 규칙 상수를 정의하고 재사용 가능한 엔진 로직을 분리했습니다.
- `ui/canvas-engine.js`: 프론트엔드에서 노드 통계 계산 시 분포 집계 및 힌트 생성 로직을 통합하여 실시간 응답성을 확보했습니다.
- **성능 최적화**: 엣지 전수 조사를 피하기 위해 `loadProjectState` 시 1회 계산 및 캐싱을 유지하며, 분포 역시 O(E) 복잡도로 효율적으로 처리합니다.

## ⚠️ 주의 사항
- 최소 연결 수(5개) 미만의 노드는 노이즈 방지를 위해 힌트 생성이 생략됩니다.
- 익명 클러스터나 정의되지 않은 그룹은 'unknown'으로 분류되어 설계 누락을 암시합니다.
