# 🚀 SYNAPSE Release Notes - v0.3.18
**Release Date:** 2026-04-17
**Focus:** Triple Expression System & Node Role Taxonomy

---

## 🌟 Overview
v0.3.18 버전은 단순한 시각화 툴을 넘어 '아키텍처 인텔리전스'로의 전환을 마쳤습니다. 각 노드를 정적/동적 지표에 따라 분류하고, 색상(Color)-레이어(Layer)-우선순위(Priority) 삼중 체계를 통해 사용자의 인지 부하를 혁명적으로 낮췄습니다.

## ✨ Key Improvements

### 1. Triple Expression System (인지-집중-판단)
- **🎨 Color (정체성 인지)**:
  - 노드 역할에 따른 고유 테두리 및 글로우 미분 적용.
  - 주황(Orchestrator), 초록(Controller), 파랑(Hub), 회색(Leaf)을 통한 즉각적인 정체성 식별.
- **🛠️ Layer (노이즈 필터)**:
  - `Hide Leaf Nodes` 토글 기능 도입.
  - 구조적 복잡함을 유발하는 리프 노드와 연관 엣지를 즉시 숨겨 핵심 아키텍처에 집중 가능.
- **⭐ Priority (정량적 판단)**:
  - 4단계 별점(`★★★☆`) 시스템을 통한 리팩토링 및 분석 우선순위 가시화.
  - 연결 밀도와 인/아웃 비율을 종합한 객관적 지표 제공.

### 2. Node Role Taxonomy (정립)
- **Single Role Principle**: 하나의 노드에 하나의 역할만 부여하여 정체성 혼선 방지.
- **Architectural Identity**: `Orchestrator`, `Controller`, `Hub`, `Leaf`로 정의된 시맨틱 라벨을 통해 설계 의도를 명확히 전달.

### 3. Engine Stability & Hygiene
- **Critical Rendering Patch**: `renderEdge` 함수 내 SyntaxError 및 변수 누락 문제를 해결하여 렌더링 파이프라인 정상화.
- **Data Integrity**: `getGroupLabel` 로직을 단일화하여 상세 연결 리스트 데이터의 정확성 100% 확보.

## ⚠️ Known Issues & Next Steps
- **Global Exploration**: 현재 시스템은 특정 노드 중심의 로컬 분석에 최적화되어 있습니다. 전체 시스템 맥락에서의 탐색 및 흐름 추적 기능을 차기 버전의 핵심 과제로 선정하였습니다.
