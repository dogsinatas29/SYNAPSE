# 🚀 v0.3.18 Release Notes - Diagnostic Hint Engine

## 📅 Release Date: 2026-04-17
## 🎯 주요 업데이트 / Key Updates

### 1. Diagnostic Hint Engine 구현 / Diagnostic Hint Engine Implementation
*   **[KO]** 노드의 연결 수치와 레이어 분포를 분석하여 아키텍처 개선 힌트를 제공하는 엔진을 구현했습니다.
*   **[EN]** Implemented a diagnostic engine that analyzes node connectivity and layer distribution to provide architectural refactoring hints.
*   **Rule 기반 진단 / Rule-Based Diagnostics**:
    *   **R1 (Multi-Domain)**: 관심사 분리 실패 감지 / Interest separation failure detection.
    *   **R2 (Concentration)**: 특정 레이어 강결합 감지 / Tight coupling to a specific layer.
    *   **R3 (High Fan-out)**: 출력 책임 과다 감해 / Excessive outbound responsibility.
    *   **R4 (High Fan-in)**: 병목 지점 감지 / System bottleneck detection.
    *   **R5 (Super Node)**: 복잡도 임계점 감지 / Complexity threshold reached (30+).

### 2. 레이어 분포 및 정체 분석 / Layer Distribution & Identity Analysis
*   **[KO]** 'Zero-Unknown' 원칙을 적용하여 `unknown` 라벨을 제거하고, `external (pathlib)`과 같이 구체적인 정체를 노출합니다.
*   **[EN]** Applied the 'Zero-Unknown' principle to eliminate generic labels and reveal specific node identities like `external (pathlib)`.

### 3. Node Summary UI 개선 / Node Summary UI Enhancements
*   **[KO]** 툴팁 내에 Top Connections 상세 리스트와 한글화된 아키텍처 힌트(심각도 표시 포함)를 추가했습니다.
*   **[EN]** Added a detailed "Top Connections" list and localized architectural hints (including severity markers) to the tooltip.

## 🛠️ 기술적 세부 사항 / Technical Details
*   **[KO]** `src/analysis/hintEngine.ts`에 로컬라이징 맵과 심각도 로직을 통합했습니다.
*   **[EN]** Integrated localization maps and severity-based logic into `src/analysis/hintEngine.ts`.
*   **[KO]** 프론트엔드 툴팁 간섭 방지 로직과 성능 최적화(O(E) 캐싱)를 완료했습니다.
*   **[EN]** Completed frontend tooltip collision prevention and performance optimization (O(E) caching).
