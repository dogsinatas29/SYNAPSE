# 🚀 SYNAPSE Release Notes - v0.3.18

**Release Date:** 2026-04-17
**Focus:** Triple Expression System & Node Role Taxonomy

---

## 🌟 Overview / 개요
**[EN]** v0.3.18 marks the transition from simple visualization to 'Architecture Intelligence'. By classifying nodes based on static/dynamic metrics, we've implemented the **Triple Expression System (Color-Layer-Priority)** to radically reduce user cognitive load.

**[KO]** v0.3.18 버전은 단순한 시각화 툴을 넘어 '아키텍처 인텔리전스'로의 전환을 마쳤습니다. 각 노드를 정적/동적 지표에 따라 분류하고, **색상(Color)-레이어(Layer)-우선순위(Priority)** 삼중 체계를 통해 사용자의 인지 부하를 혁명적으로 낮췄습니다.

---

## ✨ Key Improvements / 주요 개선 사항

### 1. Triple Expression System (인지-집중-판단)
- **🎨 Color (Perception / 정체성 인지)**:
  - **[EN]** Applied unique border/glow colors based on role: **Orange (Orchestrator)**, **Green (Controller)**, **Blue (Hub)**, **Gray (Leaf)**.
  - **[KO]** 역할별 고유 테두리 및 글로우 미분 적용: **주황(Orchestrator)**, **초록(Controller)**, **파랑(Hub)**, **회색(Leaf)**.
  
- **🛠️ Layer (Noise Filter / 노이즈 필터)**:
  - **[EN]** Introduced `Hide Leaf Nodes` toggle to eliminate structural noise and focus on core architectural paths.
  - **[KO]** `Hide Leaf Nodes` 토글 기능 도입으로 구조적 복잡함을 유발하는 리프 노드를 숨겨 핵심 아키텍처에 집중 가능.

- **⭐ Priority (Judgment / 정량적 판단)**:
  - **[EN]** Implementation of a 4-star (`★★★☆`) system to indicate refactoring and analysis priority.
  - **[KO]** 4단계 별점(`★★★☆`) 시스템을 통해 리팩토링 및 분석 우선순위 가시화.

### 2. Node Role Taxonomy (정립)
- **Single Role Principle**: 
  - **[EN]** Prevents identity confusion by ensuring each node is assigned exactly one primary role (e.g., a node cannot be both an Orchestrator and a Leaf).
  - **[KO]** 하나의 노드에 하나의 역할만 부여하여 정체성 혼선 방지 (역할 환각 방지).
- **Architectural Identity**: 
  - **[EN]** Clearly communicates design intent via semantic labels.
  - **[KO]** 시맨틱 라벨을 통해 설계 의도를 명확히 전달.

### 3. Engine Stability & Hygiene (안정성 및 정합성)
- **Critical Rendering Patch**: 
  - **[EN]** Resolved SyntaxError and missing variable declarations in `renderEdge` function.
  - **[KO]** `renderEdge` 함수 내 SyntaxError 및 변수 누락 문제를 해결하여 렌더링 파이프라인 정상화.
- **Data Integrity**: 
  - **[EN]** Unified `getGroupLabel` logic to ensure 100% accuracy in connection detail lists in tooltips.
  - **[KO]** `getGroupLabel` 로직을 단일화하여 툴팁 내 상세 연결 리스트 데이터의 정합성 100% 확보.

## ⚠️ Known Issues & Next Steps (향후 과제)
- **Global Exploration**: 
  - **[EN]** Current system is optimized for local node analysis. Expanding to 'Global Exploration' for tracing end-to-end flows is our next major goal.
  - **[KO]** 현재 시스템은 특정 노드 중심의 로컬 분석에 최적화되어 있습니다. 전체 시스템 맥락에서의 글로벌 탐색 및 흐름 추적 기능을 차기 주요 과제로 선정하였습니다.
