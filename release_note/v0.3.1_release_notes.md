# 🚀 Release Notes - v0.3.1 "Bootstrap Locked"

## 🇰🇷 한글 요약 (Korean Summary)

### 🛡️ 핵심 변경 사항: 시스템 단계 강제 및 UI 보안 강화
이번 버전에서는 시스템 초기화의 7단계를 강제하는 Phase-based 초기화 시스템(`PhaseManager`)을 도입하여 엔진의 안정성을 극대화했습니다. 또한, 보안과 리소스 최적화를 위해 Context Vault UI를 전면 차단했습니다.

1. **Phase-based 초기화 (Phase 0-7)**:
    - 데이터 파이프라인(Phase 0)부터 시스템 검증(Phase 7)까지의 모든 단계가 순차적으로 통과되어야 엔진이 활성화됩니다.
    - 단계 실패 시 다음 단계 진입을 차단하는 **System Lock** 기능을 통해 런타임 무결성을 보장합니다.
2. **Context Vault UI Lockdown**:
    - 사이드바(Explorer) 및 캔버스 내 Context Vault 관련 모든 UI(드롭다운, 클러스터, 버튼)를 숨김/비활성화 처리했습니다.
    - 불필요한 리소스 생성을 막기 위해 관련 로직을 격리했습니다.
3. **UX 개선 및 시각적 정규화**:
    - 상태 오버레이(#phase-overlay)와 DTR 컨트롤러에 드래그 기능을 추가했습니다.
    - Necrosis(💀), Tombstone(🪦) 아이콘 및 배지 스타일을 2D/3D(WebGL) 환경 모두에서 동일하게 정규화했습니다.

## 🇺🇸 English Summary

### 🛡️ Key Changes: System Phase Enforcement & UI Security Lockdown
Version 0.3.1 introduces a strict 7-phase initialization protocol (`PhaseManager`) to maximize engine stability. Additionally, the Context Vault UI has been fully restricted for enhanced security and resource optimization.

1. **Phase-based Initialization (Phases 0-7)**:
    - The engine now follows a mandatory sequence from Data Pipeline (Phase 0) to System Validation (Phase 7).
    - Features a **System Lock** mechanism that halts execution if any preceding phase fails to verify.
2. **Context Vault UI Lockdown**:
    - Removed all Context Vault entry points from the sidebar (Explorer) and canvas menus.
    - Disabled automatic directory creation and associated commands (`flushLogs`, `manualPbScan`) to minimize overhead.
3. **UX Refinement & Visual Standardization**:
    - Implemented draggable status overlays for the Phase Debugger and DTR Controller.
    - Standardized icons for Necrosis (💀), Tombstone (🪦), and Edge badges across both 2D and 3D (WebGL) rendering paths.
