# 🚀 SYNAPSE v0.3.1 Release Notes - "Bootstrap Locked"

## [Status: Verified by Commander]

## 📅 배포 일시: 2026.03.31
## 🛠️ 주요 변경 사항

### 1. Runtime Phase Enforcement (0-6 Complete)
- 시스템 초기화 과정을 7개 단계로 강제하는 `PhaseManager` 도입 및 통합 완료.
- **Phase 0 (DATA)**: 파일 정규화 및 파이프라인 가동.
- **Phase 1 (GRAPH)**: `NodeType` Enum 도입을 통한 타입 안전성 확보.
- **Phase 2 (SNAPSHOT)**: 로컬 파일 기반 영구 저장 및 복구(Persistence) 시스템 구축.
- **Phase 3 (CONTROL)**: 16ms 주기의 안정적인 이벤트 루프 및 Sovereign Interaction 검증.
- **Phase 4 (GRID)**: 40px Snap-to-Grid 및 소스/문서 영역 분리 레이아웃.
- **Phase 5 (RENDER)**: 부하에 따른 Dynamic Threshold(0.5 ~ 0.9) 필터링 및 버젯 리포트.
- **Phase 6 (DEBUG)**: 실시간 시스템 상태 시각화 오버레이(Diagnostic Overlay) 탑재.

### 🎯 Hotfix: sendProjectState Phase Violation 해결
- **이슈**: 기존 `sendProjectState`가 Phase 1(GRAPH)과 2(SNAPSHOT)를 건너뛰고 바로 Phase 3(CONTROL)에 진입하려 하여 시스템이 `LOCKED` 되는 문제 해결.
- **해결**: `CanvasPanel.sendProjectState` 내부에 명시적인 Phase 0, 1, 2 동기화 로직 추가.
- **결과**: `No valid snapshot` 에러 해결 및 데이터 파이프라인 무결성 보장.

### 2. Performance & Stability
- **Iron Grid Refined**: 결정론적 레이아웃 보장으로 동일 데이터에 대해 항상 일관된 뷰 제공.
- **CPU Protection**: 대규모 그래프 데이터 처리 시 렌더링 예산 자동 조정으로 브라우저 크래시 방지.
- **Tick Latency**: 모든 프레임 처리를 O(1) 혹은 O(log N) 수준으로 최적화하여 60FPS 지향.

### 3. Core Modules Updated
- `src/core/PhaseManager.ts`: 상태 전이 제어.
- `src/core/ControlSystem.ts`: 인터렉션 게이트키퍼.
- `src/core/GridSystem.ts`: Snap-to-Grid 유틸리티.
- `src/core/RendererCore.ts`: 동적 필터링 엔진.
- `src/core/DebuggerSystem.ts`: 시스템 진단 도구.
- `src/webview/CanvasPanel.ts`: Phase 통합 렌더링 파이프라인.

### 4. UI/UX Refinement
- **Context Vault Lockdown**: 
    - 불필요한 정보 노출 방지를 위해 사이드바 및 캔버스 클러스터에서 Context Vault UI를 완전히 제거하였습니다.
    - 웹뷰 상단 툴바(Main Menu)의 "⏺ Context" 드롭다운과 "View" 메뉴 내의 진입점 버튼을 전부 숨김 처리하여 사용자의 혼선을 방지했습니다.
    - `.synapse_contexts/` 디렉터리 자동 생성 및 관련 명령(flushLogs, manualPbScan)을 비활성화하여 리소스 낭비를 방지했습니다.
- **Draggable Status Overlay**: 
    - 화면 상단의 시스템 상태 오버레이(#phase-overlay)를 드래그 앤 드롭으로 이동 가능하도록 개선하였습니다.
    - `makeDraggable` 유틸리티 기능을 강화하여 절대 좌표 기반의 자유로운 UI 배치를 지원하며, Inference Pressure 컨트롤러(#dtr-controller)에도 동일 기능을 적용했습니다.

### 5. Validation
- `SystemValidation.test.ts`를 통한 전 단계 Phase 전이 및 락(Lock) 로직 검증 완료.
- Context Vault UI 비활성화에 따른 캔버스 렌더링 무결성 확인.

## ⚠️ 주의 사항
- **System Lock**: 부적절한 Phase 점프나 데이터 위변조 탐지 시 시스템이 즉시 `LOCKED` 상태로 전환될 수 있습니다. 이 경우 `synapse.resetEngine`을 수행하십시오.
- **Persistence**: Snapshot은 프로젝트 루트의 `data/synapse_history.json`에 저장됩니다.
