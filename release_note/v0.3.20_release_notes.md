🚀 SYNAPSE v0.3.20 Release Notes - Rust Persistence & Stability hardening

## 🇰🇷 Korean

### 1. Rust 프로젝트 완벽 지원 (Persistence)
- **경로 기반 ID 체계 도입**: 기존 파일명 기반 ID에서 물리적 경로(`filePath`) 기반 체계로 전면 전환했습니다. 이를 통해 Rust 프로젝트의 `mod.rs`, `lib.rs`와 같은 중복 파일명 충돌 문제를 완벽히 해결했으며, 대규모 프로젝트에서도 고유한 노드 식별이 가능해졌습니다.
- **Rust 파싱 엔진 고도화**: `use a::b::{c, d};`와 같은 다중 참조 구문 및 `pub mod` 선언을 인식하여 정교한 모듈 의존성 그래프를 생성합니다.

### 2. 시뮬레이션 및 물리 안정화
- **Align Architecture 버튼 기능 정상화**: "반응 없음"으로 보고된 아키텍처 정렬 기능의 시뮬레이션 루틴을 엔진 렌더 루프에 통합했습니다. 이제 클릭 시 엔진이 수면 모드에서 즉시 깨어나 노드들을 역할별로 재배치합니다.
- **물리 안정성 확보 (Velocity Clamping)**: 정렬 정렬 시 노드가 비정상적으로 가속되어 화면 밖으로 튕겨나가는 현상을 방지하기 위해 최대 속도 제한 및 감쇄 로직을 강화했습니다.

### 3. 렌더링 및 UI 안정성 강화
- **크래시 방지 시스템**: 클러스터 라벨이나 역할 정보가 누락되었을 때 렌더링 루프가 멈추던 `TypeError`를 해결했습니다.
- **공격적 로딩 UI 처리**: 데이터 로딩이 완료되면 즉시 `Loading...` 오버레이를 제거하여 UX 정체를 해소했습니다.
- **Role 감지 로직 고도화**: 소규모 프로젝트에서도 역할이 누락되지 않도록 임계값을 조정하고 기본 분류를 추가했습니다.

## 🇺🇸 English

### 1. Robust Rust Support (Persistence)
- **Path-based ID System**: Transitioned from filename-based IDs to physical path-based (`filePath`) IDs. This completely resolves naming conflicts in Rust projects (e.g., multiple `mod.rs` or `lib.rs` files) and ensures unique node identification in large-scale repositories.
- **Advanced Rust Parser**: Enhanced parsing for multi-import statements like `use a::b::{c, d};` and `pub mod` declarations to generate high-fidelity dependency graphs.

### 2. Simulation & Physics Hardening
- **Fixed Align Architecture Function**: Resolved the "no response" issue by integrating the alignment simulation routine into the core render loop. The engine now wakes immediately upon interaction to re-layout nodes.
- **Velocity Clamping & Damping**: prevent nodes from "exploding" or bouncing off-screen by implementing explicit velocity caps and increased damping factors.

### 3. Rendering & UI Stability
- **Crash Prevention**: Fixed `TypeError` crashes caused by missing cluster labels or role definitions, ensuring an uninterrupted rendering loop.
- **Aggressive Loading UI Cleanup**: Immediate removal of the `Loading...` overlay once data load completes for a smoother user experience.
- **Inclusive Role Detection**: Refined diagnostic thresholds and added a `Standard component` fallback to ensure every node has a meaningful architectural identity.
