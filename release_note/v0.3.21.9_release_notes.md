# Release Notes - v0.3.21.9

## 🚀 Accel Parity & Hybrid Badge Core

가속 모드(WebGL)와 기본 모드(2D) 간의 시각적 경험을 완벽하게 동기화하고, 노드 상태 정보를 강화했습니다.

### 🔍 주요 변경 사항

#### 1. WebGL Semantic Icon Engine 강화
- `webgl-renderer.js`에 `getSemanticIcon` 로직을 이식하여 가속 모드에서도 노드 타입별 정밀한 아이콘(⚙️, 📡, ↻, ◈ 등)이 표시됩니다.
- 기존의 단순한 아이콘 판별 방식을 2D 엔진과 동일한 시맨틱 분석 방식으로 교체했습니다.

#### 2. Hybrid Badge Rendering 파이프라인 구축
- `canvas-engine.js`에 `renderNodeBadges`를 구현하여 노드 위에 상태 배지를 2D Canvas로 덧그리는 하이브리드 방식을 도입했습니다.
- **승인 상태**: ✅ (Approved), 🤖 (AI Generated)
- **위험 상태**: ⚠️ (Warning), 💣 (Critical/Necrosis)
- **보안 상태**: 🔒 (Locked/Protected)
- 가속 모드(Accel: ON) 상태에서도 이러한 중요 마커들이 누락 없이 고해상도로 렌더링됩니다.

#### 3. 시각적 일관성 (Visual Parity)
- 2D와 WebGL 간의 아이콘 매핑 로직을 단일화하여 모드 전환 시 시각적 튐 현상을 제거했습니다.
- 줌 레벨에 따른 LOD(Level of Detail) 연동을 강화했습니다.

### 🛠️ 기술 세부 사항
- `ui/webgl-renderer.js`: `getSemanticIcon(node)` 메서드 추가 및 `updateTextData` 리팩토링.
- `ui/canvas-engine.js`: `renderNodeBadges(node, x, y, zoom)` 메서드 추가 및 하이브리드 루프 최적화.

### ⚠️ 주의 사항
- 이모지 폰트 렌더링을 위해 시스템 폰트 스택(`Noto Color Emoji`, `Apple Color Emoji` 등)을 우선 사용합니다.
