# 🚀 SYNAPSE Release Notes - v0.3.21
## 📅 Release Date: 2026-04-18

---

### [English] 🇺🇸

#### **Key Highlights: Edge Bundling & Zero-Config UX**
This release focuses on visual clarity, seamless onboarding, and state reliability. We've transformed the spaghetti-like dependencies into elegant bundled flows and removed the friction of manual configuration.

#### **1. Visual Consistency & Convention Sync**
- **Semantic Edge Colors**: Restored type-based colors (Dependency: Beige, API: Aqua, DB: Magenta) by removing the global green override for confirmed edges.
- **Intelligent Node Badges**: Implemented real-time status badges on nodes (✅ Confirmed, 🤖 AI Validated, ❓ Pending, ❌ Purge, 🔒 Locked).
- **Hazard Markers**: Added visual indicators for high-risk points (💣 Mine) and architectural faults (⚠️).
- **Semantic Mappings**: New node types and icons for **Signal (📡)**, **Payload (📊)**, and **Async (🕒)** flows.

#### **2. Edge Bundling Lite (Bezier Convergence)**
- **Visual Clarity**: Replaced straight lines with quadratic Bezier curves that converge toward shared arcs.
- **Performance**: Optimized O(1) per-frame calculation with `isFinite` math protection.

#### **3. Zero-Config Onboarding**
- **Instant Access**: The 🧠 Canvas button is now available in the editor title bar for all file types.
- **Auto-Discovery**: If no state is detected, SYNAPSE automatically offers "Lite Bootstrap" to scan your project instantly.

### [Korean] 🇰🇷

#### **1. 시각적 일관성 및 규격 동기화**
- **시맨틱 엣지 색상**: 확정된 엣지의 일괄 녹색 표시 버그를 해결하여, 타입별 고유 색상(의존성: 베이지, API: 아쿠아, DB: 마젠타)을 완벽히 복구했습니다.
- **지능형 노드 배지**: 노드 상단에 실시간 상태 배지(✅ 승인됨, 🤖 AI 검증됨, ❓ 대기중, ❌ 삭제대상, 🔒 잠금됨)를 도입했습니다.
- **위험 마커**: 고위험 지점(💣 지뢰) 및 아키텍처 결함(⚠️) 시각적 표시기를 추가했습니다.
- **시맨틱 매핑**: **시그널(📡)**, **페이로드(📊)**, **비동기(🕒)** 흐름을 위한 전용 노드 타입 및 아이콘을 지원합니다.

#### **2. 엣지 번들링 라이트 (베지어 수렴)**
- **시각적 명확성**: 직선을 2차 베지어 곡선으로 교체하고 공통 아크로 수렴시켜 시각적 노이즈를 획기적으로 줄였습니다.

#### **3. 제로-컨피그 온보딩**
- **즉시 접근**: 이제 어떤 파일 확장자에서도 에디터 상단의 🧠 캔버스 아이콘을 통해 즉시 진입할 수 있습니다.
- **자동 분석**: 데이터가 없는 프로젝트에서 자동으로 "Lite Bootstrap"을 제안하여 수동 설정 없이 아키텍처를 스캔합니다.

- Added `Emergency Fallback Principles` for Projects without `GEMINI.md`.
- Lowered bundling threshold to 20 edges for consistent visual feedback.
- Standardized Ghost Node path delimiters to prevent edge evaporation.
