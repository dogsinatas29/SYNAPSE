# 🚀 SYNAPSE Release Notes - v0.3.21
## 📅 Release Date: 2026-04-18

---

### [English] 🇺🇸

#### **Key Highlights: Edge Bundling & Zero-Config UX**
This release focuses on visual clarity, seamless onboarding, and state reliability. We've transformed the spaghetti-like dependencies into elegant bundled flows and removed the friction of manual configuration.

#### **1. Edge Bundling Lite (Bezier Convergence)**
- **Visual Clarity**: Replaced straight lines with quadratic Bezier curves that converge toward shared arcs.
- **Orientation Grouping**: Parallel edges are now quantized into 16 directional buckets, creating unified "data streams".
- **Performance**: Optimized O(1) per-frame calculation with `isFinite` math protection.

#### **2. Zero-Config Onboarding**
- **Instant Access**: The 🧠 Canvas button is now available in the editor title bar for all file types.
- **Auto-Discovery**: If no state is detected, SYNAPSE automatically offers "Lite Bootstrap" to scan your project instantly.
- **Silent Start**: No more intrusive startup popups; the engine activates only when you need it.

#### **3. Amnesia Guard (Snapshot Sovereignty)**
- **Integrity Check**: Prevents "Amnesia" where valid project states were being overwritten by empty or partial results.
- **Sync Lock**: Serializes state broadcasts to eliminate race conditions during initial data loading.

#### **4. Multi-Language Precision**
- **Rust**: Enhanced nested `use` item extraction.
- **Python**: Robust relative import resolution (stripping leading dots).
- **C/C++**: Improved header-to-source link resolution.

### [Korean] 🇰🇷

#### **핵심 하이라이트: 엣지 번들링 및 제로-컨피그 UX**
이번 릴리즈는 시각적 명확성, 매끄러운 온보딩, 그리고 상태 신뢰성에 집중했습니다. 스파게티처럼 얽힌 의존성을 우아한 번들 흐름으로 변환하고, 수동 설정의 번거로움을 제거했습니다.

#### **1. 엣지 번들링 라이트 (베지어 수렴)**
- **시각적 명확성**: 직선을 2차 베지어 곡선으로 교체하고, 공통 아크를 향해 수렴하도록 계산하여 시각적 노이즈를 획기적으로 줄였습니다.
- **방향성 그룹화**: 평행한 엣지들을 16개 방향 버킷으로 양자화하여 하나의 통합된 "데이터 스트림"처럼 보이게 합니다.
- **안정성**: `isFinite` 보호 로직을 통해 기하학적 계산 오류에 의한 엣지 유실을 차단했습니다.

#### **2. 제로-컨피그 온보딩**
- **즉시 접근**: 이제 어떤 파일 확장자에서도 에디터 우측 상단의 🧠 캔버스 아이콘을 통해 즉시 진입할 수 있습니다.
- **자동 분석**: 데이터가 없는 프로젝트에서 캔버스를 열면 자동으로 "Lite Bootstrap"을 제안하여 수동 설정 없이 아키텍처를 스캔합니다.
- **정숙한 시작**: 확장 프로그램 활성화 시 나타나던 방해되는 팝업들을 제거했습니다.

#### **3. Amnesia Guard (스냅샷 주권)**
- **무결성 검증**: 불완전한 스캔 결과가 유효한 프로젝트 상태를 덮어쓰는 '기억 상실' 현상을 원천 차단했습니다.
- **동기화 락**: 초기 데이터 로딩 시 레이스 컨디션을 방지하기 위해 상태 브로드캐스트를 직렬화했습니다.

#### **4. 다국어 분석 정밀도**
- **Rust**: 중첩된 `use` 아이템 추출 능력 강화.
- **Python**: 상대 경로 임포트(`.`) 처리 로직 개선.
- **C/C++**: 헤더와 소스 파일 간의 링크 정확도 향상.

- Standardized Ghost Node path delimiters to prevent edge evaporation.
