## 🚀 주요 변경 사항 / Key Changes

### 1. Interaction & State Synchronization (Jitter Fix)
- **🇰🇷 MouseUp & Timestamp Guard**: 드래그 종료 시점의 `didDrag` 상태를 지역 변수로 캡처하고, `saveState` 이후 500ms 및 드래그 종료 후 300ms 타임스탬프 가드를 적용하여 백엔드의 지연된 스캔 응답이 현재 좌표를 덮어쓰지 않도록 차단했습니다.
- **🇺🇸 MouseUp & Timestamp Guard**: Captured the `didDrag` state as a local variable at the end of an interaction and implemented timestamp guards (500ms post-save / 300ms post-drag) to prevent stale backend scan results from overwriting current coordinates.
- **🇰🇷 Position Persistence Guard**: `loadProjectState` 실행 시 사용자 조작 위치가 백엔드 데이터보다 우선적으로 보존되도록 로직을 강화했습니다.
- **🇺🇸 Position Persistence Guard**: Enhanced `loadProjectState` to prioritize current UI coordinates over incoming backend data during incremental updates, ensuring manual placements are preserved.

### 2. Coordinate System Normalization
- **🇰🇷 Absolute Coordinate Sovereignty**: 클러스터 그룹화 시 노드 좌표를 상대 좌표로 변환하던 로직을 제거했습니다. 모든 노드는 이제 클러스터 소속과 관계없이 절대 월드 좌표를 유지하여 SSoT 무결성을 확보했습니다.
- **🇺🇸 Absolute Coordinate Sovereignty**: Removed the logic that converted node positions to relative coordinates during clustering. All nodes now maintain absolute world coordinates for true Single Source of Truth (SSoT) integrity.
- **🇰🇷 Jitter Threshold Optimization**: 드래그 감지 임계값을 5px에서 1px로 조정하여 미세한 이동 시에도 조작 위치가 보호되도록 개선했습니다.
- **🇺🇸 Jitter Threshold Optimization**: Lowered the drag detection threshold from 5px to 1px to ensure manual positions are protected even during minimal movements.

### 3. Synchronization Integrity & Sovereignty
- **🇰🇷 Disk/Scan Protection**: 파일 저장이나 주기적 스캔(`mutateSyncFromDisk`, `mergeFromScan`) 시 `dirty` 상태의 노드 좌표를 보호하여 드래그 도중 위치가 튀는 현상을 근본적으로 해결했습니다.
- **🇺🇸 Disk/Scan Protection**: Protected the coordinates of `dirty` nodes during disk syncs and periodic scans, eliminating the root cause of nodes jumping back to their original positions.
- **🇰🇷 Cluster Assignment Sovereignty**: 사용자가 명시적으로 지정한 클러스터 배정이 AI 자동 배정 로직보다 우선하도록 Sovereignty 로직을 강화했습니다.
- **🇺🇸 Cluster Assignment Sovereignty**: Strengthened sovereignty logic to ensure user-explicit cluster assignments take precedence over AI-driven automatic classification.
