## 🌟 Overview / 개요
**[EN]** v0.3.22 focuses on "Seeing is Believing." We've introduced high-fidelity video demonstrations and a comprehensive visual language specification to ensure users can intuitively grasp the architecture. Furthermore, we've resolved critical semantic resolution bugs in tooltips to guarantee 100% data reliability.

## ✨ Key Improvements / 주요 개선 사항

### 1. High-Fidelity Demonstrations (시각적 증명)
- **[EN]** Added interaction videos to README, showcasing Zoom, Layer Visibility, Traffic Heatmap, and Deep Zoom details (icons/badges/tooltips).
- **[KO]** README에 인터랙션 영상을 추가하여 줌, 레이어 가시성, 트래픽 히트맵 및 상세 줌 인(아이콘/배지/툴팁) 기능을 시각적으로 증명.

### 2. Standardized Visual Language (시각 언어 규격화)
- **[EN]** Documented the full visual lexicon including Entity Types (12 icons), Node Status (7 states), Flow Markers, and Edge Conventions.
- **[KO]** 엔티티 타입(12종), 노드 상태(7종), 흐름 마커 및 엣지 규격을 포함한 전체 시각 언어 사전을 문서화.

### 3. Semantic Reliability Patch (시맨틱 신뢰성 강화)
- **[EN]** Resolved the "unknown" node label issue in tooltips by reordering `updateNodeStats` and adding `data.cluster_id` fallback logic.
- **[KO]** `updateNodeStats` 실행 순서 조정 및 `data.cluster_id` 폴백 로직 추가를 통해 툴팁 내 'unknown' 노드 라벨 표시 문제 해결.
