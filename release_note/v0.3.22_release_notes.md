# 📜 Release Notes - v0.3.22 (Bilingual)

## [English] 🚀 Stabilization & Parity Patch
This version focuses on achieving full 2D/3D rendering parity and resolving critical runtime crashes. We have implemented a more intelligent tooltip system based on architectural "Senior's Prescriptions."

### ✨ Key Improvements
- **Engine Recovery**: Fixed all Syntax and Reference errors that caused rendering blackouts.
- **Visual Parity**: Synchronized 3D WebGL borders, colors, and shapes (Boxes) with the 2D Canvas engine.
- **Intelligent Tooltips**: 
    - Added **100ms Debounce** for data stability.
    - Integrated **Architectural Icons** (📄, ⚡) into connection lists.
    - Added **LOD Guard** to hide detailed lists at low zoom levels (< 0.4).
- **Layout Robustness**: Fixed text clipping and improved tooltip visual depth.

## [한국어] 🚀 안정화 및 렌더링 동기화 패치
본 버전은 2D와 3D 렌더링 엔진 간의 시각적 불일치를 해결하고, 치명적인 런타임 오류를 박멸하는 데 집중했습니다. 시니어 엔지니어의 처방을 기반으로 더욱 지능적인 툴팁 시스템을 구축하였습니다.

### ✨ 주요 개선 사항
- **엔진 복구**: 렌더링 블랙아웃을 유발하던 모든 구문 및 참조 오류를 해결했습니다.
- **시각적 통합**: 3D WebGL의 테두리, 색상, 노드 형상(Box)을 2D 캔버스 엔진과 100% 동기화했습니다.
- **지능형 툴팁**:
    - 데이터 정합성을 위한 **100ms 데바운스** 적용.
    - 연결 리스트에 **아키텍처 아이콘**(📄, ⚡) 및 실명 바인딩.
    - 저배율(< 0.4)에서의 성능 최적화를 위한 **LOD 가드** 도입.
- **레이아웃 강화**: 텍스트 잘림 현상을 해결하고 시각적 가시성을 대폭 개선했습니다.
