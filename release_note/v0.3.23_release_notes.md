# 🚀 SYNAPSE Release Notes - v0.3.23

## 📅 Release Date: 2026-05-02

## 🌟 Summary / 요약
This release introduces the **Hybrid Blacklist System** and **Explorer Context Menu Integration**, significantly reducing noise in large-scale project analysis and maximizing user convenience. It also resolves canvas layout collapse issues during editor splitting.

이번 릴리스는 대규모 프로젝트 분석 시 발생하는 노이즈를 효율적으로 제거하고, 사용자 경험(UX)을 극대화하는 **하이브리드 블랙리스트 시스템**과 **탐색기 우클릭 등록** 기능을 도입했습니다. 또한, 에디터 분할 시 발생하던 캔버스 레이아웃 붕괴 문제를 해결하여 시각적 안정성을 확보했습니다.

---

## ✨ Key Updates / 주요 업데이트

### 1. 🚫 Hybrid Blacklist System (L2 Hardening) / 하이브리드 블랙리스트 시스템
- **[EN] O(1) Path Matching**: Instantly determines blacklist status even with massive path data without performance degradation.
- **[KR] O(1) 경로 매칭**: 대규모 경로 데이터에서도 성능 저하 없이 블랙리스트 여부를 즉시 판별합니다.
- **[EN] Absolute Path Intelligence**: Intelligently detects absolute paths (Linux/Windows) and normalizes them to project-relative paths.
- **[KR] 절대 경로 인텔리전스**: 리눅스 및 윈도우의 절대 경로를 지능적으로 감지하여 프로젝트 루트 기준의 상대 경로로 정규화 후 체크합니다.
- **[EN] Real-time Engine Sync**: Changes in blacklist settings are instantly synced to the engine, removing nodes from the canvas without a restart.
- **[KR] 실시간 엔진 동기화**: 블랙리스트 설정 변경 시 메모리 상의 엔진 상태가 즉시 동기화되어 별도의 재시작 없이 캔버스에서 노드가 제거됩니다.

### 2. 🖱️ Explorer Context Menu Integration / 탐색기 컨텍스트 메뉴 통합
- **[EN] Add to Blacklist**: Right-click any file or folder in the VS Code Explorer to instantly exclude it.
- **[KR] 블랙리스트 즉시 등록**: VS Code 탐색기에서 파일이나 폴더를 우클릭하여 즉시 분석 대상에서 제외할 수 있습니다.
- **[EN] Instant Refresh**: The graph refreshes automatically upon registration, making excluded targets disappear immediately.
- **[KR] 즉각적인 갱신**: 등록과 동시에 캔버스 그래프가 자동으로 갱신되어 분석 제외 대상이 즉시 사라집니다.

### 3. 🖼️ Canvas Layout Recovery / 캔버스 레이아웃 복구
- **[EN] Flex-based Resizing**: Removed hardcoded 400px height limits, enabling flexible canvas sizing based on CSS Flexbox.
- **[KR] 유연한 리사이징**: 하드코딩된 400px 높이 제한을 제거하고, CSS Flexbox를 기반으로 캔버스 크기를 유연하게 조정합니다.
- **[EN] Resizing Stability**: Resolved layout clipping or distortion when splitting editor groups or resizing windows.
- **[KR] 리사이징 안정성**: 에디터 그룹 분할 또는 창 크기 조절 시 캔버스가 잘리거나 찌그러지는 현상을 완벽하게 해결했습니다.

## 🛠️ Technical Details / 기술적 세부 사항
- **RuleEngine.ts**: Enhanced `projectRoot` awareness and `normalizePath` logic. / `projectRoot` 인지 로직 및 경로 정규화 강화.
- **StateManager.ts**: Optimized blacklist filtering within the snapshot generation loop. / 스냅샷 생성 루프 내 필터링 최적화.
- **extension.ts**: Integrated Explorer context menu commands with UI refresh. / 탐색기 메뉴 커맨드 등록 및 UI 새로고침 연동.
- **ui/canvas-engine.js**: Implemented dynamic viewport initialization. / 인라인 스타일 제거 및 유동적 뷰포트 로직 도입.
