# SYNAPSE Release Notes - v0.3.24

---

## 📄 Korean (한국어)

### 📌 개요
본 릴리즈(v0.3.24)는 SYNAPSE 부트스트랩 인프라 하드닝 작업의 일환으로, `RULES.md` 내 정의된 생각 제어 밸브(DTR) 및 '강제 파일 투사 규칙(Forced File Projection Rules)'을 익스텐션 소스 레벨에 기본값으로 내장하였습니다. 이로써 익스텐션 설치 후 신규 프로젝트 부트스트랩 시 필수 보안 및 로깅 규칙이 자동으로 확립됩니다.

### 🚀 주요 변경 사항

#### 1. Default RULES.md의 소스 단 임베딩 (`src/bootstrap/BootstrapEngine.ts`)
*   익스텐션 활성화 또는 부트스트랩 시 프로젝트 루트에 `RULES.md`가 존재하지 않을 경우 자동 생성되던 기존 임시 더미 템플릿을 실제 **DTR 룰북 및 강제 파일 투사 규칙 전문**이 반영된 실전 규격서 사양으로 교체했습니다.
*   앞으로 시냅스가 활성화된 모든 프로젝트 공간에 생성되는 `RULES.md`에는 다음과 같은 강력한 투사 규칙이 강제 포함됩니다:
    *   사용자 원본 프롬프트 내용 (Raw User Prompt) 기록 명시
    *   이번 프롬프트로 인해 수행한 추론 과정 요약 (Core CoT) 기록 명시
    *   수정 및 생성된 변경 파일 목록 (Affected Files Diff) 기록 명시

#### 2. 패키지 버전 관리 (`package.json`)
*   신규 기능 탑재 및 배포를 위해 익스텐션 패키지 버전을 `0.3.23`에서 `0.3.24`로 상향 조정했습니다.

### ⚙️ 상세 변경 파일 내역
*   `package.json` [version bump: 0.3.23 -> 0.3.24]
*   `src/bootstrap/BootstrapEngine.ts` [`ensureRulesFile` 메서드 내 defaultRules 템플릿 문자열 업데이트]

## 📄 English (영어)

### 📌 Overview
This release (v0.3.24) hardens the SYNAPSE bootstrapping infrastructure by embedding the DTR Thought Control and the 'Forced File Projection Rules' directly into the extension's source level. When a new project is initialized, the standard architecture rules document (`RULES.md`) is automatically created with these security and logging guidelines.

### 🚀 Key Changes

#### 1. Source-Level Embedding of Default RULES.md (`src/bootstrap/BootstrapEngine.ts`)
*   Replaced the existing dummy rules template with the full **DTR Rulebook & Forced File Projection Rules** specifications.
*   All future `RULES.md` files auto-generated in new projects will enforce the following logging guidelines for AI agents:
    *   Mandatory logging of the **Raw User Prompt**.
    *   Mandatory logging of the **Core Chain-of-Thought (CoT)** reasoning summary.
    *   Mandatory logging of the **Affected Files Diff**.

#### 2. Extension Version Bump (`package.json`)
*   Incremented the extension version from `0.3.23` to `0.3.24` to release the new defaults.

### ⚙️ Affected Files
*   `package.json` [version bump: 0.3.23 -> 0.3.24]
*   `src/bootstrap/BootstrapEngine.ts` [Updated `defaultRules` template string inside `ensureRulesFile` method]
