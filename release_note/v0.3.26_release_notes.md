## 🇰🇷 한국어 (Korean)

### 요약
이번 릴리즈에서는 3D 가속(WebGL) 모드가 꺼져 있을 때(2D 모드) 노드 간 연결선(엣지)이 렌더링되지 않던 치명적인 UI 버그를 해결했습니다.

### 수정 및 개선 사항
* **2D 모드 엣지 가시성 복구**:
  * 테마에서 정의된 실선 엣지의 기본 대시 설정 `[0, 0]`이 HTML5 Canvas 2D 컨텍스트에서 유효하지 않은 패턴으로 해석되어 선이 투명하게 지워지던 호환성 문제를 해결했습니다.
  * `setLineDash`를 호출하기 전, 대시 패턴이 `[0, 0]`과 같이 모두 `0`으로 구성된 경우 브라우저 표준 실선 표현 형식인 빈 배열 `[]`로 안전하게 치환해 전달하도록 보완했습니다.
  * 이로써 WebGL이 비활성화된 환경에서도 노드 간 흐름과 관계를 온전히 파악할 수 있게 되었습니다.
* **성능 및 예외 처리**:
  * 대시 체크 로직을 최적화하여 60FPS 프레임 루프(O(1) 성능 제약) 내에서 오버헤드 없이 안정적으로 동작하도록 고안했습니다.

## 🇬🇧 영어 (English)

### Summary
In this release, we fixed a critical UI bug where the edge lines connecting nodes were not rendered when 3D acceleration (WebGL) was turned OFF (2D mode).

### Fixes & Improvements
* **Restored Edge Visibility in 2D Mode**:
  * Resolved a browser compatibility issue where the default dash pattern `[0, 0]` defined for solid edges was interpreted as an invalid/empty dash pattern by the HTML5 Canvas 2D renderer, resulting in completely invisible lines.
  * Intercepted the line dash settings inside the 2D rendering pipeline to safely translate any all-zero dash arrays (e.g. `[0, 0]`) into an empty array `[]` (the standard canvas format for solid lines) before passing them to the `setLineDash` API.
  * Users can now fully visualize the flow and relationships of the code architecture even in non-accelerated environments.
* **Performance & Robustness**:
  * Optimized the check routine to guarantee zero overhead within the 60FPS render loop, strictly satisfying the O(1) frame constraints.
