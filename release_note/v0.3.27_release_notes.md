# Synapse Visual Architecture - v0.3.27 Release Notes

[Status: Verified by Commander]

## Summary
This release resolves critical UI data sync bugs (edge data loss resulting in `Edges: 0`) and folder mapping bugs when toggling layers on the canvas. It also includes 2D and 3D rendering pipeline optimizations.

## Changes

### 1. Engine Core & Data Sync (StateManager / CanvasPanel)
- **Edge Loss Restoration**: Sourced NVM/auto-discovery pipeline triggers `StateManager.mergeFromScan` which now dynamically merges or restores the existing authoritative edge list (`coreSnap.edges`) when scan payloads contain empty edge lists (e.g. from background reality checks). This fixes the `Edges: 0` bug.
- **Folder Cluster Isolation**: Corrected `generateMergedState` to correctly identify directory-scanned folders (e.g., `cluster_demo`, `cluster_src`) by checking for alphanumeric subpaths in `cluster_*` labels, ensuring they are classified under the base logic (`ai`) layer.
- **Layer Synchronization Sovereignty**: Updated `mutateAddCluster` and `CanvasPanel`'s `ADD_CLUSTER` dispatch to dynamically check and preserve the correct layer tags (`ai` for system scan folders and `user` for manual user-grouped nodes), protecting folders and code nodes from vanishing when the `User Custom` layer is toggled `OFF`.

### 2. Rendering Pipelines (WebGL & Canvas 2D)
- **NaN Packing Protection**: Hardened GPU data buffers in `webgl-renderer.js` against packing empty dash patterns (replacing `undefined` fallback variables with `0.0` safety values).
- **O(1) Hot Path Execution**: Removed `.every()` Array iterations in the Canvas 2D frame loop inside `canvas-engine.js` (rendering edges).

### 3. 2D/3D Edge Rendering Alignment (renderEdges2D / renderNodes2D)
- **Unified Visibility Cache**: Node and edge visibility filtering (`showBaseLayer`, `showUserLayer`, `showExternalLayer`, collapsed clusters, leaf node hide, top-N focus) is now computed **once per state change** (`isGraphDataDirty`) at the beginning of the Graph Mode branch in `render()`. Both 2D and 3D pipelines consume the exact same `_visibleNodesCache` / `_visibleEdgesCache` arrays.
- **Viewport Culling Bypass**: Removed viewport-bounds culling from `renderEdges2D()` that was incorrectly discarding most edges at low zoom levels (node renderer had already bypassed culling for safety in v0.3.20). Edges now render in full parity with WebGL 3D mode.
- **O(1) Frame Loop**: `renderEdges2D()` and `renderNodes2D()` now iterate directly over the pre-computed cache arrays — all per-frame O(N) classification logic eliminated.
- **Duplicate WebGL Cache Removed**: Redundant node/edge cache block inside the WebGL branch removed; the unified top-level cache covers both render modes.
- Applies to both `ui/canvas-engine.js` and `demo/canvas-engine.js`.
