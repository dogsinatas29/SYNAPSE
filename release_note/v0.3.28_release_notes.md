# Synapse Visual Architecture - v0.3.28 Release Notes

[Status: Verified by Commander]

## 📝 Summary / 요약

This release is a targeted bug-fix patch addressing a compound rendering regression where switching from Accel:ON (WebGL) to Accel:OFF (2D Canvas) caused edges to nearly disappear, dark circle dot artifacts to appear on nodes, and spaghetti-like downward distortions. Seven independent root causes were identified and corrected across the 2D rendering pipeline, including sub-pixel anti-aliasing fade-outs, silent `NaN` failures, and mathematically flawed bundling algorithms.

이번 릴리즈는 Accel:ON (WebGL)에서 Accel:OFF (2D Canvas)로 전환 시 엣지가 사라지거나, 노드에 검은 도트 잔상이 남거나, 엣지가 기형적으로 아래로 쏠려 스파게티처럼 왜곡되는 복합 렌더링 버그를 해결한 긴급 패치입니다. 서브픽셀 렌더링 소실, 조용한 `NaN` 실패, 수학적 결함이 있는 번들링 알고리즘 등 2D 렌더링 파이프라인 전반에 걸쳐 7가지의 근본 원인을 찾아 수정했습니다.

## 🚀 Changes / 상세 수정 내역

### 1. O(1) Hot Path — `isPathSelected` Computation Fix (`renderEdge`)
- **Root Cause:** `Array.from(this.selectedNodes).some(n => ...)` was called inside `renderEdge()` for every edge on every frame, causing massive O(N) CPU spikes in Accel:OFF mode.
  - **원인:** `renderEdge` 내부에서 매 프레임 모든 엣지에 대해 배열 순회 연산(`.some()`)이 발생하여 CPU를 심각하게 점유함.
- **Fix:** Cached `this._selectedNodeIds` once per frame and replaced the O(N) lookup with an O(1) `Set.has()`.
  - **수정:** 선택된 노드 목록을 매 프레임 1회 캐싱하고 O(1) 해시 테이블 조회 방식으로 교체하여 프레임 드랍 방지.

### 2. 2D Edge Base Alpha Raised for WebGL Parity / 기본 알파 상향
- **Root Cause:** Default `finalAlpha` for 2D edges was fixed at `0.3`, rendering them invisible on dark themes.
  - **원인:** 2D 엣지의 기본 투명도가 `0.3`으로 고정되어 어두운 배경에서 보이지 않음.
- **Fix:** Increased base alpha to `0.5` and path-selected to `0.6` to match WebGL parity.
  - **수정:** WebGL과 동일한 수준의 가시성을 위해 기본 알파를 `0.5`, 선택 경로를 `0.6`으로 상향.

### 3. `isGraphDataDirty` Not Reset in 2D Render Path / 더티 플래그 미초기화
- **Root Cause:** The 2D `else` branch did not reset `this.isGraphDataDirty = false`, forcing full visibility cache rebuilds every frame.
  - **원인:** 2D 렌더링 분기 종료 후 플래그가 초기화되지 않아 매 프레임마다 캐시를 강제 재생성함.
- **Fix:** Mirrored the WebGL reset logic at the end of the 2D branch.
  - **수정:** 2D 분기 종료 후 3종의 dirty 플래그를 모두 `false`로 초기화.

### 4. `globalAlpha` Leak from Pulse Animation / 펄스 애니메이션 투명도 누수 방지
- **Root Cause:** The Pulse block leaked its `globalAlpha` state, causing subsequent `renderNode` calls to draw nearly transparent backgrounds (Black Dot artifacts).
  - **원인:** 펄스 렌더링 후 캔버스 글로벌 알파 값을 복원하지 않아, 뒤이어 그려지는 노드의 배경이 투명해지면서 검은색 도트 잔상을 유발함.
- **Fix:** Added `this.ctx.globalAlpha = 1.0` after the Pulse block.
  - **수정:** 펄스 블록 종료 후 즉시 `globalAlpha`를 `1.0`으로 복구.

### 5. Canvas2D Sub-pixel Anti-aliasing Fade-out / 서브픽셀 굵기 감쇄 현상 수정
- **Root Cause:** Canvas2D anti-aliased sub-pixel lines (scaled below 1px during zoom-out) by dropping their opacity, making edges disappear completely.
  - **원인:** 화면을 축소(Zoom-out)할 경우 엣지의 두께가 1픽셀 미만이 되며, 캔버스의 안티앨리어싱 특성으로 인해 투명해지며 선이 아예 사라지는 문제 발생.
- **Fix:** Enforced a dynamic minimum screen-space thickness scaling to guarantee lines are rendered with at least a 2.0 pixel visual weight.
  - **수정:** Zoom 역수를 기반으로 화면상에서 최소 2픽셀 두께 이상으로 강제 보정 및 굵기 값 덮어씌우기 버그 해결.

### 6. Edge Bundling Logic `NaN` Silent Failure / 번들링 로직 좌표 연산 실패
- **Root Cause:** `cluster.width / 2` evaluated to `NaN` for implicitly sized clusters, passing invalid control points to `quadraticCurveTo(NaN, NaN)` and silently skipping line strokes.
  - **원인:** 클러스터 정보에 `width`, `height` 속성이 없는 경우 중심좌표를 계산하다 `NaN`이 반환되었고, 선을 그리는 함수가 에러 없이 조용히 실패하여 배지만 공중에 떠다니는 현상 유발.
- **Fix:** Added fallback dimensions (`width || 400`).
  - **수정:** 클러스터 기본 크기 폴백을 제공하여 `NaN` 오염을 원천 차단.

### 7. Canvas 2D Edge Distortion Parity (Downward Belly Fix) / 수학적 패리티 동기화 및 엣지 왜곡 제거
- **Root Cause:** The 2D rendering loop grouped edges into a `bundles` Map and aggressively anchored the control points to the target cluster's Y-center, causing all edges to sag downward into massive U-shaped "bellies" if the target was physically low on the screen.
  - **원인:** 기존 2D 번들링 로직이 타겟 클러스터의 Y축 중심 좌표에 제어점을 강제로 끌어당기게 하드코딩 되어 있어, 타겟이 화면 하단일 경우 선들이 극단적으로 밑으로 늘어지는 거대한 왜곡 현상 유발.
- **Fix:** Completely eliminated the O(N) cluster grouping loop. Replaced the flawed 2D calculation with the mathematically precise **Perpendicular Normal Vector** logic identical to WebGL, granting perfectly symmetrical arches and eliminating the spaghetti distortion.
  - **수정:** 성능 병목이었던 O(N) 클러스터 그룹화 코드를 프레임 루프에서 완전 폐기하고, 노드 간 거리 기반의 '직교 법선 벡터(Perpendicular Normal Vector)' 연산을 WebGL과 100% 동일하게 이식하여 완벽한 대칭형 활꼴을 구현하고 왜곡을 제거함.
