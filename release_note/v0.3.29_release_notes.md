# Synapse Visual Architecture - v0.3.29 Release Notes

[Status: Verified by Commander]

## 📝 Summary / 요약

This release resolves three interrelated visualization issues: (1) cluster/node overlapping after project re-scan caused by all nodes defaulting to `{x:0, y:0}`, (2) the External Ghosts cluster box disappearing when only the External layer is visible, and (3) excessive cluster expansion after "Align Architecture" that caused clusters to overlap. Fixes span the DataPipeline (initial circular spread), the shared cluster overlap resolution engine, and layer visibility filtering.

이번 릴리즈는 3가지 시각화 문제를 해결합니다: (1) 모든 노드가 `{x:0, y:0}`으로 초기화되어 발생하는 재스캔 후 클러스터/노드 겹침, (2) External 레이어만 켰을 때 External Ghosts 클러스터 박스가 사라지는 문제, (3) "Align Architecture" 후 클러스터가 과도하게 팽창하여 겹치는 문제. DataPipeline(초기 원형 분산), 공유 클러스터 중첩 해소 엔진, 레이어 가시성 필터 전반에 걸쳐 수정이 이루어졌습니다.

## 🚀 Changes / 상세 수정 내역

### 1. Initial Spread — Circular Layout in DataPipeline (`src/core/DataPipeline.ts`)
- **Problem:** All nodes and folder clusters were created with `position: {x:0, y:0}`, causing complete overlap on re-scan.
  - **문제:** 모든 노드와 폴더 클러스터가 `{x:0, y:0}`으로 생성되어 재스캔 시 완전히 겹침.
- **Fix:** Folder clusters are now placed in a deterministic circular layout using FNV-1a hash of `cluster_id`. Nodes are arranged in a compact 3-column grid (80x50px spacing) relative to their cluster center.
  - **수정:** 폴더 클러스터를 FNV-1a 해시 기반 원형으로 배치하고, 노드는 클러스터 중심 기준 3열 그리드(80x50px 간격)로 정렬.

### 2. Cluster Push-Apart Engine (`ui/canvas-engine.js` — new method)
- **Problem:** No cluster-level collision detection existed — only individual nodes were pushed apart.
  - **문제:** 클러스터 간 충돌 감지가 전혀 없었음 — 개별 노드만 밀어냄.
- **Fix:** Added `resolveClusterOverlaps()` — AABB overlap detection with Mass-weighted push-apart, Virtual Padding (40px), and 3 Iterations. Includes Sign Guard, Zero-Divide Guard, and Shift Guard exception handling.
  - **수정:** `resolveClusterOverlaps()` 신규 메서드 추가 — AABB 중첩 감지 + Mass 기반 Push-Apart + 가상 패딩 40px + 3회 반복. Sign Guard, Zero-Divide Guard, Shift Guard 예외 처리 포함.

### 3. External Ghosts Cluster Layer Visibility Fix (`ui/canvas-engine.js`)
- **Problem:** When only External layer was ON (Base/User OFF), ghost nodes appeared but their parent `cluster_ghosts` box was invisible.
  - **문제:** External 레이어만 ON 시 ghost 노드는 보이지만 `cluster_ghosts` 박스는 보이지 않음.
- **Root Cause:** `getClusterBounds()` lacked an `isExternalNode` check, filtering out all external nodes from bounds calculation → `minX=Infinity` → cluster skipped.
  - **원인:** `getClusterBounds()`에 `isExternalNode` 체크가 없어 external 노드가 bounds 계산에서 제외됨.
- **Fix:** Added `isExternalNode` filter in `getClusterBounds()`. Also hardened layer fallback logic in 3 locations to map `cluster_ghosts` → `'external'` layer.
  - **수정:** `getClusterBounds()`에 `isExternalNode` 가시성 체크 추가 + 3개 지점의 layer fallback에 `cluster_ghosts` 예외 처리 강화.

### 4. Align Architecture — Cluster Expansion Reduction (`ui/canvas-engine.js`)
- **Problem:** `applyRoleAlignment()` spread nodes across ~1900px per cluster (roleOffsets ±600 + COLUMN_WIDTH=350), then no overlap resolution ran after alignment.
  - **문제:** `applyRoleAlignment()`가 클러스터당 ~1900px로 노드를 퍼뜨렸으나 정렬 후 중첩 해소가 실행되지 않음.
- **Fix:** Reduced roleOffsets by half (Leaf:-300, Hub:-100, Orch:100, Ctrl:300) → X spread ~950px. Added `resolveClusterOverlaps()` call on alignment completion.
  - **수정:** roleOffsets를 절반으로 축소(Leaf:-300, Hub:-100, Orch:100, Ctrl:300) → X spread ~950px. 정렬 완료 시 `resolveClusterOverlaps()` 자동 실행.

### 5. DataPipeline Node Spacing Tuning
- **Problem:** Initial grid spacing (120x60px) caused clusters to be oversized.
  - **문제:** 초기 grid 간격(120x60px)으로 클러스터가 과대하게 커짐.
- **Fix:** Reduced to 80x50px. Increased circular layout radius coefficient from `×150` to `×200` for more breathing room.
  - **수정:** 80x50px로 축소. 원형 배치 반경 계수를 `×150`에서 `×200`으로 증가.

## ⚠️ Notes / 참고 사항

- All fixes operate on shared `this.nodes[*].position` data — both 2D Canvas and WebGL renderers benefit automatically.
- `resolveClusterOverlaps()` runs only during `loadProjectState()` (once per re-scan) and after alignment completes — never inside the frame loop.
- Virtual Padding (40px) ensures traffic corridors between cluster boundaries.
