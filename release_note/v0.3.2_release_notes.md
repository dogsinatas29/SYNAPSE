# v0.3.2 Release Notes - Edge Rendering Parity

## 🚀 개요
3D 가속(WebGL) 모드에서의 엣지 렌더링 품질을 2D 캔버스 수준으로 끌어올렸습니다. 엣지의 방향성(Arrow) 시인성을 확보하고, 끝으로 갈수록 가늘어지는 부자연스러운 현상을 제거하여 대규모 그래프에서도 명확한 데이터 흐름을 파악할 수 있게 되었습니다.

## ✨ 주요 변경 사항
- **엣지 경계 처리 (Edge Boundary Clipping)**
  - 엣지가 노드 중심이 아닌 노드 외곽 경계선(120x60)에서 정확히 멈추도록 좌표 계산 로직을 개선했습니다.
  - 이로 인해 노드 내부에 숨겨져 보이지 않던 화살표가 노드 경계면에 항상 노출됩니다.
- **일정한 엣지 두께 유지 (Uniform Thickness)**
  - 기존의 Tapering(가늘어짐) 현상을 제거하고, 엣지 전체 구간에서 설정된 `lineWidth`가 일정하게 유지되도록 셰이더를 재설계했습니다.
- **화살표 형상 정규화 (Arrowhead Normalization)**
  - 3.5배 확장된 쿼드 영역을 활용하여 2D 캔버스와 동일한 날카롭고 선명한 화살표를 구현했습니다.
- **WebGL 셰이더 최적화**
  - 단일 쿼드 인스턴싱 내에서 바디와 헤드를 구분하여 렌더링함으로써 드로우 콜을 늘리지 않고 품질을 개선했습니다.
