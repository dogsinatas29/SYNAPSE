# 🚀 SYNAPSE v0.3.30.2 Release Notes
**Theme: Security Hardening & Architecture Integrity**

## 🇰🇷 Korean (한국어)

### 🛡️ 심층 보안 검증: 6대 크리티컬 공격 벡터 원천 차단
이번 마일스톤에서는 협업 모드에서의 보안 취약점을 전수 검사하였으며, 단 하나의 레이스 컨디션 없이 완벽하게 방어됨을 구조적으로 증명했습니다.
- **Path Traversal & 샌드박스 탈출 방어:** 수확(Harvest) 시 요청 경로가 실제 프로젝트 범위를 벗어나거나 조작된 경우 즉각 차단합니다.
- **권한(Auth) 및 SSE 스트림 오염 방어:** 모든 주요 API 및 실시간 소켓 통신은 강력한 글로벌 Auth 미들웨어의 통제를 받으며 유효한 토큰 없이 접근을 허용하지 않습니다.
- **락(Lock) 우회 방어:** 네트워크 끊김 현상이 발생해도 상태머신(State Machine)의 락이 꼬이거나 풀리지 않는 완벽한 Fail-Safe 무결성을 검증했습니다.

### 🧠 아키텍처 구조 진단 및 성능 검증 (Tier B)
시스템이 한계 상황에서 어떻게 동작하는지 스트레스 테스트 및 한계 진단을 수행했습니다.
- **자원 누수 제로(0) 증명:** 1,000회 연속 수확 및 스냅샷 발생 등 극한의 조건에서도 File Descriptor 누수나 비정상적인 메모리 증가가 발생하지 않음을 확인했습니다.
- **이벤트 루프(Event Loop) 지연 한계 발견:** `synapse_history.json` 데이터가 방대해질 경우 동기식(Sync) I/O 구조로 인해 발생하는 시스템 지연을 관측했습니다. 이는 v0.4.0에서 비동기 격리(Async Isolation) 아키텍처로 완전히 재설계하기 위한 중요한 진단 성과입니다.

### 🐞 버그 수정 및 역호환성(Backward Compatibility) 안정화
- **어드민 포트 충돌 방어 및 인증(403) 버그 수정:** 고스트 프로세스 점유로 서버가 임시 포트로 열릴 경우, 프론트엔드가 이를 정상적으로 동기화하지 못해 발생하던 어드민 생성 403 인증 에러를 고쳤습니다.
- **레거시 계정 데이터(`accounts.json`) 파싱 복구:** 과거 버전에서 배열 포맷으로 저장된 레거시 사용자 데이터를 읽어올 때 발생하던 크래시 및 계정 초기화 현상을 수정했습니다.
- **수확 히스토리(`synapse_history.json`) `unshift` 에러 방어:** 수확(Harvest) 완료 후 히스토리를 저장할 때, 기존 레거시 배열 포맷 데이터를 파싱하다 터지던 `TypeError (reading 'unshift')` 크래시를 방어하고 역호환성을 확보했습니다.

## 🇺🇸 English

### 🛡️ Deep Security Hardening: Defending 6 Critical Attack Vectors
In this milestone, we conducted extensive security audits in collaborative mode, proving absolute structural defense with zero race conditions.
- **Path Traversal & Sandbox Escape Prevention:** Instantly blocks any Harvest path manipulation attempting to reach outside the Project Root sandbox.
- **Auth Bypass & SSE Contamination Prevention:** All critical APIs and real-time socket streams are rigorously guarded by a global auth middleware, rejecting any unauthenticated access.
- **Lock Bypass Prevention:** Verified absolute Fail-Safe integrity where State Machine locks are never corrupted or bypassed, even during abrupt network disconnects.

### 🧠 Architecture Diagnostic & Performance Verification (Tier B)
We stress-tested the system to observe behavior under extreme loads.
- **Zero Resource Leaks Proved:** Confirmed zero File Descriptor (FD) leaks and normal heap memory recovery under intense continuous workloads (1,000+ Harvests).
- **Event Loop Starvation Diagnosed:** Diagnosed latency spikes caused by synchronous I/O operations when `synapse_history.json` grows infinitely. This crucial finding directly establishes the blueprint for the Async Isolation architecture coming in v0.4.0.

### 🐞 Bug Fixes & Backward Compatibility Stabilization
- **Fixed Port Conflict & 403 Auth Error:** Resolved a bug where the UI failed to synchronize with temporary port assignments (due to ghost processes), which previously caused Admin Creation to fail with a 403 error.
- **Legacy Account Data (`accounts.json`) Parsing Fix:** Implemented safe parsing to support legacy array-formatted user account data, preventing crashes and unintended data resets.
- **Harvest History (`synapse_history.json`) `unshift` Error Prevention:** Fixed a critical `TypeError (reading 'unshift')` crash that occurred when the server attempted to parse legacy array-formatted history files during Harvest execution. Both legacy and modern formats are now safely supported.
