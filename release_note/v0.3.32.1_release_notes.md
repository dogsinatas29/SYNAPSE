# 🚀 SYNAPSE v0.3.32.1 Release Notes

## 🌐 Cross-Network Trace & Semantic Flow Layout

### 🇺🇸 English
**SYNAPSE has successfully upgraded Flow View and achieved distributed architecture collaboration via Harvest!**
- **Semantic Flow Layout & Barycenter Ordering:** Upgraded Flow View from simple topological layers to a Semantic Flow Layout. Introduced single-pass Barycenter Ordering for X-axis placement, drastically reducing edge crossings and improving readability.
- **Back-edge & Entry Point Visualization:** Implemented Entry Point Resolver to establish true execution flow. Visualized back-edges (cycles) in distinct red dashed lines.
- **Universal Network Link Parser:** Introduced the `[SYNAPSE_NETWORK_LINK]` macro. Cross-project dependencies can now be explicitly defined regardless of language syntax (e.g., in `.ts`, `.rs`, `.py`), bypassing the limitations of conservative import resolvers.
- **Client Node Mirroring (IFF Logic):** Fixed an issue where the client's local nodes were rendered as remote (Magenta) on their own screen. The system now perfectly distinguishes between local nodes (gray/default) and remote client nodes (Magenta) by comparing `clientLayer` with `localClientId`.
- **Harvest DAG Merge:** Confirmed that when a client connects to the host server, the client's local files (e.g., `TEST_network.ts`) seamlessly attach as child nodes to the host's files (e.g., `composer.rs`), visualizing the entire cross-network dependency trace in a single unified Flow View.

### 🇰🇷 한국어
**SYNAPSE의 순서도 렌더링 품질이 획기적으로 개선되었으며, Harvest를 통한 분산 아키텍처 협업을 성공적으로 달성했습니다!**
- **시맨틱 순서도 및 무게중심(Barycenter) 정렬:** 순서도를 단순 위상 정렬에서 시맨틱 플로우 레이아웃으로 업그레이드했습니다. 단일 패스(Single-pass) 무게중심 정렬 알고리즘을 도입하여 엣지 꼬임 현상을 획기적으로 줄이고 가독성을 높였습니다.
- **사이클(Back-edge) 및 진입점 시각화:** 진정한 실행 흐름을 형성하도록 Entry Point Resolver를 구현했으며, 사이클(Back-edge) 구조를 붉은 점선으로 뚜렷하게 시각화했습니다.
- **유니버설 네트워크 링크 파서:** `[SYNAPSE_NETWORK_LINK]` 매크로를 도입했습니다. 기존의 보수적인 언어 문법 파서의 한계를 넘어, 주석 하나만으로 언어에 구애받지 않고 명시적인 크로스-프로젝트 의존성을 생성할 수 있습니다.
- **클라이언트 노드 피아식별 (IFF 로직):** 클라이언트가 로컬 화면에서 자신의 노드를 마젠타색(원격)으로 오인하던 렌더링 버그를 거울 치료(IFF 로직) 방식으로 해결했습니다. 이제 내 노드(기본색)와 다른 접속자의 노드(마젠타색)를 정확히 구분합니다.
- **Harvest DAG 병합 증명:** 클라이언트가 호스트에 접속했을 때, 클라이언트의 독립된 파일(`TEST_network.ts`)이 호스트의 메인 아키텍처 파일(`composer.rs`)에 즉각적으로 달라붙어 단일 거대 Flow View로 통합되는 **네트워크 간 의존성 추적(Cross-Network Trace)**을 완벽하게 입증했습니다.
