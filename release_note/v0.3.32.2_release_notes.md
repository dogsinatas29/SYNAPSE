# SYNAPSE v0.3.32.2 Release Notes

## 🚀 Key Updates & Fixes (주요 업데이트 및 수정 사항)

### 1. 🐞 [CRITICAL FIX] File Deletion Sync Bug (수동 노드 삭제 동기화 버그 수정)
- **EN:** Fixed a critical bug where manually created generic files (with `.md`, `.txt`, `.py`, etc. extensions) on the SYNAPSE canvas would not be properly deleted from the physical filesystem. The deletion logic now dynamically maps nodes to files and resolves absolute/relative path conflicts flawlessly.
- **KR:** 캔버스에서 수동으로 생성한 제네릭 파일(`md`, `txt`, `py` 등)을 삭제할 때 물리 시스템에서 실제 파일이 삭제되지 않던 치명적 결함을 해결했습니다. 노드와 파일 간의 매핑 로직을 다변화하고 절대/상대 경로 조합 시 발생하던 오류를 원천 차단했습니다.

### 2. 🛡️ [CRITICAL FIX] Multi-Language External Packages Expansion (다국어 외부 라이브러리 지원 확장)
- **EN:** Massively expanded the `EXTERNAL_PACKAGES` whitelist in the `ReferenceVerifier`. SYNAPSE now recognizes over 100+ standard frameworks and external libraries across JS/TS, Python, Rust, Go, Java, Swift, and C++. Third-party imports (like `express`, `tokio`, `fastapi`) will no longer render as erroneous red ghost nodes, but as clean external references.
- **KR:** `ReferenceVerifier`의 `EXTERNAL_PACKAGES` 화이트리스트를 대규모 확충했습니다. JS/TS, Python, Rust, Go, Java, Swift, C++ 전반에 걸쳐 100여 개 이상의 주요 외부 라이브러리(예: `express`, `tokio`, `fastapi`)를 인식하여, 외부 임포트가 붉은색 에러 노드(Ghost)로 오진되지 않게끔 고도화했습니다.

### 3. 🌐 [CRITICAL FIX] Cross-Workspace Network Link Resolution (네트워크/원격 클러스터 시각화 수정)
- **EN:** Enhanced regex parsing to accurately detect external workspace references (e.g., `[SYNAPSE_NETWORK_LINK]` target paths). Additionally, isolated all external sandbox nodes into a dedicated `cluster_ghost_network_remote` cluster so cross-project RPC/IPC connections are rendered safely and beautifully.
- **KR:** 외부 워크스페이스나 절대 경로를 통한 원격 참조(`[SYNAPSE_NETWORK_LINK]`)를 추출하는 정규식 엔진을 강화했습니다. 또한 외부에서 연결된 Ghost 노드들을 전용 클러스터인 `cluster_ghost_network_remote`로 할당하여, 프로젝트 간 통신(RPC/IPC) 구조가 직관적으로 보이게 수정했습니다.

### 4. 📐 [CRITICAL FIX] Root Node Layout Elimination Bug (루트 파일 좌표 할당 누락 착시 버그 수정)
- **EN:** Fixed a persistent visual bug where files in the root directory (unclustered nodes) appeared stacked infinitely at coordinates `(0,0)` and seemed to disappear. The layout engine now generates a dynamic `📁 Root` cluster to ensure unassigned nodes correctly participate in physics-based world packing, granting each root file its own independent coordinates.
- **KR:** 루트 디렉토리에 있는 파일들(클러스터 미할당 노드)이 모두 `(0,0)` 좌표에 쌓여 겹침 현상으로 인해 사라진 것처럼 보이던 치명적인 레이아웃 착시 버그를 수정했습니다. 이제 팩킹 엔진에 가상의 `📁 Root` 클러스터를 주입하여, 루트 파일들도 독립적인 물리 좌표를 배정받고 안전하게 펼쳐집니다.

### 5. 🧩 [IMPROVEMENT] Manual Node Dynamic Extension Inference (수동 노드 확장자 동적 추론)
- **EN:** When creating a node via the UI without an explicit extension, SYNAPSE now automatically infers the "Top Extension" based on the project's ecosystem (e.g., automatically appending `.ts` in TypeScript projects, `.rs` in Rust) instead of hardcoding `.py`.
- **KR:** UI에서 확장자를 생략하고 노드(파일)를 생성할 경우, 프로젝트 내의 다른 파일들을 전수 조사하여 가장 빈번하게 사용된 확장자를 자동으로 접미(Append)하도록 로직을 업그레이드했습니다. (TypeScript 프로젝트면 `.ts`, Rust면 `.rs` 할당)

### 6. 🧽 [IMPROVEMENT] Schema Validation False Positive Resolved (직렬화 허위 경고 로그 제거)
- **EN:** Patched a false positive console error (`Schema Validation Failed`) that occurred when saving the workspace layout state (`synapse_workspace.json`). The JSON validator now gracefully bypasses node-array checks for non-graph configuration objects.
- **KR:** 워크스페이스 UI 상태(`synapse_workspace.json`) 저장 시, 노드 정보가 없음에도 스키마 검증기에서 배열 타입 오류를 내뿜던 허위 경고(False Positive) 로그를 예외 처리하여 깔끔하게 제거했습니다.
