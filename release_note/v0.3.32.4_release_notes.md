# Release Notes - v0.3.32.4

## 🚀 UX & Visibility Control Improvements (UX 및 가시성 옵션 개선)

This release focuses on dramatically improving the user experience of navigating and interacting with large-scale architecture graphs, specifically enhancing the Cluster Visibility panel, remote client namespaces, and state reset reliability.

이번 릴리스는 대규모 아키텍처 그래프를 탐색하고 상호작용하는 사용자 경험(UX)을 대폭 개선하는 데 중점을 두었으며, 특히 클러스터 가시성 패널, 원격 클라이언트 네임스페이스 격리, 상태 초기화의 안정성을 강화했습니다.

### 🌟 Key Features & Improvements (주요 변경 사항)

**1. Recursive Node Counting in Visibility Panel (폴더 계층 누적 노드 카운트 적용)**
- **EN:** The Cluster Visibility panel now recursively accumulates node counts from all descendant child clusters. A parent folder will accurately display the total number of files/nodes contained within its entire sub-tree, mirroring native file explorer behavior.
- **KO:** 클러스터 가시성 패널의 폴더 이름 옆 `( )` 카운트가 직접 소속된 노드뿐만 아니라 하위/손자 클러스터의 모든 노드 개수를 상위 부모 폴더까지 합산(Accumulate)하여 표시합니다. 중간 부모 폴더가 `(0)`으로 표시되던 직관성 문제를 완벽히 해결했습니다.

**2. Cascade Cluster Visibility Toggling (클러스터 연쇄 숨김 동기화)**
- **EN:** Toggling the visibility of a parent cluster in the visibility panel now automatically cascades the state to all its descendant clusters, ensuring the view remains clean and logically sound.
- **KO:** 부모 클러스터의 체크박스를 끄거나 켤 때, 해당 부모에 속한 모든 하위 자식 클러스터들의 가시성 상태가 연쇄적으로 동기화(Cascade)되어 대규모 구조를 한 번에 숨기고 펼치기 편리해졌습니다.

**3. Remote Client Namespace Isolation (원격 접속 클라이언트 클러스터 격리)**
- **EN:** Remote client architecture structures are now securely isolated under their own `👤 {username}` root virtual cluster, preventing path collisions with the host project's local directories.
- **KO:** 원격 클라이언트의 파일들이 로컬 프로젝트(서버)의 폴더와 섞이는 문제를 해결하기 위해, 모든 원격 클러스터 ID에 계정명 접두어를 부여하고 사용자별 최상위 가상 폴더(`👤 계정명`) 아래에 깔끔하게 격리되도록 분리했습니다.

**4. Real-time REVEAL Navigation (카메라 이동 기능 실시간 좌표 추적 수정)**
- **EN:** The `REVEAL` (→) camera navigation button now accurately tracks the real-time physics and manual drag coordinates of nodes, preventing camera jumps to stale saved positions.
- **KO:** 캔버스에서 노드를 직접 드래그하여 물리적으로 위치를 변경한 후 `REVEAL` 이동 버튼을 눌러도, 과거의 디스크 저장 좌표가 아닌 현재 캔버스 상의 실시간 좌표를 정확히 추적하여 카메라가 이동하도록 개선되었습니다.

### 🐛 Bug Fixes (버그 수정)

- **Layout Engine Hierarchy Fix (다중 루트 폴더 분산 버그 해결):** Fixed an issue where intermediate parent clusters without direct nodes were incorrectly pruned from the layout, causing orphaned child clusters to spam the root level. (노드를 직접 소유하지 않은 '중간 경로 클러스터'가 활성 목록에서 누락되어 하위 폴더들이 최상단에 중복 노출되던 계층 단절 버그를 복구했습니다.)
- **Memory Flush on Reset State (초기화 메모리 누수 해결):** Fixed a critical zombie-resurrection bug where resetting the project state cleared the disk file but failed to flush the backend canvas engine memory. (초기화 기능 작동 시 디스크 파일만 비워지고 백엔드 메모리 상태는 남아 이전 데이터가 다시 부활하던 치명적인 누수 문제를 해결했습니다.)
- **Blacklist Context Menu:** Replaced the "Add to Blacklist" command with a smart "Toggle Blacklist" command in the VS Code explorer context menu. (기존 "Add to Blacklist" 명령어를 추가/제거가 모두 가능한 스마트 "Toggle Blacklist"로 통합 개편했습니다.)
- **Safe Manual Node Creation:** Ensured that manual file creation via the canvas safely creates all intermediate parent directories first to prevent `ENOENT` errors. (수동 노드 생성 시 존재하지 않는 중간 폴더 경로로 인해 발생하던 파일 생성 실패 에러를 방어하는 디렉토리 확보 로직을 추가했습니다.)
- **Strict Typing Fix:** Resolved a `TS2322` strict null check error during remote cluster hierarchy parsing. (원격 클러스터 파싱 중 발생하던 TypeScript 엄격 타입 에러를 수정했습니다.)
- **Harvest Local Scan Client Identification Fix (Harvest 로컬 스캔 계정명 식별 오류 수정):** Fixed a bug where absolute path scanning failed to identify client harvest folders, preventing the `[username]` prefix from appearing on cluster labels. (파일 스캔 중 절대 경로 변환으로 인해 발생하던 하베스트 폴더 인식 실패 버그를 정규식 매칭으로 해결하여 클러스터 이름에 계정명이 정상적으로 표시되도록 조치했습니다.)
- **Frontend Cluster Label Enforcement (프론트엔드 UI 클러스터 라벨링 강제 보장):** Added safety logic to dynamically prepend `[username]` to cluster labels before rendering if the cluster contains `clientUsername` metadata, supporting manually loaded JSON data. (외부 JSON 로딩 시에도 데이터에 계정명이 존재하면 프론트엔드가 렌더링 직전에 `[username]` 라벨을 강제로 주입하도록 방어 로직을 추가했습니다.)
