# SYNAPSE v0.3.32 Release Notes

## Contribution Entity Relationship Visualization

**Release Date:** 2026-06-26
**Status:** ✅ Completed

---

## Summary

v0.3.32 introduces Contribution Entity Relationship visualization, enabling users to track how client contributions flow through the Compare and Harvest pipeline.

---

## Changes

### New Features

| Feature | Description |
|---------|-------------|
| ContributionNode/Edge Types | New TypeScript interfaces for contribution entities |
| CompareProjection | Converts CompareResult[] → ContributionNode(kind='compared') |
| HarvestProjection | Converts HarvestCandidate[] → ContributionNode(kind='harvested') |  
| EdgeGenerator | Links compared/harvested nodes via derived_from edges |
| Contribution Flow View | New flow visualization for entity lineage |

## Technical Details

### Identity Model
- Canonical Identity: `(filePath, userId)`
- Node ID: `hash(filePath, userId)` (SHA256, 16 chars)

### Graph Structure
```
Compared (filePath, userId)
    ↓ (derived_from)
Harvested (filePath, userId)
```

### Design Decisions
- **Option A (Lifecycle Boundary)**: Lifecycle limited to Compared → Harvested. Archive excluded.
- **Option B (Graph Relationship)**: derived_from edges represent entity lineage, not workflow.

---

## Non-Goals (Explicitly Excluded)

- Lifecycle State Visualization
- Workflow Visualization
