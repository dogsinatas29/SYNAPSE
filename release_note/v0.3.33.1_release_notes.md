# 🚀 Release Notes - v0.3.33.1 (LOD & Visibility Optimization)

## 📌 Release Summary (요약)

**EN:** Version 0.3.33.1 introduces a massive overhaul of the LOD (Level of Detail) engine and fixes critical visual bugs related to cluster visibility. The "Roots Only" display mode has been completely fixed to render the Continent-level structure exactly as intended. Additionally, trackpad zoom logic was refactored for smoother navigation without hypersensitivity issues.

**KO:** 버전 0.3.33.1은 LOD(Level of Detail) 엔진의 개편과 클러스터 가시성과 관련된 치명적인 시각적 버그들을 수정했습니다. "Roots Only(루트만 표시)" 모드가 수정되어 의도했던 대로 Continent 레벨 구조를 정확하게 렌더링합니다. 또한, 트랙패드 줌 로직이 개편되어 부드러운 내비게이션을 제공합니다.

---

## ✨ Key Updates (주요 업데이트)

### 1. 3-Level Edge LOD Implementation (3단계 엣지 LOD 도입)
- **EN:** Implemented `FULL`, `CLUSTER`, and `NONE` LOD modes for Edge rendering to resolve the issue where all edges unexpectedly disappeared at certain zoom thresholds on massive repositories (like VSCode-main). Removed hardcoded zoom limits.
- **KO:** 거대 저장소(예: VSCode-main)에서 특정 줌 레벨 도달 시 모든 엣지가 사라져 버리는 현상을 해결하기 위해 `FULL`, `CLUSTER`, `NONE` 3단계 엣지 LOD 모드를 도입했습니다. 하드코딩된 줌 임계값을 완전히 제거했습니다.

### 2. "Roots Only" Visibility Bug Fix (루트 전용 가시성 버그 수정)
- **EN:** Fixed a critical logic flaw in `expandRootsOnly()` where the top-most project root (`folder_root`) was incorrectly collapsed, causing Continents (e.g., `src`, `ui`) to be entirely hidden. "Roots Only" now correctly forces depth-0 roots to be expanded and cleanly collapses depth-1 Continents.
- **KO:** `expandRootsOnly()` 로직의 결함을 수정했습니다. 기존에는 최상위 프로젝트 루트(`folder_root`) 자체가 통째로 닫히면서, 정작 사용자가 보고 싶어 하는 Continent(`src`, `ui` 등)가 화면에서 완전히 사라지는 문제가 있었습니다. 이제 "Roots Only"는 최상위 루트를 열고 1단계 Continent들을 닫힘(Collapsed) 박스로 깔끔하게 표시합니다.

### 3. Trackpad "Microscope" Zoom Fix (트랙패드 줌 버그 수정)
- **EN:** Replaced the previous linear zoom multiplier with a non-linear sensitivity curve based on `e.deltaY` to resolve extreme sensitivity (microscope effect) when zooming with trackpads.
- **KO:** 트랙패드로 줌인/아웃 시 화면이 비정상적으로 급격히 확대/축소되던 현미경 효과(Microscope effect)를 해결하기 위해 `e.deltaY` 기반 비선형 민감도 커브를 적용했습니다.

### 4. Root-Level Orphan Nodes Resolution (루트 레벨 고아 노드 처리)
- **EN:** Resolved an issue where root-level files (such as `package.json` or `README.md`) became "orphan" nodes lacking `cluster_id`. They are now successfully assigned to the overarching `folder_root` cluster.
- **KO:** 프로젝트 루트 위치의 파일들이 `cluster_id`를 잃어버리고 고아(Orphan) 노드가 되던 문제를 해결했습니다. 이제 `folder_root` 클러스터에 정상적으로 배정됩니다.
