# SYNAPSE v0.3.33 Release Notes

[Status: Verified by Commander]

This release introduces a massive overhaul to the Cluster Dragging architecture and significantly improves the Cluster Visibility UX to help manage complex, large-scale architectures seamlessly.

## 🌟 Key Features

**1. Unified Cluster Dragging Architecture (단일 클러스터 이동 아키텍처 개편)**
- **EN:** Completely refactored cluster interactions. Dragging a cluster now recursively moves all nested child clusters, grandchild clusters, and their contained nodes together as a single unified entity. This eliminates the visual chaos of tearing apart nested structures.
- **KO:** 기존 고립된 노드 드래그 방식에서 벗어나, 상위 클러스터 드래그 시 소속된 모든 하위 클러스터와 노드들이 재귀적으로 함께 이동하도록 단일 경로(`draggingCluster`)로 통합했습니다.

**2. Rapid Cluster Visibility Actions (클러스터 가시성 빠른 제어)**
- **EN:** Added three new quick-action buttons to the Cluster Visibility Panel: `Collapse All (-)`, `Roots Only`, and `Expand All (+)`. This enables instant manipulation of the Level of Detail (LOD) for massive node environments.
- **KO:** 클러스터 가시성 패널에 3개의 퀵 액션 버튼(`모든 클러스터 -`, `루트만 보기`, `모든 클러스터 +`)을 추가하여 대규모 구조의 시야를 빠르게 제어할 수 있습니다.

**3. Depth-Based Hit Detection (깊이 기반 히트 감지)**
- **EN:** Implemented depth-based priority for hit detection (`getClusterHeaderAt`) to ensure reliable parent cluster selection. Deeply nested UI overlapping no longer prevents the selection of the correct root or parent cluster.
- **KO:** 깊이(Depth) 기반 우선순위를 적용한 히트 감지를 통해 중첩된 환경에서도 부모 클러스터의 헤더가 우선적으로 정확히 선택되도록 개선했습니다.

## 🛠️ 성능 최적화 및 핫픽스 (Performance & Hotfixes)
- **Webview ServiceWorker InvalidStateError 우회**: `CanvasPanel.ts`에서 엔진 스크립트를 하드 인라인 처리하여 VS Code의 로컬 리소스 페치 오류 차단.
- **O(E) 엣지 루프 제거**: Webview 프레임 렌더링 시 발생하는 10분 지연(IPC Serialize) 방지.
- **O(N^2) Overlap 연산 제거**: 노드 수 1000개 초과 시 물리 연산을 우회하여 렌더러 정지 방지.
