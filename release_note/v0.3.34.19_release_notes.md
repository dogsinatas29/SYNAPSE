## 한국어

### 개요
v0.3.34.19는 SYNAPSE의 아키텍처 감사(Auditor) 파이프라인을 단순한 분류기에서 완전히 검증 가능한 시스템으로 격상시킨 버전입니다. "왜 이 파일이 상위권인가?"에 대한 증거를 모든 단계에서 투명하게 제시하며, 테스트 아티팩트 오염, 역할 분류 오류, 통계 왜곡 등 지속적으로 지적되어 온 신뢰성 문제를 전면 해소합니다.

### 주요 변경 사항

#### 1. Auditor Explainability (설명 가능성)
- **Ghost vs External 분리**: 기존에 뭉뚱그려져 있던 Ghost 의존성을 `GRAMMAR_REFERENCE`, `NPM_PACKAGE`, `UNRESOLVED_IMPORT` 등 6개 항목으로 정밀 분해하여 보고서에 투명하게 공개.
- **Confidence Matrix**: Audit 신뢰도를 하드코딩 없이 `Base 70 + 가감항` 산식으로 동적 계산, 계산 근거를 보고서에 명시.
- **Assembly Audit Reason Codes**: ASSEMBLY_POINT 판정 승인/거부 시 구체적인 사유 코드(`REJECTED_LOW_FANOUT`, `ASSEMBLY_HIGH_BOUNDARY_RATIO` 등) 기록.

#### 2. TEST_ARTIFACT 오염 완전 차단
- **분류 순서 버그 수정**: `ArchitectureAuditor.audit()`이 정렬(sort) 이후에 실행되어 `TEST_ARTIFACT` 페널티가 무력화되던 로직 오류 수정. Auditor를 정렬 이전에 실행하도록 순서 조정.
- **Boundary Evidence 노이즈 제거**: 테스트 자산(`/test/`, `fixtures`, `simulation`)으로 향하는 엣지를 아키텍처 경계 산정에서 원천 차단.
- **결과**: RAW Top 20 → 페널티 정렬 → 최종 Top 10 파이프라인이 물리적으로 검증됨. `vscode-test-resolver`(Boundary 72, FanOut 76)가 RAW 14위에서 최종 Top 10 탈락 확인.

#### 3. Top N 집계 버그 수정
- **bfsLimit 상향 조정**: 후보 풀을 50개로 하드코딩하던 컷오프를 제거. `bfsLimit = min(200, max(100, nodes*0.05))`로 동적 산출하여 Top 100이 실제로 100개 파일을 반영.
- **결과**: 이전 보고서의 `Top 10 = Top 50 = Top 100 = 695`에서 `Top 10 = 656, Top 50 = 2,781, Top 100 = 4,927`로 정상화.

#### 4. UNKNOWN 역할 분류 대폭 개선
- `UI_COMPONENT`(`browser`, `widget`, `view`, `components`) 분류 규칙 신설.
- `DOMAIN_SERVICE`(`editor`, `workbench`, `platform`, `common`, `core`) 분류 규칙 신설.
- `window.ts`, `editor.all.ts` 등 핵심 파일이 UNKNOWN으로 분류되던 현상 해결.

#### 5. Cost Projection 0/0/0/0 버그 수정
- **원인**: `estimateCost()`가 Infrastructure Mesh 분할 후보(`infraSplitCandidates`)가 없는 건강한 코드베이스에서 즉시 `0/0/0/0`을 반환하는 역설 발생.
- **조치**: `topImpactFiles`로 fallback하여 실제 아키텍처 영향도 기반으로 비용을 추정.

## English

### Overview
v0.3.34.19 upgrades the SYNAPSE Architectural Auditor pipeline from a simple classifier to a fully verifiable system. Every top-ranked file now comes with transparent evidence at every stage. This release resolves persistent reliability concerns including test artifact contamination, role misclassification, and statistical distortion.

### Key Changes

#### 1. Auditor Explainability
- **Ghost vs External Separation**: Ghost dependencies are now decomposed into 6 precise categories (`GRAMMAR_REFERENCE`, `NPM_PACKAGE`, `UNRESOLVED_IMPORT`, etc.) and exposed in reports.
- **Confidence Matrix**: Audit confidence is dynamically computed via `Base 70 + adjustments` formula, with the full breakdown shown in reports.
- **Assembly Audit Reason Codes**: Approval/rejection of ASSEMBLY_POINT candidates is recorded with explicit reason codes (`REJECTED_LOW_FANOUT`, `ASSEMBLY_HIGH_BOUNDARY_RATIO`, etc.).

#### 2. Full TEST_ARTIFACT Contamination Elimination
- **Classification Order Bug Fixed**: `ArchitectureAuditor.audit()` was executing *after* the sort, neutralizing `TEST_ARTIFACT` penalties. Fixed by running the auditor *before* the sort.
- **Boundary Evidence Noise Removed**: Edges targeting test assets (`/test/`, `fixtures`, `simulation`) are now excluded from architectural boundary statistics.
- **Verified**: Physical proof via RAW Top 20 dump log — `vscode-test-resolver` (Boundary 72, FanOut 76) ranked #14 in RAW candidates but was completely absent from the final Top 10. ✅

#### 3. Top N Aggregation Bug Fixed
- **bfsLimit increased**: Removed 50-file hard cap. Now uses `min(200, max(100, nodes*0.05))` for dynamic candidate pool sizing.
- **Result**: Previous `Top 10 = Top 50 = Top 100 = 695` → corrected to `Top 10: 656, Top 50: 2,781, Top 100: 4,927`.

#### 4. UNKNOWN Role Classification Significantly Improved
- Added `UI_COMPONENT` rule (`browser`, `widget`, `view`, `components`).
- Added `DOMAIN_SERVICE` rule (`editor`, `workbench`, `platform`, `common`, `core`).
- Files like `window.ts` and `editor.all.ts` are no longer classified as UNKNOWN.

#### 5. Cost Projection 0/0/0/0 Bug Fixed
- **Root Cause**: `estimateCost()` immediately returned `0/0/0/0` for healthy codebases with no Infrastructure Mesh split candidates — the healthier the architecture, the worse the metrics appeared.
- **Fix**: Falls back to `topImpactFiles` to compute cost estimates based on actual architectural impact.
