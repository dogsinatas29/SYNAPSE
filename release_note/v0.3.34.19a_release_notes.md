## 한국어

### 개요

v0.3.34.19a는 v0.3.34.19에서 발견된 세 가지 버그를 수정하는 패치 릴리즈입니다.

1. **Cost Projection `Files Affected` 루트 원인 수정** — `ValidationEngine`이 candidate 객체에 `consumers` 필드를 채우지 않아, `ValidationReportBuilder`가 항상 fallback인 `impactFiles.length = 100`을 사용하던 근본 원인 제거
2. **Cost Projection `undefined` 출력 방지** — `estimatedCost`가 undefined일 때 `N/A` 대신 `0`이 출력되도록 `?? 0` 가드 추가
3. **클러스터 Collapse 상태 모델 분리** — 부모 collapse 시 자식의 사용자 의도(`collapsed`)가 덮어써지고, expand 시 자식의 자식이 강제로 열리던 문제를 `forcedCollapsed` 필드 분리로 해결

### 주요 변경 사항

#### 1. Cost Projection `consumers` 필드 미주입 버그 수정 (근본 원인)

**파일**: `src/core/validation/ValidationEngine.ts`, `src/core/validation/ValidationReportBuilder.ts`

**3단계 버그 체인**:

```text
ValidationEngine.ts
  candidate 객체 생성 시 consumers 필드 없음  ← 진짜 원인
      ↓
ValidationReportBuilder.ts
  f.consumers || []  →  항상 []
  consumerSet.size   →  0
  fallback: impactFiles.length  →  100 고정 출력
```

**관찰된 증상**:

| 상태 | 원인 |
|------|------|
| `Files Affected = 100` 고정 | `consumers` 미주입 → fallback이 Top N 컷오프(100) 사용 |
| `N/A` 출력 | `estimatedCost` 자체가 undefined일 때 optional chaining만 사용 |
| `0 / 0 / 0 / 0` | `topImpactFiles`가 빈 배열일 때 early return |

**수정 — `ValidationEngine.ts`**:

```ts
// consumers = 이 파일을 import하는 파일 목록 (fan-in sources)
const consumerSet = new Set<string>();
for (const e of intentEdges) {
    if (e.target === filePath) consumerSet.add(e.source);
}
// → candidate.consumers = [...consumerSet]
```

`intentEdges`는 이미 test/grammar 필터가 적용된 상태이므로 별도 필터 불필요.

**수정 — `ValidationReportBuilder.ts`**:

```ts
// ?? 0 가드: estimatedCost가 undefined일 때 "undefined" 대신 0 출력
`- **Files Affected**: ${report.estimatedCost?.filesAffected ?? 0}`

// consumers dedup
const consumerSet = new Set<string>();
for (const f of impactFiles) {
    for (const c of (f.consumers || [])) consumerSet.add(c);
}
const filesAffected = consumerSet.size > 0 ? consumerSet.size : impactFiles.length;
```

**수정 후 예상 변화**:

| 분석 대상 | 수정 전 | 수정 후 |
|-----------|---------|---------|
| VSCode workbench (파일 3552, BE 45975) | Files Affected = 100 | 실제 fan-in consumer 수 |
| Root 전체 (파일 13544, BE 82452) | Files Affected = 100 | 실제 fan-in consumer 수 |

로그: `[CostProjection] filesAffected=XXX(consumers=YYY)` 에서 `consumers > 0` 확인 가능.

#### 2. 클러스터 Collapse 상태 모델 분리 (`collapsed` / `forcedCollapsed`)

**파일**: `ui/canvas-engine.js`

**원인**:

`cluster.collapsed` 단일 필드가 두 가지 의미를 혼재하고 있었음:
- 사용자가 직접 접은 상태 (User Intent)
- 조상 클러스터 때문에 강제로 접힌 상태 (Ancestor Override)

부모를 collapse하면 자식의 `collapsed = true`로 덮어써서 원래 상태를 잃어버림.
부모를 expand하면 모든 descendants를 `collapsed = false`로 강제 설정.
→ 사용자가 명시적으로 접어놓은 자식 클러스터까지 전부 열림.

**수정**:

```ts
// Before: 한 필드에 두 의미 혼재
cluster.collapsed = true/false

// After: 역할 분리
collapsed: boolean        // 사용자 의도 — 절대 조상이 건드리지 않음
forcedCollapsed: boolean  // 조상 collapse 시 설정 / expand 시 해제
```

가시성 판단:
```ts
isHidden = collapsed || forcedCollapsed
```

**동작 비교**:

| 동작 | 수정 전 | 수정 후 |
|------|---------|---------|
| 부모 Collapse | 자식 `collapsed = true` (사용자 의도 덮어씀) | 자식 `forcedCollapsed = true` (사용자 의도 보존) |
| 부모 Expand | 모든 descendants `collapsed = false` (자식의 자식까지 강제 open) | 모든 descendants `forcedCollapsed = false` (사용자가 접은 자식은 그대로) |

**중첩 collapse 안전성**:
```text
Root → ParentA → ParentB → Child

ParentA Collapse  →  Child.forcedCollapsed = true
ParentB Collapse  →  Child.forcedCollapsed = true  (덮어써도 동일값, 안전)
ParentA Expand    →  Child.forcedCollapsed = false
                     (ParentB.collapsed = true이면 ParentB 체크로 여전히 가려짐)
```

**가시성 체크 수정 위치**:
- `canvas-engine.js:3810` — 박스 선택 노드 필터
- `canvas-engine.js:4216` — 히트 테스트 노드 필터
- `canvas-engine.js:8715` — WebGL LOD Activity 필터
- `toggleClusterCollapse()` — collapse/expand 전파 로직 전면 교체 (`_preCollapseState` 제거)

## English

### Overview

v0.3.34.19a is a patch release fixing three bugs discovered after v0.3.34.19:

1. **Cost Projection `Files Affected` root cause fix** — `ValidationEngine` never populated the `consumers` field on candidate objects, causing `ValidationReportBuilder` to always fall back to `impactFiles.length = 100`
2. **Cost Projection `undefined` output prevention** — added `?? 0` guards to prevent raw `undefined` from rendering as `N/A`
3. **Cluster collapse state model split** — separated user intent (`collapsed`) from ancestor override (`forcedCollapsed`) to prevent grandchild force-open on parent expand

---

### Key Changes

#### 1. Cost Projection `consumers` Field Missing — Root Cause Fix

**Files**: `src/core/validation/ValidationEngine.ts`, `src/core/validation/ValidationReportBuilder.ts`

**3-step bug chain**:

```text
ValidationEngine.ts
  candidate object built WITHOUT consumers field  ← root cause
      ↓
ValidationReportBuilder.ts
  f.consumers || []  →  always []
  consumerSet.size   →  0
  fallback: impactFiles.length  →  always 100
```

**Symptoms observed**:

| State | Cause |
|-------|-------|
| `Files Affected = 100` (fixed) | `consumers` never set → fallback uses Top N cutoff |
| `N/A` output | `estimatedCost` undefined, no fallback guard |
| `0 / 0 / 0 / 0` | `topImpactFiles` empty → early return |

**Fix — `ValidationEngine.ts`**:

```ts
// consumers = files that import THIS file (fan-in sources)
const consumerSet = new Set<string>();
for (const e of intentEdges) {
    if (e.target === filePath) consumerSet.add(e.source);
}
// → candidate.consumers = [...consumerSet]
```

`intentEdges` is already filtered (no test/grammar), so no additional filter needed.

**Fix — `ValidationReportBuilder.ts`**:
- `?? 0` guard on all four Cost Projection renderer fields (MD + HTML)
- `filesAffected` now uses deduplicated consumer set size

---

#### 2. Cluster Collapse State Model: `collapsed` / `forcedCollapsed` Split

**File**: `ui/canvas-engine.js`

`cluster.collapsed` was overloaded: user intent and ancestor override shared one field.

**Fix**: Two separate fields.

```ts
collapsed: boolean        // user's own fold intent — never touched by ancestor
forcedCollapsed: boolean  // set true on ancestor collapse, false on ancestor expand
```

```ts
// Visibility
isHidden = collapsed || forcedCollapsed
```

| Action | Before | After |
|--------|--------|-------|
| Parent Collapse | Child `collapsed = true` (user state destroyed) | Child `forcedCollapsed = true` (user state preserved) |
| Parent Expand | All descendants `collapsed = false` (force-opens grandchildren) | All descendants `forcedCollapsed = false` (user's fold state untouched) |

Visibility checks updated at: box-select filter, hit-test filter, WebGL LOD Activity filter, `toggleClusterCollapse()`.
