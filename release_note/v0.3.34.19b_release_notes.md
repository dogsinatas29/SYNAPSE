## 한국어

### 개요

클러스터 스코프 분석 시 `ValidationEngine`이 `AGGREGATE_*` 노드를 통해 외부 의존성을 오염원으로 끌어들이던 버그 수정.

**Subgraph Extraction은 성공했으나, Evidence/Impact 파이프라인이 AGGREGATE 경계 엣지를 통해 외부 경로(`extensions/*`, `cli/*`)를 다시 수집하던 문제**가 근본 원인.

---

### 버그 체인

```
VirtualDebugger
  visibleClusterIds로 targetNodes 필터 → 성공 (3541 files)
  경계 엣지를 AGGREGATE_* 노드로 대체하여 targetEdges에 포함
    예) e.from = 'AGGREGATE_folder_extensions'
        e.originalFrom = 'extensions/typescript-language-features/...'

intentEdges = snapshot.edges  ← AGGREGATE 엣지 포함

ValidationEngine
  impactMap 루프     → AGGREGATE_source 엣지 통과 → 외부 파일이 타겟으로 집계
  consumers 루프     → AGGREGATE_source가 consumer로 등록
  ghostEvidence      → AGGREGATE_source 엣지가 증거로 노출
  boundaryEvidence   → 외부 경로(extensions/copilot/cli) 그대로 출력
  couplingBreakdown  → extensions 42.7% (전역과 동일한 비율 복사)
```

### 수정

**파일**: `src/core/validation/ValidationEngine.ts`

4곳에 단일 가드 추가:

```ts
// impactMap 루프
if (e.source?.startsWith('AGGREGATE_') || e.target?.startsWith('AGGREGATE_')) continue;

// consumers 루프
if (e.target === filePath && !e.source?.startsWith('AGGREGATE_')) consumerSet.add(e.source);

// ghostEvidence / boundaryEvidence / docEvidence
if (e.source?.startsWith('AGGREGATE_')) return false;
```

### BFS 안전성 확인

3-Hop Cross-Cluster BFS(`reachability` 계산)는 `snapshot.edges`를 순회하나, AGGREGATE 노드는 `nodeMap`에 없어 `cluster_id`를 얻지 못함 → cluster count 미산입. **BFS는 별도 패치 불필요.**

## English

### Overview

Fixes evidence and impact pipeline contamination when analyzing a selected cluster scope. `AGGREGATE_*` nodes (collapsed external clusters injected by VirtualDebugger's boundary edge replacement) were leaking external paths (`extensions/*`, `cli/*`) into impact ranking, consumers, and evidence collection.

### Bug Chain

```
VirtualDebugger
  Filter targetNodes by visibleClusterIds → OK (3541 files)
  Replace boundary edges with AGGREGATE_* nodes → still in targetEdges
    e.g. e.from = 'AGGREGATE_folder_extensions'

intentEdges = snapshot.edges  ← includes AGGREGATE edges

ValidationEngine
  impactMap loop    → AGGREGATE source passes through → external files as targets
  consumers loop    → AGGREGATE sources registered as consumers
  ghostEvidence     → AGGREGATE edges surface as evidence
  boundaryEvidence  → external paths (extensions/copilot/cli) exposed
  couplingBreakdown → extensions 42.7% mirrors global stats
```

### Fix

**File**: `src/core/validation/ValidationEngine.ts`

Single guard at 4 sites:

```ts
// impactMap loop
if (e.source?.startsWith('AGGREGATE_') || e.target?.startsWith('AGGREGATE_')) continue;

// consumers loop
if (e.target === filePath && !e.source?.startsWith('AGGREGATE_')) consumerSet.add(e.source);

// ghostEvidence / boundaryEvidence / docEvidence
if (e.source?.startsWith('AGGREGATE_')) return false;
```

### Verification

| Metric | Before | After |
|--------|--------|-------|
| Files Count (workbench) | 3552 | 3541 |
| Top coupling domain | extensions (42.7%) | **vs (43.9%)** |
| Boundary Edges | 45975 | 45917 |
| Matches global JSON | Almost identical | **Independent** |

Remaining `extensions (42%)` is correct — workbench genuinely depends on extensions. BFS reachability traversal confirmed safe (AGGREGATE nodes absent from nodeMap, no cluster count impact).
