# SYNAPSE Release Notes
**Version:** v0.3.34.27
**Date:** 2026-08-21
**Type:** Milestone (Topology Mutation Architecture)

## 🚀 Overview

v0.3.34.27 릴리즈는 **가상 아키텍처 토폴로지 시뮬레이션(Virtual Topology Mutation)**의 기초를 확립한 버전입니다. 
가장 중대한 과제였던 "70K 노드를 갖춘 리눅스 커널 크기의 그래프에서 어떻게 OOM 없이 결함 시나리오를 시뮬레이션할 것인가?"를 `TopologyOverlay` 설계 패턴과 `Compute → Report → Discard` 원칙으로 돌파했습니다.

## 🛠️ Key Architectural Changes

### 1. Topology Overlay Pattern (Graph Clone Free)
- 전체 그래프 데이터를 복사하지 않고, 변경된 물리적 단절(`removedNodes`, `removedEdges`)만 Delta 형태로 기록하는 경량화된 가상 메모리 레이어를 도입했습니다.
- 이를 통해 수만 개의 노드에서 시뮬레이션을 돌려도 추가되는 메모리 오버헤드가 사실상 O(Mutated) 수준으로 0에 수렴합니다.

### 2. State Mutation Separation
- 시뮬레이션 엔진이 타겟 노드의 제거 이후 "주변 노드의 HealthState가 어떻게 오염되는가"를 임의로 추론(State Simulation)하는 행위를 원천 차단했습니다.
- 27버전은 순수하게 "어떤 노드와 엣지가 끊어질 때 망이 어떻게 단절되는가?"라는 토폴로지 중심의 물리적 파급 범위 변화만 관찰합니다.

### 3. Engine Re-use (26버전 엔진 재사용)
- 가상 시뮬레이터(`TopologyMutator`)를 위해 새로운 전파 알고리즘을 짜지 않았습니다.
- 기존 v0.3.34.26에서 검증된 `FailurePropagator` 엔진에 가상 `Overlay`만 덧씌워 투과적으로 재호출하도록 설계하여 로직 중복과 복잡도를 억제했습니다.

### 4. Simulation Target Selector
- 엔진 계층이 리포트 계층의 문자열 포맷(Blast Radius HIGH)에 의존하는 Layer Leak를 제거했습니다.
- 대신 `Top N Impact Nodes`를 산출하여 가장 치명적인 파급력을 갖는 노드들만 우선적으로 시뮬레이션 하도록 선택기(Selector)를 분리했습니다.

## 📈 Performance & Stability
- 리눅스 커널 7.2-rc3 (70,089 노드 / 386,273 엣지) 시뮬레이션 테스트 결과:
  - Topology Overlay 할당 비용: **+0.00MB 방어 완료**
  - Compute 이후 리포트를 반환함과 동시에 가비지 컬렉션 처리가 되어 메모리가 안정적으로 해제됨을 증명했습니다.

## 💡 Developer Note (Invariant)
> **Graph Clone is Strictly Prohibited**
> 
> 어떠한 경우에도 가상 시나리오를 돌려보기 위해 원본 그래프 배열이나 객체를 복사(Deep Copy)해서는 안 됩니다. 변경점이 필요하다면 반드시 `TopologyOverlay` 구조체에 오퍼레이션(`ADD`, `REMOVE`)만을 쌓아 필터로 동작하게 하십시오.
> 또한 시뮬레이션 궤적(Trajectory)은 절대로 영구 보관/캐싱되어선 안 되며, Report 생성 즉시 Discard 되어야 합니다.
