# 🚀 SYNAPSE v0.3.34.40 Release Notes

## 🆕 New Features & Enhancements

### 1. Separation of Complexity and Control Rankings (권력 구조 탐지기 도입)
- **Architectural Complexity Ranking (Report A):**
  - Identifies highly coupled subsystems that are difficult to refactor.
  - Metrics: Size, Internal Density, External Density.
  - Highlights: `drivers/gpu/drm/i915`, `drivers/gpu/drm/amd/display`.
- **Architectural Control Ranking (Report B):**
  - Identifies system dominators based on blast radius and dependency centralization.
  - Metrics: Fan-In (Inbound Edges), Size.
  - Highlights: `arch/arm`, `drivers/clk`, `drivers/acpi`, `block`.
- **Impact:** Differentiates between "messy subsystems" (Complexity) and "system controllers" (Control), providing a true architectural atlas of the Linux kernel.

### 2. Boundary Promotion Audit & Verification
- Implemented exact member file tracking (`memberFiles`) and hierarchy depth (`depth`) for rejected boundary candidates.
- Discovered that the `MIN_INTERNAL_EDGES=20` threshold is operating correctly, accurately dropping loose collections of files (e.g., `src/core/collaboration`) and keeping only genuine subsystems.
- Proved that the Boundary Detection algorithm is highly reliable and free of logic bugs regarding directory aggregation.

### 3. Metric Enhancements
- Added `inboundEdges` tracking to `BoundaryGraphBuilder.ts` and `SemanticContext.ts`.
- Refined `InsightEngine` report grouping by categorizing boundaries into Tier 1 (Architecture Level), Tier 2 (Subsystem Level), and Tier 3 (Micro Boundaries), drastically improving report readability.

## 🇰🇷 릴리즈 노트 (Korean)

### 1. 복잡도(Complexity)와 지배력(Control) 랭킹 분리
- **복잡도 랭킹 (Report A):**
  - 내부적으로 얽혀 있어 리팩토링이 어려운 서브시스템 식별.
  - `i915`, `amd/display` 등 그래픽 스택 상위 랭크.
- **지배력 랭킹 (Report B):**
  - 폭발 반경(Blast Radius)과 의존성 집중도를 기반으로 시스템 권력자 식별.
  - Fan-In(나를 참조하는 모듈 수) 알고리즘 적용 (`inboundEdges`).
  - `arch/arm`, `clk`, `acpi`, `block` 등 실제 커널 핵심 인프라 상위 랭크.
- **효과:** "단순히 지저분한 모듈"과 "시스템 전체를 지배하는 모듈"을 분리하여 완벽한 아키텍처 지도를 완성했습니다.

### 2. 바운더리 승격 감사(Audit) 및 검증
- 바운더리로 승격되지 못한 후보군에 대해 실제 파일 목록과 뎁스를 추적하는 감사 로그를 추가했습니다.
- 조사 결과, `MIN_INTERNAL_EDGES=20` 임계값이 느슨한 파일 모음(예: `collaboration`)을 정확히 쳐내고 진짜 서브시스템만 남기는 본연의 역할을 훌륭히 수행 중임을 증명했습니다.

### 3. 메트릭 고도화
- `BoundaryGraphBuilder`에 Fan-In 측정을 위한 `inboundEdges` 속성을 추가했습니다.
- 아키텍트 리포트의 가독성을 극대화하기 위해, 바운더리들을 Tier 1, 2, 3으로 분류하고 잔챙이 노드(Tier 3)는 시야에서 숨기도록 개선했습니다.
