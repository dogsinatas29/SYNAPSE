# SYNAPSE Release Notes - v0.3.34.56

## 🚀 Overview
- **버전:** v0.3.34.56
- **주요 목표:** `CascadeFailureDetector`의 `propagationDepth` 필드에 대한 Contract Void(Dead Field) 가설 검증 및 실데이터 관측 가능성 증명.

## 🧠 핵심 조사 및 증명 결과 (FACTs)
1. **전파 경로 무결성 (Consumer 도달 확인)**:
   - `CascadeFailureDetector`에서 생성된 패턴 객체가 `ReportBundleGenerator`를 거쳐 `SIMULATION_DEBUG.md`에 정상적으로 도달함을 확인했습니다.
2. **Mock 기반 랭킹 민감도 검증 (Sensitivity Analysis)**:
   - `propagationDepth=0`으로 고정할 경우, P50 컷오프(Median) 기준선이 크게 하락하며, 깊지만 좁은(Deep-but-narrow) 형태의 치명적 결함 노드들이 후보군에서 탈락하는 심각한 랭킹 요동 현상을 확인했습니다.
3. **실데이터 관측 가능성 증명 (Real-world Extractability)**:
   - `project_state.json` 스냅샷을 활용하여 `FailurePropagator`의 전파 시뮬레이션 추출에 성공했습니다.
   - 21개의 실 데이터 연쇄 붕괴 사례(`cascadeImpact > 0`)를 성공적으로 관측하였으며, 각 노드별 직/간접 피해 분포를 확보했습니다.

## ⚠️ 아키텍처 상태 선언
- **Dead Field 가설 기각 유력**: Mock 테스트 결과, `propagationDepth`는 점수식에 극적인 랭킹 변화를 일으키는 핵심 변수임이 입증되었습니다.
- **Essential Metric 미확정**: Mock에서의 변화가 실 데이터 환경(Real Dataset)에서도 동일하게 나타나는지(Cascade와 Depth가 완벽한 양의 상관관계를 갖지는 않는지) 증명될 때까지 Producer(생산자) 설계 및 복구를 유보합니다.

## 📝 넥스트 마일스톤 (.57) 예고
