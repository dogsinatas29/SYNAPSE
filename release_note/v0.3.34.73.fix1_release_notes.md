# 🚀 SYNAPSE v0.3.34.73.fix1 Release Notes

## 🇰🇷 한국어 (Korean)

### 🐛 버그 수정 및 안정성 향상 (Bug Fixes & Stability)
* **무한 부트스트랩 (EROFS) 현상 해결**: 프로젝트 초기 부트스트랩 시 샌드박스를 벗어나는 외부 참조나 시스템 노드를 물리적(Mock) 빈 파일로 생성하려다 발생하던 `EROFS (Read-only file system)` 크래시 및 무한 재시도 루프를 완벽히 해결했습니다. 이제 프로젝트 범위 내의 유효한 대상에 대해서만 스냅샷을 생성합니다.
* **C/C++ 참조 해석(Resolver) 개선**: `ReferenceResolver`가 불필요하게 `fs.existsSync`에 의존하던 결함을 제거하고, `./` 상대 경로를 정상적으로 정규화하도록 수정했습니다.

### ✨ 기능 개선 및 확장 (Enhancements)
* **C++ 스캐너 확장자 추가 (`.inc`, `.inl`, `.hh`)**: 기존 스캐너가 누락했던 `Godot` 및 C++ 생태계의 주요 템플릿/인라인/매크로 인클루드 헤더 확장자를 지원합니다. 이를 통해 **이전에 억울하게 Ghost(미해결)로 누락되었던 593건의 핵심 내부 의존성 엣지가 실제 프로젝트 노드(Real Nodes)로 100% 정상 복구(PROVEN)** 되었습니다.
* **클러스터 이동 조작(UX) 개선**: 캔버스 줌(Zoom) 비율이 낮을 때 클러스터 헤더(이동 손잡이)를 잡기 힘들던 문제를 해결했습니다. 이제 화면 스케일에 비례하는 넉넉한 히트 패딩(30px)이 추가되어 대충 잡아도 부드럽게 클러스터를 이동할 수 있습니다.

### 📊 데이터 무결성 검증 (Data Integrity)
* **Ghost 노드 재분류 완료**: 현재 그래프에 잔류한 GHOST 노드들을 전수 검증한 결과, 물리적으로 디스크에 존재하지만 엔진이 놓친 결함 건수는 **0건**임이 증명되었습니다. 남은 미해결 참조는 모두 C/C++ 표준/시스템 헤더(예: `stdio.h`, `unistd.h`), 외부 SDK 서드파티, 빌드 시점 생성 파일(`.gen.h`) 등 물리 파일이 없는 정상적인 External 의존성으로 판별되었습니다.

## 🇺🇸 English

### 🐛 Bug Fixes & Stability
* **Infinite Bootstrap (EROFS) Loop Resolved**: Fixed an issue where the `BootstrapEngine` attempted to physically write mock files for system nodes or external references outside the sandbox boundary, leading to an `EROFS (Read-only file system)` crash and an endless retry loop. Only valid in-project dependencies are now written to the snapshot.
* **C/C++ Reference Resolver Optimization**: Removed the dirty `fs.existsSync` hack and fixed the normalization logic for `./` relative paths.

### ✨ Enhancements
* **C++ Scanner Extension Support (`.inc`, `.inl`, `.hh`)**: Added support for common C++ inline, template, and macro include files that were previously ignored. As a result, **593 internal dependencies that were incorrectly classified as Ghosts have been 100% correctly restored (PROVEN)** and successfully linked to their Real Nodes.
* **Improved Cluster Dragging UX**: Expanded the hit area for cluster headers dynamically based on the camera zoom scale (30px padding). It is now much easier to grab and move clusters even when fully zoomed out.

### 📊 Data Integrity Validation
* **Ghost Node Reclassification**: Conducted a full disk validation on the remaining unresolved GHOST nodes. Proven that exactly **0 internal nodes** were missed by the engine due to a scanning defect. The remaining ghosts correctly represent genuine external dependencies without physical local files, such as C/C++ standard/system headers (`stdio.h`, `unistd.h`), third-party SDKs, and build-time generated headers (`.gen.h`).
