# 🚀 Release Notes - v0.3.34.74

## 📌 주요 변경 사항 (Key Changes)
* **Ghost 노드 유실 및 External 오분류 복구 기능 추가**: C/C++ 프로젝트 스캔 시, AST 추출 파이프라인에서 파일 누락이나 상대 경로 해석 실패(PathResolutionFailure)로 인해 `unresolved` 처리되던 include 경로들을 복구하기 위해 `projectRoot` 기반의 탐색 Fallback 로직을 추가했습니다.

## 🛠 상세 내역 (Detailed Updates)

### 1. `ReferenceResolver.ts` C++ Project Root Base Search 구현
* **UNIQUE_EXACT_MATCH 우선 복구:** `#include "core/Body.inl"`와 같이 상대 경로로 해석하면 찾을 수 없지만, 프로젝트 루트 기반으로 결합 시 실제 파일이 존재하는 경우 이를 물리적으로 확인(`fs.existsSync`)하여 `direct` 참조로 복원합니다.
* **스캐너-리졸버 갭 해소:** `existingNodeIds` 맵에 존재하지 않는 타겟이라도 `fs.existsSync`를 통과하면 `unresolved`로 누락하지 않고 `direct`로 반환합니다. 이를 통해 단순히 스캐너/AST에서 배제된 인클루드 타겟들도 그래프 엣지 유실 없이 보존됩니다.
* **성능 최적화:** 무분별한 파일 I/O를 방지하기 위해 `isCppHeader`(`endsWith('.h', '.hpp', '.inc', '.inl', '.cpp', '.cc')`) 검증을 먼저 수행한 후 C++ 타겟에 한해서만 디스크 확인 훅을 실행하도록 제한했습니다.

### 2. 코드베이스 건전성 개선
* **구문(AST) 수정 및 타입 체커 패스:** `ReferenceResolver.ts` 내 괄호 매칭 에러 및 함수 반환 관련 Syntax 픽스를 완벽히 수행하였으며 `tsc --noEmit` 검증을 통과했습니다.
* **Ghost 개체수 하향 안정화 지원:** Godot 등 거대한 코드베이스를 대상으로 할당할 때 1,416개의 미확인 참조(Ghost) 중 `PathResolutionFailure` 범주인 277건에 대한 직접적인 복구 신뢰성을 확보했습니다.

## ⚠️ 알려진 제약 사항 및 Next Steps
