### 5. 알려진 문제점 및 차기 마일스톤 과제 (Known Limitations & Next Backlog)

1. **최상위 `tests/` 상대 경로 미인식 결함**:
   - `NodeBuilder.ts`의 `relPath.includes('/test/')` 조건이 선행 슬래시 없는 최상위 디렉터리(`tests/...`)와 매칭되지 않아, Godot 등 최상위 테스트 폴더의 188개 노드가 `NodeRole.RUNTIME`으로 오분류되어 A1 후보에 잔존함. $\rightarrow$ 차기 마일스톤에서 선행 슬래시/정규식 경로 정규화 적용 예정.
2. **서드파티·외부 라이브러리 분석 범위(Scope Boundary) 선언 부재**:
   - `thirdparty/` 및 외부 라이브러리(`apksig`)가 내부 소스 코드와 동일한 위상 공간에서 경쟁하여 A1/E2 상위에 다수 노출됨. 구조적 신호(위상/임계값)만으로는 구분이 불가능하므로, 차기 마일스톤에서 **선언 기반 분석 범위(Scope Exclusion)** 계약을 도입할 예정.
3. **C/C++ 진입점(O2) 계층 역전 현상**:
   - C/C++ 구현 파일(`.cpp`)은 타 파일에서 `#include`되지 않아 기본 `inDegree = 0`인 반면, 실제 진입점인 `main/main.cpp`는 함수 호출(`type: CALL`) 엣지가 유입되어 `inDegree = 9`로 탈락함.
   - 단순 `fanIn = 0` 기준은 C/C++에서 의미를 상실하므로, 차기 마일스톤에서 **다국어 진입점 계약(Language Entry Contract)**을 수립하여 해결 예정.

## 🇺🇸 English
**Version Summary**: Build System & Packaging Pipeline Isolation, Multi-Language Module Resolver Refinement, Virtual Node Identifier Alignment, and 7-Project Full Validation

This release eliminates pipeline contamination caused by target project build systems (`build.rs`, `CMakeLists.txt`, `Makefile`, `*.gradle`, `meson.build`, `SConstruct`, etc.), packaging/installer assets (`msi`, `wix`, `nsis`, `debian`, `rpm`, `flatpak`, `snap`, `installer`, `packaging`, etc.), and build manifests (`Cargo.toml`, `package.json`, `pyproject.toml`, `go.mod`, `tsconfig.json`, etc.) entering the SYNAPSE domain graph ($V_{\text{app}}$).

Project-specific path hardcodings were completely removed in favor of universal compiler and packaging standards. Furthermore, `GhostExpander` established the strict invariant `Node.id === Node.filePath = targetNodeId`, permanently eliminating dangling edges during projection.

### Key Changes
1. **Universal Build & Packaging Asset Exclusion ($V_{\text{build}} \cap V_{\text{app}} = \varnothing$)**
   - Enforced compiler-standard exclusion (`testdata`, `msi`, `wix`, `nsis`, `debian`, `rpm`, `build.rs`, `CMakeLists.txt`, `Makefile`, etc.) across `BootstrapEngine` and `DataPipeline`.
   - Prevented changelog and document resurrection in `liteBootstrap` caused by legacy `isUserCreated` flags.
2. **Multi-Language Resolver Refinement**
   - **Rust**: Added Cargo.toml workspace and dependency path normalization, hyphen-to-underscore crate mapping, and uninitialized submodule guards.
   - Standardized Go package domain splitting, Java/Kotlin standard library vs external package separation, Node.js built-ins (`node:*`), and C POSIX header handling.
   - Refined `ShellScanner` regex to reject false-positive CLI flags, numbers, and plain English words.
3. **Architecture Report Pattern Refinement & Determinism (O2, A1, E2)**
   - **O2 (`DEPENDENCY_ROOT`)**: Excluded `NodeRole.TEST` nodes from candidate pools.
   - **A1 (`SYSTEM_CORE`) & E2 (`CHANGE_AMPLIFIER`)**: Excluded test components (`testNodeRatio >= 0.8`), replaced P50 with P90 top 10% slice (`ceil(0.1 * N)`), with deterministic tie-breaking.
   - **Factual A1 Interpretation Guide**: Updated description to clearly detail the `controlScore` calculation without subjective adjectives.
   - **Float Formatting & Byte-for-Byte Reproducibility**: Applied `toFixed(3)` with `toPrecision(3)` non-zero guards; achieved 100% SHA-256 match across runs.
4. **Virtual Node Identifier Alignment (`Node.id === Node.filePath`)**
   - Aligned `filePath` with namespaced `targetNodeId` in [`GhostExpander.ts`](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/src/core/GhostExpander.ts), ensuring zero dangling edges across `ProjectionLayer`.
5. **Known Limitations & Next Backlog**
   - Relative path matching for root-level `tests/` directories without leading slashes.
   - Declaration-based scope boundary contract (`scopeExclusions`) for separating third-party source trees.
   - Language-aware entry point contracts for C/C++ projects where `.cpp` files act as include sinks and call edges increase inDegree.
6. **Full Validation Across 7 Diverse Codebases**
   - Successfully verified zero surviving build nodes, zero spurious build edges, zero identifier mismatches, and zero dangling edges across VSCode, Linux Kernel, PostgreSQL, Godot, Kubernetes, RustDesk, and AntennaPod.
