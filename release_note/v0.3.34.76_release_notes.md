### 2. 핵심 변경 사항 (정확히 3개 파일 한정)

이번 버전은 **탐지 알고리즘을 변경하지 않고** 기존 O2가 관측하는 정적 그래프 성질(`inDegree === 0 && outDegree > 0`)과 사용자 보고서 표현 사이의 의미 불일치만 제거했습니다.

1. **[FindingReportAdapter.ts](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/src/core/reporting/FindingReportAdapter.ts#L70-L85)** (`buildOnboardingSections()`):
   - O2 섹션 제목을 `O2 — Architecture Exploration Candidates (Static Dependency Roots)`로 변경.
   - Finding 리드를 `Top ${o2Count} static dependency roots observed as architecture exploration candidates (ranked by outgoing fan-out).`로 정정.
   - Non-Claim 고지 추가: `> Note: These static dependency roots are structural exploration candidates only and do not guarantee runtime execution entry points or an optimal code reading order.`
   - Diagnostic Trace 추적 키 `onboarding.entry_points`는 기존 호환성을 위해 보존.
2. **[ReportContract.ts](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/src/core/reporting/ReportContract.ts#L110-L114)** (`QUESTION_DICTIONARY["O2"].interpretationGuide`):
   - `Static dependency roots`의 그래프 정의(`inDegree === 0 && outDegree > 0`)와 아키텍처 탐색 후보 용도, 그리고 실제 런타임 실행 진입점이나 최적 코드 읽기 순서를 나타내지 않음을 해석 가이드에 명시.
3. **[EntryPointDetector.ts](file:///home/dogsinatas/TypeScript_project/antigravity-extension-vis/src/core/analysis/patterns/detectors/EntryPointDetector.ts#L100-L105)**:
   - `DEPENDENCY_ROOT` Evidence의 `description`을 `` `Observed static dependency root with outDegree=${topExec.fanOut || 0}, inDegree=${topExec.fanIn || 0}` ``로 정합화하여 동일 객체 내 `selectionBasis`와의 문구 충돌 해소.
   - 외부 소비자 호환성을 위해 `type: "EXECUTION_METRIC"`, 클래스명 `EntryPointDetector`, 탐지 알고리즘(`L11-L98`)은 무변경 보존.
