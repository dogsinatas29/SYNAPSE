# SYNAPSE Release Notes - v0.3.34

## 🚀 Architecture Analysis Engine Bootstrap

이번 릴리즈는 기존의 `VirtualDebugger`를 근본적으로 해체하고, 읽기 전용(Read-Only) 기반의 **Architecture Analysis Engine(AAE)** 으로 대체한 구조적 대규모 개편을 담고 있습니다. 이를 통해 향후 AST(Abstract Syntax Tree) 기반의 심층 아키텍처 분석을 위한 탄탄한 인프라가 마련되었습니다.

### 🌟 핵심 변경 사항 (Core Updates)
- **Architecture Analysis Engine 도입**: 
  - 상태를 직접 변조(Mutation)하던 기존 방식을 폐기하고, 원본(ProjectState)을 훼손하지 않는 플러그인 분석 파이프라인을 구축했습니다.
- **EvidenceBundle 규격 확립**: 
  - 모든 분석 결과(Necrosis, Fracture 등)가 단일 `Finding` 타입으로 통일되어 `EvidenceBundle`이라는 컨테이너로 전달됩니다.
- **Canvas Overlay 분리**: 
  - 분석 결과는 실제 노드/엣지 상태를 덮어쓰지 않고, 렌더링 레이어(Overlay)에만 독립적으로 반영됩니다. (VP-05 Mutation Test: 0건 패스)

### 🛠️ 구조 및 렌더링 개선 (Fixes & Improvements)
- **Architecture Analysis Report 기능 강화**: 단순 VSCode 에러 덤프를 넘어 아키텍처 관점(Necrosis, Fracture, Blast Radius)의 파급 효과를 구조화하여 출력하도록 리포트 엔진 개편.
- **WebGL 가속 모드 안정성 대폭 개선**: 
  - 3D 모드(Accel ON)에서 엣지가 증발하거나 렌더링되지 않던 치명적 결함 수정.
  - External 노드 컬러 파싱 오류(하얀색 네모 출력 버그) 정규식 수정으로 해결.
- **Canvas 2D 모드 버그 픽스**: 
  - 수동 노드 생성 시 엣지 증발 버그, 클러스터 갱신 누락, Continuous Connect Mode 풀림 버그 해결.
- 기타 UI 하드코딩 오류 동기화 및 에코 모드 수면 시간 조정(5분 상향).

### 🔮 향후 로드맵 (Next Steps)
- **v0.3.34.1**: 언어별(TS, Python, Rust, Java 등) 범용 AST Resolver 엔진 도입 및 정착.
- **v0.3.35**: 안정화된 AST 심볼 데이터를 기반으로, 기존 `LogicAnalyzer`의 기능들(Dependency Pressure, Cycle Detector 등)을 신규 Analysis 플러그인으로 대거 이관 예정.
