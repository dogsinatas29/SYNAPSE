# 🛡️ Release Note v0.3.3 - Edge Metadata Parity

## 🚀 개요
본 버전은 2D와 3D 가속 모드 간의 시각적 정보량 불일치를 해결하고, 엣지 렌더링 시 정보 밀도를 복구하는 데 집중했습니다. 특히 0.3.2에서 발생했던 "공중에 뜬 화살표" 현상을 수정하고 WebGL에서도 엣지 타입과 상태를 확인할 수 있도록 개선되었습니다.

## 🛠️ 주요 변경 사항

### 1. Edge Metadata Restoration (WebGL)
- **Edge Type Icons**: 엣지 중앙에 타입별 아이콘('D', 'F', 'E', 'C', 'A', 'B', 'L')을 표시하여 정보를 직관적으로 파악할 수 있게 함.
- **Validation Badges**: AI 분석 결과(`🤖`) 및 정적 분석 경고(`⚠️`, `❌`)를 WebGL에서도 렌더링.
- **Circular Plate**: 가독성을 위해 아이콘 뒤에 반투명 원형 배경(`●`)을 추가.
- **Status Badges**: `❓`(Pending), `❗️`(Confirmed), `❌`(Delete) 배지에 대한 렌더링 위치 및 정렬 최적화.

### 2. "Floating Arrow" Fix (2D Canvas)
- 2D 엔진에서 아이콘이 활성화될 때(`showIcons`) 배지 배경을 항상 렌더링하여, 화살표가 공중에 떠 있는 듯한 시각적 부조화를 해결.

### 3. Pipeline Stabilization
- **Mid-edge Arrow**: WebGL에서도 엣지 중앙에 화살표(`▶`)를 표시하여 흐름 방향성을 강화 (2D 모드와 동일한 파선 스타일 유지).
- **Backend Data Sync**: 자동 발견된 엣지에 대한 메타데이터(status, label)를 명시적으로 주입하여 초기 로딩 시 정보가 유실되지 않도록 함.
