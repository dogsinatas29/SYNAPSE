# Release Notes - v0.3.4 (Rendering Regression Fix)

## 🎯 주요 변경 사항

### 1. 2D 캔버스 잔상(Ghosting) 및 성능 저하 해결
- `renderEdge` 내부의 `ctx.save()`와 `ctx.restore()`의 불균형을 수정하여 **Context State Stack Leak**을 완벽히 차단했습니다.
- 3 FPS까지 떨어졌던 성능 병목 현상이 제거되어 부드러운 60 FPS 렌더링이 복구되었습니다.

### 2. WebGL 3D 모드 "Black Screen" 버그 수정
- `updateTextData` 함수 내에서 `nodeMap` 참조 오류(undefined)로 인해 렌더링 파이프라인이 중단되던 크리티컬 버그를 수정했습니다.
- 이제 가속 모드(`Accel: ON`)에서도 노드와 엣지가 정상적으로 출력됩니다.

### 3. 정보 밀도(Information Density) 복구
- 줌 레벨 임계치(`showIcons`)를 `1.2`에서 `0.3`으로 하향 조정했습니다.
- 이제 75% 줌 상태에서도 엣지 타입 아이콘('D', 'F', 'E', 'C' 등)과 분석 배지를 확인할 수 있습니다.

## 🛠️ 기술 세부 사항
- **File**: `ui/canvas-engine.js`, `ui/webgl-renderer.js`
- **Bug ID**: Canvas Context Stack Overflow, WebGL Reference Error
