# Release Notes - v0.3.5 (Final Rendering & Icon Parity)

## 🎯 주요 변경 사항

### 1. 2D 캔버스 잔상(Ghosting) 완전 해결
- `fillRect` 이전에 `clearRect(0, 0, width, height)`를 명시적으로 호출하여 줌/팬 시 이전 프레임의 픽셀이 남지 않도록 버퍼를 완전히 초기화했습니다.
- 투명도(`globalAlpha`) 및 합성 연산(`globalCompositeOperation`) 초기화와 연동되어 깨끗한 화면을 보장합니다.

### 2. 3D 모드(WebGL) 아이콘 파리티(Parity) 확보
- 3D 모드에서 단순 타입 아이콘('D', 'B' 등)이 아닌, 2D 모드와 동일하게 검증 상태 배지(`⚠️`, `❌`)가 우선적으로 표시되도록 아이콘 우선순위를 조정했습니다.
- 이제 어떤 모드에서도 가독성과 정보가 동일하게 유지됩니다.

### 3. 성능병목 해소 및 전반적 안정화
- 줌/팬 성능 개선 및 메타데이터 렌더링 최적화.

## 🛠️ 기술 세부 사항
- **File**: `ui/canvas-engine.js`, `ui/webgl-renderer.js`
- **Correction**: 3D Icon Prioritization (Validation Icons > Type Icons)
- **Correction**: Absolute Buffer Clear for 2D mode.
