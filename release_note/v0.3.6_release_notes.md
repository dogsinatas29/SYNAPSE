# Release Notes - v0.3.6 (Edge Alignment & Parity Polish)

## 🎯 주요 변경 사항

### 1. 2D 캔버스 곡선 엣지 화살표/배지 위치 최적화
- 기존에 직선 중앙점을 사용하여 곡선 엣지에서 화살표/배지가 공중에 떠 보이던(Floating) 현상을 수정했습니다.
- **Quadratic Bezier Midpoint** 공식을 적용하여, 화살표와 유효성 배지가 곡선의 실제 궤적 위에 정확히 안착하도록 정밀도를 높였습니다.

### 2. 2D 아이콘 가시성 개선
- 화살표 내부에 표시되는 타입 아이콘('D', 'F', 'B' 등)의 색상을 **고대비 밝은색(#f9f5d7)**으로 변경하여, 어두운 엣지 환경에서도 명확하게 보이도록 개선했습니다.

### 3. 3D 모드(WebGL) 비주얼 파리티 확보
- 3D 모드에서 비주얼이 너무 화려하거나 이질적이지 않도록, 아이콘 뒤의 원형 플레이트(`●`)를 제거하고 2D 모드와 유사한 미니멀한 삼각형 중심 디자인으로 변경했습니다.

### 4. 용어 정리: "아이콘" -> "타입 태그"
- 알파벳 문자('D'=Dependency, 'F'=Flow 등)는 시스템 설계상 엣지의 성격을 나타내는 **Type Tag**입니다. 유효성 배지(`⚠️`, `❌`)와 구분하여 각 모드에서 동일한 위치에 표시됩니다.
