# Release Notes - v0.3.7 (Absolute Parity & Documentation Update)

## 🎯 주요 변경 사항

### 1. 2D/3D 시각적 정보 표기법 완전 통일
- **Status Badge (⚠️, ❌)**: 2D와 동일하게 3D 모드에서도 엣지 중앙 상단(`midY - 25`)으로 위치를 격리하여, 다른 정보와 겹치지 않도록 수정했습니다. 이제 3D 모드에서도 노란색 삼각형(`⚠️`)이 명확하게 보입니다.
- **Type Tag (D, B, F, C)**: 엣지의 기술적 성격(의존성, DB 쿼리 등)을 나타내는 알파벳 기호를 화살표 정중앙에 배치했습니다.
- **2D 시인성 개선**: 2D 모드 화살표 내의 타입 태그가 어두워서 안 보이던 현상을 해결하기 위해 **고대비 화이트(#f9f5d7)**로 색상을 고정했습니다.

### 2. 아키텍처 기호 대사전 (README 업데이트)
- 사용자가 문의하신 `B`, `D` 등의 기호 의미를 README.md 및 README.ko.md에 공식 테이블로 추가했습니다.
    - `D`: Dependency (의존성/임포트)
    - `B`: Bidirectional / DB Query (양방향/데이터베이스)
    - `F`: Flow (조건부 실행 흐름)
    - `C`: Call (함수/API 호출)

### 3. 용어 및 가독성 정밀 튜닝
- "아이콘"이라는 모호한 용어 대신 **상태 배지(Status Badge)**와 **타입 태그(Type Tag)**로 용어를 분리하여 매뉴얼을 정비했습니다.
