# Release Notes - v0.3.8 (Edge Icon Modernization)

## 🎯 주요 변경 사항

### 1. 엣지 타입 태그의 직관적 아이콘화 (Modernization)
- 기존의 알파벳 표기('D', 'B', 'F', 'C')가 직관적이지 않다는 사용자 피드백을 반영하여, 전용 **이모지/심볼 아이콘**으로 전면 교체했습니다.
- 이제 2D와 3D 모드 모두에서 동일하고 명확한 상징적 의미를 전달합니다.

| 종류 | 기존 (0.3.7) | **변경 (0.3.8)** | 의미 |
| :--- | :---: | :---: | :--- |
| **Dependency** | `D` | **🔗** | 파일 임포트 / 의존성 연결 |
| **API Call** | `C` | **📡** | 외부 호출 / 서비스 통신 |
| **Data Flow** | `F` | **📊** | 데이터 전송 / 페이로드 흐름 |
| **DB Query** | `B` | **🛢️** | 데이터베이스 트랜잭션 / 쿼리 |
| **Origin** | `O` | **📍** | 프롬프트/로직 기원 |
| **Loop / Back**| `L` | **🔁** | 반복문 / 역방향 흐름 |

### 2. 2D/3D 시각적 일치성 (Visual Parity)
- 3D 모드의 WebGL 텍스트 아틀라스가 새로운 이모지 심볼을 정상적으로 렌더링하도록 엔진을 튜닝했습니다.
- 2D 모드에서도 화살표 내부에 동일한 아이콘이 고대비 화이트로 선명하게 표시됩니다.
