## 🔥 Critical Hotfix Release

This release fixes 3 critical bugs reported in v0.3.9 deployment:

### Fixes Included

#### 🔴 Canvas Height = 0 (Critical)
- **Problem**: 2D mode rendered nothing (nodes invisible, only edge visible)
- **Cause**: Canvas parent container's `clientHeight` computed to 0 during WebGL disable
- **Fix**: Added minimum height enforcement in `resizeCanvas()` + forced DOM reflow trigger
- **File**: `ui/canvas-engine.js`

#### 🔴 Emoji Font Not Supported (Critical)
- **Problem**: Edge icons showed as alphabet ('D', 'B', 'F') instead of emojis (🔗, 🛢️, 📡, 📊)
- **Cause**: `Inter` font doesn't support emoji rendering
- **Fix**: Added emoji detection + emoji font stack (Noto Color Emoji, Apple Color Emoji, Segoe UI Emoji)
- **File**: `ui/webgl-renderer.js`

#### 🟠 Eco-mode Sleep During Rendering (High)
- **Problem**: Performance degradation due to sleep entering during active rendering
- **Cause**: Eco-mode idle timer triggered while renderingloop was active
- **Fix**: Added rendering state check + `lastActivityTime` update during render
- **File**: `ui/canvas-engine.js`

### Testing Verified ✅
- [✓] 2D mode: All nodes visible and interactive
- [✓] 3D mode: Icons rendered as emojis, not alphabet
- [✓] Performance: FPS stable (30+ FPS at 100+ nodes)
- [✓] Mode switching: Smooth transition between 2D/3D
