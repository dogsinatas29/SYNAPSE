# Release Notes - v0.3.9 (Final Modernization & Rendering Recovery)

## 🎯 주요 변경 사항

### 1. 2D 모드 노드 증발 현상(Blank Screen) 완전 해결
- 0.3.4 이후 레거시 코드 정리 과정에서 누락되었던 2D 노드 출력 루프(`renderNodes2D`)를 복구했으며, 줌 레벨에 따라 노드가 뷰포트에서 조기에 잘리던 계산 오류를 수정했습니다. 이제 확대/축소 시에도 노드가 사라지지 않고 선명하게 보입니다.

### 2. 3D 모드 '타입 태그' 아이콘화 강제 적용 (v0.3.8)
- 3D 모드에서 더 이상 'D', 'B' 같은 알파벳 문자가 나오지 않으며, 현대화된 **이모지 심볼**(`🔗`, `🛢️` 등)로 2D와 완벽하게 동기화되었습니다.
- **🔗 (Dependency)**, **🛢️ (DB Query)**, **📊 (Data Flow)**, **📡 (API Call)**, **📍 (Origin)**, **🔁 (Loop)**

### 3. 정보 오프셋 통일 (Status vs Type)
- 상태 경고(`⚠️`)와 타입 기호가 겹치지 않도록 **상태는 위(-25px), 타입은 중앙(0px)**으로 렌더링 위치를 격리하여 정보 가시성을 극대화했습니다.

### 4. 시각적 일치 및 잔상 제거
- **Bezier Midpoint Math**: 곡선 엣지에서 화살표와 아이콘이 궤적을 벗어나 공중에 떠 보이던(Floating) 현상을 베지어 중간 좌표 보정값으로 완벽하게 제어했습니다.
- **Ghosting Suppression**: 프레임마다 context 상태를 초기화하여 잔상이 남지 않습니다.
